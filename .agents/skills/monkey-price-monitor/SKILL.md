# 实验猴价格监控系统

## 一、系统架构

```
┌──────────────────────────────────────────────────────────────┐
│                   猴价监控系统 v2.0                            │
├──────────┬───────────┬───────────────┬───────────────────────┤
│  数据采集  │  信号分析  │  预警输出       │   执行决策             │
│ (7个维度) │ (3层过滤)  │ (红黄绿+P0-P3) │  (持有/加/减/清仓)     │
└──────────┴───────────┴───────────────┴───────────────────────┘
      │
      ├── 周度执行（每周一）→ 猴价直接信号采集（30分钟）
      ├── 月度执行（每月1日）→ 全维度更新+仪表盘（45分钟）
      ├── 季度执行（季报后）  → 财报反推+券商研报（30分钟）
      └── 事件驱动（实时）   → 政策/集采/NAMs/进口（10分钟）
```

## 二、核心定价逻辑（监控的前提）

投资逻辑链：货币超发 → 稀缺实物资产被追逐 → 实验猴（6-7年繁育周期+大分子药70%刚需+药企价格极度不敏感）→ 猴价脉冲式暴涨 → 昭衍市值重定价。

退出条件：短缺消失或恐慌消失或替代技术落地。只要这三者都还在，故事就继续。

估值锚点：
- 上轮猴价7万时市值640亿（2021.9峰值），猴价20万时市值340亿（2023.1）
- 市值见顶比猴价见顶早15个月
- 这轮猴价从7万（2024底）涨起，中性预期峰值70-80万（3.5-4x），乐观100万+
- 中性市值峰值1500亿（¥200），乐观2000亿+（¥267+）

## 三、数据采集层（7个维度）

### 维度1：政府采购网招标/中标价（周度，最核心）

**这是猴价的"定盘价"，每周采集一次。**

#### 操作步骤

1. **搜索招标公告**（预示未来1-2个月的需求信号）
   - URL: `http://www.ccgp.gov.cn/cggg/zygg/gkzb/`
   - 搜索关键词：`食蟹猴` 或 `实验猴`
   - 记录：发布日期、采购单位、采购数量、预算金额、预算单价

2. **搜索中标公告**（确认实际成交价）
   - URL: `http://www.ccgp.gov.cn/cggg/zygg/zbgg/`
   - 搜索关键词：`食蟹猴` 或 `实验猴`
   - 记录：中标日期、采购单位、中标数量、中标金额、中标单价、供应商

3. **重点关注单位**（按优先级）
   - 中国食品药品检定研究院（中检院）— 行业定盘价
   - 中国科学院上海药物研究所 — 大批量采购风向标
   - 中国医学科学院 — 权威机构
   - 各大学实验动物中心 — 散单价格

4. **备用搜索渠道**
   - 各省政府采购网（广西、广东、四川、云南、江苏、北京）
   - 中国招标投标公共服务平台: `http://www.cebpubservice.com/`
   - 医药招标网: `http://www.yyzbw.com/`

#### 数据记录格式

```
日期 | 类型(招标/中标) | 采购单位 | 品种 | 数量(只) | 总价(万元) | 单价(万元/只) | 来源URL
```

### 维度2：猴场现货报价（月度，最真实）

**操作步骤：**
1. 以购猴者身份致电3家猴场询价：
   - 广西猴场（食蟹猴主产区）：搜索"广西 实验动物 食蟹猴 养殖"
   - 广东猴场（第二大产区）：搜索"广东 食蟹猴 繁殖"
   - 四川/云南猴场：搜索"四川/云南 实验猴 养殖"
2. 询问3个问题：
   - "3-5岁雌雄各半的食蟹猴现在什么价？"
   - "现在能接单吗？最早什么时候交付？"
   - "如果要现货加急，加多少钱？"
3. 备用：搜索最新新闻报道中的猴场报价
   - 搜索关键词：`食蟹猴 报价 现货 2026`
   - 搜索关键词：`实验猴 价格 最新`

**信号判断：**
- 🟢 "不接散客" + "今年订完了" + "排期4个月+" → 供给锁死
- 🟡 接单但排期长 → 供给紧张但未锁死
- 🔴 接受散客 + 现货可交付 → 供给缓解，减仓50%

### 维度3：昭衍新药季报公允价值（季度）

**操作步骤：**
1. 搜索"昭衍新药 季报"或"昭衍新药 业绩预告"
2. 提取"生物资产公允价值变动收益"
3. 反推猴价变动：公允价值变动收益 ÷ 猴数（估算5-8万只）≈ 季度猴价变动
4. 关注扣非净利润（主业是否盈利）

**信号判断：**
- 🟢 公允价值变动>5亿/季 → 猴价大幅上涨
- 🟡 公允价值变动1-5亿/季 → 猴价温和上涨
- 🔴 公允价值变动为负 → 猴价在跌，清仓

### 维度6：NAMs替代技术（事件驱动，长尾风险）

#### 全球监管现状（基线）

| 监管机构 | 里程碑 | 时间 | 实质进展 |
|---------|--------|------|---------|
| **美国FDA** | FDA Modernization Act 2.0 签署 | 2022.12 | 法律取消IND"必须动物试验"强制要求，**允许**NAMs替代 |
| **美国FDA** | NAMs验证框架草案 | 2023-2024 | 发布指南草案，但**未批准任何NAMs作为独立决策工具** |
| **美国FDA** | 实际审批 | 截至目前 | NAMs仅作**辅助证据**，**无一例新药仅凭NAMs数据获批IND** |
| **欧洲EMA** | NAMs框架发布 | 2021 | 比美国更积极，但**同样未批准NAMs独立替代动物试验用于IND/NDA** |
| **欧洲EMA** | 化妆品禁令 | 2022 | 化妆品全面禁动物试验，但**药品安全评估仍以动物为主** |
| **中国CDE** | "先锋计划"征求意见稿 | 2026.7 | 征求意见阶段，目标是建NAMs验证/标准化/认证体系 |

**关键判断：全球三大监管机构（FDA/EMA/CDE）均未让NAMs成为独立决策工具。法律层面"允许"≠审评实践"接受"。截至2026年，没有任何一款新药仅凭NAMs数据获批IND。**

#### NAMs落地的三个硬障碍

| 障碍 | 说明 | 现状 | 突破时间预估 |
|------|------|------|------------|
| **1. 系统毒性不可测** | 器官芯片是离体的，无血液循环/免疫系统/器官间交互。药物ADME（吸收/分布/代谢/排泄）和全身免疫原性必须有完整生物体 | **无技术突破** | 10年+，目前无路径 |
| **2. 验证周期极长** | NAMs需证明与动物试验/人体试验结果一致性，积累统计置信度后监管才认可 | FDA预估5-10年，CDE尚未启动 | 5-10年 |
| **3. 产业利益链** | CRO核心资产=猴+动物设施+GLP资质，NAMs替代=资产贬值，CRO有动力延缓 | 头部CRO对冲布局NAMs，非转型 | 利益博弈持续 |

#### 分阶段风险路线图

| 阶段 | 时间 | NAMs角色 | 对猴需求影响 | 对昭衍影响 |
|------|------|---------|-----------|---------|
| **阶段0：工具验证** | 2026-2028 | CDE征求意见→正式发布→试点 | 无影响 | 无影响 |
| **阶段1：效率工具** | 2028-2030 | 药物筛选阶段部分替代（肝毒性初筛） | 筛选阶段需求-15~20%，申报仍需猴 | 主业无影响，筛选业务分流 |
| **阶段2：辅助决策** | 2030-2033 | NAMs数据作为IND申报**辅助证据**（非独立） | 猴需求-20~30% | 猴价可能回调20-30%，但稀缺性仍在 |
| **阶段3：独立决策** | 2033+ | NAMs可独立用于部分终点的安全评价 | 猴需求-50%+ | **核心逻辑破坏**，需转型 |

**核心判断：3年内NAMs不构成实质威胁。系统毒性这一关目前无技术路径突破。猴价3年稀缺+创新药需求刚性的逻辑不变。**

## 四、信号分析层（3层过滤）

### 第一层：价格趋势（周度更新）

```
输入：本周政府采购网中标价 + 猴场现货报价
输出：价格趋势判断

IF 中标价 > 上周 AND 现货价 > 中标价 × 1.1:
  → 🟢 看涨（供给紧张，现货溢价扩大）
IF 中标价 ≈ 上周 (±5%) AND 现货价 ≈ 中标价:
  → 🟡 警惕（供给缓解信号）
IF 中标价 < 上周 × 0.9 OR 连续2次下降:
  → 🔴 看跌（猴价见顶信号）
```

### 第二层：供需缺口（月度更新）

```
IF 猴场"不接散客" AND 药企新增长协 AND 缺口扩大:
  → 🟢 供给锁死，恐慌持续
IF 猴场开始接散客 AND 排期缩短:
  → 🟡 供给开始缓解
IF 缺口缩小 OR 进口量大幅增加:
  → 🔴 供需反转信号
```

### 第三层：政策与远期风险（事件驱动）

```
IF 创新药政策友好 AND 集采温和 AND NAMs仍处于阶段0-1 AND 进口未放开:
  → 🟢 需求刚性 + 供给刚性 + 远期无威胁
IF 任一政策转向:
  → 🟡 需重新评估
IF ADC纳入集采 OR NAMs被接受为IND独立安全评价数据 OR 创新药政策转向压制:
  → 🔴 逻辑破坏
```

## 十、维度8：股价异常波动监控（事件驱动，实时）

**大涨可能是出货信号，大跌可能是洗盘信号。必须先分析资金流向和龙虎榜，再决定策略。**

### 监控触发条件

当以下任一情况发生时，立即启动股价分析：
- 昭衍新药单日涨跌幅>5%
- 连续2日累计涨跌幅>10%
- 换手率>10%
- 成交额>30亿
- 龙虎榜上榜
- 公司发布异常波动公告
- 大宗交易频发
- 大股东减持公告

### 数据采集清单

| 监控项 | 搜索关键词/数据源 | 频率 | 用途 |
|--------|-----------------|------|------|
| 日K线（开盘/收盘/最高/最低/振幅） | `昭衍新药 603127 行情` | 触发时 | 判断涨跌幅度 |

| 主力资金净流入/流出 | `昭衍新药 主力资金` | 触发时 | 主力在买还是在卖 |

| 沪股通持股变动 | `昭衍新药 沪股通 持股` | 周度 | 北向资金在加还是在减 |

### 5大信号识别规则

**信号1：天量出货** 🔴

| 指标 | 阈值 | 判断 |
|------|------|------|
| 换手率 | >15% | 天量换手 |
| 成交额 | >50亿 | 天量成交（昭衍历史天量66亿） |
| 主力净流出 | >3亿 | 主力大规模出货 |
| 龙虎榜净卖出 | >3亿 | 确认出货 |

→ 全部触发=确定性出货，减仓50%

**信号2：风险提示跌停** 🔴

| 指标 | 阈值 | 判断 |
|------|------|------|
| 连续涨停 | ≥2个涨停 | 拉高尾声 |
| 公司发异常波动公告 | "非理性炒作""随时下跌" | 公司在泼冷水 |
| 公告后次日跌停 | — | 出货完成确认 |

→ 减仓30%

**信号3：外资席位齐卖** 🔴

| 卖方席位 | 含义 | 历史出现频率 |
|---------|------|-----------|
| 沪股通专用 | 北向资金 | **每次必出现** |
| 机构专用 | 基金/社保/券商自营 | **每次必出现** |
| 高盛(中国)证券 | 外资QFII | **3月+7月都出现** |
| 瑞银证券 | 外资QFII | **3月+7月都出现** |
| 国泰海通总部 | 量化基金 | **每次必出现** |

→ 这5个席位是昭衍的"卖出常客"。如果连续2天上榜卖出>1亿，减仓30%

**信号4：大宗交易+减持** 🟡🔴

| 指标 | 阈值 | 判断 |
|------|------|------|
| 大宗交易频发 | 同一营业部连续多笔 | 大股东可能在减持 |
| 卖出营业部为华泰太仓/中信江苏 | 昭衍原始股东常用通道 | 🔴 减持信号 |
| 减持公告 | >总股本1% | 🔴 内部人不看好 |

→ 减持>3%=减仓20%；减持>5%=减仓50%

**信号5：缩量洗盘** 🟢

| 指标 | 阈值 | 判断 |
|------|------|------|
| 跌幅 | >5% | 大跌 |
| 成交额 | <20亿（相对天量缩量50%+） | 缩量下跌=洗盘 |
| 主力资金净流入 | >0 | 主力在低位接回 |
| 龙虎榜无机构卖出 | — | 机构没跑 |

→ 全部触发=洗盘吸筹，持有/加仓

**洗盘概率评估：20-25%。** 公司主动发风险提示（不希望股价涨太快）+大股东已减持完毕（不需要再洗盘拉高）=不是洗盘特征。但猴价仍在涨+订单+111%=基本面支撑还在，不是清仓式出货。更准确的描述是**"出货后的震荡筑底"**——大股东和机构在高位出了货，股价在40-43区间寻找新平衡。

### 出货vs洗盘判断框架（6维度信号矩阵）

| 信号维度 | 洗盘特征 | 出货特征 | 判断方法 |
|---------|---------|---------|---------|
| **公司态度** | 不发声/维稳 | 主动发风险提示 | 查公司公告，"非理性炒作""随时下跌"=出货 |
| **大股东行为** | 不减持/增持 | 大规模减持 | 查大宗交易+减持公告，>3%=出货 |
| **主力资金** | 下跌缩量+主力回流 | 下跌放量+主力流出 | 查资金流向，连续2日主力流出>1亿=出货 |
| **换手率** | 缩量（<5%） | 放量（>10%） | 下跌时换手>10%=出货，<5%=洗盘 |
| **龙虎榜** | 无机构卖出 | 机构+外资净卖 | 机构/沪股通/高盛/瑞银上榜卖出=出货 |
| **猴价趋势** | 不变/向好 | 恶化 | 猴价涨+股价跌=市场分歧（非出货非洗盘）；猴价跌+股价跌=周期反转 |

**综合判断规则：**
- ≥4个维度命中出货特征 → **确定性出货，减仓50%+**
- 2-3个维度命中出货 → **混合型，减仓20-30%**
- ≤1个维度命中出货 + 猴价不变/向好 → **洗盘概率大，持有/加仓**
