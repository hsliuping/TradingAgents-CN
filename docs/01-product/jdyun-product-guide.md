# TradingAgents-CN 京东云版 - 产品介绍

> 版本：v3.0 | 更新：2026-08-18

## 这是什么

TradingAgents-CN 是一款 AI 驱动的 A 股研究平台。多个 AI 智能体协同工作，帮你完成从选股、研究、跟踪到复盘的全流程。

**京东云版特点**：开箱即用，无需配置。

| 对比项 | 标准版 | 京东云版 |
|--------|--------|----------|
| 部署 | 自行安装 | 京东云托管，登录即用 |
| 部署形态 | 本机/自有服务器单实例 | 独立容器 + 独立数据库，账号间数据隔离 |
| 模型 | 手动配置 API Key | 京东云预置（GLM-5 / GLM-5.1 / GLM-5.2 / DeepSeek-V4-Flash） |
| 数据源 | 多选 | 仅 Tushare（已预置） |
| License | 需激活 | 全功能开放 |

### 独立部署 · 数据隔离

京东云版采用独立容器部署，每个账号拥有专属的运行环境和独立数据库，不与其他用户共用：

- **数据隔离**：你的研究记录、关注列表、模拟持仓等数据独立存储，不与他人混用
- **服务稳定**：专属资源，不受其他用户使用高峰影响
- **隐私安全**：相当于专属环境，而非共享池

> 仅支持 A 股和 ETF。港股、美股已下线。

## 核心能力

### AI 深度研究

输入一只股票代码，多个 AI 分析师各自负责一个维度（技术面、基本面、新闻、情绪、大盘、板块），协同输出一份结构化研究报告。

- **5 级深度**：1 级快速概览（2-5 分钟）到 5 级全面分析（8-16 分钟）
- **多情景研究**：高弹性 / 防御 / 基准三种视角并列
- **辩论机制**：研究员给出结论，辩论角色提出反驳，风险评估检查风险
- **决策标签**：乐观 / 审慎 / 中性（研究倾向，不是买卖指令）

### AI 智能助手

自然语言对话，20+ 工具自动调度，不用找菜单：

| 能力 | 示例 |
|------|------|
| 联网搜索 | "帮我搜一下最近的半导体政策" |
| 板块数据 | "新能源板块今天的资金流向怎么样" |
| 触发分析 | "帮我分析一下贵州茅台" |
| 查报告 | "我上次分析过的股票有哪些" |
| 价格提醒 | "帮贵州茅台设一个 1800 元的价格下限提醒" |

### 批量筛选

- **股票筛选**：条件组合或自然语言，从全市场找标的
- **批量分析**：一次分析多只股票（京东云版逐只执行，建议 ≤5 只）
- **关注列表**：分组管理，批量分析，一键发起研究

### 交易闭环

| 环节 | 功能 | 说明 |
|------|------|------|
| 练手 | 模拟交易 | 虚拟资金买卖，验证策略 |
| 跟踪 | 持仓研究 | 组合风险、行业集中度、相关性分析 |
| 复盘 | 操作复盘 | AI 从时机/仓位/情绪/归因四个维度自动分析 |
| 纪律 | 交易计划 | 入场条件、收益关注规则、风险关注规则 |
| 沉淀 | 案例库 | 交易经验标签化管理 |

### 自动化跟踪

- **定时分析**：设置每日/每周自动跑分析任务
- **渠道推送**：飞书 / 钉钉 / 邮件接收分析结果
- **价格提醒**：收益关注价位 / 价格下限触发通知

### AI 记忆

3 层记忆，越用越懂你：

1. **股票对象记忆**：每次分析的关键结论，按股票归档
2. **偏好与纪律记忆**：投资风格、风险偏好、交易纪律
3. **智能助手事实记忆**：联网搜索提取的事实，跨会话引用

## 5 分钟上手

### 开通与登录

在京东云控制台开通服务，京东云会提供登录账号和密码。打开浏览器访问系统地址，用账号密码登录即可。


### 第一步：分析一只股票（约 3 分钟）

1. 点左侧菜单 **「单股研究」**
2. 输入股票代码，比如 `600519`（贵州茅台）
3. 分析深度选 **「3级-标准分析」**（推荐新手）
4. 分析师保持默认（市场分析师 + 基本面分析师）
5. 点 **「开始分析」**

等 4-8 分钟，在 **「任务中心」** 看进度，完成后点进去看报告。报告里每个 Tab 是一个分析维度（技术面、基本面、风险、估值等），最后有一个**决策标签**：乐观 / 审慎 / 中性。

> 决策标签只是研究倾向，**不是买卖指令**。

### 第二步：用 AI 助手问问题（约 1 分钟）

点左侧菜单 **「智能助手」**，直接打字问：

| 你想知道 | 这样问 |
|---------|--------|
| 某只股票怎么样 | "帮我分析一下 000001" |
| 某个板块表现 | "新能源板块最近怎么样" |
| 搜最新新闻 | "帮我搜一下最近的半导体政策" |
| 设价格提醒 | "帮贵州茅台设一个 1800 元的价格下限提醒" |
| 查历史报告 | "我上次分析过的股票有哪些" |

AI 助手会自动调用工具，不用你找菜单。

### 第三步：模拟交易练手（约 2 分钟）

1. 点左侧菜单 **「模拟交易」**
2. 首次进入会提示创建账户，默认 100 万虚拟资金
3. 点 **「买入」**，输入股票代码、价格、数量，确认
4. 持仓一段时间后点 **「卖出」**
5. 点左侧 **「操作复盘」**，AI 自动从时机、仓位、情绪、归因四个角度帮你复盘这笔交易

模拟交易是虚拟资金，**不能提现**，纯粹练手。

### 接下来怎么用

推荐新手路径：先做 1 次单股研究（3级-标准分析）熟悉报告结构，再逐步尝试批量分析、股票筛选、定时分析等功能。更多功能见下文「日常使用节奏」和「高级扩展」。
