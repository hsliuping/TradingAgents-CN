# TradingAgentsCN V3.0 直播前功能检查清单

> 用途：明晚直播前逐项检查，优先发现会影响演示体验的问题。  
> 建议检查时间：直播前一天晚上先跑一遍，直播当天开播前再快速过一遍核心链路。

---

## 一、直播前基础环境检查

### 1. 服务状态

- [ ] 前端可以正常打开
- [ ] 后端可以正常启动
- [ ] MongoDB 正常连接
- [ ] Redis 正常连接
- [ ] 核心接口无 500 错误
- [ ] WebSocket / SSE 正常

### 2. 账号与权限

- [ ] 直播演示账号可正常登录
- [ ] 演示账号权限完整
- [ ] 登录后不会自动掉线
- [ ] 页面刷新后认证状态正常
- [ ] 演示账号已有可展示的数据

### 3. 数据准备

- [ ] 已准备好 3 到 5 个适合演示的股票代码
- [ ] 已准备好至少 1 组自然语言选股示例
- [ ] 已准备好至少 1 份分析报告
- [ ] 已准备好至少 1 个交易计划
- [ ] 已准备好股票关注列表分组与标签示例
- [ ] 已准备好持仓或复盘示例数据

### 4. 因子回归校验

- [ ] 直播前执行一次 `python scripts/run_factor_validations.py`
- [ ] 确认基本面与技术因子校验都返回通过
- [ ] 若技术因子失败，先重跑 `python scripts/materialize_technical_indicators.py` 再复验

### 5. 页面与展示效果

- [ ] 默认进入页面内容正常
- [ ] 没有明显报错弹窗
- [ ] 没有演示时会暴露的测试数据或脏数据
- [ ] 中文文案通顺，无明显占位词
- [ ] 表格、图表、弹窗显示正常
- [ ] 深色/浅色主题不会影响演示

---

## 二、统一 AI 助手入口检查

> 直播重点之一：让观众感知“统一入口”而不是“功能分散”。

### 1. 助手入口可用性

- [ ] 统一 AI 助手入口位置清晰
- [ ] 打开助手入口速度正常
- [ ] 输入框、发送按钮、会话区域正常
- [ ] 对话历史可正常显示
- [ ] 清空/新建会话行为正常

### 2. 基础意图路由

- [ ] 输入“分析某只股票”能正确进入分析链路
- [ ] 输入“查看报告”能正确返回相关结果
- [ ] 输入“查看股票关注列表”能正确命中对应能力
- [ ] 输入“查看持仓”能正确命中对应能力
- [ ] 输入模糊问题时不会明显答非所问

### 3. 异常与兜底

- [ ] 输入无效问题时有合理提示
- [ ] 无数据时有可接受提示
- [ ] 接口超时时不会直接卡死
- [ ] 后端异常时有体面错误提示

### 4. 分析演示建议动作

- [ ] 预先准备 3 条最稳的演示问题
- [ ] 避免现场临时输入过长复杂问题
- [ ] 先演示一个短请求，再演示一个复杂请求

## 十二、建议的直播演示顺序

建议按下面顺序走，成功率更高：

1. 统一 AI 助手入口
2. 自然语言选股
3. 单股分析 / Agent 自主规划分析
4. 交易计划能力补充展示
5. Skill 能力扩展
6. 报告导出 / 股票关注列表 / 持仓 / 复盘补充展示

这样做的好处是：

- 前半段先建立“V3.0 到底变了什么”的认知
- 中段展示真正有技术含量的能力
- 后段再补充完整工作流和落地场景
