## 背景说明

我们即将推出**云端部署服务**，与当前本地版的核心区别：

| 对比项 | 当前版本（本地部署） | 云端服务 |
|--------|----------|----------|
| 大模型 | 用户自行购买 API Key（Qwen / DeepSeek 等） | 云端内置，无需单独购买 |
| 数据源 | 用户自行购买 Tushare Token | 云端内置，无需单独购买 |
| 部署方式 | 本地安装部署 | 云端部署，浏览器即用 |
| 配置复杂度 | 需配置 Provider、API Key、数据源 | 零配置，开箱即用 |
| 功能范围 | 完整功能 | 完整功能（与本地版一致） |

**简单来说**：云端服务帮您省去了自行购买大模型 API 和数据源的费用和配置麻烦，打开浏览器即可使用全部功能。

### 收费说明

**所有功能免费开放，只收 Token 费用和数据服务费。**

| 项目 | 是否收费 | 说明 |
|------|----------|------|
| 系统所有功能 | **免费** | 单股研究、批量分析、持仓研究、交易复盘、智能助手等全部功能不收费 |
| 大模型 Token 费用 | **按成本收取** | 您的每次 AI 分析实际消耗多少 Token，就付多少，不加价 |
| 数据服务费 | **包含在套餐内** | 行情数据、财务数据等数据源费用已包含，无需额外购买 |

> 收费透明：账单分项列明各项服务费，明明白白消费。系统所有分析结果定位为研究辅助参考，不输出买卖建议、目标价或收益承诺。

与常见的 SaaS 产品的根本区别：

| 对比项 | 传统 SaaS | 我们的云端服务 |
|--------|-----------|---------------|
| 部署方式 | 多租户共用一套系统，数据混存 | 独立实例、独立数据库、访问隔离 |
| 数据安全 | 数据与其他用户共存，存在交叉风险 | 独立数据库，您的数据仅限您本人访问 |
| 收费模式 | 按功能分层收费（基础版 / 高级版 / 企业版） | 功能全免费，只收 Token + 数据源成本 |
