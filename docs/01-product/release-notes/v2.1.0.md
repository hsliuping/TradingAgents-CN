# TradingAgentsCN Pro v2.1.0 上线通知

发布日期：2026-05-02  
版本号：v2.1.0

这次 v2.1.0，我们重点做的不是“多加几个按钮”，而是把产品整体往更稳、更清晰、更合规的方向推进了一步。

如果用一句话来概括这个版本：

这是一次围绕“研究辅助”定位做的产品升级。我们重新收口了报告表达、提示词模板、界面文案和高级学员权限边界，同时补充了新的模型接入能力、部分工具能力，并修复了一批影响日常使用体验的问题。

## 一、这次版本最重要的变化：产品表达更合规了

v2.1.0 最大的变化，是我们围绕“研究辅助，而不是直接投资建议”做了一轮系统级调整。

这不是简单加一句免责声明，而是把用户真正会看到、会用到的内容一起做了升级：

1. 核心提示词模板做了统一升级。
我们重写和优化了研究经理、多空研究员、风险分析师、研究简报、持仓研究、操作复盘等多条默认提示词链路，让整体输出风格更一致。

2. 报告输出风格发生了明确变化。
新版报告会更强调研究依据、逻辑链条、风险因素和执行前提，不再延续旧版中容易被理解为直接交易建议的价格区间、明确买卖点位、目标价等表达方式。

3. 界面表达同步收口。
包括页面提示、按钮命名、课程内容、检查/评估文案、结果说明等，都尽量统一为“研究辅助”口径，减少用户在不同页面看到不同表达方式的割裂感。

4. 课程内容也同步调整。
高级课程的内容表达、术语命名和案例说明，都进一步向研究工作流口径对齐。

这部分调整的目的很明确：
让产品输出更稳定、更克制，也更符合长期对外使用和合规审核的要求。

## 二、提示词体系升级后，报告风格已经变了

这次版本里，提示词体系整体升级是非常关键的一项变化。

对于多数直接使用系统默认模板的用户来说，这意味着：

1. 研究报告会更偏“研究结论 + 风险提示 + 依据说明”。
2. 系统会更少给出看起来像直接交易指令的表达。
3. 整体语言风格会比旧版更统一、更稳。

对旧版用户需要特别提醒的是：

如果你之前使用过自定义提示词模板，或者你本身更偏好旧版那种更直接、更加接近交易建议的报告风格，那么升级到 v2.1.0 时建议谨慎一些，先评估自己的使用习惯，再决定是否立即升级。

升级后，建议尽快复核一次你的自定义提示词模板，重点检查这些旧表达是否还保留在模板里：

1. 价格区间
2. 目标价
3. 明确买卖点位
4. 明确仓位指令
5. 机械触发式买卖结论

如果仍沿用旧版自定义提示词，最终输出可能和新版默认风格不一致，也可能重新带回旧的表达风险。

如果你更喜欢旧版报告风格，可以选择暂时不升级；如果已经升级到新版，也可以通过自行调整自定义提示词，把输出风格重新改回更接近你习惯的表达方式。

## 三、高级学员权限边界做了重新整理

这次我们对“哪些功能开放给所有用户，哪些功能保留给高级学员”做了一轮更清晰的整理。

### 1）从原来的高级学员范围中开放出来的功能

这次版本里，有几类原本偏高级的能力，已经开放为登录后即可使用的基础研究能力：

1. 持仓研究
2. 操作复盘
3. 交易计划的基础能力：包括创建、查看、编辑和管理

也就是说，用户现在可以更自然地把“研究、复盘、制定自己的交易计划”作为基础使用路径，而不是一上来就被高级学员门槛挡住。

### 2）继续保留或明确纳入高级学员功能的模块

这次版本里，我们也把真正适合做高级学员分层的能力边界写得更清楚了。当前保留在高级学员功能中的，主要包括：

1. 高级课程内容
2. 高级课程样例、课程下载及相关受权访问内容
3. 批量分析
4. 分析流
5. 工具配置
6. Agent 配置
7. 提示词模板管理和模板调试
8. 报告下载与批量导出
9. 邮件通知
10. 定时分析分组
11. 定时分析配置
12. 交易计划一致性检查

这次调整还有一个重要变化：
我们不只是改了前端展示，而是把后端权限也一起补齐了。用户现在看到的“高级”标识、页面拦截、接口权限会比以前更一致。

## 四、新增和补强了一部分工具能力

除了权限和表达收口，这次版本还补了几类实际可用的工具能力，让研究链路更完整。

这轮新增或增强的重点包括：

1. 新增基本面财报工具，并接入到基本面研究链路。
2. 增加本地数据源支持，方便部分用户接入本地数据能力。
3. 补强大盘分析相关工具集，让宏观和市场环境判断更完整。
4. 优化工具绑定和提示词配合，减少“有能力但没真正用起来”的情况。

从用户视角看，这部分变化意味着：
研究过程中可调用的数据和工具更丰富了，报告背后的分析依据也更扎实了。

## 五、增加 AIHubMix，模型接入能力更灵活了

v2.1.0 新增了 AIHubMix 聚合模型平台支持。

这项升级带来的直接变化是：

1. 模型接入来源更丰富。
2. 多厂商模型切换更灵活。
3. 模型配置和选择体验更清晰。
4. 多模型并存时，兼容性和稳定性比之前更好。

如果你本身就会根据不同任务切换模型，这次升级会更有感知。

## 六、还修了一批影响体验的 Bug

除了上面的产品调整，这次版本还顺手解决了一批真实影响使用体验的问题，主要包括：

1. 修复多厂商模型路由和分析链路兼容问题。
2. 修复异步执行稳定性问题，减少 cross-loop 类错误。
3. 补强市场分析输出，增加最近 5 个交易日成交量明细，并让日期说明更清楚。
4. 修复高级课程图片显示和内容加载相关问题。
5. 修复交易计划创建过程中的卡顿问题。
6. 修复部分页面重复标题、内容重复和展示噪音问题。
7. 优化安装基线、默认配置和部分初始化体验。

## 七、如果你准备升级，建议重点关注这几件事

1. 如果你使用的是旧版自定义提示词，请先复核模板内容。
2. 如果你经常导出报告，请注意下载与导出已经明确纳入高级学员功能。
3. 如果你使用交易计划功能，请注意基础管理能力已开放，但“交易计划一致性检查”仍属于高级学员功能。
4. 如果你是高级学员用户，升级后建议顺手验证一下高级课程访问、批量分析、分析流和模板功能是否符合你的预期。

## 八、总结

这次 v2.1.0，不只是“增加了一些能力”，更重要的是把产品整体做了一轮整理。

你可以把它理解成五件事：

1. 产品更合规了。
2. 提示词升级后，报告风格更统一了。
3. 高级学员权限边界更清楚了。
4. 新增了部分工具，也接入了 AIHubMix。
5. 一批影响体验的 Bug 被修掉了。

对于普通用户来说，这个版本最大的价值，是系统会更像一个研究辅助工具，而不是一个会直接替你下判断的工具。对于老用户来说，最需要留意的，是报告风格变化和自定义提示词的兼容问题。
