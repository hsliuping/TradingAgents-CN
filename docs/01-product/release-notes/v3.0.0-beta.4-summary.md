## 三、合规边界（本轮确认）

| 项 | 规则 | 来源 |
|----|------|------|
| 决策标签 | 乐观 / 审慎 / 中性，不提供买卖建议 | `research_manager_v2.py` / `trader_v2.py` |
| 收益预期 | 不提供收益率、RAROC、目标价 | 同上 |
| 术语 | "止盈/止损" -> "收益关注/价格下限" | 工具注册名 `set_stop_gain_alert` / `set_stop_loss_alert` |
| 复盘 | AI 自动分析，非手动填写表单 | `trade_review_workflow_v2.py` |
| 分析深度 | 所有 5 级都跑辩论与风险分析，仅轮数不同（1-3级=1轮，4级=2轮，5级=3轮） | 代码核实 |
