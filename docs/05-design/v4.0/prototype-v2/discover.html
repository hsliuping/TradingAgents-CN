候选发现

这个模块不是对象档案，也不是任务执行页。它主要做的是：把规则命中、事件异动、主题联动、方法筛选产生的噪音线索压缩成一个“今天值得花时间看”的候选池，再把候选分流到加入研究、发起初筛、加入监控或暂缓观察。
