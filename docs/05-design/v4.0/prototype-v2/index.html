设计原则（从前序讨论沉淀）

  • 事实 / 观点 / 规则 严格分层，每条信息都带 来源 + 时间 三元组
  • AI 介入按阶段分档：跟踪深 / 计划中 / 执行浅 / 复盘深
  • 智能助手是全局抽屉，不是一级模块；产生草稿、不直接修改资产
  • A 股语义色：红涨 / 灰跌 · 不使用绿色
  • 密度克制：24px gutter + 32px 区块间距 + 16-20px 卡内 padding
