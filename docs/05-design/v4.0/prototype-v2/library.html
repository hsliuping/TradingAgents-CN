研究库

研究库存的是已经确认过、以后还能复用的知识资产，比如观点、规则、提醒和研究卡片。它不等于原始资料库，也不等于任务列表；任务的价值只有在你确认并沉淀后，才会真正进入研究库。

这个模块主要做什么

研究库负责把一次次任务、复盘、手动记录里真正值得留下来的内容，变成可检索、可复用、可跨对象调用的资产。你以后发起新任务、做横向对比、回看旧判断，本质上都是在调研究库，而不是重新从零开始想一遍。
