## 1. 三层架构定位：三个版本目录的真实关系

`05-design/` 下的 v3.0、v4.0、v5.0 不是三代产品，而是**同一个产品的三个层次**：

```
┌─────────────────────────────────────────────────────┐
│ v5.0 = 认知内核层 —— "怎么判断、怎么纠错"               │
│   固定决策顺序（能力圈→结构→风险→价格）                  │
│   指标分层调用（价格指标禁入结构/风险判断）                │
│   结论降级（条件不满足只输出"继续观察/信息不足"）          │
│   错误库 + 复盘写回（认知资产沉淀）                      │
│   → 落地方式：内嵌于产品，不另起系统（修订 R1）           │
├─────────────────────────────────────────────────────┤
│ v3.0 = 引擎层 —— "用什么能力跑"（已基本建成）            │
│   多智能体分析引擎 / Skill 体系 / Memory / 智能助手      │
│   Agent 工坊 / 执行轨迹 / 回测 / 数据资产底座           │
│   ← 技术升级线（推理深度/结构化输出/证据池）作用于此层     │
├─────────────────────────────────────────────────────┤
│ v4.0 = 产品层 —— "交付什么价值"                        │
│   长期投研陪伴工作台（跟踪→计划→执行→复盘→沉淀闭环）      │
│   受控 Skill 增长 / 用户私有研究资产 / 边界与主权        │
│   → 载体：股票详情页（五环旅程宿主，四环已整合）          │
└─────────────────────────────────────────────────────┘
```

**组合逻辑**：v4.0 给身体（工作台形态），v5.0 给灵魂（纪律内核），v3.0 引擎层持续升级提供动力。市场判断依据：通用“AI 看股票”正被大厂免费化 + 监管收紧双杀，产品价值必须迁移到模型不能商品化的东西上——用户私有资产的复利与系统化的纠错能力。

**配套项目（三层之外的拼图）**：产品完整版图除本仓库外还有配套项目（见 `bridgewater-pat-comparison-and-execution-plan.md` 的三项目拼图）：

- **CRKB（公司研究知识底座）**：TA-CN 的“投研对象 + 事件”知识后端，对应 v4.0 "6+1 信息分类”中的投研对象知识线（即 `cognee-knowledge-memory-concept.md` §5.2“企业演化知识图谱”的具体实现）。基于 Cognee + MinerU，提供公司主档（Tushare 同步）/ 结构化事实层 / 知识图谱 / 证据回溯 / 跨期与同行对比，经 REST + MCP 接入 TA-CN，不带 UI、不自管用户。**Docker 部署已落地，API 契约 v1.0 已冻结（2026-06）**，产品文档 v0.3。TA-CN 侧的定位是消费方：不自建公司知识图谱层。
- **方法论提取**（规划中）：对应本映射文档修订 R2 的 methodology skill 线。

## 5. 统一路线图（四泳道）

> 取代此前散落的多张清单（本文 §3.3 技术升级线、v3-to-v4 triage P0-P2、PM 评估报告三期、桥水 Pat P0-P4）。

```
泳道一  引擎升级（近期 · 支撑收入）
  深度档位打通 → 裁判结构化输出 → 分析师并行化 → Prompt Caching
  → Evidence Pack → 辩论重构 → 多模态 K 线（含框架升级）

泳道二  产品闭环（中期 · 留存）
  计划环入详情页 → 沉淀动作（四库写入）→ 我的研究库
  → CRKB 接入（公司库/证据链，REST+MCP）→ 事实-观点-规则分层

泳道三  认知内核（中长期 · 壁垒）
  错误库第一期（20-50 条专家规则 + 复盘写回）→ methodology skill 3-5 套
  → 结论降级 → 选股/持仓流程接入错误库（风险雷达）

泳道四  进化机制（远期 · 自进化）
  市场裁判管道（T+1/7/30 打分）→ 记忆进化（验证教训入四库）
  → Prompt/技能进化 + 回归评测闸门 → 流程进化（记分卡反哺路由）

依赖关系：泳道一的结构化输出 = 泳道四裁判的眼睛；泳道二的沉淀动作 = 泳道三错误库的入口；
         泳道三的 methodology skill = 泳道一辩论重构的简报方扩展；
         CRKB 的结构化事实与证据回溯 = 事实-观点-规则分层与证据链溯源的数据源。
```
