## 四、MCP 生态集成

### 现状确认

- `core/mcp/server.py` 已是 **MCP Server 提供端**（FastMCP）：6 个工具（深度分析 / 报告查询 / 助手对话 / 工作流 / 智能选股 / 市场概览），支持 SSE(:8001) / Streamable HTTP / stdio 三种传输，可选 API Key 认证
- `python -m core.mcp` 可独立启动；`core/mcp/` 保留在社区版（不在剔除清单）

### 三平台接入路径（已核实）

| 平台 | 方式 | 备注 |
|---|---|---|
| TraeWork | 设置 → 添加自定义 MCP Server | 填 SSE URL 即接 |
| 钉钉 DEAP | 智能体 → MCP → 自定义 MCP | StreamableHttp URL，自动检测工具列表 |
| 企业微信 | 智能机器人（长连接 / OpenClaw） | 注意 3 分钟回复限制，analyze_stock 需 wait=False 异步 |
| 腾讯 MCP 广场 | 官方确认第三方暂不开放上架 | 不可行，不投入 |

### 关键决策

- **自部署模式，不做托管**：合规（Tushare/AKShare 公开接口 + 用户自带 token）+ 成本（不扛 LLM API 与 SLA），与 CloudBase 的 GitHub + 一键命令分发模式对齐
- **TRAE 插件市场上架暂缓**：金融投资类已有 9 个插件（iFinD/通达信/东方财富为数据层，财报解读/财务建模为单任务层，均不构成竞争；全链路层有正面竞品但差异化在研究会议 + 数字溯源 + 开源自部署）。策略：先完成 Seed Demo（TRAE 与火山同属字节，活动对接是上架渠道最短路径），带热度再谈

## 六、风险提示

- **企微接入**：3 分钟回复限制，长任务必须异步（wait=False + 任务 ID 轮询）
- **MCP 公网部署**：默认 0.0.0.0:8001 无认证，生产必须域名 + TLS + MCP_AUTH_ENABLED=true
- **插件上架转化**：自部署模式安装门槛高于托管类插件，初期接受"高门槛、高留存"，目标用户即技术型投资者
