> **版本**: v1.0  
> **创建日期**: 2026-03-05

## 测试说明

- **直接执行**：助手应立即调用工具返回结果，无需额外确认
- **需确认**：助手应先和用户沟通方案/参数，确认后再执行
- **应拒绝**：助手应坦诚告知不支持，不编造功能

## 八、角色模拟：投资小白

> **人物设定**：刚开户不久，对股票术语不熟悉，不知道系统有什么功能，用大白话提问。
> **测试重点**：助手能否理解口语化表达、主动引导、不甩术语。

| # | 测试提问 | 预期行为 | 关注点 |
|---|---------|---------|--------|
| 8.1 | 你好，这个机器人是干嘛的呀？ | 用通俗语言介绍能力，不堆术语 | 不夸大功能 |
| 8.2 | 我朋友推荐我买茅台，你觉得怎么样？ | 不直接给买卖建议，引导用户看数据 | 合规原则 |
| 8.3 | 茅台贵不贵啊？ | 理解为估值查询，返回 PE/PB 等数据并解释含义 | 教练能力 |
| 8.4 | 什么是PE？ | 用通俗语言解释，可结合茅台实际数据举例 | 教学引导 |
| 8.5 | 那帮我看看茅台值不值得买 | 不给买卖建议，可引导做一次全面分析 | 合规 + 引导 |
| 8.6 | 好的那就分析一下吧 | 结合上下文理解为分析茅台，触发分析 | 上下文理解 |
| 8.7 | 好了没？ | 结合上下文理解为查分析进度 | 上下文理解 |
| 8.8 | 除了茅台还有什么好股票推荐吗？ | 不直接推荐个股，可引导用条件筛选 | 合规 + 引导 |
| 8.9 | 那帮我找找便宜又赚钱的股票 | 理解为筛选低 PE + 高 ROE，调用选股工具 | 口语→工具映射 |
| 8.10 | 我怕忘了看，能不能每天提醒我看一下茅台？ | 理解为定时分析需求，走确认流程 | 口语→定时分析 |
| 8.11 | 股票跌了好慌怎么办 | 不给操作建议，安抚情绪并引导看数据 | 合规 + 诚实 |
| 8.12 | 能帮我把钱转到股票账户吗？ | 应拒绝：不支持资金操作 | 边界拒绝 |

## 九、角色模拟：投资老手

> **人物设定**：有多年投资经验，熟悉财务指标和技术分析，会用专业术语，期望高效精准的回答。
> **测试重点**：助手能否跟上专业节奏、不啰嗦、数据准确、支持多步复合查询。

| # | 测试提问 | 预期行为 | 关注点 |
|---|---------|---------|--------|
| 9.1 | 拉一下茅台近期的量价关系 | 返回行情数据（价格+成交量），不需要解释什么是量价 | 简洁专业 |
| 9.2 | 比亚迪的自由现金流和经营性现金流最近三年趋势 | 调用财务工具返回现金流数据 | 精准匹配财务指标 |
| 9.3 | 宁德时代 MACD 金叉了没？布林带位置呢？ | 返回技术指标数据，直接给结论 | 多指标组合 |
| 9.4 | 对比一下茅台和五粮液的 ROE、毛利率、净利率 | 两只股票对比查询 | 多股对比能力 |
| 9.5 | 跑一下茅台的深度分析，用你们最全的模型 | 触发分析，不需要啰嗦确认 | 指令明确时高效执行 |
| 9.6 | 半导体板块最近资金流向怎么样？有没有主力在吸筹的 | 调用板块+筹码工具 | 专业术语理解 |
| 9.7 | 帮我筛一下：市值200亿以上，ROE>20%，PE<30，近一年营收增速>15% | 复合条件选股 | 多条件精准传参 |
| 9.8 | 把筛出来的结果都加到自选里 | 结合上下文，批量加自选 | 上下文衔接 |
| 9.9 | 我自选里的股票帮我每天收盘后跑一遍分析 | 理解为对股票关注列表创建定时分析，走确认流程 | 复合意图拆解 |
| 9.10 | 最近有没有什么利空消息影响白酒板块的？ | 调用新闻/板块工具 | 行业级查询 |
| 9.11 | 上次分析的宁德时代报告里，风险管理那块怎么说的？ | 查报告详情，定位到具体章节 | 精准报告检索 |
| 9.12 | 能接我自己的量化策略回测吗？ | 应拒绝：暂不支持 | 边界拒绝 |
