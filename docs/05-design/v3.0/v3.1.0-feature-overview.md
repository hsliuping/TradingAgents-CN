# TradingAgents-CN v3.1.0 功能概览

> 版本主题：跟踪闭环版
> 生成日期：2026-06-03

## 版本定位

v3.1.0 的核心目标是让用户从"一次性使用"转向"持续复访"，形成 **跟踪 → 提醒 → 复盘 → 计划** 的闭环。

## 功能模块总览

| # | 功能模块 | 核心能力 | 前端路由 |
|---|---------|---------|---------|
| 1 | 定时分析 | 按计划自动触发股票分析 | `/settings/scheduled-analysis` |
| 2 | 持仓分析 | 持仓管理 + AI 分析报告 | `/portfolio` |
| 3 | 交易复盘 | 交易复盘 + 阶段复盘 | `/review` |
| 4 | 投资计划 | 交易计划管理 + AI 评估 | `/trading-system` |
| 5 | 通知中心 | 站内通知 + IM 推送 | 顶部通知入口 |
| 6 | QQ Gateway | QQ Bot 接入 + 用户映射 | `/api/gateway/qq` |

## 1. 定时分析

### 功能说明

用户可配置定时分析任务，系统按计划自动触发股票分析，完成后通过通知中心 + IM 渠道推送结果。

### 核心流程

```
创建配置 → 启用/禁用 → 调度器按计划触发 → 执行分析 → 生成通知 → 推送

## 6. QQ Gateway

### 功能说明

QQ Bot 接入层，支持 Webhook 和 WebSocket 两种模式。处理用户身份映射（QQ 用户 → 系统用户），实现 QQ 内的对话式交互。

### 核心流程

```
QQ 消息 → Gateway 适配器解析 → 用户映射 → 助手对话 → 格式化回复 → QQ 推送

## 闭环关系

```
定时分析 ──触发──→ 分析任务 ──完成──→ 通知中心 ──推送──→ QQ/Web
    ↑                                              │
    │                                              ↓
投资计划 ←──关联── 持仓分析 ←──跟踪── 交易复盘 ←──复访──
```

六个模块不是孤立的，而是形成"跟踪 → 提醒 → 复盘 → 计划"的闭环：
1. **定时分析**自动触发关注标的的分析
2. **通知中心**确保分析结果触达用户
3. **持仓分析**提供当前持仓状态
4. **交易复盘**帮助回顾历史决策
5. **投资计划**将复盘结论转化为可执行规则
6. **QQ Gateway**让用户无需打开网页即可交互
