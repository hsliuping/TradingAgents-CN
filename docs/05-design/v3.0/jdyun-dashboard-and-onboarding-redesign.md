## 1. 背景与目标

### 1.1 背景

京东云合作版（JDYUN_MODE）于 v3.0 推出，与标准版的关键差异：

| 维度 | 标准版 | 京东云版 |
|------|--------|----------|
| 大模型配置 | 用户自行注册多个厂商 | 环境变量注入唯一厂商 |
| 数据源配置 | 用户自选 Tushare/AKShare/BaoStock 等 | 环境变量注入 Tushare Token，仅支持 Tushare/AKShare |
| License | 需激活 | 无 License，全功能开放 |
| 配置管理入口 | 完整 7 标签页 | 仅"系统配置（只读）+ 数据源配置" |
| 用户角色 | 探索型/学习型用户 | 京东云平台引入的企业/机构用户 |

### 1.2 目标

1. **仪表板**：从"功能目录"转为"工作中心"，让用户进首页就能看到自己的数据
2. **引导体系**：整合 3 套重复引导为 1 套，京东云版自动跳过配置类步骤
3. **不破坏标准版**：所有改动通过 `isJdyunMode()` 条件分支，标准版保持原逻辑

### 1.3 不在本方案范围

- 标准版仪表板改造（后续单独规划）
- 学习中心（/learning）课程内容调整
- 侧边栏菜单结构调整
- 后端 LLM 推理能力升级

## 2. 京东云版用户画像分析

### 2.1 用户特征

京东云版用户与标准版有本质区别：

**标准版用户**：
- 自主注册的散户/学习者
- 愿意花时间配置 API、探索功能
- 容忍较长的引导流程
- 需要了解"系统有哪些功能"

**京东云版用户**：
- 京东云平台引入的机构/企业用户
- 由管理员统一注入配置，开箱即用
- 期望快速进入"使用"而非"配置"
- 不关心系统架构，只关心"我能做什么"

### 2.2 核心诉求

| 诉求 | 优先级 | 说明 |
|------|--------|------|
| 快速完成首次分析 | P0 | 用户最想看到的是"系统能给我什么结果" |
| 看到自己的数据 | P0 | 自选股、持仓、历史分析结果 |
| 知道下一步做什么 | P1 | 智能引导，而非功能列表 |
| 学习进阶用法 | P2 | 完成首次分析后再引导进阶课程 |

### 2.3 关键差异

**京东云版用户不需要**：
- 配置大模型/数据源（已注入）
- 激活 License（无 License）
- 了解多厂家/多数据源（只有一个）
- 复杂的功能介绍（直接用就行）

**京东云版用户更需要**：
- 知道"我现在可以做什么"
- 看到自己的任务进度
- 快速进入分析流程
- 出问题时知道找谁（管理员）

## 4. 当前引导体系问题盘点

### 4.1 现有 3 套引导

| # | 入口 | 触发 | 形式 | 问题 |
|---|------|------|------|------|
| 1 | GuideDialog.vue | 首次登录 | Modal 弹窗 | 5 步静态列表，不检测进度，内容与 /guide 重复 |
| 2 | /guide 页面 | 仪表板按钮 | 独立页面 | 7 步骤，进度检测，但内容偏标准版（含 License 激活） |
| 3 | 仪表板"系统就绪度卡" | 配置未完成 | 卡片 | 与 /guide 内容完全重复 |

### 4.2 京东云版的引导错位

参考 [Guide/index.vue:134-157](../../../frontend/src/views/Guide/index.vue#L134-L157) 步骤 4 "激活 License"：

- 京东云版无 License，但引导仍要求激活
- 步骤 1 "获取大模型 API 密钥"、步骤 2 "获取数据源 API 密钥" 在京东云版已自动注入
- 用户看到 7 步引导，实际只需做 3 步（同步 → 添加自选股 → 分析）

### 4.3 内容重叠矩阵

| 步骤 | GuideDialog | /guide 页面 | 仪表板就绪卡 |
|------|-------------|-------------|-------------|
| 配置大模型 | ✓ | ✓ | ✓ |
| 配置数据源 | ✓ | ✓ | ✓ |
| 激活 License | ✗ | ✓ | ✗ |
| 同步数据 | ✓ | ✓ | ✓ |
| 添加自选股 | ✓ | ✓ | ✗ |
| 完成分析 | ✓ | ✓ | ✗ |

3 套引导覆盖相同内容，用户看到 3 次会困惑。

1. **数据优先**：用户数据（任务、自选股、持仓）放首屏
2. **保留功能发现**：功能入口不删除，改为可折叠
3. **京东云版特化**：跳过配置类引导，直接进入"使用"
4. **不破坏标准版**：通过 `isJdyunMode()` 分支

### 5.3 关键模块设计

#### 5.3.1 KPI 数据卡片（新增）

4 个卡片横排，每个卡片包含：数值 + 副标题 + 迷你状态指示

| 卡片 | 数据源 | 计算逻辑 |
|------|--------|----------|
| 今日任务 | `/api/tasks` | 今日创建任务数 / 已完成数 |
| 本周分析 | `/api/tasks` | 本周任务总数 + 成功率 |
| 持仓盈亏 | `/api/paper/account` | 总资产 + 当日盈亏百分比 |
| API 用量 | `/api/usage/stats` | 已用 Tokens / 配额 |

**新组件**：`frontend/src/components/Dashboard/KpiCards.vue`

#### 5.3.2 进行中任务卡片（新增）

显示状态为 `running`/`processing`/`pending` 的任务，每个任务行包含：
- 任务类型图标
- 股票代码 + 任务名称
- 进度条（如可获取）
- 已用时长
- "查看"按钮跳转任务中心

**新组件**：`frontend/src/components/Dashboard/RunningTasksCard.vue`

#### 5.3.3 智能助手/学习中心推荐卡（改造）

- 改为**可关闭横幅**（高度 60px）
- 关闭状态写入 `localStorage: jdyun_dashboard_banner_dismissed`
- 横幅内容：单行文字 + 主按钮，不再占大块空间

#### 5.3.4 更多功能折叠区（新增）

收起以下内容到折叠区：
- v3.0 核心功能卡片（智能助手/智能选股/Agent工坊/MCP）
- 流程配置卡片（流程管理/Agent配置/工具/提示词）

折叠区默认收起，点击"展开"显示。展开状态写入 `localStorage`。

#### 5.3.5 京东云版特化处理

- **隐藏**：系统就绪度引导卡（配置已注入，无需引导）
- **隐藏**：GuideDialog 首次登录弹窗（改为直接路由到 /guide 的京东云版步骤）
- **保留**：自选股、模拟交易、市场快讯、多数据源同步

### 5.4 标准版仪表板（保持不变）

所有改动通过 `v-if="isJdyunMode()"` 或 `v-else` 分支，标准版保持原有布局。

## 6. 引导体系重设计方案

### 6.1 整合策略

**删除 2 套，保留 1 套**：

| 引导 | 处理方式 | 理由 |
|------|---------|------|
| GuideDialog 弹窗 | **删除弹窗逻辑，保留组件用于"查看引导"按钮** | 首次登录直接路由到 /guide |
| 仪表板系统就绪度卡 | **删除** | 与 /guide 重复，京东云版无意义 |
| /guide 页面 | **保留并升级为唯一引导** | 已有进度检测，改造为京东云版友好 |

### 6.2 京东云版引导流程

```
用户首次登录
  ↓
路由守卫检测：
  - localStorage 无 jdyun_guide_completed 标记
  - 是京东云版
  ↓
自动跳转到 /guide?mode=jdyun
  ↓
/guide 页面渲染（京东云版特化）：
  步骤 1：欢迎 + 介绍系统能力（无需配置）
  步骤 2：同步股票数据
  步骤 3：搜索并添加自选股
  步骤 4：完成首次分析
  ↓
完成全部步骤
  ↓
标记 jdyun_guide_completed=true
  ↓
跳转回 /dashboard
```

### 6.3 /guide 页面改造

#### 6.3.1 步骤精简

**标准版**（保持 7 步）：
1. 获取大模型 API
2. 获取数据源 Token
3. 填写配置
4. 激活 License
5. 同步数据
6. 添加自选股
7. 完成首次分析

**京东云版**（精简为 4 步）：
1. 欢迎使用（介绍系统能力，无需配置）
2. 同步股票数据
3. 搜索并添加自选股
4. 完成首次分析

#### 6.3.2 京东云版步骤 1 设计

```markdown
## 欢迎使用 TradingAgents-CN 京东云版

您的系统已由管理员配置完成：

✅ 大模型：GLM-5.1（已就绪）
✅ 数据源：Tushare + AKShare（已就绪）
✅ 全功能开放（无需激活 License）

接下来只需 3 步即可开始分析：
1. 同步股票基础数据
2. 添加您关注的股票
3. 完成第一次 AI 研究

[开始第一步 →]
```

#### 6.3.3 进度检测 API 复用

复用现有 `/api/system/readiness` 接口，京东云版跳过 `datasource_configured`、`llm_configured`、`license_valid` 检查（视为已完成），只检测：
- `basics_synced`：数据同步状态
- `has_favorites`：是否有自选股
- `has_analysis`：是否完成首次分析

### 6.4 标准版引导（保持不变）

标准版仍保留 7 步，逻辑不动。

### 6.5 AI 助手集成（P2 延后）

本次不做 AI 对话式引导，原因：
1. 开发成本高（1-2 周）
2. 新用户认知负担（不熟悉 AI 对话）
3. 优先级低于数据可视化

**后续规划**：在 Phase 3 集成 AI 助手浮窗，复用 /assistant 能力。

## 10. 风险与对策

### 10.1 技术风险

| 风险 | 概率 | 影响 | 对策 |
|------|------|------|------|
| 后端 `/api/usage/stats` 接口不存在 | 中 | KPI 卡片无法显示 API 用量 | 复用现有 `/api/usage/*` 接口或临时隐藏该卡片 |
| 京东云版用户无自选股数据 | 高 | 自选股卡片空状态 | 空状态引导用户添加自选股 |
| 京东云版用户无模拟交易账户 | 中 | 持仓盈亏 KPI 无数据 | 显示"暂无账户，前往开通" |
| localStorage 被禁用 | 低 | 横幅状态不记忆 | 降级为每次显示 |

### 10.2 产品风险

| 风险 | 概率 | 影响 | 对策 |
|------|------|------|------|
| 用户习惯了原仪表板，改造后不适应 | 中 | 用户反馈 | 灰度发布，先收集反馈 |
| 折叠区导致用户找不到功能 | 中 | 功能使用率下降 | 折叠区有明显的"展开"提示 |
| 引导步骤过少，用户不知道高级功能 | 低 | 进阶使用受阻 | 步骤 4 完成后推荐学习中心 |

### 10.3 回滚方案

- 所有改动通过 `isJdyunMode()` 分支
- 如需回滚，将 `isJdyunMode()` 强制返回 false 即可恢复标准版布局
- 京东云版引导可回退到 GuideDialog 弹窗模式
