# TradingAgents-CN v3.0.0 验收测试计划

## 文档目的

本计划用于 `v3.0.0` 小版本验收。

该版本的目标不是覆盖所有已实现能力，而是验证“核心投研助手主链路”是否已经成立。

## 版本定位

- 版本主题：核心投研助手版
- 目标用户：普通用户、首批付费用户
- 发布形态：GA
- 核心目标：让用户完成“提问 -> 选股 -> 分析 -> 看报告 -> 加入跟踪”主链路

## 纳入范围

1. 智能助手线程、历史、摘要、用户画像、RAG。
2. 智能选股主链路。
3. 分析触发与报告查询。
4. 股票关注列表管理。
5. 基础研究工作台体验。

## 不纳入范围

1. QQ Gateway 和 IM 推送。
2. 统一通知中心。
3. 定时分析。
4. 持仓分析、交易复盘、投资计划。
5. QMT 和 ETF。
6. MCP Server。
7. AI 工作流架构师、Agent 工坊、Skill 自动生成。

## 验收重点

1. 首次使用用户是否能快速理解产品主价值。
2. 助手是否能围绕研究主题持续对话而不串线。
3. 选股结果是否能自然进入分析和报告查看。
4. 用户是否能把感兴趣标的沉淀为后续跟踪对象。

## 核心验收场景

### 场景 A：研究入口

1. 新建研究线程并围绕单个股票连续提问。
2. 刷新页面后重新进入线程查看历史与摘要。
3. 对长对话执行“手动总结”。

预期结果：

1. 线程隔离正确。
2. 历史消息可回显。
3. 摘要能稳定生成，并包含已确认事实、待验证问题、下一步建议。

### 场景 B：自然语言选股

1. 输入一条模糊筛选需求。
2. 完成条件确认。
3. 查看结构化筛选结果。

预期结果：

1. 流程体现“确认 -> 执行 -> 结果”节奏。
2. 结果与筛选条件一致。
3. 结果页能继续触发后续分析。

### 场景 C：分析与报告闭环

1. 从助手直接发起单股分析。
2. 查询分析状态。
3. 查看最新报告和报告详情。

预期结果：

1. 任务成功创建。
2. 状态可跟踪。
3. 报告可被查询、打开和继续引用。

### 场景 D：股票关注列表沉淀

1. 将筛选结果或分析对象加入股票关注列表。
2. 查看股票关注列表列表。
3. 移除指定标的。

预期结果：

1. 增删操作成功。
2. 列表状态实时反映变化。
3. 不会出现跨用户串数据。

### 场景 E：RAG 与用户画像辅助

1. 询问金融知识类问题。
2. 在多轮交流后再次询问与用户偏好相关的问题。

预期结果：

1. 回答能体现知识增强，而不是空泛总结。
2. 回答能反映此前沉淀的偏好或上下文。

## 入口条件

1. 助手页面、智能选股、报告查询、股票关注列表等主链路页面可访问。
2. 基础分析工作流可稳定创建任务和产出报告。
3. 至少准备一组标准测试股票与测试账号。

## 退出条件

1. 核心主链路场景全部通过。
2. 不存在阻塞级串会话、串用户、报告打不开、任务无法创建问题。
3. 首次使用路径的关键文案和交互足够清楚，不需要测试人员额外解释才能完成。

## 风险提示

1. 如果线程、摘要或报告引用仍不稳定，会直接破坏首发版本口碑。
2. 如果智能选股与后续分析断链，用户会认为产品只是一个“会聊天的筛选器”。
