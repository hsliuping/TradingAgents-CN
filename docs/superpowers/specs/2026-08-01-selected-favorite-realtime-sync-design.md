# 自选股按选中项同步实时行情设计

## 问题

自选股页的批量同步只能请求历史、财务和基础数据，缺少实时行情选项。用户只能使用全量实时同步；当选股数超过 10 时，该路径调用需要独立权限的 Tushare `rt_k`，且权限错误被错误显示为“成功 0、失败 0”。

## 决策

扩展已有的批量同步工作流，而不新增平行界面：

- 批量同步对话框新增“实时行情”选项；
- 请求继续包含用户选择的 `data_source`（Tushare 或 AKShare）；
- 批量 API 新增 `sync_realtime`，仅将选中的代码传给所选服务；
- 返回统一的 `realtime_sync` 统计，字段为 `total_processed`、`success_count`、`error_count` 和 `errors`；
- Tushare 无权限或未返回行情时，将选中代码数计入 `error_count` 并返回具体错误；
- 原全量同步接口复用同一统计约定，避免再把失败显示为 0。

## 用户体验

用户勾选多条自选股，点击“批量同步”，勾选“实时行情”，选择 AKShare 或 Tushare 后执行。完成提示显示实际成功和失败数量；失败时显示首条数据源错误。历史、财务与基础同步行为不改变。

## 验收

1. 批量对话框可选择实时行情并把选中代码和用户数据源提交给批量 API。
2. AKShare 对多个选中代码只同步这些代码，并返回逐项统计。
3. Tushare 空结果/权限失败时，返回的失败数等于未同步的选中代码数，而不是 0。
4. 全量自选股实时同步也能正确显示失败数和失败原因。
