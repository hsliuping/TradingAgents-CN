# 自选股标签同步设计

## 背景

添加自选股表单允许用户输入新标签，但该操作只将标签保存到 `user_favorites.favorites[].tags`。页面中的标签数据、筛选器与标签管理则读取 `user_tags`，造成已添加标签却无法出现在标签数据中的不一致。

## 决策

在 `FavoritesService.add_favorite` 中，保存自选股前将非空标签名称写入 `user_tags`：

- 以用户 ID 和标签名为唯一键；
- 已存在的标签保持颜色、排序和其他元数据；
- 新标签使用标签服务既有默认颜色与默认排序；
- 自选股仍保存原始标签数组；
- 本次不回填历史自选股，避免未经确认地改写既有数据。

## 验收

添加包含多个新标签的自选股后，重新读取标签库可得到这些标签；重复使用既有标签不会创建重复记录；标签仍会随自选股保存。

## 测试

为服务层增加异步回归测试，验证插入多个标签的可观察结果及幂等行为。
