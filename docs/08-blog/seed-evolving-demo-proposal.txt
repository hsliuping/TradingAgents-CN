Demo 名称
《AI 研究员工厂：让 Seed-Evolving 在 A 股研究里"自我进化"》

一句话命题：让 Doubao-Seed-Evolving 驱动一个开源多智能体金融研究系统——从一句自然语言需求，到一份每条结论都可溯源的个股研究报告；研究中发现数据缺口时，现场为它编写并验证一个新工具。

一、项目背景

TradingAgentsCN（GitHub 3.1w+ Star）是基于知名开源项目 TauricResearch/TradingAgents（10w+ Star）深度中文化改造并大幅演进的 A 股多智能体研究平台，定位为研究辅助与学习工具（合规边界：不构成投资建议，不提供买卖指令）。

即将发布的 v3.6.0 社区版（与本次 Demo 同期开源）已具备完整能力底座：
- 多智能体研究会议架构：乐观/审慎情景研究员辩论 → 研究经理 → 风险审阅，多角色协作产出结论
- 80+ 内置分析工具（10 大类）：财报造假检测、破产风险评估、行业板块、筹码分布等
- Agent 自主规划：面对复杂问题自动识别分析路径、组合工具、组织步骤
- Skill 中心（工具代码生成闭环）：用户用自然语言描述数据需求，LLM 自动编写工具代码，经静态校验与沙箱运行验证（不达标自动迭代修复）后注册为系统工具，工具库按需持续扩充
- 数字溯源防线：AI 回答中的关键数字若无法溯源到工具真实返回，直接拦截并要求重答

二、Demo 演示主线（60 秒一条链路）

输入一句自然语言："帮我研究一下赛力斯，重点看它有没有爆雷风险。"

环节1 自主规划：Agent 识别需求 → 数据同步预检查 → 动态构建工具清单（缺数据时自动裁剪不可用工具）【长程 Agent · 工具选择】
环节2 多 Agent 协作：研究会议架构——乐观/审慎情景研究员并行探索、共享状态、风控审阅汇总成一份结论【多 Agent 协作 · 问题分解】
环节3 证据溯源报告：生成研究报告，每条结论高亮回链到原始工具返回与数据源（Tushare 财报/实时行情/公开新闻）【低幻觉 · 证据溯源】
环节4 现场追问挑战：故意追问诱导编造（"它市占率是多少？"——工具未返回该数据）→ 展示拦截 + 重答过程【自我验证与纠错】
环节5 Skill 现场生成：分析中发现数据缺口（如某明细数据工具返回为空）→ Skill 中心用一句话描述需求 → Seed-Evolving 编写工具代码 → 沙箱运行验证，不达标自动迭代修复 → 新工具即时注册，本次分析立即可用【Coding Agent · 交付可运行产品 · 自我验证修复】

三、为什么是 Seed-Evolving（模型优势体现点）

1. 金融是幻觉重灾区，正是低幻觉的试金石——财报数字、估值、市占率，错一个数字结论就全错。Demo 的"追问挑战"环节直接压力测试 function_calling_hallu 能力。
2. 长程多工具链路——一次研究跨 10+ 工具连续调用、多轮汇总，直接对应 Toolathlon 长任务连续执行场景。
3. Evolution 与 Evolution 的呼应——Seed-Evolving 周级迭代持续进化；TradingAgentsCN 的工具库通过按需生成新工具持续扩充。"模型在进化，工具库也在进化"是天然的叙事契合点。
4. 性价比路由——系统内置按分析深度（1-5 级：快速/基础/标准/深度/全面）分层调度，Demo 可展示 Seed-Evolving 在分层调度下的成本优势。
5. 模型能力升级，分析流同步进化——当前"多轮辩论 + 多角色交叉验证"的架构，本质是早期弱模型时代的补偿性设计：把任务拆小、机械分工、用流程轮数换可靠性。Seed-Evolving 的长程推理与自我纠错能力，让分析流可以从"用流程补能力"走向"用模型能力重构流程"——减少机械轮次，把预算投向更深的多步推理与证据链印证。这也是本次共创要验证的核心假设：更强的模型，配得上更聪明的分析流。

四、商业 / 应用价值（toB 方向）

- 券商与投研机构：研究报告初稿自动化 + 全程可溯源，符合合规审慎要求
- 财经媒体 / 资讯平台：批量个股研究内容生产，每个数字有出处
- 企业投研 / 战略部门：行业与标的研究流程标准化、分析经验持续沉淀为可复用流程
- 金融研究的"可溯源"要求天然适配 Seed-ToB 评测强调的"来源权威性与事实性"方向

五、传播性设计

- 视觉主线："结论 → 工具调用 → 数据源"三层溯源链路动效，一眼看懂"AI 没有编数字"
- 冲突点：现场追问诱导编造 → 被系统拦截 → 重答基于真实数据，戏剧性天然成立
- 开源引流：Demo 发布与 v3.6.0 社区版开源同期，观众可自行部署复现，附完整复现文档

七、技术接入说明

系统 LLM 层为 OpenAI 兼容架构，方舟接入仅需注册 volcengine provider（base_url 指向 ark 端点）+ 配置 doubao-seed-evolving 统一 Model ID——"一次接入，无感升级"与系统多模型分流架构无缝契合。

合规声明：TradingAgentsCN 为研究辅助工具，所有分析结论均为 AI 生成的研究参考，不构成投资建议。系统使用"乐观 / 审慎 / 中性"研究倾向表述，不提供买卖指令、目标价或止损止盈建议。
