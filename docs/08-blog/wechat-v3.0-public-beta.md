## 一、先讲一个"三代人"的故事

如果你是从 v1.x 一路用过来的老用户，这个演进过程你可能有印象：

**第一代（v1.x），是"能跑起来"。**
把多智能体分析框架中文化，接上 A 股数据，跑通第一份从数据到报告的分析流程。那时候的核心问题是：这条路能不能走通。

**第二代（v2.x），是"跑得准"。**
重点在数据质量、技术指标计算、分析可信度。修掉了一堆指标算错、数据不一致的坑，加了批量分析、定时分析、模拟交易、报告导出。这时候的核心问题是：结果可不可信。

**第三代（v3.0），是"用得顺"。**
这一代我不再堆功能页面，而是回答一个更根本的问题：**用户到底想完成什么事？**

这就是 v3.0 最大的变化——从"一个功能集合"，走向"一个能理解你意图的 AI 研究助手"。

## 二、v3.0 的四个核心升级

### 1. 统一 AI 助手入口：不用再"找菜单"

以前分析股票要去一个页面、查报告去另一个页面、管理关注列表再切一个页面。v3.0 把这些全部收拢到一个对话入口，你直接说想做什么：

- "帮我分析一下 002714"
- "看看我关注列表里股票的最新报告"
- "查一下我的持仓分析"

系统会自己理解意图、调起对应的能力。你只需要想"我要做什么"，不用想"在哪个菜单里"。

### 2. 选股助手：说出你的想法，而不是搭一堆条件

很多人的选股需求其实是模糊的："我想找近期趋势向上、成交活跃、基本面也有支撑的标的"。以前你得把这翻译成一堆筛选条件，现在直接说出来就行。

系统会理解你的意图，输出结构化的候选清单，还能无缝衔接到下一步的深度分析——从"想法"到"候选池"再到"研究报告"，一条链路走完。

### 3. Agent 自主规划分析：它知道该怎么拆解问题

v3.0 的 Agent 不再是"你问一句、它答一句"。面对一个复杂问题，它会自己识别分析路径、组合工具、组织步骤，最后整合成完整结论。

比如一句"这家公司有没有爆雷风险"，它会自动串起财报造假检测、破产风险评估、财务健康度打分等多个工具，给你一份有层次的研究结论，而不是零散的问答。

### 4. 80+ 内置分析工具：传统付费工具才有的能力，全部内置

这次 v3.0 内置了 **80+ 个分析工具，覆盖 10 大类**，很多是以前需要付费第三方工具才能做的事：

| 你关心的问题 | 内置能力 |
|---|---|
| 这家公司财务健康吗 | 财报造假检测（Beneish M）、破产预警（Altman Z）、财务健康打分（Piotroski F） |
| 这家公司值多少钱 | DCF 现金流折现估值、Graham 估值、PEG、WACC |
| 现在是什么市场环境 | 大盘板块行情、筹码分布、行业板块数据 |
| 我的持仓风险大吗 | 夏普比率、最大回撤、VaR、压力测试 |
| 上次为什么赚/亏 | 交易复盘、收益归因分析 |

输入一个股票代码，几分钟就能跑出一套多维度的研究简报。

## 三、我最在意的一点：数据有出处，不是"AI 猜的"

AI 工具最让人不放心的，就是一本正经地编数字。

v3.0 在这件事上下了很大功夫：

- **每个数据点都能查到来源**：财务数据来自 Tushare 财报，行情来自实时接口，新闻来自公开新闻源
- **AI 推论会被明确标记**：哪些是拿到的真实数据、哪些是 AI 推理的结论，报告里分得清清楚楚
- **编造数字会被拦截**：系统内置了数字溯源校验，AI 回答里的关键数字如果无法溯源到工具真实返回，会被直接拦下来要求重答，而不是放任它"猜一个"

说白了：**宁可告诉你"这个数据没拿到"，也不编一个看起来很像的数字。**

这是我认为一个研究工具最基本的底线。

## 四、公测版需要知道的事

这次发布的是 **v3.0.0-beta.4 公开测试版**，几件事提前说清楚：

**1. 目前仅支持 A 股市场分析。**

**2. 需要配置大模型 API Key。**
系统本身不绑定某家大模型，DeepSeek、通义千问等主流国内模型都可以配置使用（推荐配置方式详见安装后的系统管理界面）。

**3. 分析前请先做数据同步。**
安装完成后，先按引导完成数据源配置和股票数据同步，再发起分析，否则可能出现数据不全。

**4. 公测版 = 可能还有 bug。**
遇到问题欢迎反馈，公测阶段的问题会优先修复。你的反馈会直接影响正式版的发布质量。

**5. 合规声明（重要）。**
TradingAgentsCN 定位为**研究辅助与学习工具**，所有分析结论均为 AI 生成的研究参考，**不构成投资建议**。系统的决策结论只使用"乐观 / 审慎 / 中性"等研究倾向表述，不提供买卖指令、目标价或止损止盈建议。投资决策请独立判断、自主负责。
