# A 股行业分析框架速查手册

> 基于 Tushare stock_basic_info 行业分类，按业务模式与分析框架相近原则合并为 37 个大类。
> 每个行业定义了核心分析维度（★=极关键 ▲=高重要 ●=中重要）、分析重点、关键指标和可比公司。

---

## 一、金融（4 个）

### 1. 银行

| 维度 | 重要性 | 说明 |
|------|--------|------|
| 净息差(NIM) | ★ | 银行核心盈利能力指标，反映资产端收益率与负债端成本之差。降息周期下NIM承压，关注资产负债结构对冲能力 |
| 不良贷款率 | ★ | 资产质量核心指标，关注五级分类迁移趋势、不良生成率及核销转出节奏 |
| 拨备覆盖率 | ▲ | 风险缓冲厚度，拨备越厚盈利调节空间越大，但过高可能暗示隐藏利润 |
| 资本充足率 | ▲ | 监管核心约束，决定分红与规模扩张天花板。关注核心一级资本充足率与TLAC达标进度 |
| ROE/ROA | ▲ | 股东回报率。银行ROE持续下行是全行业趋势，关注ROE是否高于权益成本 |
| 信贷投放增速 | ● | 反映实体信贷需求和银行风险偏好。关注对公/零售结构变化及普惠小微占比 |
| 中间业务收入占比 | ● | 财富管理、结算清算、投行等非息收入占比，衡量轻资产转型进度 |

**分析重点**：利率环境变化对NIM的影响、信贷投放节奏与结构、资产质量变化趋势（特别是地产和城投敞口）、监管政策对资本金和业务结构的约束。同时需关注存款定期化趋势对负债成本的影响。

**关键指标**：NIM / 不良率 / 拨备覆盖率 / ROE / 核心一级资本充足率 / 贷存比 / 非息收入占比 / 成本收入比

**可比公司**：招商银行、兴业银行、平安银行、宁波银行、邮储银行

### 2. 证券

| 维度 | 重要性 | 说明 |
|------|--------|------|
| 经纪业务市占率 | ★ | 股基交易额市场份额，反映零售客户基础和渠道能力 |
| 投行业务收入 | ▲ | IPO/再融资/债券承销规模和收入，关注项目储备和审核节奏 |
| 资管/AUM规模 | ▲ | 主动管理规模、公募基金利润贡献，衡量财富管理转型成效 |
| 自营投资收益率 | ▲ | 自营盘规模和收益率，关注固收/权益配置结构和风险敞口。市场波动直接冲击利润 |
| ROE | ▲ | 券商ROE波动大，牛市高企熊市低迷，需关注ROE中枢是否抬升 |
| 两融余额市占率 | ● | 信用业务规模和市场份额，反映高净值客户粘性 |
| 场外衍生品规模 | ● | 雪球/收益互换等业务规模，高ROE业务但监管趋严 |

**分析重点**：券商是强周期行业，分析时必须结合市场环境判断各业务线趋势。重点关注：财富管理转型带来的收入结构变化、投行注册制下的项目储备质量、自营业务的风险敞口控制、以及行业并购整合预期。

**关键指标**：经纪市占率 / 投行收入 / 资管AUM / 自营收益率 / ROE / 两融余额 / 杠杆率

**可比公司**：中信证券、华泰证券、东方财富、中金公司、国泰君安

### 3. 保险

| 维度 | 重要性 | 说明 |
|------|--------|------|
| 新业务价值(NBV) | ★ | 新签保单的未来利润折现，寿险核心增长指标。关注NBV增速和Margin |
| 保费收入增速 | ★ | 总保费和首年保费增速，区分寿险/财险/健康险。关注代理人数量和产能 |
| 投资收益率 | ▲ | 保险资金运用收益率，与长端利率高度相关。需关注权益/固收/另类配置结构 |
| 偿付能力充足率 | ▲ | 监管核心指标，决定业务扩张和分红能力。关注核心偿付能力充足率 |
| 综合成本率(财险) | ▲ | 赔付率+费用率，低于100%才承保盈利。车险综改下持续承压 |
| 退保率 | ● | 反映保单质量和客户满意度，退保率高可能暗示产品设计或销售误导问题 |

**分析重点**：保险分析需区分寿险和财险两条线。寿险看NBV增速和代理人产能恢复，财险看综合成本率和大灾影响。利率下行是保险股最大的宏观压制因素。

**关键指标**：NBV增速 / NBV Margin / 保费增速 / 总投资收益率 / 综合偿付能力充足率 / 综合成本率 / 代理人数量 / 内含价值

**可比公司**：中国平安、中国人寿、中国太保、新华保险、中国人保

---

### 4. 多元金融

| 维度 | 重要性 | 说明 |
|------|--------|------|
| 业务结构 | ★ | 融资租赁/信托/小贷/担保/AMC各自占比，不同业务周期属性差异大 |
| 杠杆率/负债率 | ★ | 金融企业杠杆水平决定经营弹性，高杠杆在经济下行期风险放大 |
| 资产质量 | ▲ | 不良率/逾期率/关注类占比，反映信用风险暴露程度 |
| 净息差/利差 | ▲ | 融资成本与放款收益率之差，衡量核心盈利能力 |
| ROE | ● | 股东回报率，需关注ROE是否覆盖资金成本 |

**分析重点**：多元金融涵盖融资租赁、信托、AMC、小贷等多种业态，需分别分析各项业务的周期属性。重点关注宏观经济下行期的信用风险暴露、监管收紧对业务模式的影响。

**关键指标**：ROE / 不良率 / 杠杆率 / 净息差 / 拨备覆盖率

**可比公司**：江苏金租、五矿资本、中航产融、越秀资本、浙江东方

## 二、消费（5 个）

### 5. 白酒

| 维度 | 重要性 | 说明 |
|------|--------|------|
| 品牌力与定价权 | ★ | 高端酒批价走势、渠道价差、终端动销率。品牌梯队决定定价权和抗周期能力 |
| 渠道库存 | ★ | 经销商库存天数和打款意愿，库存周期是白酒最重要先行指标 |
| 预收款/合同负债 | ▲ | 经销商提前打款，反映渠道信心和下一季度营收确定性 |
| 产品结构升级 | ▲ | 吨价变化、高端/次高端占比提升，反映消费升级趋势 |
| 营收与利润增速 | ▲ | 量价拆分：销量增速×吨价增速，区分增长驱动因素 |
| 毛利率/净利率 | ● | 白酒行业毛利率极高（60-90%），关注品牌结构对毛利率的拉动作用 |
| 费用率 | ● | 销售费用率变化反映渠道竞争强度，管理费用率反映经营效率 |

**分析重点**：白酒是A股最优质的赛道之一，核心逻辑是品牌护城河+消费升级+价格带扩容。分析需关注：茅台批价作为行业风向标、渠道库存周期（压货→去库存→补库存）、以及商务消费场景的恢复情况。高端酒看品牌溢价，次高端看全国化扩张，地产酒看区域深耕。

**关键指标**：批价 / 吨价 / 预收款 / 毛利率 / ROE / 合同负债 / 销售费用率 / 营收增速

**可比公司**：贵州茅台、五粮液、泸州老窖、山西汾酒、洋河股份、古井贡酒

---

### 6. 大众食品

| 维度 | 重要性 | 说明 |
|------|--------|------|
| 市场份额 | ★ | 细分赛道市占率及变化趋势，龙头份额提升是核心投资逻辑 |
| 渠道覆盖 | ▲ | 经销商数量、终端网点数、渠道下沉深度。零食量贩/即时零售等新渠道占比 |
| 毛利率 | ▲ | 反映品牌溢价和定价能力。关注原料成本波动对毛利率的冲击 |
| 产品创新 | ▲ | 新品收入占比、爆款产品生命周期。大单品依赖度高的公司风险集中 |
| 营收增速 | ● | 量价拆分：销量×均价，区分量增和价增驱动 |
| 原材料成本 | ● | 大豆/小麦/糖/棕榈油/包材等价格波动直接影响毛利率 |
| 销售费用率 | ● | 快消品竞争激烈，费用投放效率决定利润率 |

**分析重点**：大众食品涵盖调味品、乳制品、休闲食品、饮料、啤酒等，核心逻辑是刚需+消费升级+渠道变革。分析需关注：细分赛道天花板和集中度提升空间、成本端（原料+包材）价格走势、渠道结构变化（传统经销商→社区团购→零食量贩→即时零售）。

**关键指标**：市占率 / 毛利率 / 销售费用率 / ROE / 营收增速 / 净利率 / 经销商数量

**可比公司**：海天味业、伊利股份、农夫山泉、安井食品、绝味食品、青岛啤酒

### 7. 家用电器

| 维度 | 重要性 | 说明 |
|------|--------|------|
| 内外销增速 | ★ | 外销受全球需求和贸易政策影响，内销与地产竣工和消费补贴相关 |
| 品牌溢价 | ▲ | 高端子品牌占比（如卡萨帝/COLMO），品牌结构决定毛利率天花板 |
| 毛利率 | ▲ | 受原材料（铜/铝/塑料/钢板）价格、汇率、产品结构三重影响 |
| 地产后周期联动 | ▲ | 白电/厨电与地产竣工面积高度相关，关注竣工增速和保交楼进度 |
| 海外产能布局 | ● | 东南亚/墨西哥工厂进度，规避关税壁垒和降低制造成本 |
| 库存周转 | ● | 渠道库存水平和周转天数，反映终端动销情况 |

**分析重点**：家电行业已进入成熟期，核心逻辑从量增转向价增（产品升级+品牌出海）。分析需关注：白电龙头的高股息属性、小家电的品类创新和渠道变革、以及智能家居生态的布局。地产周期和原材料价格是最重要的外部变量。

**关键指标**：毛利率 / 内外销增速 / ROE / 分红率 / 库存周转天数 / 汇率敞口

**可比公司**：美的集团、海尔智家、格力电器、老板电器、苏泊尔、科沃斯

---

### 8. 商贸零售

| 维度 | 重要性 | 说明 |
|------|--------|------|
| 同店增速 | ★ | 同店销售增长率，是零售业最核心的运营指标，剔除新开店扰动 |
| 线上渗透率 | ▲ | 电商/即时零售GMV占比和增速，线上占比越高成长性越强 |
| 坪效/人效 | ▲ | 单位面积/单人产出，衡量运营效率的核心指标 |
| 供应链效率 | ▲ | 自有品牌占比、SKU精简、仓储物流成本率，供应链能力决定毛利率上限 |
| 毛利率 | ● | 直接反映选品能力和品牌溢价，但需结合库存周转综合判断 |
| 门店扩张 | ● | 净开店数和储备项目，但需区分内生增长和粗放扩张 |

**分析重点**：零售业正经历渠道变革（传统商超→社区团购→即时零售→会员店）。分析需关注：业态转型方向和投入产出比、线上线下一体化运营能力、以及消费降级趋势下折扣零售的机会。

**关键指标**：同店增速 / 毛利率 / 线上GMV占比 / 坪效 / 库存周转天数 / 净利率

**可比公司**：中国中免、永辉超市、名创优品、家家悦、王府井

### 9. 纺织服饰

| 维度 | 重要性 | 说明 |
|------|--------|------|
| 品牌力 | ★ | 品牌认知度、复购率、客单价。运动服饰品牌壁垒最高，女装品牌迭代快 |
| 库存周转 | ★ | 服装行业库存是最大风险，库存天数和库龄结构反映经营质量 |
| 渠道结构 | ▲ | 直营/加盟/电商占比，DTC直营占比越高毛利率越高但费用也越高 |
| 毛利率 | ▲ | 品牌溢价能力的直接体现，运动服饰60%+，大众休闲40-50% |
| 同店增速 | ▲ | 剔除开店影响的有机增长，反映品牌势能和产品力 |
| 海外订单 | ● | 纺织制造端：海外品牌代工订单量，受全球消费和贸易政策影响 |

**分析重点**：服饰行业分品牌端和制造端。品牌端看：品牌势能（国潮崛起/运动户外）、DTC转型效果、库存管理能力。制造端看：全球品牌客户订单、产能全球化布局（东南亚）、原材料（棉花/化纤）价格波动。

**关键指标**：库存周转天数 / 毛利率 / 同店增速 / 直营占比 / 电商增速 / 净利率

**可比公司**：安踏体育、李宁、波司登、申洲国际、比音勒芬、华利集团

## 三、医药（4 个）

### 10. 化学制药

| 维度 | 重要性 | 说明 |
|------|--------|------|
| 集采影响评估 | ★ | 已纳入集采品种收入占比、即将集采品种、集采后量价变化。集采是化药企业最大变量 |
| 研发管线 | ★ | 在研品种数量、临床阶段分布、靶点选择。仿制药向创新药转型进度 |
| 一致性评价 | ▲ | 通过一致性评价品种数量，决定能否参加集采和享受政策红利 |
| 原料药价格 | ▲ | 原料药价格周期波动，向上周期利润率大幅改善 |
| 毛利率 | ▲ | 集采品种毛利率大幅下滑，需关注创新药/首仿药等高毛利品种占比 |
| 研发费用率 | ● | 创新转型需要持续高研发投入，10-15%为合理区间 |

**分析重点**：化学制药正经历从仿制药向创新药的转型阵痛。分析需区分：仿制药（存量、集采压力、成本控制）、创新药（管线价值、BD交易、临床数据）。原料药板块看价格周期和CDMO转型。

**关键指标**：研发费用率 / 毛利率 / 集采品种占比 / 创新药收入占比 / 营收增速 / 净利率

**可比公司**：恒瑞医药、科伦药业、人福医药、恩华药业、华海药业、普洛药业

### 11. 生物制药

| 维度 | 重要性 | 说明 |
|------|--------|------|
| 创新药管线 | ★ | 管线数量、临床阶段分布（I/II/III期/NDA）、靶点差异化。管线价值是估值核心 |
| 临床数据 | ★ | 关键临床数据读出时间表，阳性/阴性数据对股价影响巨大 |
| BD/对外授权 | ▲ | License-out交易金额和首付款，海外授权是验证管线价值的重要信号 |
| 商业化能力 | ▲ | 已上市产品销售放量情况、医保谈判结果、销售团队规模 |
| 现金储备 | ▲ | 在手现金/烧钱率，创新药企在盈利前依赖融资，现金跑道长度至关重要 |
| 研发费用 | ● | 研发投入规模和增速，但需关注研发效率（投入产出比） |

**分析重点**：生物制药是高风险高回报的赛道。分析需关注：管线梯队（FIC/BIC/Me-better分类）、关键临床数据读出节点、BD交易能力（买进/卖出管线）、以及融资环境对估值的影响。biotech和big pharma的分析逻辑差异较大。

**关键指标**：管线数量 / 现金/烧钱率 / 研发费用 / License-out金额 / 产品收入 / 市研率

**可比公司**：百济神州、信达生物、康方生物、荣昌生物、君实生物、复宏汉霖

### 12. 中药

| 维度 | 重要性 | 说明 |
|------|--------|------|
| 品牌壁垒 | ★ | 老字号品牌价值是中药最核心的护城河，品牌认知度决定定价权和复购率 |
| OTC渠道 | ★ | OTC终端覆盖率、药店陈列、品牌营销投入。OTC品牌消费品逻辑，受集采影响小 |
| 原材料成本 | ▲ | 天然牛黄/麝香/三七/党参等药材价格波动，直接影响毛利率 |
| 政策支持 | ▲ | 中药审评审批改革、基药目录调整、医保支付政策变化 |
| 产品梯队 | ▲ | 核心大单品依赖度、新品储备和上市节奏 |
| 毛利率 | ● | 品牌中药毛利率通常50-70%，受原材料价格和提价节奏影响 |

**分析重点**：中药兼具药品属性和消费品属性。品牌中药（片仔癀/同仁堂）看品牌壁垒和提价能力，OTC中药看渠道下沉和品类扩张，中药创新药看审评审批提速。政策暖风（中药十四五规划）是板块核心催化剂。
