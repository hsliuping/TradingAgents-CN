# 第一部分：从散户到有研究框架的决策者

> 本部分共 2 课时，帮助学员理解从情绪化交易走向研究驱动、复盘纠偏和持续迭代的完整转变。

---

## 第1课：从散户到有研究框架的决策者

**课时**：1 课时  
**目标**：理解散户反复犯错的根源，认识研究驱动与复盘纠偏的价值，明确 AI 系统与用户各自的边界

---

### 1.1 为什么散户总在重复同样的错误？

A 股市场里最常见的问题，并不只是“信息不够”，而是**没有把信息整理成可复核的判断链条**。

很多散户其实每天都在看行情、看群聊、看新闻，但结果依然是：

1. 热点来了就急着跟；
2. 波动一大就开始慌；
3. 盈亏一结束，既说不清当初为什么做，也说不清以后怎么改。

这说明真正缺的，不是再多看几条消息，而是一个能把研究、判断、复核和改进连起来的工作方法。

#### 1.1.1 不是信息少，而是证据链断裂

最典型的散户决策，往往长这样：

```text
听说某只股票很热
-> 看了一眼走势
-> 感觉题材不错
-> 直接参与
```

这个过程最大的问题是，里面几乎没有真正可复核的证据。

你很难回答下面这些问题：

- 现在看到的是短期情绪，还是中期逻辑？
- 支持判断的核心证据是什么？
- 最关键的不确定性是什么？
- 什么情况出现后，原判断要立刻重评？

一旦这些问题都答不上来，后面无论盈利还是亏损，都会变成“靠感觉解释”。

#### 1.1.2 不是没有努力，而是没有统一的判断边界

很多散户的问题也不是完全不认真，而是不同阶段用的是不同标准。

例如：

1. 选标的时看热点；
2. 持有时看情绪；
3. 下跌时改成看长期；
4. 上涨时又突然只看短线兑现。

这种切换之所以危险，不是因为它一定亏钱，而是因为它让你根本无法确认：

- 自己到底是按什么框架在判断；
- 这次判断和上次判断有没有一致性；
- 是市场变了，还是自己临时改口径了。

没有统一边界的结果，就是每次都像重新开始。

#### 1.1.3 真正严重的，不是亏损本身，而是无法复盘

对一个学习中的投资者来说，最糟糕的情况往往不是某一笔亏损，而是这笔亏损结束后，你仍然说不清：

1. 错在研究不完整；
2. 错在执行偏离；
3. 错在持仓阶段没有复核；
4. 还是错在情绪上头后推翻了原计划。

同样，盈利也不自动代表过程正确。

如果一笔交易赚了钱，但你实际上跳过了关键证据检查、没有按自己的边界执行、也没有在事后沉淀经验，那么这笔盈利很可能只是一种偶然结果，而不是能力提升。

所以，第 1 课最重要的认识是：

**散户真正需要摆脱的，不只是追涨杀跌，而是“无法解释、无法复核、无法改进”的循环。**

---

### 1.2 课程真正要培养的，不是“会下指令的人”

过去很多课程喜欢把目标写成“从散户到系统交易者”，但如果不先把边界讲清楚，这个说法很容易被理解成：

- 系统替我做判断；
- 我只要照着执行；
- 最后靠模板或参数就能稳定赚钱。

当前课程不应该再走这个方向。

这一版高级课程真正要培养的，是：

**一个能阅读研究、整理证据、区分边界、复盘偏差并持续修正自己方法的人。**

#### 1.2.1 普通散户和研究型决策者的差别

| 维度 | 普通散户 | 研究型决策者 |
| ------ | ------ | ------ |
| 关注点 | 热点、情绪、短期波动 | 证据、边界、不确定性、后续观察 |
| 判断方式 | 凭感觉切换口径 | 尽量保持同一套研究框架 |
| 持仓跟踪 | 主要盯价格 | 结合持仓研究检查风险焦点和机会信号 |
| 复盘方式 | 看盈亏、看运气 | 看复盘结论、暴露的问题、后续改进重点、偏离计划之处 |
| 改进方式 | 临时换想法 | 把重复问题写回个人计划和版本记录 |

这张表里最关键的一点，不是“谁更聪明”，而是谁能把自己的判断过程留下来并反复校正。

#### 1.2.2 研究型决策者的四个核心特征

#### 1. 先研究，再决定是否值得继续跟

不是看到机会就急着参与，而是先判断这份研究是否足够支撑它进入观察池，或者进一步进入执行准备。

#### 2. 把观察型和执行准备型分开

一份报告可以值得继续跟踪，但还不够支撑更进一步的动作。能不能把这两者分开，是成熟度很高的一条分界线。

#### 3. 持仓后继续重评，不把盈利自动当成逻辑成立

价格先走出来，并不等于核心逻辑已经证实。进入持仓阶段后，仍然需要根据财报、问询、行业进展、风险焦点和用户版视图持续复核原判断。

#### 4. 用复盘纠偏，而不是只看一次结果

真正有价值的复盘，重点不是高分低分，而是：

- 这次做对了什么；
- 暴露了什么问题；
- 偏离计划的地方在哪；
- 哪些问题重复出现，已经值得写回自己的系统。

#### 1.2.3 交易计划在这一版课程里的正确定位

交易计划仍然重要，但它在当前课程里的位置已经发生了变化。

它不该再被理解成一张统一的买卖脚本，而应该被理解成：

1. 你的研究框架；
2. 你的执行边界；
3. 你的复盘纪律；
4. 你的版本迭代记录。

它的详细建立方法会在第 23 课展开，但从第 1 课开始，你就应该知道：

**计划不是替你做决定的模板，而是帮助你以后能解释自己、约束自己、修正自己的工作底稿。**

### 1.3 当前系统真实能帮你做什么？

我们的 AI 系统不是一个“自动替你交易”的机器，而是一个把研究、跟踪、复盘和纠偏做得更稳定的辅助系统。

#### 1.3.1 系统和用户的分工

```text
系统负责：
- 汇总多源数据
- 组织多智能体研究
- 输出研究摘要、用户版研究简报和综合结论
- 在持仓阶段整理风险焦点、机会信号和后续观察事项
- 在复盘阶段总结优点、问题、改进重点和计划偏离
- 评估个人交易计划的完整性和一致性

用户负责：
- 理解研究结论和关键限制
- 决定是否纳入观察、是否升级判断
- 决定是否在模拟或实盘环境中执行
- 决定自己的风险暴露边界
- 把复盘问题回写到个人计划
```

这条分工必须非常清楚。

系统可以给你高质量研究和复核线索，但不会替你承担最终判断，也不应该输出面向未来的动作脚本。

#### 1.3.2 当前系统的三类核心输出

#### 1. 单股研究输出

当前真实单股研究更重要的部分，主要包括：

- 研究摘要；
- 用户版研究简报；
- 综合研究结论；
- 核心依据；
- 关键不确定性；
- 判断调整条件；
- 后续观察事项；
- 多空辩论与风险治理结论。

这些内容解决的不是“立刻怎么做”，而是“当前能看到什么、还缺什么、接下来该盯什么”。

#### 2. 持仓研究输出

进入持仓后，系统不会只盯价格，而是围绕：

- 当前结论；
- 结论依据；
- 风险评估；
- 机会评估；
- 用户版视图；
- 研究附录。

它的作用是帮助你检查：原判断是否仍成立，哪些风险升级了，哪些机会信号出现了，哪些证据节点必须重评。

#### 3. 交易复盘输出

当前真实交易复盘报告更重要的部分，主要是：

- 复盘结论；
- 做得好的地方；
- 暴露的问题；
- 后续改进重点；
- 时机、仓位、情绪、归因的文字分析；
- 计划执行良好之处；
- 偏离计划之处。

这里的核心不是“分数高低”，而是通过文字化复盘把问题归位。

#### 1.3.3 还要再加上一层：个人计划与版本迭代

当前平台里的个人交易计划模块，除了创建和编辑，还支持：

- AI 评估；
- 评估历史；
- 与 AI 讨论优化建议；
- 版本管理。

这意味着课程中的“成长”不该再写成模糊口号，而应该落到一个真实闭环：

```text
研究
-> 跟踪
-> 复盘
-> 计划评估
-> 版本修订
-> 下一轮验证
```

这条链路一旦建立起来，系统才真正开始帮你成长。

### 1.4 AI 多智能体协作，为什么能帮你更少凭感觉？

#### 1.4.1 它的价值不在“更会下指令”，而在“更会整理视角”

传统散户常见的问题，是把单一信号误当成完整判断：

- 看见走势强，就觉得逻辑成立；
- 看见估值低，就觉得一定有价值；
- 看见消息热，就觉得应该跟上。

AI 多智能体协作的价值，是把这些不同维度拆开看，再重新组合。

在当前系统里，更接近真实研究团队的工作顺序是：

1. 大盘、行业、技术、基本面、新闻、情绪等分析师先并行提供素材；
2. 乐观情景与审慎情景做观点碰撞；
3. 风险角色对不同情景进行再过滤；
4. 最后输出研究摘要、用户版简报和综合研究结论。

这个结构最大的好处，是让你看到：

- 支持结论的证据来自哪里；
- 反对结论的证据来自哪里；
- 哪些问题仍然没有答案；
- 现在最适合保持什么强度的判断。

#### 1.4.2 当前课程里，单股研究该怎么理解

到了 v2.0 口径，单股研究最重要的不是“生成一个动作结论”，而是把下面四件事说清楚：

1. 当前方向是什么；
2. 为什么这么看；
3. 为什么还不能更乐观或更悲观；
4. 下一步到底要观察什么公开信号。

也就是说，单股研究不是把复杂问题变成一句命令，而是把复杂问题拆成一组可继续核对的证据。

#### 1.4.3 从“凭感觉”到“有依据”的真正转变

这种转变不是让你变得更依赖 AI，而是让你更容易回答这些问题：

- 这次判断的核心依据是什么？
- 这次判断最大的限制是什么？
- 我现在是在观察，还是已经具备更强的准备度？
- 如果后续信息和现在相反，我应该先看哪一条证据？

只要你越来越能回答这些问题，就说明你正在从“跟着波动走”转向“跟着证据走”。

### 1.5 可进化投资法的核心，不是更激进，而是更能纠偏

#### 1.5.1 什么叫“可进化”？

在这套课程里，“可进化”不是指：

- 每次都更大胆；
- 每次都改更多参数；
- 每次都希望更快赚到结果。

它真正的含义是：

**你能不能把重复出现的问题稳定识别出来，并把它们写回自己的系统。**

#### 1.5.2 当前产品对应的真实闭环

```text
观察池筛选
-> 单股研究
-> 判断是观察型还是执行准备型
-> 持仓后持续做持仓研究
-> 交易完成后做复盘
-> 把暴露的问题、后续改进重点、偏离计划之处写回个人计划
-> 做 AI 评估和版本迭代
-> 用下一轮样本继续验证
```

这才是当前课程应该讲的“可进化闭环”。

#### 1.5.3 当前真正值得优化的，不是分数本身

当前系统里仍然保留了一些评分字段，但第 1 课就应该先讲清楚：

- 分数可以帮助你排序检查优先级；
- 分数不能替代文字结论；
- 分数不能代替暴露的问题、后续改进重点和偏离计划之处；
- 分数更不能重新变成课程的主轴。

真正更有价值的优化信号通常是：

1. 同类问题是否反复出现；
2. 计划偏离是否减少；
3. 持仓研究里的关键风险是否更早进入你的复核列表；
4. 计划修订是否越来越有针对性，而不是越来越混乱。

#### 1.5.4 一个更符合当前口径的成长路径

与其讲“从散户到高手”的空口号，不如用当前平台真实支持的四个阶段来理解成长：

#### 阶段 1：记录型用户

- 开始看研究摘要和用户版研究简报；
- 开始保存复盘和持仓研究样本；
- 先把过程留痕。

#### 阶段 2：复核型用户

- 能说清楚哪些是核心依据，哪些是不确定性；
- 能区分观察型和更进一步的判断强度；
- 不再把波动本身当成全部信息。

#### 阶段 3：版本化用户

- 能把复盘里的重复问题回写到自己的计划；
- 能用 AI 评估检查计划的结构缺口；
- 开始保留版本变化记录。

#### 阶段 4：迭代型用户

- 同类偏差逐步减少；
- 复盘越来越聚焦真实根因；
- 对研究、跟踪和纪律之间的关系越来越清楚。

这四个阶段不夸张，但更真实，也更可执行。

#### 1.5.5 一个简化案例：从追热点到会纠偏

下面这个例子，比“靠三轮提分变高手”更符合当前课程口径。

#### 第一轮

小王看到一只热门股票很强，原本准备直接跟进。但当他第一次认真看完研究摘要和用户版研究简报后，发现：

- 现在只有情绪支持；
- 关键财务和风险证据仍然缺失；
- 更适合进入观察，而不是急着升级判断。

这一步的进步，不是“赚了多少”，而是第一次学会了**不因为热度就自动推进动作**。

#### 第二轮

后来小王对另一只标的进行了跟踪，进入了持仓阶段。持仓研究不断提醒他：

- 当前盈利虽然出现，但核心逻辑仍待验证；
- 财报和公告是下一次必须复核的节点；
- 风险焦点还没有解除。

而复盘报告又指出：

- 他在关键节点前没有做足复核；
- 虽然结果不差，但过程里存在偏离计划之处。

这一步的进步，是第一次知道：

**盈利并不自动等于过程正确。**

#### 第三轮

小王把复盘里反复出现的问题，写进了自己的交易计划：

- 财报、问询、行业关键数据披露后必须复核；
- 没有补齐关键证据时，不得把判断从观察自动升级；
- 每次复盘后都要记录偏离计划的地方。

之后他再做新一轮样本时，同类偏差开始减少。

这才是真正有价值的“进化”：

不是更会追求结果，而是更会修正自己。

### 1.6 本课小结与思考

#### 本课要点回顾

1. 散户最核心的问题，不只是情绪化，而是缺少可复核的证据链和统一边界；
2. 当前课程要培养的，不是照着系统下指令的人，而是能读研究、能做复核、能做纠偏的人；
3. 当前系统最真实的价值，在于提供单股研究、持仓研究、交易复盘、计划评估与版本迭代支持；
4. 可进化投资法的核心，不是调出更激进的系统，而是把重复问题稳定写回自己的方法；
5. 从第 1 课开始，就要把“最终判断由用户负责”这条边界放在最前面。

#### 思考题

1. 回顾你过去的一次操作，你现在能不能说清楚当时的核心依据、最大不确定性和应当重评的条件？
2. 你更常见的问题，是研究不完整、持仓后不复核，还是事后不沉淀？
3. 如果一份研究报告只能告诉你“看起来不错”，却说不清关键限制和后续观察事项，你会把它当成高质量研究吗？为什么？
