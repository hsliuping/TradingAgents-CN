## 13.1 为什么风险管理如此重要？

### 13.1.1 一个数学事实

```
亏损与回本的关系
│
├── 亏损10% → 需要上涨11%才能回本
├── 亏损20% → 需要上涨25%才能回本
├── 亏损30% → 需要上涨43%才能回本
├── 亏损40% → 需要上涨67%才能回本
├── 亏损50% → 需要上涨100%才能回本
└── 亏损80% → 需要上涨400%才能回本
```

**结论**：亏损越大，回本越难。风险管理的核心是**避免大亏**。

### 13.1.2 风险管理的核心理念

```
风险管理的核心理念
│
├── 保护本金
│   └── 本金是你的"子弹"，没有子弹就无法战斗
│
├── 控制亏损
│   └── 小亏是正常的，大亏是致命的
│
├── 活得久比赚得多更重要
│   └── 只要还在市场，就有机会
│
└── 风险与收益成正比
    └── 高收益必然伴随高风险，要学会平衡
```

## 13.2 什么是风险辩论？

### 13.2.1 风险辩论的定义

风险辩论是系统对投资风险的全面分析，它从多个维度评估一只股票的风险。

```
┌─────────────────────────────────────────────────────────────┐
│                       风险辩论                               │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   ┌─────────────────────────────────────────────────────┐  │
│   │                  风险分析维度                         │  │
│   ├─────────────────────────────────────────────────────┤  │
│   │                                                      │  │
│   │  市场风险 ──── 大盘下跌、系统性风险、黑天鹅事件       │  │
│   │                                                      │  │
│   │  行业风险 ──── 行业政策、竞争格局、技术替代           │  │
│   │                                                      │  │
│   │  公司风险 ──── 经营风险、财务风险、管理层风险         │  │
│   │                                                      │  │
│   │  估值风险 ──── 估值过高、泡沫风险、增速不匹配         │  │
│   │                                                      │  │
│   │  流动性风险 ── 成交量低、换手率低、停牌风险           │  │
│   │                                                      │  │
│   └─────────────────────────────────────────────────────┘  │
│                                                             │
│   ┌─────────────────────────────────────────────────────┐  │
│   │                  风险评估结果                         │  │
│   ├─────────────────────────────────────────────────────┤  │
│   │  风险等级：低 / 中 / 高                               │  │
│   │  主要风险点：XXX                                      │  │
│   │  风险应对建议：XXX                                    │  │
│   └─────────────────────────────────────────────────────┘  │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 13.2.2 五大风险类型详解

**1. 市场风险（系统性风险）**

```
市场风险
│
├── 定义
│   └── 整个市场下跌带来的风险，无法通过分散投资消除
│
├── 来源
│   ├── 宏观经济下行
│   ├── 货币政策收紧
│   ├── 地缘政治事件
│   └── 黑天鹅事件（如疫情）
│
├── 特点
│   ├── 影响所有股票
│   ├── 无法通过选股避免
│   └── 只能通过仓位控制应对
│
└── 应对方法
    ├── 控制总仓位
    ├── 熊市轻仓
    └── 保留现金
```

**2. 行业风险**

```
行业风险
│
├── 定义
│   └── 特定行业面临的风险
│
├── 来源
│   ├── 行业政策变化（如教培行业）
│   ├── 技术替代（如传统汽车被新能源替代）
│   ├── 竞争加剧
│   └── 行业周期下行
│
├── 特点
│   ├── 影响整个行业
│   ├── 可以通过行业分散避免
│   └── 需要关注政策和技术变化
│
└── 应对方法
    ├── 分散投资不同行业
    ├── 关注行业政策
    └── 避免夕阳行业
```

**3. 公司风险（个股风险）**

```
公司风险
│
├── 定义
│   └── 特定公司面临的风险
│
├── 来源
│   ├── 业绩下滑
│   ├── 财务造假
│   ├── 管理层变动
│   ├── 重大诉讼
│   └── 产品质量问题
│
├── 特点
│   ├── 只影响特定公司
│   ├── 可以通过分散投资降低
│   └── 需要深入研究公司
│
└── 应对方法
    ├── 分散投资多只股票
    ├── 深入研究公司基本面
    └── 设置止损
```

**4. 估值风险**

```
估值风险
│
├── 定义
│   └── 股价高于内在价值带来的风险
│
├── 来源
│   ├── PE过高
│   ├── 增速不匹配估值
│   ├── 市场情绪过热
│   └── 泡沫
│
├── 特点
│   ├── 高估值股票下跌空间大
│   ├── 需要判断合理估值
│   └── 与市场情绪相关
│
└── 应对方法
    ├── 关注估值指标（PE、PB、PEG）
    ├── 与历史和同行比较
    └── 避免追高
```

**5. 流动性风险**

```
流动性风险
│
├── 定义
│   └── 无法以合理价格买卖股票的风险
│
├── 来源
│   ├── 成交量低
│   ├── 换手率低
│   ├── 停牌
│   └── 小盘股
│
├── 特点
│   ├── 买卖困难
│   ├── 滑点大
│   └── 可能无法及时止损
│
└── 应对方法
    ├── 选择成交量大的股票
    ├── 避免小盘股
    └── 分批买卖
```

## 13.3 风险等级的含义

### 13.3.1 风险等级定义

| 风险等级 | 含义 | 特征 |
|---------|------|------|
| **低风险** | 风险可控，安全边际足 | 基本面稳健、估值合理、行业稳定 |
| **中风险** | 存在一定风险，需关注 | 有一些风险点，但整体可控 |
| **高风险** | 风险较大，需谨慎 | 多个风险点，不确定性大 |

> **重要提示**：以下表格是**你的个人决策框架**，不是AI系统输出的建议。

> 下表是一个通用参考，你应根据自身风险承受能力调整。

## 13.4 AI风险辩论深度解读

### 13.4.1 风险辩论的工作流程

TradingAgentsCN系统的风险辩论功能通过**三个风险分析师**从不同稳健性视角审阅研究结论，最后由**风险经理**综合各方观点，形成最终的风险治理结论。

> **核心理解**：风险辩论不是"投资风险偏好的分组讨论"，而是"从三个角度检验当前研究结论是否站得住脚"。
> 三位分析师不是代表三类投资者，而是同一位严谨研究者从不同质疑角度出发的分析视角。

```
风险辩论工作流程
│
├── 阶段1：研究简报输入
│   └── 研究经理输出的研究简报（多空辩论共识、关键分歧与信息缺口）
│
├── 阶段2：三个风险分析师并行审阅（研究结论稳健性视角）
│   ├── 高弹性情景分析师（risky_analyst_v2）🔥
│   │   └── 审阅：研究结论能否上修？需要哪些额外证据？
│   │
│   ├── 防御情景分析师（safe_analyst_v2）🛡️
│   │   └── 审阅：研究结论最容易在哪里失效？前提最脆弱的地方？
│   │
│   └── 基准情景分析师（neutral_analyst_v2）⚖️
│       └── 审阅：当前最经得起证据检验的基准情景是什么？
│
├── 阶段3：风险辩论（多轮）
│   ├── 第一轮：三个分析师各自发表稳健性审阅观点
│   ├── 第二轮：分析师互相补充和质疑对方的审阅结论
│   └── 第三轮（可选）：进一步辩论
│
└── 阶段4：风险经理综合风险治理结论
    └── 综合三方观点，形成风险等级、关键风险清单、研究谨慎度要求、后续观察重点
```

### 13.4.2 三个风险分析师的对比

> **一个关键认知**：三位分析师的区别不是"谁更激进/谁更保守"，而是"他们问的是哪个方向的问题"。
> - 高弹性情景分析师问：**"还差什么证据，才能支撑更乐观的判断？"**
> - 防御情景分析师问：**"哪个前提假设最容易崩塌？"**
> - 基准情景分析师问：**"综合来看，现在最稳妥的情景是什么？"**

---

#### 高弹性情景分析师（Risky Analyst v2.0）🔥

**审阅视角**：研究结论的**上修空间**

**关注重点**：
- 🔥 **上修依赖**：当前研究结论如果要更乐观，还需要哪些额外证据或更强的证据？
- 📈 **催化条件**：哪些公开信号出现后，可以支撑更积极的研究判断？
- 🔍 **偏保守诊断**：当前研究结论是否过于保守？是否低估了某些积极因素？
- ⚡ **证据门槛**：达到上修所需的最低验证条件是什么？

**输出内容**（高弹性审阅观点）：
- 当前研究结论中，哪些地方存在上修空间
- 若要支撑更乐观判断，需要哪些额外证据
- 当前被低估或未充分挖掘的积极因素
- 接下来值得优先追踪的高弹性信号

**注意**：高弹性情景分析师**不是"鼓励你大仓位冒险"**，它的作用是帮你理解：
> 如果后续某个条件成立，研究结论有没有可能变更乐观——这是纯研究层面的问题，不是操作建议。

**示例输出**：
```
【高弹性情景审阅】

上修空间识别：
- 研究简报对公司盈利能力的判断偏中性，主要依赖2023年数据
- 若Q1业绩兑现超预期，盈利质量判断可以上修至"偏积极"
- 行业政策利好目前仅作为"可能性"描述，若政策细则落地，
  支撑强度可以从"待验证"升级为"已确认"

当前被低估的积极因素：
- 技术面指标组合（MACD金叉 + 布林带中轨支撑）尚未在研究
  结论中得到充分权重
- 行业资金流入信号连续3周净流入，审慎情景研究员对此未充分回应

上修所需验证条件：
- 下季度业绩超预期
- 政策文件正式发布
- 行业资金流入维持当前趋势至少4周

当前判断：研究结论上修空间存在，但触发条件仍待验证
```

---

#### 防御情景分析师（Safe Analyst v2.0）🛡️

**审阅视角**：研究结论的**失效风险**

**关注重点**：
- 🛡️ **脆弱前提**：当前研究结论最依赖哪个前提假设？这个前提有多可靠？
- ⚠️ **失效条件**：哪个风险出现后，研究结论会被推翻或显著削弱？
- 🔒 **下修诊断**：当前研究结论是否过于乐观？是否忽略了某些重要风险？
- 📉 **风险证据**：哪些已知信息指向风险，但在当前研究结论中权重不足？

**输出内容**（防御审阅观点）：
- 当前研究结论中，哪些前提假设最不稳固
- 使研究结论失效所需的触发条件
- 当前被忽视或低估的风险因素
- 最值得持续盯防的失效信号

**注意**：防御情景分析师**不是"劝你不要参与"**，它的作用是帮你理解：
> 如果哪个条件发生了变化，你当前的研究判断是否还站得住脚——这也是纯研究层面的问题。

**示例输出**：
```
【防御情景审阅】

脆弱前提识别：
- 当前研究结论偏积极的最核心前提：大客户订单保持稳定
- 但大客户集中度高（前五大客户占比60%），这个前提风险较高
- 研究简报中仅作"当前数据显示稳定"，缺乏前瞻性验证

失效条件：
- 如大客户采购计划出现收缩迹象，研究结论须下修
- 3个月后大额解禁若引发集中减持，市场面压力将显著增加
- 估值已高于行业平均，若市场风险偏好下降，容错空间压缩

当前被低估的风险：
- 解禁压力在研究简报中提及不足
- 竞争对手新品发布时间与观察窗口重叠

关键失效信号（需持续观察）：
- 大客户公告或采购季度数据
- 解禁后前两周的成交异常
```

---

#### 基准情景分析师（Neutral Analyst v2.0）⚖️

**审阅视角**：**当前最稳妥的基准情景**

**关注重点**：
- ⚖️ **证据权衡**：综合高弹性和防御两方审阅，哪个情景现在最经得起证据检验？
- 📊 **已验证 vs 待验证**：明确区分哪些结论基于已确认事实，哪些仍需验证
- 🎯 **信息缺口**：当前最影响判断的信息缺口在哪里？
- 🔍 **监测信号**：接下来最值得持续跟踪的公开信号是什么？

**输出内容**（基准情景判断）：
- 当前最稳妥的基准情景描述（不是平均，而是判断）
- 已验证证据 / 仍待验证证据 / 暂时无法判断的事项
- 最关键的共识点与分歧点
- 后续最值得跟踪的观察信号

**重要原则**：如果高弹性和防御双方的证据都不够充分，基准情景分析师可以直接写"信息不足，维持观望"。不会为了"保持平衡"而强行给出折中结论。

**示例输出**：
```
【基准情景审阅】

当前基准情景：
- 综合现有证据，最稳妥的情景是"偏中性，但存在上行弹性"
- 该情景比单纯乐观更稳妥的原因：解禁压力是确定性事件，
  不能忽略；但上修空间的证据质量也较高

证据状态分层：
- 已验证：基本面盈利能力稳健（3年数据支持）、技术面短期
  趋势向上（MACD金叉已出现）
- 仍待验证：Q1业绩超预期、政策细则落地
- 暂时无法判断：大客户季度采购数据（下周公布）

关键共识（多空双方均认可）：
- 基本面具备一定抗风险能力
- 解禁压力是近期最确定的短期不利因素

核心分歧：
- 高弹性视角：上行证据已充分，上修条件可以提前布局
- 防御视角：大客户集中风险未被充分权衡，应等待季报验证

当前基准情景维持不变的条件：
- 大客户采购数据无重大变化
- 解禁期无集中减持信号

最值得跟踪的公开信号：
1. 下周大客户采购数据公告
2. 解禁日后前两周的成交量异常
```

### 13.4.3 如何从风险辩论中提取关键信息

#### 提取框架

**第一步：识别三个视角各自的核心结论**

```
三个视角提取
│
├── 从高弹性情景分析师提取
│   └── 研究结论的上修空间在哪里？触发条件是什么？
│
├── 从防御情景分析师提取
│   └── 研究结论最脆弱的前提是什么？失效条件是什么？
│
└── 从基准情景分析师提取
    └── 当前最稳妥的情景是什么？共识与分歧各是什么？
```

**第二步：识别三方共识**

三个分析师都认同的风险或条件，往往是最值得重视的：

```
共识识别
│
├── 如果三方都提到某个风险 → 这是高确定性风险
├── 如果两方提到 → 这是中等确定性风险
└── 如果只有一方提到 → 这是待验证风险，需要自己判断
```

**第三步：识别关键分歧**

三方观点中存在实质性分歧的地方，往往指向当前信息最不确定的地方：

```
分歧识别
│
├── 高弹性 vs 防御的分歧 → 通常是"机会成本 vs 失效风险"的权衡
├── 基准 vs 任意一方的分歧 → 通常是"证据充分性"的判断差异
└── 关注：基准情景分析师是否认为分歧已足够明确？
```

**第四步：识别最优先跟踪的信号**

综合三方，提取出最值得在接下来持续观察的公开信号清单：

```
信号优先级
│
├── 高优先级：基准情景分析师和防御情景分析师都提到的观察信号
├── 中优先级：只有一方提到的信号
└── 低优先级：高弹性分析师提到但防御和基准都未重视的信号
```

### 13.4.4 风险经理（Risk Manager）的综合结论解读

**风险经理（Risk Manager v2.0）**综合三个风险分析师的审阅结论，形成最终的风险治理结论。

#### 风险经理的职责

```
风险经理的职责
│
├── 综合研判（不是平均，而是判断）
│   ├── 提炼三方共识
│   ├── 识别最关键的风险分歧
│   └── 判断哪些风险已足以限制研究结论
│
├── 形成风险治理结论
│   ├── 风险等级（低/中/高）
│   ├── 关键风险清单（最重要的待验证条件）
│   ├── 研究谨慎度要求（结论可以放多大的权重）
│   └── 判断调整原则（哪些信号出现后需要重新判断）
│
└── 输出综合研究结论（final_trade_decision字段）
    └── 注意：字段名含"trade"是历史兼容设计，实际内容是研究结论，不是交易指令
```

#### 风险治理结论的解读

**报告结构**：

```
风险治理结论结构
│
├── 风险等级
│   └── 低风险 / 中风险 / 高风险
│
├── 关键风险清单
│   ├── 风险1：XXX（确定性+影响程度）
│   ├── 风险2：XXX
│   └── 风险3：XXX
│
├── 研究谨慎度要求
│   ├── 结论可信度：高/中/低
│   └── 建议验证后再使用的内容
│
├── 判断调整原则
│   └── 哪些信号出现时，应重新审视研究结论
│
└── 综合研究结论（研究结果摘要）
    └── 基于以上风险治理，当前整体判断是什么
```

**解读要点**：

1. **风险等级**：
   - **低风险**：研究证据充分，待验证条件较少，结论可以给予较高权重
   - **中风险**：存在若干待验证条件，结论可用但要明确边界
   - **高风险**：关键前提仍不确定，结论仅供参考，需等待更多证据

2. **关键风险清单**：
   - 重点关注被标记为"高确定性"的风险
   - 这些风险与你的实际持仓/观察计划需要匹配

3. **综合研究结论**：
   - 这是研究层面的综合判断，不是买卖指令
   - 你需要基于这个判断，自己决定是否参与、如何管理持仓

4. **研究谨慎度**：
   - 直接告诉你当前报告的置信边界
   - 谨慎度越高，表示当前更应该等待，而不是立刻行动

### 13.4.5 实战：利用风险辩论做研究验证

#### 案例：某科技股的风险辩论解读

**背景**：研究经理已输出研究简报，综合判断偏多，但提到大客户集中度高和近期解禁两个待验证风险。

**步骤1：查看风险辩论报告**

进入"单股研究"页面，选择股票，提交分析，等待结果。

**步骤2：阅读三个分析师的稳健性审阅**

**高弹性情景分析师输出**：
```
【高弹性情景审阅】

上修空间识别：
- 研究结论对公司盈利质量的判断偏中性，主要依赖最新年报
- 若Q1季报显示盈利提速，当前"偏积极偏保守"的结论可以上修
- 行业政策利好目前是"待验证"，若细则落地，支撑强度升级

当前被低估的积极因素：
- MACD金叉+布林带中轨支撑，技术面信号质量较高，研究结论
  中这部分证据权重偏低

上修所需验证条件：
- Q1业绩报告超预期
- 行业政策细则正式发布
- 板块资金净流入维持4周以上

当前判断：上修空间存在，但触发条件仍待验证
```

**防御情景分析师输出**：
```
【防御情景审阅】

脆弱前提：
- 研究结论偏积极的核心前提：大客户订单稳定
- 大客户集中度60%，这个前提风险较高，研究结论对此权重不足

失效条件：
- 若大客户季报显示采购收缩，研究结论须立即下修
- 3个月后解禁是确定性事件，若引发集中减持，市场面压力显著增加
- 估值已在行业均值偏上，容错空间有限

当前被低估的风险：
- 解禁量占总股本20%，在研究简报中仅作边注提及，权重不足

关键失效信号（持续观察）：
- 大客户公告或季度采购数据
- 解禁后前两周的成交异常
```

**基准情景分析师输出**：
```
【基准情景审阅】

当前基准情景："偏中性，存在上行弹性，但解禁是近期确定性约束"

证据状态分层：
- 已验证：盈利能力稳健（年报数据支持）、技术面短期趋势向上
- 仍待验证：Q1业绩超预期、政策细则落地
- 暂时无法判断：大客户下季度采购数据

三方共识：
- 解禁是近期最确定的不利因素
- 基本面具备一定支撑

核心分歧：
- 高弹性视角：上行证据已充分，可以开始关注
- 防御视角：大客户集中风险未被充分权衡，应先等季报

最值得跟踪：
1. 大客户下季度采购数据公告
2. 解禁日后两周成交异常
```

**步骤3：识别共识与关键分歧**

```
三方共识（确定性较高，需要重视）：
├── 解禁压力是近期最确定的不利因素
└── 基本面具备一定支撑（均认可，无分歧）

关键分歧：
├── 高弹性 vs 防御：上行证据是否已充分 → 待季报验证后判断
└── 基准情景：偏中性，不支持在待验证条件确认前贸然行动
```

**步骤4：查看风险经理综合结论**

```
【风险治理结论】

风险等级：中风险

关键风险清单：
1. 大客户集中度高（确定存在，影响中等）→ 须跟踪季报
2. 解禁压力（3个月后确定发生，影响中等）→ 解禁前需重新评估
3. 估值偏高（估值略高，容错有限，影响低中）

研究谨慎度要求：
- 当前研究结论有效，但大客户季报和解禁两个条件验证前，
  结论使用需保持谨慎

判断调整原则：
- 若季报显示大客户采购收缩 → 研究结论转向审慎
- 若解禁后出现集中减持信号 → 研究谨慎度升级
- 若Q1业绩超预期且政策落地 → 研究结论可考虑上修

综合研究结论：
- 整体来看，当前证据支持偏中性到偏积极的研究方向，但两个
  待验证风险（大客户季报、解禁）限制了当前结论的强度。
- 建议持续跟踪，待大客户季报公布后再决定是否调整研究结论。
```

**步骤5：基于研究结论，制定你自己的跟踪计划**

> **提示**：以下是你作为用户的自主决策过程，AI不替你做这些决定。

**我的研究跟踪计划**：
1. **结论理解**：
   - AI研究结论：偏中性偏积极，但解禁和大客户是两个重要待验证约束
   - 当前不适合把研究结论视为强确认，应作为"值得跟踪"处理

2. **观察安排**：
   - 关注大客户下季度采购数据公告（最高优先级）
   - 解禁日前一个月开始重点观察市场面异动

3. **自己的仓位/止损决策**（与AI无关，自主决定）：
   - 如果参与，根据中风险等级参考上限（≤20%），结合个人情况设定
   - 止损位自行根据技术面设定，AI不提供价格建议

4. **何时重新分析**：
   - 大客户季报公布后立即重新跑一次AI研究

**步骤6：记录研究计划**

在"笔记"或"研究记录"中记录：
- 当前AI研究结论和风险等级

1. 进入"单股研究"页面

**默认配置**：

  - 1级深度：1轮
  - 2级深度：1轮
  - 3级深度：2轮
  - 4级深度：2轮

1. 找到三个风险分析师节点：
   - `risky_analyst_v2`（激进）

   - `neutral_analyst_v2`（中性）

2. 配置每个分析师的提示词：
   - 进入"Agent配置"页面
   - 找到对应的风险分析师
   - 修改系统提示词和用户提示词
   - 可以调整分析师的评估重点和风格

1. 找到"风险管理者"节点（`risk_manager_v2`）
2. 配置参数：
   - **偏好类型**（preference_type）：
     - `aggressive`（激进）：偏向激进观点
     - `neutral`（中性）：平衡各方观点（默认）
     - `conservative`（保守）：偏向保守观点

3. 配置提示词：
   - 进入"Agent配置"页面
   - 找到"风险管理者"
   - 修改系统提示词和用户提示词
   - 可以调整风险管理者的决策风格

### 13.5.3 如何调整风险偏好

#### 在单股研究中调整风险偏好

**操作步骤**：
1. 进入"单股研究"页面
2. 选择股票，设置分析参数
3. 在"偏好类型"中选择：
   - **激进**：风险经理偏向关注上修空间，对待验证证据容忍度更高
   - **中性**：风险经理平衡三方观点，归纳共识与分歧（默认）
   - **保守**：风险经理偏向关注失效风险，对待验证条件要求更严格

**影响**：
- **激进偏好**：
  - 风险经理会更关注研究结论的上修空间
  - 对潜在证据不足的乐观判断容忍度更高
  - 风险等级评估可能偏低

- **中性偏好**（默认）：
  - 风险经理平衡三方审阅论据，归纳共识与分歧
  - 研究结论的谨慎度要求较平衡
  - 风险等级评估较为客观

- **保守偏好**：
  - 风险经理会更关注研究结论的失效风险和谨慎度要求
  - 对待验证条件要求更严格
  - 风险等级评估可能偏高

#### 在工作流中调整风险偏好

**步骤1：修改风险管理者配置**

1. 在分析流管理页面中，点击"编辑"按钮，进入分析流编辑器
2. 找到"风险管理者"节点
3. 在节点配置中添加：
   ```json
   {
     "preference_type": "conservative"  // 或 "aggressive", "neutral"
   }
   ```

**步骤2：修改风险管理者提示词**

1. 进入"Agent配置"页面
2. 找到"风险管理者"
3. 选择对应的偏好类型（激进/中性/保守）
4. 修改系统提示词和用户提示词
5. 保存配置

### 13.5.4 如何解读风险评分

#### 风险评分的含义

风险管理者会给出一个**风险得分**（0-100分），对应不同的风险等级：

| 风险得分 | 风险等级 | 含义 | 用户仓位参考上限 | 止损参考 |
|---------|---------|------|---------|---------|
| **0-30分** | 低风险 | 研究证据充分，陈述边界清晰 | ≤30%（用户自定） | 8-10%（用户自定） |
| **31-60分** | 中风险 | 存在待验证条件，研究结论谨慎使用 | ≤20%（用户自定） | 5-8%（用户自定） |
| **61-100分** | 高风险 | 关键前提不确定，谨慎使用结论 | ≤10%（用户自定） | 3-5%（用户自定） |

#### 风险评分的解读

**低风险（0-30分）**：
- ✅ 研究证据充分，陈述前提清晰
- ✅ 行业稳定，无明显失效风险
- ✅ 结论可用，用户可按个人风险偏好设定仓位（参考上限≤30%）
- ✅ 止损由用户根据技术面自行设定

**中风险（31-60分）**：
- ⚠️ 存在若干待验证条件，结论需谨慎使用
- ⚠️ 需关注风险经理列出的主要风险点
- ⚠️ 用户可参考仓位上限≤20%，具体分配自定
- ⚠️ 止损不宜设得过宽

**高风险（61-100分）**：
- ❌ 关键前提仍待验证，结论确定性低
- ❌ 建议等待风险经理列出的关键信号后再重新评估
- ❌ 用户如参与，仓位上限≤10%，具体分配自定
- ❌ 止损应设得较紧

#### 风险评分的影响因素

风险评分会受到以下因素的影响：

```
风险评分影响因素
│
├── 市场风险
│   ├── 大盘趋势：下跌趋势 → 风险得分+10
│   ├── 市场情绪：悲观 → 风险得分+5
│   └── 系统性风险：高 → 风险得分+15
│
├── 行业风险
│   ├── 行业政策：利空 → 风险得分+10
│   ├── 行业竞争：激烈 → 风险得分+5
│   └── 行业周期：下行 → 风险得分+10
│
├── 公司风险
│   ├── 业绩：下滑 → 风险得分+15
│   ├── 财务：问题 → 风险得分+20
│   ├── 大客户集中度：高 → 风险得分+10
│   └── 解禁压力：大 → 风险得分+10
│
├── 估值风险
│   ├── PE：过高 → 风险得分+10
│   ├── 估值泡沫：存在 → 风险得分+15
│   └── 增速不匹配：是 → 风险得分+10
│
└── 流动性风险
    ├── 成交量：低 → 风险得分+5
    └── 停牌风险：存在 → 风险得分+10
```

### 13.5.5 实战：创建个人风险管理流程

#### 案例：创建保守型风险管理流程

**需求**：创建一个更保守的风险管理流程，优先保护本金。

**步骤1：创建分析流程副本**

1. 进入"分析流管理"页面
2. 找到"v2.0单股研究工作流"
3. 点击"复制"按钮，创建副本
4. 重命名为"保守型风险分析流程"

**步骤2：配置风险辩论节点**

1. 在分析流管理页面中，点击"编辑"按钮，进入分析流编辑器
2. 找到"风险辩论"节点
3. 配置参数：
   - **辩论轮次**：设置为3轮（增加辩论深度）
   - **参与者**：保留所有三个分析师

**步骤3：配置风险管理者节点**

1. 找到"风险管理者"节点
2. 在节点配置中添加：
   ```json
   {
     "preference_type": "conservative"
   }
   ```

**步骤4：修改风险管理者提示词**

1. 进入"Agent配置"页面
2. 找到"风险管理者"
3. 选择"保守"偏好类型
4. 修改系统提示词：
   ```
   你是一位保守倾向的风险治理经理。
   
   你的职责是审阅研究结论的稳健性，并把风险分歧整理成最终的综合研究结论。
   
   工作重点：
   1. 更严格地要求待验证条件得到充分确认，再提升结论强度
   2. 对研究结论的失效风险给予更大权重
   3. 如信息不足，明确写出"材料待验证"，不得补造强结论
   4. 风险等级评估偏保守，宁可降低结论强度也不过度乐观
   
   请使用中文，严禁输出目标价、仓位建议、止损建议。
   ```
5. 保存配置

**步骤5：测试工作流**

1. 进入"单股研究"页面
2. 选择"保守型风险分析流程"
3. 选择一只股票，提交分析
4. 查看风险辩论结果，验证是否符合保守型要求

**步骤6：调整和优化**

根据测试结果，调整：
- 风险辩论轮次
- 风险管理者提示词
- 风险评分标准

## 13.6 本课小结与思考

### 本课要点回顾

1. **风险管理的重要性**：避免大亏，保护本金
2. **五大风险类型**：市场、行业、公司、估值、流动性
3. **风险等级**：低/中/高，对应不同仓位策略
4. **AI风险辩论**：
   - 三个风险分析师（激进、保守、中性）从不同角度评估
   - 风险管理者综合各方观点，形成最终风险评估
5. **风险管理工作流配置**：
   - 如何配置风险分析流程
   - 如何调整风险偏好
   - 如何解读风险评分

### 思考题

1. **实践题**：选择一只你感兴趣的股票，使用系统的单股研究功能，查看风险辩论报告，提取关键风险点，并制定风险控制计划。

2. **分析题**：对比三个风险分析师的输出，你认为哪个分析师的观点最符合你的风险偏好？为什么？

3. **决策题**：如果风险经理给出的风险等级为"高风险"（关键前提待验证），你会如何使用这份研究结论？研究结论"待验证"和"已确认"对你的决策参考价值有何不同？

4. **进阶题**：创建一个个人风险管理流程，配置适合你风险偏好的风险管理者提示词，并测试其效果。
