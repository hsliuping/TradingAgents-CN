# 第22课：中长线实战案例（下）

**课时**：1课时  
**目标**：学会像教练一样处理中长线下半场，先用真实持仓研究复核一笔已经跑出利润的仓位，再用真实复盘把“结果正确、过程失范”拆成下一轮必须执行的纪律清单。

---

## 22.1 本课先给结论：中长线下半场，不是盯着浮盈发呆

第21课解决的是上半场的问题：

**一份真实单股研究，到底够不够支撑它进入长期观察池。**

第22课解决的是后半场的问题：

1. 一笔中长线持仓已经跑出利润后，怎样继续复核，而不是被盈利冲昏；
2. 一轮交易周期结束后，怎样把复盘结果改写成下一次真的会执行的纪律。

如果我是你的中长线教练，我在第22课不会先问你：

1. 现在浮盈已经这么高，是不是说明逻辑已经兑现；
2. 这笔仓位还能不能继续拿；
3. 这次赚到了，是不是说明方法已经成熟。

我会先逼你回答四个问题：

1. 原来的长期判断，现在还活着吗；
2. 当前盈利，到底是逻辑被验证了，还是价格先跑出来了；
3. 这笔持仓现在最需要防的反证是什么；
4. 这次收益里，哪些来自方法，哪些只是标的本身足够强。

只要这四个问题还答不清，中长线下半场就还没有真正开始。

## 22.2 本课为什么要切换到 300750 的真实样本

### 22.2.1 上一课的 000001 只适合讲“进入前”

第21课用 000001 讲的是：

如果你想回看上半场引用的原始研究样本，可以直接打开：[000001 在 2026-04-30 的完整研究报告](/learning/advanced/sample/000001-research-report-2026-04-30)。

1. 怎样把一份真实研究定级为观察型；
2. 为什么它还不能升级到执行准备；
3. 下一次最值得等的验证是什么。

但系统当前可直接教学的完整中长线下半场样本，并不是 000001。

如果为了故事连贯，硬把不存在的持仓链和复盘链拼到 000001 身上，课程就会从“真实运行时结构”退回“讲师脑补剧情”。这不能接受。

### 22.2.2 下半场改用当前完整度更高的真实闭环样本

本课下半场改用系统里当前完整度更高的一组真实样本：

1. 标的：300750 宁德时代；
2. 持仓研究样本：已经持有 153 天，剩余 200 股，浮动收益率约 29.65%；
3. 交易复盘样本：交易跨度 93 天，三次买入，一次卖出；
4. 复盘总结：结果正确、过程失范；
5. 关联方法：中线价值成长系统。

这样写，不是为了换一只更“好看”的票，而是为了忠于真实样本。

你可以把第22课理解成两段训练：

1. **持仓复核训练**：一笔已经浮盈明显的中长线仓位，为什么仍然要继续复核；
2. **交易后纠偏训练**：一份收益不错的复盘，为什么仍然会判定过程不合格。

## 22.3 中长线持仓阶段，教练先让你看哪四个问题

### 22.3.1 先看你现在站在周期的什么位置

中长线持仓阶段，第一件事不是重新讲故事，而是先确认你站在什么位置看这份研究。

对 300750 这个样本来说，持仓快照最重要的不是“赚了接近 30%”，而是：

1. 这不是刚建仓的样本；
2. 这也不是刚形成研究结论的样本；
3. 它已经跨过完整季度窗口，必须重读原逻辑；
4. 账户里的持仓权重已经不轻，不能再用“先看看再说”的态度对待。

所以第一层判断应该是：

**这是一笔已经进入长期复核期的持仓，不是新开题。**

### 22.3.2 再看原来的支撑证据还剩多少

中长线最怕的不是看错，而是逻辑已经开始走样，你却还在用旧的理由继续拿着。

这份样本当前还成立的支撑，至少有三类：

1. 中期价格结构没有明显破坏；
2. 现金流和财务结构没有出现直接打脸的公开证据；
3. 海外客户、储能、新技术这些长期增长线索，仍然有继续跟踪价值。

这些支撑足够解释“为什么这笔仓位还没有被立刻降级”，但还不够解释“为什么可以停止复核”。

### 22.3.3 第三看最大的反证正在靠近哪里

一笔中长线仓位已经盈利后，最危险的不是回撤本身，而是你不再认真看反证。

这个样本当前最值得防的三条反证是：

1. 净资产收益率回落，到底是不是暂时波动，仍缺少足够清晰的解释；
2. 毛利率波动与行业趋势之间的背离，还没有被讲透；
3. 当前增长斜率，是否还能支撑已经抬高的估值预期，仍然存在疑问。

这三条反证说明：

**利润已经跑出来，不等于底层经营质量已经被证明。**

### 22.3.4 最后看下一次复核到底先看什么

中长线持仓研究真正的价值，不是告诉你“继续拿着”，而是替你写出下一次先看什么。

对这个样本来说，下一次复核优先级很清楚：

1. 下一期财报里净资产收益率的分解；
2. 问询回复或公告里，对毛利率波动和盈利驱动的解释；
3. 动力电池装机量、市占率、海外客户进展这些能证明长期主线是否继续推进的公开信息。

只要这一步没写清，中长线持有就很容易变成“利润好看，所以先继续拿着”。

## 22.4 系统在中长线持仓阶段，真正给你什么支撑

当前系统里的持仓研究，不应该被你理解成“长期持有许可单”。

它真正提供的，是下面五类支撑：

| 你在持仓阶段要回答的问题 | 系统主要提供什么 | 你该怎么用 |
| ------ | ------ | ------ |
| 这笔仓位现在处于什么状态 | 持仓快照、当前结论 | 先确认它属于验证期、强化期，还是该降级 |
| 为什么它还没被推翻 | 核心依据、关键支撑点 | 只保留仍然有效的长期支撑 |
| 哪条反证最值得警惕 | 风险焦点、不确定性说明 | 先盯最容易把长期逻辑掀翻的缺口 |
| 哪些信号会让结论上修 | 机会线索、后续观察事项 | 明确未来升级必须等什么公开验证 |
| 下一次复核何时开始 | 研究附录、事件型观察点 | 把复核从“看盈亏”变成“看证据更新” |

把这张表看明白，你就会知道：

**中长线持仓研究不是让你更放心，而是让你更有顺序地继续怀疑。**

## 22.5 教练示范：怎么读这份真实中长线持仓研究

### 22.5.1 第一步：先承认“盈利已经很可观，但逻辑仍待验证”

这份样本最有教学价值的一句话，不是浮盈数字，而是对当前状态的描述：

**盈利已经很可观，但核心逻辑仍待验证。**

这句话直接纠正了中长线里最常见的误区：

1. 价格可以先走出来；
2. 利润可以先跑出来；
3. 但底层经营质量不一定已经同步完成验证。

如果你读完一份持仓研究，只记住“这笔赚了很多”，那你还没有读到最关键的那一层。

### 22.5.2 第二步：把“为什么还能继续拿”的证据单独列出来

复核时，不要先看能不能加大使用强度，先看它为什么还没有被降级。

对这个样本来说，仍能支持继续跟踪的理由至少有三条：

1. 中期结构没有坏；
2. 财务与现金流没有出现明确失真信号；
3. 长期成长线索仍在，相关公开信息没有集体熄火。

这三条足够支持“继续复核”，但不等于“可以停止质疑”。

### 22.5.3 第三步：把“最该担心的缺口”重新抄一遍

真正决定中长线持仓质量的，不是你能找出多少利好，而是你愿不愿意把反证反复抄下来。

对这个样本来说，最该重抄的三条缺口是：

1. 净资产收益率回落的成因和修复路径仍未完全讲清；
2. 毛利率变化为什么与行业趋势出现背离，仍缺少可以验证的归因；
3. 当前成长斜率与估值匹配度之间的张力，仍然存在。

只要这三条没有明显被回答，这笔仓位就应该被定义为：

**盈利中，但仍处在验证期。**

### 22.5.4 第四步：把它压成一张长期持仓复核卡

你可以把这份持仓研究直接压成一张卡：

```text
样本：300750

当前状态：
- 盈利可观，但逻辑仍待验证

当前仍有效的支撑：
- 中期结构未坏
- 现金流与财务结构未见明显失真
- 长期成长线索仍有公开跟踪价值

当前最该防的反证：
- 净资产收益率回落原因未说透
- 毛利率波动归因未讲透
- 成长斜率与估值匹配度仍有压力

下一次财报复核：
- 净资产收益率分解
- 毛利率变化解释
- 核心盈利驱动是否更清楚

下一次产业复核：
- 装机量与市占率变化
- 海外客户与新技术进展

升级条件：
- 关键经营质量信号开始补齐

降级条件：
- 反证强化，或核心成长线索明显减弱
```

这张卡，才是中长线持仓阶段真正能用的东西。

## 22.6 交易结束后，教练怎么带你读这份真实复盘

这一段要切换到另一个问题：

**这笔交易的结果不错，但它的过程到底合不合格。**

### 22.6.1 先看一句话复盘，不急着看细节

这份复盘最核心的一句话，就是：

**结果正确、过程失范。**

这句话在中长线里的分量非常重，因为它要求你把两件常被混在一起的事分开：

1. 标的本身够强，所以收益不错；
2. 你的执行过程，未必真的合格。

如果这句话读不进去，后面的复盘几乎都会被收益蒙过去。

### 22.6.2 再看做对了什么，不要因为批评过程就抹掉有效部分

教练式复盘不会把所有东西都骂掉。

这份样本里，做对的地方是清楚的：

1. 的确抓住了强基本面和行业稀缺性带来的超额收益；
2. 的确享受到了个股主线继续展开的回报；
3. 这说明研究视角里，有部分判断是有效的。

所以复盘的第一层不是否定，而是区分：

1. 什么是应该保留的研究能力；
2. 什么是不能误以为已经成熟的执行能力。

### 22.6.3 再看真正的问题点，不要被收益冲掉

这份复盘真正暴露的问题，不在收益数字，而在过程断点：

1. 入场前缺少完整的验证留痕；
2. 中途卖出动作没有很好服从原系统边界；
3. 财报后复核这类关键动作没有稳定执行；
4. 整个交易过程里，证据链和日志记录都不够完整。

这在中长线里的翻译就是：

**研究能力有一部分是对的，但执行纪律没有跟上。**

### 22.6.4 最后看为什么“收益不错”仍然不能反推“方法成熟”

这份样本最值得用户反复消化的一点，就是收益不能反推过程正确。

原因很简单：

1. 这次收益的大头，主要来自标的本身的强势展开；
2. 行业和市场只提供了很有限的背景支持；
3. 买入和卖出的关键依据，没有被足够严谨地记录下来；
4. 所以你不能因为最后是赚的，就自动把这次执行当成可复制模板。

这一步很残酷，但非常必要。

中长线里最危险的，不是做错一次；
中长线里最危险的，是做对一次之后，就以为自己以后都会这样对。

## 22.7 教练示范：怎么把复盘结果改写成下一次纪律卡

### 22.7.1 先写“这次继续保留什么”

不是所有复盘都只能写错误。

对这个样本来说，应该保留的至少有两条：

1. 持续跟踪强基本面和产业主线的研究能力；
2. 能抓住个股主线展开，而不是只跟随市场情绪的研究习惯。

### 22.7.2 再写“这次必须停止什么”

真正的纪律卡，重点是停掉那些会反复伤害系统的做法。

对这个样本来说，必须停止的至少有三条：

1. 入场前不留痕；
2. 关键动作发生时，不按原系统边界重新核对；
3. 财报后复核这类硬动作被拖延或跳过。

### 22.7.3 第三写“下次必须补什么证据”

如果复盘只留下感受，没有留下证据要求，下次还是会重复老问题。

这个样本最该补的证据至少包括：

1. 每次关键动作前，对应的验证依据；
2. 每次复核时，财报、公告和产业进展的记录；
3. 每次偏离原计划时，必须写清楚为什么偏离。

### 22.7.4 最后写“下次必须先写好哪条纪律”

这一步才是第22课真正的落点。

对这个样本，我会要求你把下面四条纪律写进下一轮周期里：

1. 入场前必须完成关键证据留痕；
2. 财报和重大公告后，必须按固定模板复核一次；
3. 任何偏离原系统边界的动作，都必须写清楚依据；
4. 复盘时必须把结果和过程拆开，不允许只看最终收益。

## 22.8 这节课真正要你带走的两张卡

### 22.8.1 长期持仓复核卡

```text
当前状态：
- 盈利可观，但逻辑仍待验证

仍有效的支撑：
- 还没被推翻的 2-3 条长期依据

当前最大反证：
- 现在最可能先坏掉的 2-3 条条件

下一次复核：
- 下一期财报先看什么
- 下一次产业进展先看什么

升级条件：
- 哪类底层经营质量信号补齐后，判断才能上修

降级条件：
- 哪类反证强化后，必须重评
```

### 22.8.2 周期复盘纠偏卡

```text
这次真正做对了什么：
- 1-2 条应保留的研究能力

这次真正做错了什么：
- 1-2 条必须停止的执行习惯

这次最该补强的证据：
- 下次关键动作前必须留下什么记录

这次最该写进纪律的条款：
- 下次必须先写好再动手的规则
```

如果你能把第21课和第22课分别稳定压成这两张卡，中长线课程才算真正从“会看研究”走到“会管理自己的长期判断”。

## 22.9 本课小结与思考

### 22.9.1 本课要点回顾

1. 第22课的核心不是教你盯着浮盈管理情绪，而是训练你怎样继续复核一笔已经跑出利润的中长线持仓。
2. 300750 这个样本最关键的一句话是：盈利已经很可观，但核心逻辑仍待验证。
3. 一份好的持仓研究，最后必须被压成“当前状态 + 仍有效支撑 + 最大反证 + 下一次复核重点”的长期复核卡。
4. 一份好的复盘，不会因为结果不错就放过过程问题；“结果正确、过程失范”正是这类样本最有训练价值的地方。
5. 第22课最后必须落到纪律层：保留什么、停止什么、补什么证据、写进哪条规则。

### 22.9.2 思考题

1. 300750 这笔持仓里，哪些证据说明“还能继续复核”，哪些证据又说明“还不能停止怀疑”？
2. 为什么这份样本已经有明显利润，却仍然不能直接写成“逻辑已经兑现”？
3. “结果正确、过程失范”这句话里，哪一半更容易被你忽略？为什么？
4. 请把你最近一笔中长线持仓，也压成“长期持仓复核卡 + 周期复盘纠偏卡”，检查自己是不是只记住了收益，没有记住过程。

## 第九部分总结：中长线实战不是熬时间，而是跨周期持续验证原判断

学完第 20 课到第 22 课，这一部分真正要你带走的，不是长期故事，而是三条更稳的中长线底线：

1. 中长线的起点不是预设结果，而是先建立观察池标准、执行准备阈值和长期复核节奏；
2. 一笔已经有利润的持仓，仍然要通过长期复核卡继续检查支撑、反证和关键公开验证，而不是把盈利自动当成逻辑兑现；
3. 一份收益不错的周期复盘，仍然必须拆开研究能力和执行纪律，把“结果正确、过程失范”写回下一版规则。

如果把第九部分压成一句话，就是：

**从这里开始，你做中长线不再只是看时间够不够长，而是看原判断有没有被更长周期的公开证据真正支持。**

这也是进入交易计划建立部分前最重要的长期方法基础。

**下一课预告**：下一课将把这两节中长线案例继续回收到个人交易计划里，重点不再是单笔样本怎么读，而是怎样把长期观察、持仓复核和周期复盘，真正写成自己的计划基线。
