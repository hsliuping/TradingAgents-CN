# 报告字段重命名和顺序优化

## 📋 修改概述

**修改日期**: 2026-01-10  
**修改目的**: 优化报告展示，让用户清晰理解从初步分析到最终研究结论的完整推理过程

---

## 🔄 字段重命名

### 1. `investment_plan` → `💡 初步研究观察`

**来源**: 研究经理（Research Manager）  
**阶段**: 第三阶段（研究团队分析）  
**内容**: 综合多头和空头研究员观点后的初步研究观察  
**特点**:
- 基于技术面、基本面、市场情绪的综合分析
- 尚未经过风险管理团队评估
- 可能包含较为积极的研究倾向

**修改前**: `📋 投资建议`  
**修改后**: `💡 初步研究观察`

---

### 2. `final_trade_decision` → `🎯 最终研究结论`

**来源**: 风险评估师（Risk Assessor）  
**阶段**: 第六阶段（最终研究结论）  
**内容**: 综合风险审阅后的最终研究结论  
**特点**:
- 经过高弹性、防御、基准情景研究员的风险评估
- 包含仓位管理参考、风险关注与收益关注等风险审阅内容
- 更加稳健，仅供研究参考

**修改前**: `🎯 最终分析结果`  
**修改后**: `🎯 最终研究结论`

---

## 📊 展示顺序优化

### 修改前
报告模块按照对象键的顺序展示（不确定顺序）

### 修改后
按照分析流程的顺序展示：

```
第一阶段：宏观分析（2个）
├── 📊 大盘指数分析
└── 🏭 行业板块分析

第二阶段：分析师团队（4个）
├── 📈 市场技术分析
├── 💰 基本面分析
├── 💭 市场情绪分析
└── 📰 新闻事件分析

第三阶段：研究团队（多情景研究 + 初步研究观察）
├── 🐂 乐观情景研究员 / 积极证据研究
├── 🐻 审慎情景研究员 / 谨慎证据研究
├── 🔬 研究经理分析
└── 💡 初步研究观察 ← 研究经理的初步研究观察

第四阶段：研究整合团队（1个）
└── 💼 研究整合员计划

第五阶段：风险管理团队（风险审阅）
├── ⚡ 高弹性情景研究员 / 高弹性风险情景
├── 🛡️ 防御情景研究员 / 防御风险情景
├── ⚖️ 基准情景研究员 / 基准风险情景
├── 👔 风险评估师
└── ⚠️ 风险审阅

第六阶段：最终研究结论（1个）
└── 🎯 最终研究结论 ← 风险审阅后的最终研究结论
```

---

## 💡 用户体验改进

### 改进前的问题
1. ❌ 两个字段名称相似（"投资建议" vs "最终分析结果"），用户困惑
2. ❌ 展示顺序混乱，看不出分析流程
3. ❌ 不清楚两个研究结论的区别和关系

### 改进后的优势
1. ✅ 名称清晰区分（"初步研究观察" vs "最终研究结论"）
2. ✅ 按照分析流程顺序展示，逻辑清晰
3. ✅ 用户能理解完整的推理过程：
   - 初步研究观察 → 基于市场分析
   - 风险审阅 → 评估初步研究观察的风险
   - 最终研究结论 → 综合风险审阅后的研究结论

> **重要提示**：本系统为研究辅助工具，所有输出仅供研究参考，不构成投资建议。

## 🔧 技术实现

### 前端修改文件

1. **`frontend/src/views/Reports/ReportDetail.vue`**
   - 添加 `moduleOrder` 数组定义展示顺序
   - 添加 `orderedModuleNames` 计算属性
   - 修改 `getModuleDisplayName` 函数中的字段名称
   - 修改默认激活模块的逻辑

2. **`frontend/src/views/Analysis/SingleAnalysis.vue`**
   - 修改 `reportMappings` 数组的顺序和名称
   - 更新 `iconMap` 和 `descMap` 中的字段名称和描述

### 后端无需修改
- 后端返回的字段名称保持不变（`investment_plan`, `final_trade_decision`）
- 只在前端展示层修改名称
