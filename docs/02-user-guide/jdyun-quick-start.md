# 京东云版快速上手

> 5 分钟读完，马上能用。

---

## 这是什么

TradingAgents-CN 是一个 AI 股票研究平台。你输入股票代码，AI 自动跑基本面、技术面、风险评估，输出一份研究报告。

**你不需要配置任何东西**，登录就能用。

---

## 第一步：分析一只股票（3 分钟）

1. 点左侧菜单 **「单股研究」**
2. 输入股票代码，比如 `600519`（贵州茅台）
3. 分析深度选 **「3级-标准分析」**（推荐新手）
4. 分析师保持默认（市场分析师 + 基本面分析师）
5. 点 **「开始分析」**

等 4-8 分钟，在 **「任务中心」** 看进度，完成后点进去看报告。

报告里每个 Tab 是一个分析维度（技术面、基本面、风险、估值…），最后有一个**决策标签**：乐观 / 审慎 / 中性。

> ⚠️ 决策标签只是研究倾向，**不是买卖指令**。

---

## 第二步：用 AI 助手问问题（1 分钟）

点左侧菜单 **「智能助手」**，直接打字问：

| 你想知道 | 这样问 |
|---------|--------|
| 某只股票怎么样 | "帮我分析一下 000001" |
| 某个板块表现 | "新能源板块最近怎么样" |
| 搜最新新闻 | "帮我搜一下最近的半导体政策" |
| 设价格提醒 | "帮贵州茅台设一个 1800 元的价格下限提醒" |
| 查历史报告 | "我上次分析过的股票有哪些" |

AI 助手会自动调用工具，不用你找菜单。

---

## 第三步：模拟交易练手（2 分钟）

1. 点左侧菜单 **「模拟交易」**
2. 首次进入会提示创建账户，默认 100 万虚拟资金
3. 点 **「买入」**，输入股票代码、价格、数量，确认
4. 持仓一段时间后点 **「卖出」**
5. 点左侧 **「操作复盘」**，AI 自动从时机、仓位、情绪、归因四个角度帮你复盘这笔交易

模拟交易是虚拟资金，**不能提现**，纯粹练手。

## 日常怎么用（进阶）

| 做什么 | 去哪里 |
|--------|--------|
| 找股票 | **股票筛选** -- 按条件过滤，或用自然语言描述 |
| 管理关注股 | **股票关注列表** -- 分组管理，批量分析 |
| 自动跟踪 | **设置 → 定时分析配置** -- 每天自动跑分析 |
| 收通知 | **设置 → 渠道推送** -- 飞书/钉钉/邮件 |
| 看组合风险 | **持仓研究** -- 行业集中度、相关性分析 |
| 定交易纪律 | **交易计划** -- 设入场条件、收益关注/风险关注规则 |

## 省 Token 的小技巧

- 先跑 **1级-快速分析**（2-5 分钟），觉得有价值再跑 3 级
- 批量分析**一次不超过 5 只**（京东云版逐只执行）
- 日常用 **GLM-5**（默认），深度推理才用 GLM-5.1
- 批量任务用 **DeepSeek-V4-Flash**（快且省）

## 常见问题

| 问题 | 答案 |
|------|------|
| 港股/美股能分析吗？ | 不能，仅支持 A 股和 ETF |
| 报告里有目标价吗？ | 没有，只有乐观/审慎/中性三个标签 |
| 分析卡住了？ | 京东云有 LLM 限速，系统会自动重试，耐心等 |
| 怎么看 Token 用了多少？ | **系统管理 → 使用统计** |
| 模型能换吗？ | 可以在下拉菜单切换（GLM-5 / GLM-5.1 / GLM-5.2 / DeepSeek-V4-Flash） |
