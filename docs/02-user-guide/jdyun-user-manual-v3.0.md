## 京东云版是什么

京东云合作版是 TradingAgents-CN Pro 与京东云模型服务合作的定制版本，专为京东云用户设计：

- **零配置开箱即用**：大模型 API Key、数据源 Token、Embedding 模型等全部通过环境变量注入，无需在界面手动配置
- **首次启动自动初始化**：首次启动时系统自动从环境变量写入 Provider、模型配置、Tushare 数据源
- **限速友好**：内置 429 限速应对机制（指数退避重试 + 降并发 + 任务间间隔）
- **合规分析**：仅支持 A 股市场分析，遵循合规要求，不提供投资建议

> 🔧 **京东云版标识**：本手册中带 🔧 图标的章节或功能，介绍的是标准版才有的功能（如 License 授权、Provider 自定义等），京东云版用户**默认跳过**。

## 与标准版的核心差异

| 对比项 | 标准版 | 京东云版 |
|--------|--------|----------|
| 大模型配置 | 用户在界面手动配置 Provider 和 API Key | 通过环境变量注入，**界面隐藏配置入口** |
| 可用模型 | 支持多家供应商（通义千问、DeepSeek、智谱等） | 仅京东云提供的 4 个模型（GLM-5 / GLM-5.1 / GLM-5.2 / DeepSeek-V4-Flash） |
| 数据源 | 支持 Tushare / AKShare / BaoStock | **仅 Tushare**（Token 由京东云提供） |
| Embedding 模型 | 用户自行选择 | 固定使用 **Qwen3-Embedding-8B**（4096 维） |
| License 授权 | 需激活 License 区分高级/基础功能 | **无需激活**，所有功能默认开放 |
| 首次启动 | 需手动配置 API 密钥 | 自动从环境变量初始化数据库 |
| LLM 限速 | 无特殊限制 | 内置 429 重试（最多 8 次）+ 降并发机制 |
| 批量分析并发 | 默认 3 | 降为 **1** |
| Worker 任务并发 | 默认 5 | 降为 **1** |
| 任务间间隔 | 无 | **10 秒** |

> 💡 **核心差异一句话**：京东云版用户**不需要做任何配置**就能用，省去了选模型、配 Key、激活 License 的步骤。代价是可用模型和数据源被锁定为京东云提供的内容。

## 快速开始（5 分钟上手）

### 方式一：便携版部署（推荐个人用户）

适合：单台 Windows 电脑、单机自用、不想折腾 Docker 的用户。

**步骤 1：准备环境**

- Windows 10/11
- 8GB 以上内存
- 10GB 以上可用磁盘空间

**步骤 2：解压安装包**

将京东云版便携包解压到任意目录（建议非中文路径），例如 `D:\TradingAgentsCN-JDYUN`。

**步骤 3：配置凭据**

编辑 `.env` 文件，填入京东云提供的凭据：

```bash
JDYUN_MODE=true
OPENAI_API_BASE=https://modelservice.jdcloud.com/v1
OPENAI_API_KEY=your_jdyun_api_key
OPENAI_MODEL=GLM-5
EMBEDDING_MODEL=Qwen3-Embedding-8B
TUSHARE_TOKEN=your_tushare_token
```

> ⚠️ **必须修改的字段**：`OPENAI_API_KEY` 和 `TUSHARE_TOKEN`（联系京东云获取）。其他字段保持默认即可。

**步骤 4：启动服务**

双击 `start.bat`，等待 1-2 分钟（首次启动需初始化数据库）。

**步骤 5：访问系统**

打开浏览器访问 `http://localhost:8082`，使用默认账号登录：

| 角色 | 用户名 | 密码 |
|------|--------|------|
| 管理员 | `admin` | `admin123` |

> ⚠️ 首次登录后请立即到"个人设置 → 安全设置"修改密码。

---

### 方式二：单容器部署（推荐云端用户）

适合：云服务器部署、长期运行、需要远程访问的用户。

**步骤 1：准备服务器**

- Linux / Windows 服务器（推荐 2 核 4GB 以上）
- 已安装 Docker 和 Docker Compose
- 开放 8082 端口

**步骤 2：创建部署目录**

```bash
mkdir -p /opt/tradingagents-jdyun
cd /opt/tradingagents-jdyun
```

**步骤 3：拉取镜像**

```bash
docker pull tradingagents-cn-pro:3.0.0
```

> 联系京东云获取镜像地址（Docker Hub 或私有仓库）。

**步骤 4：创建数据卷**

```bash
# ⚠️ 关键：使用 ta-mongo-data 而非其他名称
docker volume create ta-mongo-data
docker volume create ta-redis-data
```

> 💡 **为什么叫 ta-mongo-data？** 这是京东云版约定的数据卷名，**用于持久化存储 MongoDB 业务数据**。重启容器时必须挂载这个卷，否则数据会"丢失"（其实是初始化了空白卷）。详见 [Q5：单容器重启后数据丢失](#q5单容器重启后数据丢失)。

**步骤 5：创建 .env 文件**

```bash
cat > .env <<EOF
JDYUN_MODE=true
OPENAI_API_BASE=https://modelservice.jdcloud.com/v1
OPENAI_API_KEY=your_jdyun_api_key
OPENAI_MODEL=GLM-5
EMBEDDING_MODEL=Qwen3-Embedding-8B
TUSHARE_TOKEN=your_tushare_token
EOF
```

**步骤 6：启动容器**

```bash
docker run -d \
  --name tradingagents \
  -p 8082:8082 \
  -v ta-mongo-data:/data/db \
  -v ta-redis-data:/data/redis \
  --env-file .env \
  --restart unless-stopped \
  tradingagents-cn-pro:3.0.0
```

**步骤 7：访问系统**

打开浏览器访问 `http://服务器IP:8082`，等待 1-2 分钟（首次启动会执行数据库初始化）。

## 环境变量详解

### 必填配置

| 环境变量 | 必填 | 说明 | 示例值 |
|---------|------|------|--------|
| `JDYUN_MODE` | ✅ | 京东云模式开关，必须为 `true` | `true` |
| `OPENAI_API_BASE` | ✅ | 京东云模型服务地址（统一入口） | `https://modelservice.jdcloud.com/v1` |
| `OPENAI_API_KEY` | ✅ | 京东云提供的 API Key | 联系京东云获取 |
| `OPENAI_MODEL` | ✅ | 默认对话模型 | `GLM-5` |
| `EMBEDDING_MODEL` | ✅ | Embedding 模型（已锁定） | `Qwen3-Embedding-8B` |
| `TUSHARE_TOKEN` | ✅ | Tushare 数据源 Token | 联系京东云获取 |

> 💡 **为什么对话模型和 Embedding 模型共用 `OPENAI_API_BASE`？** 京东云模型服务对外提供 OpenAI 兼容 API，对话和 Embedding 调用走同一个入口，节省配置复杂度。

### 可选配置（限速调优）

| 环境变量 | 默认值 | 说明 |
|---------|--------|------|
| `JDYUN_LLM_MAX_RETRIES` | `8` | LLM 调用遇到 429 限速时的最大重试次数（指数退避：1s→2s→4s→8s→...→128s） |
| `JDYUN_LLM_MAX_RPM` | `30` | LLM 每分钟最大请求数（超过则排队等待） |
| `JDYUN_BATCH_MAX_CONCURRENT` | `1` | 批量分析最大并发数（**不要调大**，会触发限速） |
| `JDYUN_WORKER_MAX_CONCURRENT` | `1` | Worker 最大并发任务数（**不要调大**） |
| `JDYUN_STOCK_INTERVAL_SECONDS` | `10` | 定时分析股票间的间隔秒数（限速时可调大） |

> ⚠️ **不要轻易调大并发数**：京东云模型服务有 QPS 限制，调大并发反而会触发更频繁的 429 报错，降低整体效率。默认值已经过生产验证。

## 可用的模型与数据源

### 对话模型（4 个）

可在分析任务的下拉菜单中切换：

| 模型名称 | 定位 | 适用场景 |
|---------|------|---------|
| **GLM-5** | 通用对话 | 日常分析、文档摘要（默认） |
| **GLM-5.1** | 增强推理 | 复杂推理、深度分析 |
| **GLM-5.2** | 长文本 | 超长研报分析 |
| **DeepSeek-V4-Flash** | 高速模型 | 快速分析、批量任务 |

> 💡 **如何选择？**
> - 日常单股研究 → GLM-5（默认）
> - 持仓深度分析 → GLM-5.1（推理更强）
> - 批量分析 → DeepSeek-V4-Flash（速度更快、省 token）
> - 财报全文分析 → GLM-5.2（长文本）

### Embedding 模型

京东云版**锁定使用** Qwen3-Embedding-8B，输出维度 4096。

> ⚠️ **重要提醒**：不要尝试在系统设置中切换 Embedding 模型。京东云版已固定为 Qwen3-Embedding-8B，且向量数据库的 collection 维度已按 4096 维创建。**切换会报错**。

### 数据源

京东云版**仅支持 Tushare**。

| 数据源 | 京东云版 | 说明 |
|--------|----------|------|
| Tushare | ✅ | Token 由京东云提供，无需用户配置 |
| AKShare | ❌ | 不支持 |
| BaoStock | ❌ | 不支持 |
| QMT | ❌ | 不支持 |
| Wind / Choice | ❌ | 不支持 |

## 核心功能使用指南

### 单股研究

最常用的功能。输入股票代码，系统会调用多个 AI Agent 协同分析，输出多维度研究报告。

**操作步骤**：

1. 点击左侧导航栏"单股研究"
2. 输入股票代码（如 `601919`、`600519`、`000001`）
3. 选择分析深度（推荐：3级-标准分析）
4. 选中分析师（推荐：市场分析师 + 基本面分析师）
5. 点击"开始分析"
6. 等待 5-15 分钟，在"任务中心"查看进度
7. 分析完成后查看报告

**京东云版注意事项**：

- 每次分析前会校验 LLM 限速，可能需要短暂排队
- 建议先看"快速分析"再决定是否做"深度分析"（节省 token）
- 同一只股票短时间内重复分析会复用历史结果

### 批量分析与定时分析

> 🔧 **批量分析**（标准版功能）京东云版**支持但限制并发为 1**，建议单次不超过 10 只股票。

> 🔧 **定时分析**（标准版功能）京东云版**支持**，可设置错峰执行（如凌晨 1-6 点）避开 LLM 限速高峰。

**定时分析配置建议**：

- **盘后分析**：设置在 16:30 之后执行，确保当日数据已同步
- **错峰分组**：不同关注组别设置在不同时间段，避免同时触发
- **间隔调大**：可在 `.env` 中将 `JDYUN_STOCK_INTERVAL_SECONDS` 调到 20-30 秒

### 通用研究

通用研究（`/analysis/general`）适用于**没有明确股票代码**的研究场景，例如：

- "分析一下最近白酒板块的趋势"
- "对比宁德时代和比亚迪的竞争优势"
- "帮我研究一下最近涨得好的半导体股票"

操作步骤：

1. 点击左侧导航栏"通用研究"
2. 选择分析流程（默认即可）
3. 填写分析目标（自然语言描述需求）
4. 点击"开始分析"
5. 在"任务中心"查看进度

> 💡 **提示**：通用研究的输入是自然语言，不强制要求股票代码。系统会自动判断是否需要指定具体股票。

### 模拟交易与持仓分析

京东云版完整支持模拟交易和持仓分析功能：

- **模拟交易**（`/paper`）：虚拟资金买卖，验证策略
- **持仓研究**（`/portfolio`）：基于真实持仓的多维度分析
- **操作复盘**（`/review`）：回顾历史交易，提取经验

这些功能不依赖 LLM，可离线使用。

### 智能助手（AI 对话）

主入口在仪表板或顶部导航栏的"智能助手"图标。

**京东云版的助手能力**：

- 20+ 工具，支持对话式触发分析、查报告、查关注列表
- 多主题会话，记忆上下文
- 兼容 OpenAI 标准的 API 调用

**常用场景**：

- "帮我分析一下 600519"
- "我最近关注了哪些股票"
- "今天有什么任务在跑"
- "我的 token 还剩多少"

### 使用问答助手（右下角浮窗）

京东云版**新增**使用问答助手（右下角浮窗入口），专门回答系统使用问题。

**能回答的 8 类问题**：

| 类别 | 示例问题 |
|------|---------|
| 数据同步 | "数据同步好了吗？需要重新同步吗？" |
| 模拟交易 | "我模拟账户现在多少钱？今天盈亏多少？" |
| Token 用量 | "今天用了多少 token？还剩多少配额？" |
| 任务进度 | "我提交的分析跑到哪一步了？还要多久？" |
| 任务记录 | "我最近做过哪些分析？" |
| 系统状态 | "系统在哪个模式？默认模型是什么？" |
| 用户状态 | "我有多少只关注的股票？有多少定时分析？" |
| 使用手册 | "怎么配置数据源？怎么看报告？" |

**使用方式**：

1. 点击右下角"使用问答"浮窗按钮
2. 在弹出抽屉中输入问题
3. 系统调用工具查询真实数据并回答
4. 可按 `Ctrl+Enter` 发送

> 💡 **设计理念**：使用问答助手**只回答"系统使用"类问题**，不调用任何金融市场数据工具，避免被诱导做出投资决策。所有回答都基于真实数据库状态，不是"AI 猜的"。

## 京东云版专属问题排查

### Q1：分析任务报 429 限速错误

**症状**：单股研究、批量分析、定时分析任务报 "Rate limit exceeded" 或 "429 Too Many Requests"。

**原因**：触发京东云 LLM 服务的 QPS 限速。

**解决方案**（按推荐度排序）：

1. **无需操作**：系统已内置指数退避重试（最多 8 次），大多数情况会自动恢复
2. **调大任务间隔**（如果频繁失败）：
   ```bash
   # .env 文件
   JDYUN_STOCK_INTERVAL_SECONDS=30
   ```
3. **避开高峰时段**：将定时分析设置在凌晨 1-6 点
4. **降低分析深度**：从"深度分析"改为"标准分析"或"快速分析"，减少 LLM 调用次数
5. **减少批量规模**：单次批量分析不超过 5 只股票

> ⚠️ **不要**调大 `JDYUN_BATCH_MAX_CONCURRENT` 或 `JDYUN_WORKER_MAX_CONCURRENT` 到大于 1，会更频繁触发限速。

### Q2：界面看不到 LLM 配置入口

**答**：这是京东云版的**设计特性**，不是 Bug。

京东云版通过环境变量配置 LLM，无法在界面修改。如果需要调整模型或限速策略，编辑 `.env` 文件并重启服务。

### Q3：数据源为什么只有 Tushare

**答**：京东云版只集成了 Tushare 数据源。AKShare、BaoStock、QMT 等数据源在京东云版中未启用，因为：

- 京东云版只支持 A 股（系统全局限制）
- Tushare 已能覆盖 A 股 99% 的数据需求
- 多数据源会增加 LLM 选源复杂度

如果需要其他数据源，请使用标准版。

### Q4：切换模型后 Embedding 向量报错

**症状**：提示 "Embedding dimension mismatch" 或 "Vector collection not found"。

**原因**：京东云版 Embedding 模型**已锁定**为 Qwen3-Embedding-8B（4096 维），不支持在系统设置中切换。

**解决方案**：

- 如果您**误操作**切换了 Embedding 模型，请改回 `Qwen3-Embedding-8B`
- 如果系统自动切换了，请联系京东云技术支持

> ⚠️ **不要切换 Embedding 模型**：不同 Embedding 模型的向量语义空间不兼容，切换后需要重新生成所有向量数据，且已分析的语义检索结果会失效。

### Q5：单容器重启后数据丢失

**症状**：重启 Docker 容器后，发现历史任务、关注列表、配置全部消失。

**原因**：使用了**错误的 Docker 数据卷名**。京东云版单容器约定的数据卷名是 `ta-mongo-data`，如果使用 `ta-data` 或其他名称，Docker 会创建**空白卷**覆盖真实数据。

**解决方法**：

```bash
# 1. 停止并删除错误容器
docker stop tradingagents
docker rm tradingagents

# 2. 验证真实数据卷
docker volume ls | grep mongo
# 应该看到 ta-mongo-data，且 Size 字段非零（如 2.5GB）

# 3. 用正确卷名重新启动
docker run -d \
  --name tradingagents \
  -p 8082:8082 \
  -v ta-mongo-data:/data/db \
  -v ta-redis-data:/data/redis \
  --env-file .env \
  --restart unless-stopped \
  tradingagents-cn-pro:3.0.0
```

**预防措施**：

- 升级前记录好数据卷名：`docker volume ls > volumes.txt`
- 升级后用 `docker volume inspect ta-mongo-data` 确认卷还在
- 定期备份 MongoDB：`docker exec tradingagents mongodump --out=/backup`

### Q6：批量分析只跑 1 只就不动了

**症状**：批量分析 5 只股票，第 1 只完成后剩余 4 只始终处于"排队"状态。

**原因**：京东云版 `JDYUN_BATCH_MAX_CONCURRENT=1`，单只完成后**需要等待 10 秒**才会启动下一只（避免触发限速）。

**解决方案**：

- 耐心等待，10 秒后会自动启动下一只
- 如果想加快，在 `.env` 中降低 `JDYUN_STOCK_INTERVAL_SECONDS=5`（但会增加 429 风险）

## 最佳实践

### 避峰原则

京东云 LLM 服务的限速策略**不公开**，但实测以下规律：

- **工作日 9:30-15:00**（A股交易时段）：限速最严
- **工作日 16:00-22:00**：限速中等
- **工作日 22:00-次日 8:00**：限速最宽松
- **周末全天**：限速宽松

**建议**：

- 日常单股研究：随时可做
- 批量分析：放在工作日 20:00 后
- 定时分析：设置在凌晨 1:00-6:00

### 任务间隔设置

| 场景 | 推荐间隔 | 原因 |
|------|---------|------|
| 定时分析 5 只以内 | 10 秒（默认） | 平衡效率与限速 |
| 定时分析 5-10 只 | 20-30 秒 | 降低 429 风险 |
| 紧急单股研究 | 0 秒（即时） | 不影响其他任务 |
| 批量分析 ≥ 5 只 | 15-20 秒 | 单批可能触发限速 |

### 批量规模控制

- **单次批量 ≤ 5 只**：推荐，几乎不会触发限速
- **单次批量 5-10 只**：可接受，建议错峰
- **单次批量 > 10 只**：不推荐，建议分批

### Token 用量监控

京东云版有 **Token 配额**，使用完毕后会拒绝服务。

**监控方式**：

1. 进入"设置 → 使用统计"
2. 查看今日、本周、本月 Token 消耗
3. 关注"按模型分布"和"按任务类型分布"两个维度

**节省 Token 的方法**：

- 优先使用"快速分析"（5-10 分钟 vs 深度分析 10-15 分钟）
- 减少同时选中的分析师数量（2 个 vs 4 个）
- 使用 GLM-5 而非 GLM-5.2（除非需要长文本分析）
- 批量任务使用 DeepSeek-V4-Flash（速度更快、省 token）

### 功能边界

京东云版**仅支持 A 股市场分析**，港股、美股功能已暂停（系统全局限制）。

### 免责声明

本平台提供的研究报告**仅供学习参考，不构成任何投资建议**。所有分析结果由 AI 模型基于历史数据生成，**不代表对未来收益的承诺**。投资有风险，决策需谨慎。

### 数据来源

- **行情数据**：Tushare（公开金融数据接口）
- **新闻数据**：Tushare 公开新闻接口
- **财务数据**：Tushare 财报数据
- **AI 推论**：基于 LLM 推理，系统会标记哪些是真实数据、哪些是 AI 推论

### 用户数据

- 用户的关注列表、任务记录、设置等数据**存储在本机 MongoDB**
- 用户的分析请求、报告内容**仅在用户和京东云 LLM 服务之间传递**，不经过第三方
- 系统不收集任何用户隐私信息

### 模型输出

LLM 可能产生错误或误导性输出，**所有结论都需要用户自行判断**。系统不提供"目标价"、"买卖建议"等具体投资指引，仅提供分析维度和参考数据。
