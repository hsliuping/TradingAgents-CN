## 关于本手册

### 阅读对象

本手册面向首次使用 TradingAgents-CN Pro 京东云版的用户，开通账号后即可使用全部功能。本手册按章节顺序介绍所有功能模块的使用方法，您也可以通过目录直接跳转到感兴趣的功能。

### v3.0 版本说明

v3.0 是一次平台化升级，核心变化包括：

- 智能助手从"分析触发器"升级为"投资研究协同入口"，支持 20+ 操作工具、多主题会话
- 新增 MCP Server 开放接口，可被 Claude Desktop、Cursor 等外部客户端调用
- 新增 AI 工作流架构师，自然语言描述需求即可自动规划工作流
- 新增 Skill 自动生成系统，AI 自主编写并验证新工具
- 新增选股助手、统一通知系统（邮件/飞书/钉钉多渠道推送）等能力

### 京东云版与标准版差异

京东云版**默认所有功能开放**（包括 Agent 工坊、Skill 中心、MCP 服务器等"高级功能"），无需 License 激活。

| 对比项 | 标准版 | 京东云版 |
|--------|--------|----------|
| 部署方式 | 用户自行安装部署 | **京东云托管，开箱即用** |
| 大模型配置 | 用户在界面手动配置 Provider 和 API Key | 京东云预配置，**界面隐藏配置入口** |
| 可用模型 | 支持多家供应商（通识千问、DeepSeek、智谱等） | 仅京东云提供的 4 个模型（GLM-5 / GLM-5.1 / GLM-5.2 / DeepSeek-V4-Flash） |
| 数据源 | 支持 Tushare / AKShare / BaoStock | **仅 Tushare**（Token 由京东云提供） |
| Embedding 模型 | 用户自行选择 | 固定使用 **Qwen3-Embedding-8B**（1024 维） |
| License 授权 | 需激活 License 区分高级/基础功能 | **无需激活**，所有功能默认开放 |
| LLM 限速 | 无特殊限制 | 内置 429 重试（最多 8 次）+ 降并发机制 |
| 批量分析并发 | 默认 3 | 降为 **1** |
| Worker 任务并发 | 默认 5 | 降为 **1** |
| 任务间间隔 | 无 | **10 秒** |

> 💡 **核心差异一句话**：京东云版用户**不需要做任何配置**就能用，省去了安装部署、选模型、配 Key、激活 License 的步骤。代价是可用模型和数据源被锁定为京东云提供的内容。

## 京东云版是什么

京东云合作版是 TradingAgents-CN Pro 与京东云模型服务合作的定制版本，专为京东云用户设计：

- **开箱即用**：系统已由京东云部署完成，开通账号后直接登录使用
- **零配置**：大模型 API Key、数据源 Token、Embedding 模型等全部由京东云预配置，无需用户配置
- **限速友好**：内置 429 限速应对机制（指数退避重试 + 降并发 + 任务间间隔）
- **合规分析**：仅支持 A 股市场分析，遵循合规要求，不提供投资建议
- **纯文本分析**：所有模型仅支持文本输入输出，不支持图片、图表等视觉内容分析

> 🔒 **京东云版标识**：本手册中带 🔒 标识的内容，介绍的是京东云版与标准版的差异点。

### 5 个最值得立刻体验的能力

> 这 5 个能力很多是 v2.x 已有、v3.0 加强的实用工具，**v3.0 的真正升级在治理能力（可追溯/可验证/可纠错）**，分析工具只是基础。

| 能力 | 工具名 | 用法 | 适用场景 |
|------|--------|------|----------|
| **1. 财报造假检测** | `get_beneish_mscore` | 输入股票代码，5 分钟出 8 维度评分（> -1.78 提示造假可能） | 重仓股/关注标的必查 |
| **2. 破产风险评估** | `get_altman_zscore` | 5 因子模型，< 1.81 提示破产风险 | ST 候选/财务异常股 |
| **3. DCF 现金流折现估值** | `get_dcf_valuation` | 预测期 + 永续期，自动算公司值多少钱 | 长期价值投资决策 |
| **4. K 线形态识别** | `get_candlestick_patterns` | 自动识别 25+ 种 K 线形态（锤子/吞没/十字星/晨星/三兵） | 短线择时、找拐点 |
| **5. 经典图表形态** | `get_chart_patterns` | 头肩顶底、双顶双底、三角、旗形、楔形 | 中长线趋势判断 |

### 数据有出处，不是"AI 猜的"

每个数据点都能查到来源：

- **PE/PB/ROE** → 来自 Tushare 财报数据
- **行情数据** → 来自 Tushare 实时接口
- **新闻** → 来自 Tushare 公开来源新闻接口
- **情绪** → 优先基于新闻内容和用户提交的社交媒体记录进行分析
- **AI 推论** → 来自 LLM，**系统会标记哪些是 AI 推论哪些是真实数据**

报告里如果出现"AI 推论"标签，说明这个结论是 AI 推理的（不是直接拿到的数据），请结合其他信息判断。

## 学习路径（从入门到精通）

### 阶段 1：入门（第 1 天）— 跑通第一次分析

**目标**：完成第一次单股研究，看懂报告结构。

1. 登录系统，进入仪表板
2. 点击"单股研究"卡片
3. 输入一只熟悉的股票代码（如 `600519`）
4. 保持默认设置（3级-标准分析 + 市场分析师 + 基本面分析师）
5. 点击"开始分析"，等待 4-8 分钟
6. 任务完成后查看报告

**掌握要点**：

- ✅ 仪表板是入口，能看到系统就绪度
- ✅ 单股研究是核心，3级-标准分析是推荐起点
- ✅ 报告有 14 个 Tab，每个 Tab 展示一个分析维度
- ✅ 决策标签只有 3 个：**乐观/审慎/中性**（不构成投资建议）

### 阶段 2：基础（第 1 周）— 熟练使用核心功能

**目标**：熟练使用 5 个核心功能模块。

1. **股票筛选**：用条件筛选或自然语言找股票
2. **股票关注列表**：分组管理关注的股票
3. **股票详情页**：在详情页查看行情和单股分析
4. **智能助手**：用自然语言发起分析和查询
5. **任务中心**：跟踪所有分析任务的状态

**掌握要点**：

- ✅ 用智能助手替代部分菜单操作
- ✅ 用股票关注列表管理研究标的
- ✅ 用任务中心跟踪批量/定时分析
- ✅ 学会看执行轨迹（排查问题时开启）

### 阶段 3：进阶（第 2-4 周）— 交易功能与高级分析

**目标**：使用交易相关功能，开始模拟交易。

1. **模拟交易**：初始化模拟账户，开始模拟买卖
2. **持仓研究**：分析持仓的组合风险
3. **操作复盘**：对每笔模拟交易做复盘
4. **交易计划**：制定系统化的交易计划
5. **通用研究**：分析行业/主题（无明确股票）
6. **AI 记忆**：查看系统对您的了解

**掌握要点**：

- ✅ 5 类复盘 Agent（时机/仓位/情绪/归因/复盘经理）自动跑
- ✅ 持仓研究基于模拟交易数据
- ✅ 通用研究是工作流驱动的
- ✅ AI 记忆会自动积累分析洞见

### 阶段 4：高级（第 1-2 月）— 自定义工作流与 Agent

**目标**：使用分析流等高级功能，定制自己的分析流程。

1. **分析流**：了解 v2.0 分析引擎和 6 种流程类型
2. **流程管理**：使用预置模板创建工作流
3. **AI 工作流架构师**：用自然语言生成工作流
4. **Agent 工坊**：自定义分析师
5. **Skill 中心**：查看和创建 Skill
6. **MCP 服务器**：被外部客户端调用

**掌握要点**：

- ✅ 分析流是 v3.0 的核心高级功能
- ✅ 6 种流程类型对应不同场景
- ✅ AI 工作流架构师能自动规划工作流
- ✅ Agent 工坊让您自己造新分析师

### 阶段 5：专家（持续）— 系统优化与最佳实践

**目标**：掌握限速应对、成本控制、数据管理等最佳实践。

1. **限速应对策略**：避开高峰时段、降低分析深度
2. **成本控制实践**：减少 Token 消耗
3. **数据管理实践**：数据同步、缓存管理
4. **学习中心**：查看系统课程

### 学习路径总结

| 阶段 | 周期 | 核心目标 | 关键功能 |
|------|------|----------|----------|
| 入门 | 第 1 天 | 跑通第一次分析 | 单股研究 |
| 基础 | 第 1 周 | 熟练 5 个核心功能 | 筛选、关注列表、智能助手 |
| 进阶 | 第 2-4 周 | 交易功能与高级分析 | 模拟交易、复盘、通用研究 |

### 1.2 单股研究

#### 功能说明

单股研究是系统的核心功能，输入一只股票代码，选择需要的分析维度和分析深度，系统将调用多个 AI 分析师协同完成深度分析，生成结构化研究报告。

#### 支持的市场

- **A 股市场**：沪深主板、创业板、科创板、北交所（6 位数字代码，如 `000001`）
- **ETF 基金**：如 `510050`、`159919` 等

> ⚠️ **京东云版仅支持 A 股和 ETF 分析**，港股、美股功能已暂停。

#### 操作步骤

1. **进入单股研究**
   - 左侧导航栏"单股研究"，或仪表板快捷入口。

2. **输入股票信息**
   - 在"股票代码"输入框中直接输入股票代码（如 `000001`、`512400`）。
   - 在"市场类型"下拉框选择对应市场：A 股市场、ETF 基金。

3. **选择分析日期（可选）**
   - 默认为当天，可手动选择历史日期作为分析基准日。

4. **选择分析深度**
   - 系统提供 5 个分析深度级别：
     - **1 级 - 快速分析**：基础数据概览，快速决策（2-5 分钟）
     - **2 级 - 基础分析**：常规投资决策（3-6 分钟）
     - **3 级 - 标准分析**：技术 + 基本面，推荐（4-8 分钟）
     - **4 级 - 深度分析**：多轮辩论，深度研究（6-11 分钟）
     - **5 级 - 全面分析**：最全面的分析报告（8-16 分钟）

5. **选择分析师团队**
   - 系统提供多个分析师角色，以卡片形式展示，点击卡片切换选中/取消：
     - **市场分析师**：分析个股价格走势与技术指标
     - **基本面分析师**：分析公司财务状况、业务模式和竞争优势
     - **新闻分析师**：分析相关新闻、公告和市场事件的影响
     - **社媒分析师**：分析社交媒体情绪、投资者心理和舆论导向
     - **大盘分析师**：分析大盘指数走势（仅 A 股可选）
     - **板块分析师**：分析行业趋势、板块轮动和同业对比（仅 A 股可选）
     - **ETF 分析师**：分析 ETF 净值、跟踪误差和持仓结构（仅 ETF 市场可选）
   - 默认选中"市场分析师"和"基本面分析师"。

6. **提交分析**
   - 点击"开始分析"。
   - 等待 2-16 分钟（取决于分析深度），在"任务中心"查看进度。
   - 分析完成后查看报告。

#### 一份完整的报告覆盖哪些维度

下面这张表是**每次分析实际会跑的分析维度**：

| 维度 | 由谁负责 | 在报告里能看到什么 |
|------|---------|------------------|
| **价格走势** | 市场分析师 | 当前价、涨跌幅、成交量、换手率 |
| **技术指标** | 市场分析师 | 方向信号、超买超卖、趋势方向 |

| **图表形态** | 市场分析师 | 头肩顶底、双顶双底、三角 |

| **财务表数据** | 基本面分析师 | 营收、利润、毛利率、现金流 |
| **盈利质量** | 基本面分析师 | 5 维度 0-100 分 |
| **财务健康** | 基本面分析师 | Altman Z、Piotroski F |
| **财报造假检测** | 基本面分析师 | Beneish M（8 维度） |
| **估值水平** | 基本面分析师 | PE/PB/PS/PEG |
| **DCF 估值** | 基本面分析师 | 公司值多少钱 |

#### 执行轨迹（v3.0 核心能力 — 让 AI 跑哪里都能查到）

**这是 v3.0 最重要的可追溯能力。** 任务详情页的"执行轨迹"标签页会把这次分析**每一步**都记录下来，AI 不是黑盒了。

**怎么开**（两种方式）：

- **方式 1（推荐）— 全局开关**："个人设置 → 助理设置 → 执行轨迹" → 启用。开启后所有新分析任务都会记录。
- **方式 2（单次）— 任务级开关**：在任务详情页右上角点击"开启记录"按钮，只针对当前任务。

> 💡 默认**关闭**（避免给数据库造成压力）。建议在排查问题时开启，正常分析时关闭。

**开启后能看到什么**：

| 字段 | 含义 | 排查问题时的用途 |
|------|------|----------------|
| **Agent 列表** | 这次分析跑了哪些 Agent | 确认每个 Agent 是不是都跑到了 |
| **每个 Agent 的输入** | 它看到了什么 | 排查"为什么这个 Agent 结论这么奇怪" |
| **系统提示词 + 用户提示词** | LLM 实际收到的 prompt | 排查"是不是 prompt 没传对" |
| **LLM 原始返回** | LLM 实际说了什么 | 排查"是不是 LLM 答非所问" |
| **工具调用记录** | 调用了哪些工具、传了什么参数 | 排查"是不是工具拿错数据了" |
| **校验结果** | 输出是否符合格式 | 排查"为什么这次报告格式不对" |
| **Token 用量** | 这次分析消耗多少 Token | 排查"为什么 Token 涨这么多" |
| **耗时** | 每个 Agent 用了多少秒 | 排查"为什么这么慢" |

#### 注意事项

- 京东云版任务并发为 1，逐个执行。
- 排队中的任务可以随时取消。
- 失败任务重试时，会重新消耗 Token。
- 开启执行轨迹对 Token 消耗几乎无影响（只记录不增加新 LLM 调用），但会增加数据库存储。

## 第二章 学习研究与模拟功能

> 本章介绍用于学习研究和策略验证的功能模块，包括模拟交易、持仓研究、操作复盘和交易计划。这些功能帮助您在虚拟环境中验证研究假设、复盘操作行为、制定系统化跟踪计划，**不构成任何投资建议**。

### 2.1 模拟交易

#### 功能说明

模拟交易系统提供虚拟资金环境，支持模拟买入、模拟卖出、模拟持仓管理，帮助您在不投入真实资金的情况下学习市场操作流程、验证研究假设。v3.0 支持 A 股和 ETF 模拟交易。

#### 操作步骤

1. **初始化模拟账户**
   - 首次进入"模拟交易"，系统会提示创建模拟账户。
   - 设置初始资金（默认 100 万人民币）。
   - 选择账户类型：A股账户。

2. **模拟买入（虚拟建仓）**
   - 点击"买入"按钮。
   - 输入股票代码、模拟买入价格、数量。
   - 可选择"市价"（以最新价成交）或"限价"（按指定价格挂单）。
   - 系统自动计算手续费、印花税等成本。
   - 确认后提交，成交后更新持仓和可用资金。

3. **模拟卖出（虚拟平仓）**
   - 在持仓列表中选择要卖卖的股票。
   - 点击"卖出"，输入模拟卖出价格和数量。
   - 系统自动计算盈亏。

4. **持仓查看**
   - "持仓"页签显示当前所有持仓。
   - 每只股票显示：持仓数量、成本价、现价、浮动盈亏、盈亏比例。

5. **交易记录**
   - "记录"页签显示所有历史交易明细。
   - 支持按时间、股票筛选。

6. **账户统计**
   - "统计"页签显示账户总览：总资产、总市值、可用资金、总盈亏、收益率。
   - 提供收益曲线图。

#### 京东云版注意事项

- 🔒 **京东云版不支持 QMT 同步**，模拟账户需手动初始化
- 模拟交易数据不影响真实账户，仅用于学习研究和策略验证
- 模拟交易不模拟涨跌停限制和停牌，与真实交易存在差异
- 手续费按真实费率计算（A股约万分之 2.5 + 印花税千分之 1）
- 模拟账户资金可重置，重置后清空所有持仓和记录

### 2.2 持仓研究

#### 功能说明

持仓研究模块对您当前的模拟持仓进行深度分析，评估组合的风险暴露、行业集中度、相关性和优化建议。

#### 操作步骤

1. **进入持仓研究**
   - "持仓研究"页面自动读取模拟交易中的持仓数据。
   - 也可手动导入持仓（支持 Excel 模板上传）。

2. **组合概览**
   - 显示组合总市值、行业分布、仓位分布。
   - 饼图展示各行业占比、各股票占比。

3. **风险评估**
   - **行业集中度**：分析是否过度集中于某行业。
   - **个股集中度**：分析单只股票占比是否过高。
   - **相关性分析**：计算持仓间相关系数，评估分散度。
   - **Beta 暴露**：计算组合相对大盘的 Beta 值。

4. **优化建议**
   - 系统基于现代投资组合理论给出配置参考。
   - 标注过度集中的持仓，提示仓位集中风险。
   - 推荐可补充的行业或标的以提升分散度。

5. **一键分析**
   - 可对单只持仓发起"单股研究"，快速获取深度分析报告。

#### 京东云版注意事项

- 🔒 **京东云版需手动添加持仓**，不支持 QMT 同步

### 2.3 操作复盘

#### 功能说明

操作复盘模块帮助您回顾历史交易行为，分析盈亏原因，总结交易经验，持续改进交易策略。v3.0 引入 **5 个专项复盘 Agent**，把复盘从"凭感觉写总结"升级为"结构化归因分析"。

#### 5 类复盘 Agent

每次创建复盘时，**5 个 Agent 会各管一摊**，从不同角度帮您分析这笔交易：

| 复盘 Agent | 关注什么 | 会问您什么 |
|-----------|---------|----------|
| **时机复盘**（timing） | 交易时点 | 当时是不是好时机？是不是追高了？是不是杀跌了？ |
| **仓位复盘**（position） | 仓位大小 | 仓位是不是太重？调仓节奏是否合理？ |
| **情绪复盘**（emotion） | 决策心态 | 当时是不是被情绪左右？有没有 FOMO、恐惧、贪婪？ |
| **归因复盘**（attribution） | 盈亏来源 | 这次赚/亏是来自行业 β、个股 α、还是运气？ |
| **复盘经理**（review_manager） | 综合归因 | 综合上述 4 个角度，给出最终结论 |

#### 操作步骤

1. **创建复盘记录**
   - "操作复盘"页面，点击"新建复盘"。
   - 选择要复盘的交易（从模拟交易记录中选取）。
   - 或手动录入一笔交易进行复盘。

2. **5 类复盘自动触发**
   - 选择交易后，系统自动调用 4 个分析师并行分析，再由复盘经理汇总
   - 每个分析师独立生成报告（3-5 分钟）
   - 复盘经理综合 4 个角度给出最终结论

3. **复盘内容**
   - **交易背景**：当时为什么做这笔交易？
   - **决策依据**：基于什么信息或信号？
   - **实际结果**：盈亏情况、持有时间。
   - **5 类 Agent 报告**：时机、仓位、情绪、归因、综合
   - **经验总结**：做对了什么？做错了什么？
   - **改进点**：下次类似情况如何操作？

4. **复盘统计**
   - 统计页面展示：总交易次数、胜率、平均盈亏、盈亏比。

5. **关联分析报告**
   - 复盘时可关联当时的研究报告，对比"分析结论"与"实际走势"的偏差。

#### 反思自动沉淀

每次复盘完成后，**复盘反思**（trade_lesson）会被自动写入 AI 记忆。Agent 在下次分析时会引用您之前的教训。

#### 注意事项

- 复盘是提升交易能力的关键环节，建议对每笔重要交易都进行复盘。
- 复盘记录会自动关联到 AI 记忆系统，智能助手可在后续分析中参考您的交易偏好。
- 5 类复盘 Agent 每次都会跑（不可单独关闭），但您可以只看"复盘经理"的综合结论。

### 2.4 交易计划

#### 功能说明

交易计划模块帮助您制定系统化的交易计划，包括入场条件、仓位管理、收益关注规则和风险关注规则，并可关联分析报告自动生成计划。

#### 操作步骤

1. **创建交易计划**
   - "交易计划"页面，点击"新建计划"。
   - 选择目标股票。
   - 可选择"从分析报告生成"（系统根据最新报告自动填充建议参数）。

2. **设置计划要素**
   - **入场条件**：价格触发条件、技术指标条件、基本面条件。
   - **计划仓位**：初始仓位、追加观察规则、最大仓位。
   - **收益关注规则**：收益关注价位、分批跟踪、移动跟踪。
   - **风险关注规则**：风险关注价位、风险比例、时间观察。
   - **跟踪周期**：短线（数日）/ 波段（数周）/ 中线（数月）/ 长线（数年）。

3. **计划模板**
   - 系统内置多种研究跟踪计划模板（趋势跟踪、价值投资、事件驱动等）。
   - 可基于模板快速创建，再根据实际情况调整。
   - 支持保存自定义模板。

4. **计划执行跟踪**
   - 计划创建后进入"待执行"状态。
   - 当市场价格触发入场条件时，系统会发出通知。
   - 可手动标记"已入场"、"已触及收益关注位"、"已触及风险关注位"。

5. **计划与复盘联动**
   - 计划完成后可一键生成"操作复盘"记录，形成闭环。

#### 注意事项

- 交易计划不会自动下单，仅作为学习研究和纪律约束工具，**不构成投资建议**。
- 收益/风险价格条件触发时系统会推送通知，但不会自动执行交易。
- 建议在模拟交易中验证计划假设后再作为个人决策参考。

## 第三章 智能助手

### 3.1 AI 对话助手

#### 功能说明

智能助手是 v3.0 的核心升级模块，从"分析触发器"进化为"投资研究协同入口"。支持自然语言对话，可调用 20+ 操作工具，跨模块完成任务，支持多主题会话。

#### 核心能力

智能助手的 20+ 工具按功能分为 5 大类：

| 工具类别 | 典型能力 | 示例说法 |
|---------|---------|---------|
| **分析触发** | 发起单股/批量分析 | "帮我分析一下贵州茅台" |
| **报告查询** | 搜索、查看、解读历史报告 | "查一下我上个月的分析报告" |
| **联网搜索** | Web 搜索、近期信息搜索、网页内容抓取 | "帮我搜一下最近的半导体新闻" |
| **板块数据** | 板块行情、板块数据、资金流向、同业对比 | "新能源板块最近表现怎么样" |
| **价格提醒** | 设置收益关注提醒、设置价格下限提醒 | "帮我设一个 50 元的价格下限提醒" |

此外还支持：任务管理、股票关注列表管理、持仓分析、交易复盘、交易计划管理、复杂任务拆解、RAG 金融知识检索。

#### 操作步骤

1. **进入智能助手**
   - 左侧导航栏"智能助手"，或按 `Ctrl+/` 快捷键。

2. **创建会话**
   - 点击"新建会话"，可选择会话主题（如"贵州茅台研究"、"消费板块跟踪"）。
   - 每个主题独立维护消息历史与上下文。

3. **对话交互**
   - 直接输入问题或指令，例如：
     - "帮我分析一下贵州茅台最近的基本面"
     - "我最近关注的股票表现怎么样？"
     - "帮我把 ROE 大于 20% 的股票筛出来"
     - "查一下我上个月买的宁德时代现在赚了多少"
     - "帮我搜一下最近的新能源行业政策"
     - "白酒板块今天的资金流向怎么样"
     - "帮我给贵州茅台设一个 1800 元的价格下限提醒"
   - 助手会理解意图、调用工具、返回结构化结果。

4. **多轮对话**
   - 助手会记住最近 10 条对话上下文，支持追问。
   - 例如先问"分析贵州茅台"，再问"它的风险点有哪些"，助手能理解"它"指代贵州茅台。

5. **会话管理**
   - 可创建多个会话主题，切换时上下文独立。
   - 支持手动"总结会话"生成结构化摘要。
   - 可重命名、删除、归档会话。

#### 京东云版注意事项

- 京东云版的助手基于京东云提供的 LLM 服务
- 多主题会话、记忆上下文功能与标准版一致
- 工具集与标准版一致（20+ 个工具）

### 3.2 AI 记忆

#### 功能说明

AI 记忆是 v3.0 的记忆系统，系统会自动记忆每次分析的关键结论、用户的交易偏好和关注重点，在后续分析中作为上下文注入，实现"越用越懂您"。

#### 记忆区块

AI 记忆页面由 **3 个垂直堆叠的记忆区块**组成，从上到下依次为：

| 区块 | 记忆什么 | 数据来源 |
|------|---------|---------|
| **股票对象记忆** | 每次分析的结论（带市场、标的、日期、结论的对象化长期记忆） | `analysis_insight` 类记忆，按股票归档 |
| **我的偏好与纪律记忆** | 您的投资风格、风险偏好、持仓周期、行业偏好，以及交易复盘和投资计划同步的纪律要点 | `user_preference` + `trade_pattern` 两类记忆合并展示 |
| **智能助手事实记忆** | 智能助手通过联网工具提取并保存的事实（含数据采集时间与有效期），跨会话自动引用 | `assistant_memory_facts` |

#### 操作步骤

1. **查看记忆**
   - "AI 记忆"页面从上到下浏览 3 个区块。
   - 股票对象记忆支持按股票代码、市场筛选。
   - 每条记忆显示：内容摘要、来源、创建时间。

2. **记忆管理**
   - **删除记忆**：过期或错误的记忆可删除（支持批量删除）。
   - **手动添加**：可在偏好与纪律区块手动录入一条记忆。

3. **记忆注入**
   - 系统在执行分析时，会自动检索相关记忆并注入到分析师的上下文中。
   - 在智能助手对话中，用户画像记忆会自动注入。

#### 注意事项

- 记忆系统是 AI 能力的"放大器"，但记忆条目过多可能增加 Token 消耗。
- 建议定期清理过期记忆。
- 原始自由文本记忆已从用户视图隐藏，只展示对象化的长期记忆。

### 3.3 使用问答助手（右下角浮窗）

#### 功能说明

系统提供使用问答助手（右下角浮窗入口），专门回答系统使用问题。区别于智能助手，使用问答助手只回答"系统使用"类问题，不调用任何金融市场数据工具。

#### 能回答的 8 类问题

| 类别 | 示例问题 |

### 5.1 批量分析

#### 功能说明

批量分析支持同时分析多只股票，适用于跟踪多只标的的用户。

#### 操作步骤

1. **进入批量分析**
   - 左侧导航栏"批量分析"。

2. **添加分析任务**
   - 点击"新建批量分析"。
   - 输入股票代码列表（每行一个，或粘贴从 Excel 复制的代码）。
   - 选择分析深度和分析师团队。

3. **提交分析**
   - 点击"开始分析"。
   - 系统会逐个执行（**京东云版并发为 1**）。

4. **查看进度**
   - 在"任务中心"查看每只股票的分析进度。

#### 京东云版注意事项

- 关注分组超过 5 只时，建议拆分为多个小分组分时段执行
- 批量分析完成后，可通过"渠道推送"自动发送通知

### 5.2 定时分析

#### 功能说明

定时分析可让系统按预设时间自动跑分析任务，并通过渠道推送（飞书/钉钉/邮件）通知用户。

#### 5.2.1 定时分析分组

定时分析跑的是**关注分组里的股票**，所以需要先创建关注分组。

> 💡 **操作路径**：股票关注列表 → 新建分组（详见 1.5 股票关注列表）

#### 5.2.2 定时分析配置

##### 操作步骤

1. **进入定时分析**
   - 设置 → 定时分析配置

2. **创建定时任务**
   - 点击"创建配置"
   - 填写配置名称（如"每日盘后跟踪"）
   - 启用（默认开启）

3. **配置时间段（time_slots）**
   - 每个时段是独立的触发规则
   - 简单模式：预设盘前 9:15 / 开盘 9:30 / 收盘 15:00
   - 高级模式：Cron 表达式
   - 选择分析深度（1-5 级）
   - 选择关注分组

4. **选择推送渠道**
   - 选择哪些渠道接收通知

5. **测试配置**
   - 点击"测试执行"按钮
   - 验证 Cron 表达式、关注分组、渠道配置

6. **启用任务**
   - 配置列表右侧有开关
   - 关闭后定时任务暂停，配置保留

##### 京东云版定时分析建议

- **盘后分析**：设置在 16:30 之后执行
- **错峰分组**：不同关注组别设置在不同时间段
- **大分组拆分**：关注分组超过 5 只时，建议拆分为多个小分组

## 第九章 常见问题（FAQ）

### Q1：登录后看不到某些功能？

**答**：京东云版默认所有功能开放。如果您看不到某些功能，请联系京东云技术支持。

### Q2：分析任务报 429 限速错误怎么办？

**答**：
- 系统已内置指数退避重试（最多 8 次），大多数情况会自动恢复
- 避开高峰时段（交易时段 9:30-15:00）
- 降低分析深度
- 减少批量规模（单次不超过 5 只）
- 联系京东云技术支持调整限速策略

### Q3：界面看不到 LLM 配置入口？

**答**：这是京东云版的设计特性。LLM 配置由京东云统一管理，用户无需关心。

### Q4：数据源为什么只有 Tushare？

**答**：京东云版只集成 Tushare，因为：
- 京东云版只支持 A 股
- Tushare 已能覆盖 A 股 99% 的数据需求
- 多数据源会增加 LLM 选源复杂度

### Q5：批量分析只跑 1 只就不动了？

**答**：京东云版并发为 1，逐只执行。耐心等待，或：
- 减少批量规模（单次不超过 5 只）
- 避开高峰时段

### Q6：港股/美股能分析吗？

**答**：不能。京东云版仅支持 A 股和 ETF，港股、美股功能已暂停。

### Q7：报告里的"目标价"、"买卖建议"在哪？

**答**：京东云版**不提供**这些内容。所有决策标签只有 3 个：**乐观/审慎/中性**（表达研究倾向，不构成投资建议）。

### Q8：模拟交易的钱能提现吗？

**答**：不能。模拟交易是纯练手，资金是虚拟的。

### Q9：Embedding 模型能切换吗？

**答**：不能。京东云版锁定使用 Qwen3-Embedding-8B（1024 维），切换会报错。

### Q10：AI 助手回答错了怎么办？

**答**：在同一会话里直接说"你错了，应该是 X"，AI 会基于上下文修正。

### Q11：AI 记忆的会话能分享吗？

**答**：默认不分享，每个用户独立。需要导出可以复制粘贴到外部。

### Q12：能选择 GLM-5 之外的模型吗？

**答**：不能。京东云版仅提供 4 个模型：GLM-5、GLM-5.1、GLM-5.2、DeepSeek-V4-Flash。

## 第十章 最佳实践

### 10.1 新手使用建议

#### 第 1 天：跑通第一次分析

1. 登录系统，进入仪表板
2. 点击"单股研究"卡片
3. 输入一只熟悉的股票代码（如 `600519`）
4. 保持默认设置（3级-标准分析 + 市场分析师 + 基本面分析师）
5. 等待 4-8 分钟，看报告

#### 第 1 周：熟练核心功能

- 用股票筛选找标的
- 用关注列表管理标的
- 用智能助手替代部分菜单操作
- 学会看任务中心和执行轨迹

#### 第 1 月：交易功能

- 初始化模拟账户
- 跑几笔模拟交易
- 复盘每笔交易
- 制定交易计划

### 10.2 日常研究工作流

#### 早间（9:00 之前）

- 查看昨晚定时分析推送
- 标记需要关注的股票

#### 盘中（9:30-15:00）

- 进入股票详情页看实时行情
- 关注 AI 决策变化

#### 盘后（15:00 之后）

- 进入持仓研究看组合表现
- 跑深度分析（4级或5级）

#### 周末

- 用通用研究分析行业/主题
- 复盘本周交易
- 更新关注列表

### 10.3 成本控制实践

#### 节省 Token 的方法

- 优先使用"快速分析"（2-5 分钟 vs 深度分析 6-11 分钟）
- 减少同时选中的分析师数量（2 个 vs 4 个）
- 使用 GLM-5 而非 GLM-5.1（除非需要深度推理）
- 批量任务使用 DeepSeek-V4-Flash（速度更快、省 token）

#### 监控 Token 用量

- 进入"设置 → 使用统计"
- 查看今日、本周、本月 Token 消耗
- 关注"按模型分布"和"按任务类型分布"两个维度

### 10.4 限速应对策略

#### 京东云 LLM 限速

🔒 京东云 LLM 服务有 QPS 限速。具体限速策略由京东云确定，**未对外公开**。

#### 系统已自动应对

- 指数退避重试：遇到 429 错误自动重试（最多 8 次）
- 降并发机制：批量分析并发为 1，Worker 任务并发为 1
- 任务间间隔：每只股票分析间隔 10 秒

#### 用户操作建议

- **遇到限速**：通常系统会自动恢复，无需操作
- **频繁限速**：降低分析深度（从 5 级降为 3 级），减少批量规模
- **极端情况**：联系京东云技术支持调整

#### 批量规模控制

- **单次批量 ≤ 5 只**：推荐，几乎不会触发限速
- **单次批量 5-10 只**：可接受，建议错峰
- **单次批量 > 10 只**：不推荐，建议分批

### 10.5 数据管理实践

- 关注列表每个分组不超过 50 只
- 定期清理过期 AI 记忆
- 重要报告及时导出（PDF 或 Markdown）

## 附录：合规说明

### 功能边界

京东云版**仅支持 A 股市场分析**，港股、美股功能已暂停（系统全局限制）。

### 免责声明

本平台提供的研究报告**仅供学习参考，不构成任何投资建议**。所有分析结果由 AI 模型基于历史数据生成，**不代表对未来收益的承诺**。投资有风险，决策需谨慎。

### 数据来源

- **行情数据**：Tushare（公开金融数据接口）
- **新闻数据**：Tushare 公开新闻接口
- **财务数据**：Tushare 财报数据
- **AI 推论**：基于 LLM 推理，系统会标记哪些是真实数据、哪些是 AI 推论

### 用户数据

- 用户的关注列表、任务记录、设置等数据**存储在京东云服务器**
- 用户的分析请求、报告内容**仅在用户和京东云 LLM 服务之间传递**，不经过第三方
- 系统不收集任何用户隐私信息

### 模型输出

LLM 可能产生错误或误导性输出，**所有结论都需要用户自行判断**。系统不提供"目标价"、"买卖建议"等具体投资指引，仅提供分析维度和参考数据。

**决策标签说明**：系统使用三个合规标签表达研究结论倾向：
- **乐观**：积极信号，可结合其他维度考虑
- **审慎**：谨慎信号，建议等待更多信息
- **中性**：弱信号，需要更多数据支持

这些标签表达的是研究倾向，**不构成交易建议**。

### AI 标识

AI 生成内容（如研究报告、复盘结论）会明确标识"AI 生成"，方便用户区分。
