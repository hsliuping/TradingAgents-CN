# TradingAgents-CN v1.1.0 发布说明

> **发布日期**：2026-07-24
> **版本类型**：功能增强版本
> **上一版本**：v1.0.1

---

## 📋 版本概述

v1.1.0 在 v1.0.1 的基础上，重点集成了火山方舟模型服务、增强了推理模型支持、统一了开发启动脚本，并完善了项目文档体系。

---

## ✨ 新功能

### 1. 火山方舟（VolcEngine Ark）Provider 集成

- 新增火山方舟 Provider 注册与基础设施适配
- 支持编程版模型硬编码配置
- 前端火山方舟 Provider 配置界面与测试模型输入框
- 密码兼容性处理

### 2. 推理模型优化

- `reasoning_effort` 参数全链路传递（前端 → 后端 → LLM 调用）
- 推理模型超时保护优化
- 数据模型添加 `reasoning_effort` / `test_model` 字段
- 火山方舟模型过滤支持

### 3. 统一开发启动脚本

- 新增 `start_dev.ps1` 统一启动脚本
- 支持 v1.0 / v2.0 / v2.1 / v3.0 多版本开发环境一键启动
- 自动设置正确的 MongoDB / Redis / 后端 / 前端端口
- 支持京东云合作版模式（独立容器、端口、数据卷）

## 📦 升级指南

从 v1.0.1 升级到 v1.1.0：

1. 拉取最新代码：`git pull origin main`
2. 更新依赖：`pip install -r requirements.txt`
3. 更新前端依赖：`cd frontend && npm install`
4. 使用统一启动脚本：`.\start_dev.ps1 docker 3.0` → `.\start_dev.ps1 backend 3.0` → `.\start_dev.ps1 frontend 3.0`
