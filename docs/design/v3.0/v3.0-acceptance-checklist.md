# TradingAgents-CN v3.0 功能验收清单

## 文档目的

本清单用于 v3.0 版本 UAT / 验收测试。

自 2026-05-11 起，`v3.0` 已按 `v3.x-release-plan.md` 拆分为多个小版本。

因此，本文件当前更适合作为“v3.x 全量能力池参考”，而不是单一小版本的最终发布验收范围。

单版本验收请优先参考：

- `v3.0.0`：`docs/design/v3.0/v3.0.0-acceptance-test-plan.md`
- `v3.1.0`：`docs/design/v3.1/v3.1.0-acceptance-test-plan.md`
- `v3.2.0`：`docs/design/v3.2/v3.2.0-acceptance-test-plan.md`
- `v3.3.0`：`docs/design/v3.3/v3.3.0-acceptance-test-plan.md`
- `v3.4.0`：`docs/design/v3.4/v3.4.0-acceptance-test-plan.md`

整理依据：

- `docs/design/v3.0/implementation-status-report.md`
- `docs/design/v3.0/` 目录下各专项设计文档

本清单只保留“当前应作为验收对象的功能”，并将“设计预留 / 部分实现 / 后续扩展”单独列出，避免把规划项误判成缺陷。

## 使用说明

验收优先级定义：

- `P0`：核心阻塞项。失败应阻塞 v3.0 验收。
- `P1`：重要增强项。建议验收，但可根据发布范围决定是否阻塞。
- `P2`：设计预留、部分实现或后续扩展项。不建议作为本轮阻塞标准。

建议验收顺序：

1. 智能助手与研究工作台
2. 智能选股、MCP、Gateway、通知
3. AI 工作流架构师、Agent 工坊、Skill 生成
4. QMT / ETF
5. 统一记忆、动态产出、协作运行时等增强项

## 五、验收结论填写模板

建议每个功能点按以下格式记录：

| 功能点 | 结果 | 说明 |
| --- | --- | --- |
| 示例：P0-01 多主题研究会话 | 通过 / 不通过 / 有条件通过 | 如“不通过”，记录复现步骤、日志、截图、影响范围 |

推荐的最终结论口径：

- `通过`：P0 全部通过，P1 无阻塞风险
- `有条件通过`：P0 通过，但 P1 / P2 有待修整项
- `不通过`：存在 P0 失败项
