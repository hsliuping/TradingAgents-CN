# TradingAgents-CN 使用指南

欢迎使用 TradingAgents-CN v1.0.0-preview！本指南将带您全面了解系统的各项功能，帮助您快速上手，充分利用 AI 智能分析能力做出更明智的投资决策。

**⚠️ 重要免责声明**

TradingAgents-CN 是一个 AI 多 Agents 的股票分析学习平台。平台中的分析结论、观点和“投资建议”均由 AI根据股票数据自动生成，仅用于学习、研究与交流，不构成任何形式的投资建议或承诺。用户据此进行的任何投资行为及其产生的风险与后果，均由用户自行承担。市场有风险，入市需谨慎。

**🤖 第四步：选择 AI 模型**

系统按分析的Agent功能不同区分调用快速/深度模型：

使用快速思考模型的Agent（高并发、含大量工具调用）

  市场分析师、新闻分析师、社媒分析师、基本面分析师

  看涨研究员、看跌研究员（研究辩论前两位角色）

  交易员决策起草、信号处理（将报告提炼为结构化决策）

  风险评估中的：激进/保守/中性 分析师

使用深度思考模型的Agent（跨源综合、关键裁决）

  研究经理（整合各分析结果，形成阶段性结论）

  风险经理（综合风险意见，形成最终风险裁决）

模型选型建议（按研究深度）

快速/基础：分析师与前处理全用“快速模型”；研究经理处使用一次“深度模型”合成结论

标准：分析师与工具调用用“快速模型”；研究经理与风险经理用“深度模型”做关键裁决

深度/全面：在“研究经理/风险经理”处多轮调用“深度模型”（辩论/风控轮次更多），其余仍以“快速模型”并发处理

模型示例（可按部署情况替换）

  快速：GPT‑4o‑mini、Gemini 2.5 Flash、qwen-turbo

  深度：GPT‑4、Claude 4.5、DeepSeek、qwen-plus

分析级别与模型选择的关系（越往后越复杂）

不同的研究深度会改变“辩论/风控轮次、跨源整合复杂度、需要的上下文与Token预算”。因此越高的级别越需要在关键裁决环节使用更强的“深度模型”，效果才会更好：

**级别1｜快速**

  轮次：辩论/风控均为最低轮次

  Token/复杂度：低（以数据抓取、指标计算、初步判断为主）

  模型使用：分析师/工具=快速；研究经理=深度×1；风险经理=深度×1

  适用：快速浏览与初步判断，低成本、低时延

**级别2｜基础**

  轮次：与快速类似，但启用记忆等增强项

  Token/复杂度：低-中

  模型使用：分析师/工具=快速；研究经理=深度×1；风险经理=深度×1

  适用：日常评估，兼顾速度与完整性

**级别3｜标准（推荐）**

  轮次：辩论=1轮；风控=2轮

  Token/复杂度：中

  模型使用：分析师/工具=快速；研究经理=深度×1；风险经理=深度×1（风控更充分）

  适用：速度/质量平衡的常用设置

**级别4｜深度**

  轮次：辩论≥2轮；风控≥2轮

  Token/复杂度：中-高（跨源综合、逻辑链更长）

  模型使用：分析师/工具=快速；研究经理=深度多次；风险经理=深度多次

  适用：重大决策与高价值标的，建议使用更强深度模型

**级别5｜全面**

  轮次：辩论≈3轮；风控≈3轮

  Token/复杂度：高（长上下文、强推理、结果复核）

  模型使用：分析师/工具=快速；研究经理/风险经理=深度多次（必要时交叉复核）

  适用：最全面的尽调式分析，成本与时延最高

提示：提高研究深度会显著提升关键裁决环节（研究经理/风险经理）对深度模型的调用次数与上下文长度；选择更强的深度模型，通常能带来更清晰的投资逻辑、更稳妥的风控结论与更一致的结果质量。

🆘 常见问题

Q1: 如何开始第一次分析？

A: 进入"单股分析"页面，输入股票代码，选择分析深度，点击"开始分析"。



Q2: 分析需要多长时间？

A: 根据分析深度不同，快速分析 4-6 分钟，深度分析 10-15 分钟。

   

Q3: 如何查看历史分析报告？

A: 进入"分析报告"页面，可以查看所有历史报告。



Q4: 如何添加自选股？

A: 在股票详情页或分析报告页，点击"添加到自选股"按钮。



Q5: 如何导出分析报告？

A: 在报告详情页，点击"导出 Markdown"按钮。
