# TradingAgents-CN 平台功能与作用梳理

## 1. 平台定位

TradingAgents-CN 是一个面向中文用户的 AI 多智能体股票研究与学习平台。

它把股票数据同步、AI 分析、任务队列、研究报告、模拟交易、模型配置和系统运维整合到一个 Web 后台中，适合用于：

- 学习 AI、大语言模型和多智能体股票分析原理
- 做 A 股、港股、美股的辅助研究
- 批量生成和沉淀股票分析报告
- 对比不同 LLM 厂家、模型效果和使用成本
- 在虚拟账户里验证分析结论和交易想法
- 作为二次开发的投研系统底座

重要说明：平台定位是学习、研究和策略实验，不提供证券投资咨询服务，也不应直接作为实盘投资建议。

## 3. 核心业务功能

### 3.1 仪表板

仪表板是系统首页，用于快速了解平台当前状态。

主要能力：

- 快速进入单股分析、批量分析、股票筛选、任务中心、学习中心
- 查看最近分析任务
- 查看市场快讯
- 查看自选股摘要
- 查看模拟交易账户资金和总资产
- 查看多数据源同步状态

适用场景：

- 每天打开系统后的总览页
- 快速进入常用分析流程
- 判断数据源和模拟账户是否正常

### 3.2 学习中心

学习中心用于帮助用户理解 AI 股票分析的底层逻辑。

内容包括：

- AI 基础知识
- 大语言模型基本概念
- 提示词工程
- 模型选择指南
- 多智能体股票分析原理
- AI 使用风险与局限
- TradingAgents 源项目与论文资源
- 常见问题

适用场景：

- 新用户学习平台原理
- 团队内部培训
- 理解不同模型和分析深度的区别

### 3.3 单股智能分析

单股分析是平台的核心功能之一。

主要能力：

- 输入股票代码，支持 A 股、港股、美股
- 自动识别或手动选择市场类型
- 选择分析日期
- 选择分析深度
- 选择参与分析的智能体团队
- 配置快速分析模型和深度决策模型
- 实时查看分析进度
- 生成结构化分析结果和模块化报告
- 分析后可跳转模拟交易

分析深度通常包括：

- 快速分析
- 基础分析
- 标准分析
- 深度分析
- 全面分析

适用场景：

- 深入研究一只股票
- 对比不同 AI 模型给出的分析结果
- 形成可复盘的股票研究报告

### 3.4 批量分析

批量分析用于同时分析多只股票。

主要能力：

- 批量输入股票代码
- 自动解析股票列表
- 校验股票代码格式
- 设置批次标题和描述
- 统一设置分析深度、语言、分析师团队和高级参数
- 批量创建分析任务
- 后续在任务中心查看进度和结果

适用场景：

- 板块研究，例如银行、消费、科技、新能源
- 股票池初筛后的批量深入分析
- 同一分析框架下比较多个标的

### 3.5 任务中心

任务中心用于管理 AI 分析任务。

主要能力：

- 按进行中、已完成、失败、全部分类查看任务
- 按时间、市场、状态、股票筛选
- 搜索股票代码或名称
- 查看分析结果
- 查看报告详情
- 查看失败原因
- 重试失败任务
- 将异常任务标记失败
- 删除任务记录

适用场景：

- 管理长时间运行的 AI 分析
- 排查分析失败原因
- 批量分析后集中查看结果

### 3.6 报告中心

报告中心用于管理历史分析报告。

主要能力：

- 查看报告列表
- 按股票代码、股票名称、市场、日期筛选
- 查看报告详情
- 按模块阅读报告内容
- 下载和导出报告
- 查看报告关联的模型信息和创建时间

报告内容通常会按照分析模块组织，例如：

- 市场分析
- 基本面分析
- 新闻分析
- 社媒或情绪分析
- 风险分析
- 投资参考结论

适用场景：

- 沉淀研究成果
- 回看历史 AI 分析逻辑
- 给团队成员或客户做研究材料草稿

## 4. 股票数据与投研辅助功能

### 4.1 股票详情页

股票详情页展示单只股票的综合信息。

主要能力：

- 查看实时行情
- 查看基本面指标
- 查看 K 线数据
- 查看新闻和公告
- 查看财务数据
- 查看历史分析记录
- 发起 AI 分析
- 加入或移出自选股
- 清理缓存
- 同步股票数据
- 跳转模拟交易

单股同步支持：

- 实时行情
- 历史行情
- 财务数据
- 基础数据

适用场景：

- 在分析前检查数据是否完整
- 从行情、财务、新闻多个维度快速了解股票
- 对单只股票做数据补全

### 4.2 股票筛选

股票筛选用于构建候选股票池。

筛选条件包括：

- 市场类型
- 行业分类
- 市值范围
- 市盈率 PE
- 市净率 PB
- ROE
- 涨跌幅
- 成交量水平
- 技术形态

筛选结果展示：

- 股票代码
- 股票名称
- 行业
- 当前价格
- 涨跌幅
- 市值
- PE
- PB
- ROE
- 板块
- 交易所

可执行操作：

- 对筛选结果发起单股分析
- 加入或移出自选股
- 导出筛选结果

适用场景：

- 从全市场中找候选标的
- 根据估值、盈利能力和技术形态做初筛
- 为批量分析准备股票列表

### 4.3 自选股管理

自选股用于管理个人关注列表。

主要能力：

- 添加自选股
- 编辑自选股
- 删除自选股
- 按市场、板块、交易所、标签筛选
- 搜索股票代码或名称
- 管理自定义标签
- 添加备注
- 单只股票同步数据
- 批量同步自选股数据
- 从自选股跳转详情、分析、模拟交易

适用场景：

- 管理长期关注股票
- 给股票打标签，例如“高股息”“AI”“观察中”
- 批量维护自选股行情和财务数据

## 5. 模拟交易功能

模拟交易是虚拟交易环境，不连接真实券商账户。

主要能力：

- 查看 A 股、港股、美股虚拟账户
- 查看现金、持仓市值、总资产、已实现盈亏
- 下市场单
- 买入或卖出股票
- 查看当前持仓
- 查看订单历史
- 将交易与分析报告关联
- 从持仓跳转股票详情或分析页面
- 重置模拟账户

适用场景：

- 对 AI 分析结果做虚拟验证
- 观察交易想法在虚拟账户中的表现
- 做策略学习和演练

## 6. 配置与模型管理

### 6.1 大模型厂家管理

平台支持配置多个 LLM 厂家或 OpenAI 兼容聚合渠道。

可管理内容：

- 厂家名称和标识
- API Key
- Base URL
- 启用状态
- 厂家能力
- 描述信息

常见厂家或渠道包括：

- OpenAI
- DeepSeek
- Google AI
- 阿里百炼 DashScope
- OpenRouter
- AiHubMix
- 302.AI
- One API / New API 等 OpenAI 兼容渠道

### 6.2 模型配置

模型配置用于管理实际参与分析的模型。

可管理内容：

- 模型名称
- 显示名称
- 所属厂家
- 启用状态
- 输入/输出 Token 定价
- 模型能力
- 默认快速分析模型
- 默认深度决策模型
- 超时、温度等参数

适用场景：

- 根据成本和能力选择模型
- 区分快速任务和深度任务
- 管理多个供应商的模型池

### 6.3 数据源配置

数据源配置用于管理股票数据来源。

支持的数据源包括：

- Tushare
- AKShare
- BaoStock
- 其他扩展数据源

可管理内容：

- 数据源启用状态
- API Key 或 Token
- 优先级
- 市场分类
- 分组
- 连通性测试

适用场景：

- 确保股票数据可用
- 配置数据源优先级
- 在某个数据源失败时使用备用链路

## 10. 推荐使用流程

首次使用建议按以下流程：

1. 登录系统
2. 进入配置管理
3. 配置 LLM 厂家和 API Key
4. 配置模型目录和可用模型
5. 配置数据源，例如 Tushare、AKShare、BaoStock
6. 在多数据源同步页面测试数据源
7. 对一只股票执行单股数据同步
8. 打开股票详情页检查行情、财务和新闻数据
9. 发起一次单股分析
10. 在任务中心查看分析进度
11. 在报告中心查看分析报告
12. 根据分析结果在模拟交易中做虚拟交易实验

日常使用建议流程：

1. 打开仪表板查看状态
2. 检查多数据源同步是否正常
3. 使用股票筛选或自选股确定候选标的
4. 对重点股票执行单股分析
5. 对股票池执行批量分析
6. 在任务中心跟踪进度
7. 在报告中心复盘报告
8. 用模拟交易验证想法

## 12. 使用限制与注意事项

1. 平台不是证券投资咨询工具，输出内容不能直接作为买卖依据。
2. AI 分析依赖数据源质量，数据缺失或同步失败会影响结果。
3. 完整分析需要可用的 LLM API Key。
4. 不同模型的能力、成本、延迟差异较大，需要结合 Token 统计选择。
5. Tushare、AKShare 等数据源可能存在限流、网络失败或接口变化。
6. 模拟交易仅用于虚拟验证，不代表真实交易可执行结果。
7. 生产环境应修改默认管理员密码、JWT 密钥、数据库密码等敏感配置。
8. 商业使用需要注意项目许可证和授权边界。
