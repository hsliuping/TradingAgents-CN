# 📚 工作流模板总览

## 概述

TradingAgents-CN v2.0/v3.0 提供了多种预定义的工作流模板，涵盖从简单到复杂的各种分析场景。用户可以直接使用这些模板，也可以基于模板进行自定义修改。

---

## 🎯 模板分类

### 1. 基础模板

| 模板 | ID | 描述 | 节点数 | 适用场景 |
|------|----|----|--------|---------|
| **空白流程** | `blank_workflow` | 只包含开始和结束节点 | 2 | 自定义流程、学习、原型开发 |
| **单智能体流程** | `single_agent_*` | 单个 Agent 执行 | 3 | 调试、单一分析 |
| **快速分析流** | `simple_analysis` | 2个分析师 + 交易员 | 5 | 快速决策、日常参考 |

### 2. 完整分析模板

| 模板 | ID | 描述 | 节点数 | 适用场景 |
|------|----|----|--------|---------|
| **TradingAgents 完整分析流** | `default_analysis` | 6个分析师 + 辩论 + 风险管理 | 15+ | 深度分析、重要决策 |
| **v2.0 完整分析流** | `v2_stock_analysis` | 基于 v2.0 Agent 架构 | 15+ | v2.0 架构分析 |

### 3. 专项分析模板

| 模板 | ID | 描述 | 节点数 | 适用场景 |
|------|----|----|--------|---------|
| **持仓分析流程** | `position_analysis_v2` | 技术面 + 基本面 + 风险评估 | 6 | 持仓诊断、操作建议 |
| **交易复盘流程** | `trade_review_v2` | 时机 + 仓位 + 情绪 + 归因 | 7 | 交易复盘、经验总结 |

## 📦 模板详细说明

### 1. 空白流程 (BLANK_WORKFLOW) 🆕

**特点**:
- ✅ 最简单的模板，只有 start 和 end
- ✅ 完全自定义，无预设节点
- ✅ 适合学习和快速原型开发
- ✅ **支持调试功能** - 可直接执行测试 ✨

**使用场景**:
```python
from core.workflow.templates import BLANK_WORKFLOW

# 复制模板
workflow = BLANK_WORKFLOW.model_copy(deep=True)

# 添加自定义节点
workflow.nodes.append(...)
```

**调试功能**:
- 在工作流编辑器顶部工具栏点击"执行"按钮（绿色）
- 输入股票代码即可执行测试
- 实时查看工作流执行结果
- 支持快速迭代：修改 → 保存 → 执行 → 调整

**详细文档**: [空白工作流使用指南](./BLANK_WORKFLOW_GUIDE.md)

---

### 2. 单智能体流程 (SingleAgentWorkflow)

**特点**:
- ✅ 动态创建，支持任意 Agent
- ✅ 用于调试和测试
- ✅ 简单直接

**使用场景**:
```python
from core.workflow.templates import SingleAgentWorkflow

# 创建单 Agent 工作流
workflow = SingleAgentWorkflow(
    agent_id="market_analyst_v2",
    config={"focus": "技术分析"}
)
```

### 3. 快速分析流 (SIMPLE_WORKFLOW)

**流程图**:
```
开始
 ├─> 市场分析师 ─┐
 └─> 新闻分析师 ─┴─> 交易员 ─> 结束
```

**特点**:
- ✅ 2个分析师并行分析
- ✅ 省略辩论和风险管理
- ✅ 执行速度快（~2-3分钟）

**适用场景**:
- 日常快速决策
- 盘中快速参考
- 初步筛选股票

---

### 4. TradingAgents 完整分析流 (DEFAULT_WORKFLOW)

**流程图**:
```
开始
 ├─> 大盘分析师 ─┐
 ├─> 板块分析师 ─┤
 ├─> 市场分析师 ─┤
 ├─> 基本面分析师 ─┤
 ├─> 新闻分析师 ─┤
 └─> 社交媒体分析师 ─┴─> 看多研究员 ←→ 看空研究员 (辩论)
                          ↓
                      研究经理 ─> 交易员 ─> 风险经理 ─> 结束
```

**特点**:
- ✅ 6个专业分析师并行分析
- ✅ 多轮辩论机制
- ✅ 完整的风险管理
- ✅ 辩论轮次根据分析深度动态调整

**分析深度配置**:
| 深度 | 多空辩论 | 风险辩论 | 记忆 | 耗时 |
|------|---------|---------|------|------|
| 1级(快速) | 1轮 | 1轮 | ❌ | ~5分钟 |
| 2级(基础) | 1轮 | 1轮 | ✅ | ~8分钟 |
| 3级(标准) | 1轮 | 2轮 | ✅ | ~10分钟 |
| 4级(深度) | 2轮 | 2轮 | ✅ | ~15分钟 |
| 5级(全面) | 3轮 | 3轮 | ✅ | ~20分钟 |

## 🚀 如何选择模板

### 决策树

```
需要自定义流程？
├─ 是 → 使用 BLANK_WORKFLOW
└─ 否 → 继续

需要快速分析？
├─ 是 → 使用 SIMPLE_WORKFLOW
└─ 否 → 继续

分析类型？
├─ 股票分析 → DEFAULT_WORKFLOW 或 V2_STOCK_ANALYSIS_WORKFLOW
├─ 持仓分析 → POSITION_ANALYSIS_WORKFLOW_V2
└─ 交易复盘 → TRADE_REVIEW_WORKFLOW_V2
```

---

## 💡 最佳实践

1. **从简单开始**
   - 新手建议从 SIMPLE_WORKFLOW 开始
   - 熟悉后再使用完整分析流

2. **根据场景选择**
   - 日常决策：SIMPLE_WORKFLOW
   - 重要决策：DEFAULT_WORKFLOW
   - 持仓管理：POSITION_ANALYSIS_WORKFLOW_V2

3. **自定义优化**
   - 基于 BLANK_WORKFLOW 创建个性化流程
   - 根据投资风格调整节点组合

4. **性能考虑**
   - 节点越多，执行时间越长
   - 并行节点可以提高效率
   - 合理设置分析深度
