# 高级实战课程：建立你的交易计划

## 📚 课程概述

| 项目 | 内容 |
| ---- | ---- |
| **课程名称** | 高级实战课程：从散户到系统交易者：AI赋能的可进化投资法 |
| **目标学员** | 完成初级课程、有一定炒股经验、尚未形成交易计划的散户投资者 |
| **课程目标** | ① 掌握完整的投资决策流程 ② 建立个人交易计划 ③ 学会风险管理 |
| **核心理念** | 所有分析结果都是参考，最终决策由用户自己做出 |
| **课程时长** | 24课时 |

---

## 🎯 课程目标

完成本课程后，学员将能够：

1. **独立完成完整的投资决策流程**
   - 从选股到复盘的全流程闭环
   - 熟练使用系统各项功能

2. **建立个人交易计划**
   - 拥有自己的选股规则
   - 拥有自己的择时规则
   - 拥有自己的仓位管理规则
   - 拥有自己的复核边界与纪律规则

3. **学会风险管理**
   - 理解并应用风险辩论
   - 按跟踪卡和重评条件持续校正判断
   - 通过复盘持续改进

## 🔄 研究闭环

本课程围绕**研究闭环**展开，覆盖从研究、跟踪到复盘与版本迭代的完整工作流：

```text
┌─────────────────────────────────────────────────────┐
│                                                     │
│   选股 → 择时 → 执行 → 持仓管理 → 风险管理 → 复盘   │
│    │                                          │     │
│    └──────────── 反馈优化 ←───────────────────┘     │
│                                                     │
└─────────────────────────────────────────────────────┘
```

| 环节 | 系统功能 | 核心输出 |
| ---- | ---- | ---- |
| 选股 | 单股研究、批量分析 | 研究摘要、用户版研究简报、后续观察事项 |
| 择时 | 大盘分析、行业分析、多空辩论 | 主情景、关键分歧、后续验证信号 |
| 执行 | 模拟交易 | 研究联动的流程演练、订单上下文 |
| 持仓管理 | 持仓研究 | 当前结论、风险焦点、后续观察点 |
| 风险管理 | 风险辩论、风险跟踪 | 风险边界、重评条件、验证清单 |
| 复盘 | 交易复盘、案例库 | 复盘结论、暴露的问题、后续改进重点 |

## ⚠️ 重要提醒

1. **所有分析结果都是参考**：系统给出的建议不是投资决策，最终决策由用户自己做出
2. **投资有风险**：股市有风险，入市需谨慎
3. **先用模拟交易练习**：建议先在模拟交易中练习，积累经验后再进行实盘操作
4. **持续学习和改进**：交易是一个持续学习的过程，通过复盘不断优化自己的交易计划
