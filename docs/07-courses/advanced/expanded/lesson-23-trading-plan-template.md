# 第23课：个人交易计划模板

**课时**：1课时  
**目标**：学会把前面几课读过的真实研究方法，收成一份属于自己的计划基线，让观察、升级、持仓复核和交易后纠偏都有统一的执行框架。

---

## 23.1 本课先给结论：个人交易计划，不是系统替你写好的动作单

第23课最容易重新滑回旧口径的地方，就是把“个人交易计划”理解成一张未来动作清单：

1. 先写买什么；
2. 再写什么时候动；
3. 然后写用多大暴露；
4. 最后再配一套固定退出脚本。

这样写的问题，不是看起来不完整，而是会把第18到第22课刚建立起来的研究顺序全部压扁。

如果我是你的教练，这一课我不会先问你：

1. 你准备默认用什么参数；
2. 你想把哪条规则写得最严格；
3. 你要不要照着系统草稿直接生成一版。

我会先逼你回答四个问题：

1. 你到底在用什么方法，把一只标的放进观察范围；
2. 你到底凭什么把它从观察型升级到执行准备型；
3. 进入跟踪或持有后，你到底按什么节奏复核；
4. 一笔交易结束后，你到底怎么把问题写回规则。

只要这四个问题答不清，你写出来的就不是计划，只是一份看起来很像计划的表格。

## 23.2 这一课为什么必须接在案例课后面讲

### 23.2.1 前面几课已经把方法拆给你看了

如果你回看第18到第22课，会发现它们其实已经把个人计划最重要的几层材料都准备好了：

1. 第18课教你怎么把短线研究压成观察卡；
2. 第19课教你怎么把短线跟踪和复盘压成复核卡、纠偏卡；
3. 第21课教你怎么把中长线研究压成长期观察卡；
4. 第22课教你怎么把长期持仓和周期复盘压成长期复核卡、周期纠偏卡。

所以第23课真正要做的，不是再发一套模板，而是回答一句更要命的话：

**这些卡片，怎样才能变成你以后每次都会用的个人计划基线。**

### 23.2.2 计划的价值，不在“写完”，而在“以后能反复对照”

当前系统里的个人交易计划模块，真正有价值的不是表单本身，而是它可以承接后面的真实动作：

1. 你可以创建、编辑、设为默认；
2. 你可以对整份计划做 AI 评估；
3. 你可以保留评估历史和版本记录；
4. 你可以在复盘里对照计划执行良好之处与偏离计划之处；
5. 你可以把优化建议应用回自己的草稿。

所以计划不是“写完就结束”，而是：

**以后每次研究、复核、复盘，都拿它回来对照。**

## 23.3 教练先让你写的，不是规则，而是你的决策口径

### 23.3.1 第一步：先写你是什么类型的决策者

很多人一打开计划页，就急着填规则。

这是顺序错误。

在写规则之前，你先得写清楚：

1. 你主要做短周期、中周期，还是更长验证周期；
2. 你更依赖结构信号、财报验证，还是两者结合；
3. 你能承受多高的不确定性，才允许继续跟踪；
4. 你愿意投入多高频率的复核工作。

更直接地说，你先要写清：

**你是谁，决定了后面规则该长什么样。**

### 23.3.2 第二步：把“我怎么做判断”写成一句流程话

这一句特别重要。

它不能写成空话，比如：

1. 追求高质量收益；
2. 坚持知行合一；
3. 严格执行纪律。

这些话没有复核价值。

更有用的写法应该像这样：

```text
我先用真实研究判断标的是观察型还是执行准备型，
再根据关键不确定性是否缩小、公开证据是否补齐，决定是否升级判断；
进入跟踪或持有后，按财报、公告、行业进展和复盘偏差持续重检原逻辑。
```

这句话的价值在于，它把你的方法先压成了可对照的流程线。

---

## 23.4 第一层计划：把前面的观察卡，写成“进入观察池的规则”

### 23.4.1 先回答“什么样的研究，值得我继续看”

第18课和第21课已经给过你答案。

一只标的值得进入观察范围，不是因为它看起来热，也不是因为有人说便宜，而是因为那份研究至少要回答清楚：

1. 当前状态是什么；
2. 最强支撑是什么；
3. 最大限制是什么；
4. 下一次最值得等的验证是什么。

所以你的选股规则，不该写成“某个题材、某种指标、某个位置”，而该先写成：

**什么样的研究质量，才配占用我的注意力。**

### 23.4.2 把观察规则写成四条“必须满足”

你完全可以直接写成下面这种口径：

1. 研究必须能明确说出当前定级，而不是只给结论口号；
2. 研究必须能同时说出最强支撑和最大限制；
3. 研究必须说明后续该看什么公开信号；
4. 风险边界不能处于明显失真或无法解释状态。

这四条，就是把前面案例课里的观察卡正式写进计划。

### 23.4.3 再写三条“直接排除”

一份计划如果只写“满足什么”，通常会太松。

更稳的写法，是同时写清什么情况直接排除：

1. 只有情绪化结论，没有关键证据和限制；
2. 关键缺口长期存在，却没有明确补证路径；
3. 连判断何时失效都没写清。

只要这三类对象不先排掉，你的观察池很快就会膨胀成噪音池。

---

## 23.5 第二层计划：把升级卡，写成“什么时候才能提高使用强度”

### 23.5.1 先分清“观察型”和“执行准备型”

第18、19、21、22课已经反复证明：

最容易让判断走样的，不是看错，而是过早升级。

所以你的计划里必须写清楚：

1. 什么情况只是继续观察；
2. 什么情况才允许进入执行准备；
3. 什么情况下必须先降级，而不是继续脑补。

计划一旦没有这层分级，你后面的执行边界一定会越来越糊。

### 23.5.2 把升级条件写成“证据升级”，不是“热度升级”

更符合当前课程口径的写法，应该把择时或升级规则写成下面这种结构：

1. 关键不确定性开始缩小；
2. 新披露的财报、公告、产业信息开始补齐原来的核心缺口；
3. 风险边界没有继续恶化；
4. 结构或市场反馈，不再和基本研究方向明显冲突。

这四条的共同点是：

**都要求你指出哪条公开证据让判断变化。**

### 23.5.3 再写清“哪些情况禁止误升级”

这一层特别容易被忽略，但它其实比升级条件更重要。

你最好把下面三条直接写进计划：

1. 不是因为连续上涨就自动升级；
2. 不是因为市场讨论热就自动升级；
3. 不是因为已经有浮盈就自动把逻辑当成已验证。

前面四节案例课里，几乎所有容易犯的错，都能回收到这三条里。

---

## 23.6 第三层计划：把复核卡，写成“进入跟踪和持有后怎么继续检查”

### 23.6.1 不要先写动作，先写复核节奏

很多人一写持仓规则，就开始写未来动作。

这仍然是旧口径。

更重要的，是先写：

1. 哪些节点必须复核；
2. 每次复核先看什么；
3. 哪些反证一出现，就必须重评。

因为真正让判断保持清醒的，不是动作预设，而是复核节奏。

### 23.6.2 把复核节奏写成“事件型检查表”

前面的短线和中长线案例已经把这一层拆得很清楚了。

你完全可以直接写成：

1. 财报、公告、问询、行业关键数据披露后必须复核；
2. 用户版视图里的风险焦点升级时必须复核；
3. 研究附录对应的结构信号明显走坏时必须复核；
4. 一笔仓位进入明显盈利后，不允许因为盈利而跳过复核。

这四条，正是把第19课和第22课的复核卡写进你的计划。

### 23.6.3 再写清“什么叫必须重评”

没有这一步，复核很容易沦为“看过了，但没改变任何东西”。

更有用的写法，是直接写：

1. 核心支撑被推翻时必须重评；
2. 最大限制加重时必须重评；
3. 风险边界明显恶化时必须重评；
4. 原来依赖的关键证据被新公开信息否定时必须重评。

这几条比任何现成数值都更像真正的计划骨架。

---

## 23.7 第四层计划：把纠偏卡，写成“交易结束后必须留下什么”

### 23.7.1 先写复盘的最低完成标准

一份计划如果没有复盘要求，最后一定只会留下结果，不会留下方法。

所以你的复盘规则至少应该要求每次完整交易结束后，必须写下四件事：

1. 这次真正做对了什么；
2. 这次真正做错了什么；
3. 这次最该补强的证据是什么；
4. 这次最该写进纪律的条款是什么。

这四条，其实就是第19课和第22课里“纠偏卡”的直接回收。

### 23.7.2 再写“问题映射回哪一层”

好复盘和差复盘的差别，不在文字多寡，而在于有没有回写动作。

你最好在计划里直接规定：

1. 研究证据不足，回写到观察规则或升级规则；
2. 持仓阶段漏复核，回写到复核节奏；
3. 偏离原判断边界，回写到纪律规则；
4. 重复出现的问题，必须触发版本更新。

这样复盘才不是感想，而是系统维护。

### 23.7.3 最后写清“哪些行为绝对不能放过”

纪律规则不该写成抽象美德，而应该直接点名你最容易犯的错误。

更好的写法是：

1. 不把 AI 输出当行动指令；
2. 不因为盈利放松证据标准；
3. 不在未复核关键事实时临时改口径；
4. 不跳过完整复盘和版本记录。

这才是你真正会用上的纪律条款。

## 23.8 系统里现有的计划功能，应该怎么用才不走偏

### 23.8.1 创建页不是让你填满，而是让你写准

系统里现在确实有：

1. 创建、编辑、查看、删除和设为默认；
2. 选股、升级、暴露边界、风险管理、纪律等模块输入；
3. AI 辅助生成部分草稿。

但这一页的重点不是“把格子填满”，而是把前面课程里已经验证过的方法，准确写进对应模块。

### 23.8.2 AI 评估是查结构缺口，不是替你下判断

系统提供 AI 评估、评估历史和优化讨论，这些能力很有用，但它们的正确用途必须讲清楚：

1. 用 AI 评估检查计划是否完整、一致、可执行；
2. 用优化讨论补强结构缺口；
3. 不把 AI 评估当成“系统替我确认未来动作”。

AI 评估是在看你的计划结构，不是在替你拍板具体标的。

### 23.8.3 版本管理和复盘对照，才是这页真正的核心价值

这也是第23课最该讲透的一点。

计划模块真正厉害的，不是你今天能写出一版，而是：

1. 你能保留版本；
2. 你能在复盘里看到哪些地方符合计划，哪些地方偏离计划；
3. 你能把反复出现的问题，稳定写回下一版。

也就是说，个人交易计划不是一页设置项，而是你的个人工作基线。

## 23.9 一份更符合当前课程口径的第一版计划卡

```text
我的决策口径：
- 先判断标的是观察型还是执行准备型
- 只有当关键不确定性缩小、公开证据补齐时才升级
- 进入跟踪或持有后，按财报、公告、行业进展和复盘偏差持续复核

进入观察范围的条件：
- 研究能说清当前定级、最强支撑、最大限制、下一次验证重点

直接排除条件：
- 只有结论没有证据
- 关键缺口无法补证
- 没写失效条件

升级条件：
- 关键不确定性缩小
- 公开证据补齐核心缺口
- 风险边界未恶化

禁止误升级：
- 不是因为连续上涨就升级
- 不是因为讨论热就升级
- 不是因为已有浮盈就把逻辑当成已验证

复核节奏：
- 财报、公告、问询、行业关键数据后复核
- 风险焦点升级时复核
- 结构明显破坏时复核

必须重评的情况：
- 核心支撑被推翻
- 最大限制加重
- 风险边界恶化

交易后必须留下：
- 这次做对了什么
- 这次做错了什么
- 这次最该补的证据
- 这次最该写进纪律的条款

纪律底线：
- 不把 AI 输出当行动指令
- 不因为盈利放松证据标准
- 不跳过复核、复盘和版本记录
```

这张卡，不是标准答案。

它的作用是告诉你：

**一份真正能用的个人计划，不是未来动作列表，而是把前面几课的方法收成你自己的长期工作底线。**

## 23.10 本课小结与思考

### 23.10.1 本课要点回顾

1. 第23课的重点不是照着系统生成一份规则表，而是把前面案例课的观察卡、复核卡、纠偏卡收成个人计划基线。
2. 计划最先该写的不是参数，而是你的决策口径和方法顺序。
3. 观察规则解决“什么值得看”，升级规则解决“什么时候提高使用强度”，复核规则解决“进入跟踪或持有后怎么继续检查”，纠偏规则解决“交易结束后怎么把问题写回系统”。
4. 系统里的 AI 评估、优化讨论、版本管理和复盘对照，真正服务的是计划迭代，不是替你做具体动作判断。
5. 一份好的计划，最后必须能回到真实复盘里逐条对照，而不是只停留在创建页。

### 23.10.2 思考题

1. 你现在最缺的是观察规则、升级规则、复核规则，还是纠偏规则？为什么？
2. 你最近一次把判断提得太快，是因为证据真的补齐了，还是因为热度和盈利让你误升级了？
3. 如果你只能先写三条纪律底线，你最想先锁死哪三条？
4. 请把你最近用得最多的一套判断方法，压成“进入观察范围的条件 + 升级条件 + 复核节奏 + 纪律底线”的第一版计划卡。
