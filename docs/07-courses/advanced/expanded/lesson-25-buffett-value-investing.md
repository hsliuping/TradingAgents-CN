# 第25课：用巴菲特方法做价值投资——在平台上落地一套投资大师流程

**课时**：2课时
**目标**：学会将巴菲特的价值投资方法论拆解为可执行的 AI 工作流，通过 Agent 工坊和 Skill 工坊补齐平台缺少的分析维度，最终产出一套"巴菲特选股流程"。

---

## 25.1 本课先给结论：大师方法论 ≠ 照搬公式

巴菲特的方法被讲了无数遍，但真正落地时，大多数人的做法是：

1. 找一个低 PE 的股票；
2. 看一眼 ROE 够不够高；
3. 套一个 DCF 算一下"内在价值"；
4. 觉得便宜就买。

这样做的问题，是把一套完整的投资哲学压缩成了几个财务比率的筛选。

如果我是你的投资教练，这一课我不会先教你：

1. ROE 的公式是什么；
2. DCF 的折现率怎么算；
3. 安全边际取 20% 还是 30%。

我会先逼你回答三个问题：

1. 巴菲特选股的完整流程有几步，每步要回答什么问题；
2. 平台现有的 Agent 和工具能覆盖哪几步，缺哪几步；
3. 缺的部分怎么用 Agent 工坊和 Skill 工坊补上。

只要这三个问题答不清，"在平台上落地巴菲特方法"就只是一句口号。

## 25.2 巴菲特方法论的六步拆解

巴菲特的选股决策不是看几个指标，而是一套从"能力圈"到"持有决策"的完整推理链。我们把它拆成六步：

| 步骤 | 巴菲特的原话（意译） | 要回答的核心问题 |
|------|----------------------|-----------------|
| 1. 能力圈 | "我不投看不懂的生意" | 这家公司的商业模式我能理解吗？ |
| 2. 护城河 | "我喜欢有持久的竞争优势的公司" | 它的竞争优势是什么？能持续多久？ |
| 3. 财务质量 | "关注 ROE、利润的稳定性、低负债" | 财务报表是否支撑它的护城河故事？ |
| 4. 管理层 | "关注管理层是否诚实、能干" | 管理团队的资本配置能力如何？ |
| 5. 估值与安全边际 | "用合理的价格买入伟大的公司" | 内在价值是多少？当前价格有没有安全边际？ |
| 6. 持有决策 | "我最喜欢的持有期是永远" | 这是一家可以长期持有的公司吗？ |

这六步不是平行关系，而是有先后依赖：

```
能力圈 → 护城河 → 财务质量 → 管理层 → 估值 → 持有决策
  筛选     深挖     交叉验证   补充判断   量化    最终裁决
```

> 教练提示：如果你跳过"能力圈"和"护城河"直接看财务数据，很容易被"数据好看但生意模式差"的公司骗到。巴菲特方法的核心不是算数，是先判断生意模式好不好，再用财务数据验证。

### 25.3.3 缺口分析

对照巴菲特六步，平台缺什么：

| 巴菲特步骤 | 现有覆盖 | 缺口 |
|-----------|---------|------|
| 1. 能力圈 | 板块分析师部分覆盖 | 缺少"商业模式可理解性"判断 |
| 2. 护城河 | **完全缺失** | 需要创建护城河分析师 |
| 3. 财务质量 | 基本面分析师 + F-Score/Z-Score | 基本够用，缺 ROE 趋势分析 |
| 4. 管理层 | 新闻分析师部分覆盖 | 缺少管理层资本配置评估 |
| 5. 估值与安全边际 | 估值分析师 + DCF | 基本够用，缺安全边际计算 |
| 6. 持有决策 | 研究经理 + 风险辩论 | 需要巴菲特视角的判断标准 |

> 教练提示：缺口不是"什么都要补"，而是"哪些缺口会影响决策质量"。护城河和管理层是巴菲特方法最核心的两步，这两步缺了，整个流程就变成了"只是算财务比率"。

## 25.4 补齐缺口：用 Agent 工坊创建三个自定义 Agent

我们需要创建三个自定义 Agent 来补齐巴菲特方法的关键步骤。

### 25.4.1 护城河分析师（Moat Analyst）

**定位**：巴菲特六步中的第 2 步，评估公司是否有持久的竞争优势。

**创建步骤**：

1. 进入"分析流 → Agent 工坊"，点击"新建 Agent"。
2. 在需求描述中输入：

```
我需要一个护城河分析师，专门评估上市公司的竞争优势持久性。
分析维度包括：
1. 品牌价值：品牌是否具有定价权，消费者是否愿意支付溢价
2. 成本优势：是否具有规模效应或独特的成本结构
3. 网络效应：用户增长是否带来网络价值指数级增长
4. 转换成本：客户更换供应商的成本有多高
5. 无形资产：专利、牌照、特许经营权等
6. 规模优势：市场份额和规模经济

输出要求：
- 每个维度给出 1-5 分的评分和依据
- 综合给出护城河强度等级（无/弱/中等/强/极强）
- 判断护城河是在加深还是在收窄
- 列出护城河可能被侵蚀的风险因素

请使用中文输出，适合 A 股市场分析。
```

3. 与 AI 讨论需求，确认规格后生成测试版本。
4. 测试通过后发布，Agent ID 为 `moat_analyst_buffett`。

**关联工具**（在 Agent 配置中绑定）：
- `get_stock_fundamentals_unified`：获取财务数据
- `get_piotroski_fscore`：获取基本面质量评分
- `get_value_screening`：获取行业对比数据

### 25.4.2 管理层评估师（Management Assessor）

**定位**：巴菲特六步中的第 4 步，评估管理层质量和资本配置能力。

**创建步骤**：

1. 在 Agent 工坊中新建 Agent，需求描述：

```
我需要一个管理层评估师，专门评估上市公司管理团队的质量。
分析维度包括：
1. 资本配置能力：再投资回报率、并购历史、分红政策
2. 诚信度：管理层指引与实际业绩的一致性，信息披露透明度
3. 股东导向：是否优先考虑股东利益，回购时机选择
4. 战略执行力：战略规划与实际执行的匹配度
5. 管理层稳定性：核心团队任职年限，股权激励结构

输出要求：
- 每个维度给出评分（1-5）和依据
- 综合给出管理层质量等级（差/一般/良好/优秀）
- 列出管理层的主要优点和需要关注的疑点
- 特别关注：过去 3 年是否有损害股东利益的行为

请使用中文输出，适合 A 股市场分析。
```

2. 讨论需求，确认规格后生成测试版本。
3. 测试通过后发布，Agent ID 为 `management_assessor_buffett`。

**关联工具**：
- `get_stock_fundamentals_unified`：获取分红、回购数据
- `get_earnings_quality`：检测盈利质量
- `get_beneish_mscore`：检测盈余操纵

### 25.4.3 巴菲特估值师（Buffett Valuator）

**定位**：巴菲特六步中的第 5 步，用巴菲特的"Owner Earnings"方法计算内在价值和安全边际。

**创建步骤**：

1. 在 Agent 工坊中新建 Agent，需求描述：

```
我需要一个巴菲特风格的估值师，使用巴菲特的"Owner Earnings"方法计算内在价值。
巴菲特的 Owner Earnings = 净利润 + 折旧摊销 - 资本支出 - 营运资金变化

分析要求：
1. 计算 Owner Earnings，并与自由现金流对比验证
2. 用 Owner Earnings 作为基础进行 DCF 估值
3. 评估 ROE 趋势：过去 5-10 年的 ROE 是否稳定在 15% 以上
4. 评估利润稳定性：过去 10 年利润是否持续增长，波动率如何
5. 计算安全边际：内在价值 vs 当前股价的折价/溢价

输出要求：
- Owner Earnings 计算明细
- 内在价值区间（保守/基准/乐观）
- 安全边际百分比
- 巴菲特风格的投资判断：
  - "伟大的公司"：ROE>20%，护城河强，利润稳定增长
  - "好的公司"：ROE 15-20%，护城河中等
  - "普通公司"：ROE<15% 或护城河弱
  - "避开"：亏损、负债过高、护城河在收窄
- 是否符合巴菲特的"用合理的价格买入伟大的公司"标准

请使用中文输出，适合 A 股市场分析。
```

2. 讨论需求，确认规格后生成测试版本。
3. 测试通过后发布，Agent ID 为 `buffett_valuator`。

**关联工具**：
- `get_dcf_valuation`：DCF 估值
- `get_cashflow_enhancement`：现金流分析
- `get_extended_valuation`：多模型估值对比
- `get_stock_fundamentals_unified`：财务数据

## 25.5 补齐缺口：用 Skill 工坊创建辅助分析技能

除了三个 Agent，我们还需要创建两个 Skill 来提供定量数据支撑。

### 25.5.1 ROE 趋势分析 Skill

**定位**：巴菲特最看重的财务指标是 ROE，他要求"过去 10 年 ROE 稳定在 15% 以上"。现有工具不直接提供多年 ROE 趋势。

**创建步骤**：

1. 进入"分析流 → Skill 中心"，点击"新建 Skill"。
2. 描述需求：

```
创建一个 ROE 趋势分析工具。
功能：获取指定股票过去 5-10 年的 ROE 数据，计算趋势和稳定性。

输出内容：
1. 各年度 ROE 数值
2. ROE 均值、标准差、变异系数
3. ROE 趋势判断（上升/稳定/下降/波动）
4. 杜邦分析分解：ROE = 净利率 × 资产周转率 × 权益乘数
5. 巴菲特标准判断：过去 5 年 ROE 是否均 >15%
```

3. 系统生成 Skill 代码，经过静态检查和沙箱测试后可用。
4. 人工审查代码逻辑，确认无误后发布，Skill ID 为 `get_roe_trend_analysis`。

### 25.5.2 安全边际计算 Skill

**定位**：巴菲特要求买入价格低于内在价值一定幅度（通常 20-30%），现有 DCF 工具输出的是每股内在价值，但不会直接计算安全边际。

**创建步骤**：

1. 在 Skill 中心新建 Skill，描述需求：

```
创建一个安全边际计算工具。
功能：基于 DCF 估值结果和当前股价，计算安全边际。

输入：股票代码
输出：
1. 调用 DCF 估值获取保守/基准/乐观三种情景的内在价值
2. 获取当前股价
3. 计算各情景下的安全边际 = (内在价值 - 当前价格) / 内在价值
4. 给出投资建议：
   - 安全边际 > 30%：有吸引力的买入机会
   - 安全边际 15-30%：合理价格
   - 安全边际 0-15%：价格偏高
   - 安全边际 < 0：高估
```

2. 系统生成代码，测试通过后发布，Skill ID 为 `get_margin_of_safety`。

## 25.6 编排巴菲特选股工作流

有了三个自定义 Agent 和两个 Skill 后，我们可以编排完整的巴菲特选股工作流。

### 25.6.1 工作流全景图

```
开始
  │
  ▼
[并行分析阶段]
  ├─ 大盘分析师 v2 ──────── 评估市场环境
  ├─ 板块分析师 v2 ──────── 评估行业景气度（能力圈初筛）
  ├─ 基本面分析师 v2 ────── 财务报表分析
  ├─ 估值分析师 v2 ──────── PE/PB/DCF 估值
  ├─ 护城河分析师 [自定义] ─ 竞争优势评估 ★ 新增
  ├─ 管理层评估师 [自定义] ─ 管理层质量评估 ★ 新增
  ├─ 新闻分析师 v2 ──────── 新闻和公告
  └─ 社媒分析师 v2 ──────── 舆论情绪
  │
  ▼
[合并分析结果]
  │
  ▼
[多空辩论]
  ├─ 乐观研究员 v2 ──────── 巴菲特视角看多论点
  └─ 审慎研究员 v2 ──────── 巴菲特视角看空论点
  │
  ▼
[研究经理 v2] ──────────── 综合评估（应用巴菲特标准）
  │
  ▼
[风险辩论]
  ├─ 高弹性风险分析师 v2 ── 上行催化
  ├─ 防御风险分析师 v2 ──── 安全边际压力测试
  └─ 基准风险分析师 v2 ──── 基准情景
  │
  ▼
[风险管理者 v2] ────────── 风险裁决
  │
  ▼
[条件分支：是否通过巴菲特初筛？]
  ├─ 是 → 巴菲特估值师 [自定义] ── 计算安全边际 ★ 新增
  │        │
  │        ▼
  │      [研究整合员 v2] ── 生成巴菲特风格投资建议
  │
  └─ 否 → [研究整合员 v2] ── 输出不通过原因
  │
  ▼
结束
```

### 25.6.2 创建步骤

有两种方式创建这个工作流：

**方式一：AI 智能创建（推荐）**

1. 进入"分析流 → 流程管理"，点击"AI 智能创建"。
2. 选择流程类型：单股研究流程。
3. 在需求描述中输入：

```
我需要一个基于巴菲特价值投资方法论的工作流，包含以下步骤：
1. 并行分析阶段：使用大盘分析师、板块分析师、基本面分析师、估值分析师、护城河分析师、管理层评估师、新闻分析师、社媒分析师，8 个分析师并行工作
2. 多空辩论：乐观研究员和审慎研究员围绕巴菲特标准辩论
3. 研究经理综合评估
4. 风险辩论：三方风险分析师从不同角度审阅
5. 风险管理者裁决
6. 条件分支：如果通过巴菲特初筛（护城河>=中等、ROE>15%、管理层>=良好），进入巴菲特估值师计算安全边际；否则直接输出不通过原因
7. 研究整合员生成最终巴菲特风格投资建议

其中护城河分析师、管理层评估师、巴菲特估值师是我在 Agent 工坊创建的自定义 Agent。
```

4. AI 会自动规划节点拓扑，确认后自动创建缺失的 Skill 并绑定工具。

**方式二：手动编排**

1. 进入"分析流 → 流程管理"，点击"新建分析流程"。
2. 选择"空白流程"，命名后进入编辑器。
3. 从左侧节点面板拖拽节点：
   - 拖入 1 个"开始"节点
   - 拖入 1 个"并行开始"节点
   - 拖入 8 个"智能体"节点，分别配置为上述 8 个分析师
   - 拖入 1 个"并行合并"节点
   - 拖入 1 个"辩论"节点
   - 拖入 2 个"智能体"节点，配置为乐观/审慎研究员
   - 拖入 1 个"智能体"节点，配置为研究经理
   - 拖入 1 个"辩论"节点
   - 拖入 3 个"智能体"节点，配置为三方风险分析师
   - 拖入 1 个"智能体"节点，配置为风险管理者
   - 拖入 1 个"条件分支"节点
   - 拖入 1 个"智能体"节点，配置为巴菲特估值师
   - 拖入 1 个"智能体"节点，配置为研究整合员
   - 拖入 1 个"结束"节点
4. 按照全景图连接节点。
5. 条件分支节点的两条边分别设置标签"通过"和"不通过"。
6. 点击"验证"检查结构完整性。
7. 保存并发布。

### 25.6.3 条件分支配置

条件分支是巴菲特工作流的核心创新点——它让系统自动判断是否值得深入估值。

在条件分支节点的配置面板中设置：

| 条件 | 表达式 | 说明 |
|------|--------|------|
| 通过 | `moat_rating in ['中等', '强', '极强'] and roe_5yr_avg > 15 and management_rating in ['良好', '优秀']` | 护城河至少中等、5 年平均 ROE>15%、管理层至少良好 |
| 不通过 | 其他情况 | 输出不通过原因，跳过估值步骤 |

> 教练提示：条件分支的价值不在于"省时间"，而在于"纪律性"。巴菲特方法的核心纪律就是"不投没有护城河的公司"，不管财务数据多好看。条件分支把这条纪律固化在流程里。

## 25.7 提示词优化：让 Agent 说"巴菲特的话"

创建好 Agent 和工作流后，还需要优化提示词，让每个 Agent 的分析视角更贴近巴菲特的思维框架。

### 25.7.1 优化乐观研究员的提示词

默认的乐观研究员是通用的看多视角。我们需要让它从巴菲特的角度构建看多论点。

在"系统管理 → 提示词模板"中，找到 `bull_researcher_v2` 的系统提示词，关联到巴菲特工作流（绑定 `workflow_id`），修改为：

```
你是一位运用巴菲特价值投资方法论的研究员，负责从乐观角度分析投资机会。

你的分析框架：
1. 护城河论证：这家公司的竞争优势是什么？为什么竞争对手难以复制？
2. 财务质量：ROE 是否持续高于 15%？利润是否有稳定的增长趋势？
3. 商业模式：这是不是一门"简单、可预测"的好生意？
4. 管理层：管理层是否像企业所有者一样思考和行动？
5. 长期前景：10 年后这家公司还会存在并且更强吗？

你不需要做技术分析，不需要关注短期股价波动。
你需要回答的核心问题是：这是一家"伟大的公司"吗？

请基于分析师提供的数据和报告，构建偏多论点，说明：
- 护城河的来源和持久性
- 财务数据如何验证护城河故事
- 管理层的哪些行为支持你的论点
- 10 年后的长期前景
- 成立的前提条件和潜在催化
```

### 25.7.2 优化审慎研究员的提示词

```
你是一位运用巴菲特价值投资方法论的研究员，负责从审慎角度分析投资风险。

你的分析框架：
1. 护城河风险：竞争优势是否在收窄？技术变革、新进入者是否在侵蚀护城河？
2. 财务疑点：利润增长是否来自主营业务？现金流是否支撑利润？有没有盈余管理迹象？
3. 商业模式风险：这门生意的脆弱点在哪里？什么情况会让它从"好生意"变成"差生意"？
4. 管理层疑点：管理层是否有损害股东利益的历史？资本配置决策是否合理？
5. 长期风险：10 年后这家公司可能面临什么挑战？

你需要回答的核心问题是：什么会让这家公司"不再伟大"？

请构建偏审慎论证，识别：
- 护城河可能被侵蚀的路径
- 财务数据中的预警信号
- 管理层的可疑行为
- 行业格局变化的风险
- 失效条件和反向证据
```

### 25.7.3 优化研究经理的提示词

```
你是一位运用巴菲特价值投资方法论的研究经理，负责综合多空观点形成研究结论。

你的裁决标准（巴菲特风格）：
1. 这是不是一家"伟大的公司"？（护城河强 + ROE 高 + 管理层优秀）
2. 如果是伟大的公司，当前价格是否合理？（安全边际）
3. 如果不是伟大的公司，是"好的公司"还是"普通公司"？
4. 10 年后这家公司会比现在更强还是更弱？

你的输出必须包含：
- 巴菲特评级：伟大/好/普通/避开
- 核心论点：一句话总结为什么
- 关键分歧：多空双方的核心分歧点
- 观察重点：后续需要持续关注什么
- 初步结论：是否值得进入估值环节
```

## 25.8 实战演练：用贵州茅台（600519）跑一遍

### 25.8.1 为什么选茅台

茅台是 A 股最接近巴菲特"伟大公司"标准的标的：
- 护城河极强（品牌溢价 + 产能稀缺）
- ROE 长期 >25%
- 利润持续增长
- 商业模式简单可预测

用茅台跑流程，能让你看到"通过巴菲特筛选"的标准答案长什么样。

### 25.8.2 执行步骤

1. 确保已创建三个自定义 Agent 和两个 Skill。
2. 确保已编排并发布巴菲特选股工作流。
3. 进入"单股研究"，输入股票代码 `600519`。
4. 选择分析流程为"巴菲特选股工作流"。
5. 分析深度选择 3 级（标准）。
6. 点击"开始分析"。

### 25.8.3 预期输出

分析完成后，你应该能看到以下报告：

**护城河分析师报告**：
- 品牌价值：5/5（奢侈品定位，消费者愿付极高溢价）
- 成本优势：4/5（毛利率 90%+，成本占比极低）
- 转换成本：3/5（消费习惯，但非锁定）
- 规模优势：4/5（产能稀缺构成天然壁垒）
- 综合评分：极强，护城河在加深

**管理层评估师报告**：
- 资本配置：4/5（高分红率，再投资回报高）
- 诚信度：4/5（信息披露较透明）
- 综合评分：良好

**巴菲特估值师报告**：
- Owner Earnings 验证：与自由现金流基本一致
- 内在价值区间：保守 1,800 元 / 基准 2,100 元 / 乐观 2,500 元
- 安全边际：根据当前股价计算
- 巴菲特评级：伟大的公司

**条件分支结果**：通过巴菲特初筛，进入估值环节

**研究整合员报告**：
- 巴菲特评级：伟大的公司
- 建议：符合"用合理的价格买入伟大的公司"标准
- 长期持有建议：10 年视角下，品牌价值和产能稀缺性仍将支撑竞争力

> 教练提示：用茅台跑流程的目的是"校准"，让你知道"通过巴菲特筛选"的报告长什么样。之后你可以用其他股票跑，对比差异，理解为什么某些公司"不通过"。

## 25.9 对比案例：用一个"不通过"的股票理解纪律

跑完茅台后，建议找一个"看起来不错但巴菲特标准不通过"的股票做对比。

推荐选择一只周期股（如钢铁、化工），你会看到：

1. 护城河评分偏低（产品同质化，无定价权）
2. ROE 波动大（周期性导致利润不稳定）
3. 条件分支判断为"不通过"
4. 系统直接输出不通过原因，跳过估值环节

这个对比会让你理解：巴菲特方法的纪律性不在于"算得准不准"，而在于"该不该算"。没有护城河的公司，估值再便宜也不在巴菲特的能力圈内。

## 25.10 本课要点回顾

| 要点 | 说明 |
|------|------|
| 巴菲特六步 | 能力圈 → 护城河 → 财务质量 → 管理层 → 估值 → 持有决策 |
| 平台缺口 | 缺护城河分析、管理层评估、巴菲特估值三个维度 |
| 补齐方式 | Agent 工坊创建 3 个 Agent，Skill 工坊创建 2 个 Skill |
| 条件分支 | 把"不投没有护城河的公司"这条纪律固化在流程里 |
| 提示词优化 | 让乐观/审慎研究员和研究经理都从巴菲特视角分析 |
| 实战校准 | 用茅台跑一遍看"通过"长什么样，用周期股看"不通过" |
