# 第12课：扩大、收缩与结束计划判断框架

**课时**：1课时
**目标**：学会在不脱离研究口径的前提下，把持仓研究输出转成扩大、收缩或结束一笔暴露的个人判断框架，并在计划结束后衔接到可复盘的总结材料。

---

## 12.1 为什么第12课才讨论动作判断

### 12.1.1 第11课解决“怎么解释”，第12课才解决“何时调整”

第11课已经把单笔持仓研究的真实阅读顺序固定下来了：

1. 持仓快照。
2. 当前结论。
3. 核心依据。
4. 风险提示。
5. 后续观察点。
6. 不确定性说明。
7. 研究附录。

只有在这些内容已经读清楚以后，第12课才有资格讨论动作判断。否则“扩大、收缩、结束计划”就会重新退化成情绪化反应。

### 12.1.2 这节课的重点不是“动作本身”，而是判断门槛

第12课最重要的不是告诉你该做什么，而是告诉你：

1. 什么情况下，研究才足以支持扩大暴露。
2. 什么情况下，虽然主线未完全失效，但已经该优先收缩。
3. 什么情况下，继续保留这笔暴露其实已经变成另一条假设，原计划应当结束。

所以这节课的关键词不是“操作”，而是**门槛**。

### 12.1.3 当前系统真正能提供的判断入口

在当前系统里，第12课真正应使用的判断入口是：

1. **当前结论**：这笔持仓现在属于什么研究状态。
2. **核心依据**：为什么这笔暴露还没有被否定。
3. **风险提示**：当前最可能出问题的地方在哪里。
4. **后续观察点**：下一步哪些公开信号会改变判断。
5. **不确定性说明**：为什么现在还不能更强。
6. **风险评估 / 机会评估**：对整体风险焦点和潜在上修条件的补充说明。

当前课程不再把旧式压缩结论字段和价格化摘要当正文主轴，因为这些并不是当前持仓研究详情页最稳定、最直观的用户可见结构。

---

## 12.2 先用持仓研究判断当前属于哪种状态

### 12.2.1 先把状态分出来，再谈动作

从第11课走到第12课，第一步不是立即决定动作，而是先判断当前更接近哪种状态：

1. **准备扩大**：核心依据在增强，风险没有同步扩散，观察点开始收敛。
2. **维持观察**：主线仍在，但新的验证还不够强，当前最合理的是继续跟踪。
3. **准备收缩**：风险提示开始触及原主线，或当前暴露与剩余证据强度不再匹配。
4. **结束计划**：原有假设被持续证伪，继续持有需要依赖另一套新叙事。

这四类状态不是系统直接给你的标签，而是你基于报告内容做出的判断归纳。

### 12.2.2 当前结论只负责定性，不负责代替你下决定

当前结论最适合回答的是：

1. 这笔暴露是否还处在“逻辑未破坏但待验证”的状态。
2. 还是已经来到“风险显著上升、原优势不再清晰”的阶段。

它能帮你把问题问对，但它不应被误读成自动动作口令。

### 12.2.3 核心依据和风险提示必须配对读

动作判断最怕只看一边：

1. 只看核心依据，会高估当前主线的稳固程度。
2. 只看风险提示，会把尚未证伪的持仓过早判死。

正确做法是同时回答：

- 这笔暴露为什么还能留。
- 它现在又为什么不能更强。

这两个答案一旦并排摆好，动作门槛就会自然清晰很多。

---

## 12.3 什么情况下才值得评估扩大暴露

### 12.3.1 扩大暴露的前提不是“涨得好”，而是“证据更强”

是否值得评估扩大暴露，最核心的问题只有一个：

**这笔持仓的支撑证据，比上一次更强了吗？**

常见的“更强”表现包括：

1. 原本待验证的变量，出现了新的公开确认。
2. 风险提示没有升级，甚至开始收敛。
3. 后续观察点从很多个缩到少数几个关键变量。
4. 账户边界仍允许继续表达这条研究线。

### 12.3.2 真实样本最能说明“盈利不等于可以继续加重”

最新持仓研究样本里，有一类情况非常典型：

1. 已经持有较长时间。
2. 当前浮盈已接近三成。
3. 但结论仍然是“盈利可观但核心逻辑待验证”。

它同时给出两组信息：

1. **核心依据**仍在，例如中期价格基础没坏、财务结构未失稳。
2. **风险焦点**也很明确，例如盈利驱动机制、毛利率解释和成长斜率仍缺乏更强实证。

这类样本最重要的教训就是：

- 浮盈不是扩大的理由。
- 没有新增验证信号时，最合理的状态通常还是维持跟踪，而不是放大表达。

### 12.3.3 什么时候才真的接近“可扩大”

一笔持仓真正接近“可扩大”，通常要同时满足三件事：

1. **后续观察点里最关键的变量被新财报、公告或权威披露确认。**
2. **不确定性说明明显缩短，而不是继续扩大。**
3. **风险提示仍然是可管理的约束，而不是开始改写原逻辑。**

只要这三件事没有同时出现，就还没到真正评估扩大暴露的门槛。

### 12.3.4 扩大暴露时该怎么写个人预案

如果你判断已经接近扩大门槛，预案至少应写清楚四件事：

1. **触发条件**：哪条新证据出现才执行。
2. **表达上限**：最多增加到什么程度，不能一次打满。
3. **取消条件**：如果后续公开信号转差，哪一步不再执行。
4. **复核时间**：下一轮检查点是什么时候。

第12课讨论的是这种预案结构，而不是统一比例模板。

## 12.4 什么情况下应优先收缩暴露

### 12.4.1 收缩暴露不等于完全否定原逻辑

很多时候，收缩暴露不是因为主线彻底死亡，而是因为：

1. 风险开始压过新增证据。
2. 当前暴露强度已经跑在研究验证前面。
3. 继续维持原有表达，会让组合承受不对称风险。

所以第12课要强调：

**收缩首先是边界动作，其次才是观点动作。**

### 12.4.2 哪些信号更接近“该收缩了”

常见信号包括：

1. 风险提示开始由单点担忧扩散成多点约束。
2. 后续观察点没有收敛，反而越来越多。
3. 当前不确定性迟迟没有解决，持仓却已经占用了过多账户空间。
4. 组合中同主题暴露已过高，而新证据并不足以支撑继续集中。

### 12.4.3 收缩时最重要的是明确“保留什么，回收什么”

收缩暴露不是一句抽象表态，而是需要回答：

1. 你回收的是哪部分风险预算。
2. 你保留的是哪部分继续跟踪权。
3. 你是在等待关键验证，还是在为新的更强研究线腾空间。

如果这三件事说不清楚，收缩就很容易变成临场焦虑，而不是纪律动作。

### 12.4.4 收缩后的跟踪不能断

只要原主线还没有完全失效，收缩后就仍然要继续跟踪：

1. 哪些关键证据还能修复当前判断。
2. 哪些风险一旦进一步确认，就该继续收缩或结束。
3. 哪些新的公开信号会让你重新评估这笔暴露的合理性。

所以收缩后的状态，往往是“保留研究权，降低表达强度”。

## 12.5 什么情况下应结束当前计划

### 12.5.1 结束计划的本质是承认原假设不再成立

结束计划不是情绪化认输，也不是价格一跌就认错，而是承认一件事：

**继续保留这笔暴露，已经需要另一套新叙事，而不是原来的假设。**

一旦走到这一步，原计划就应当结束。

### 12.5.2 哪些情况更接近“该结束了”

常见情形包括：

1. 原本最关键的验证变量，最终被公开数据持续证伪。
2. 风险提示已经从“可能约束”升级为“直接改写主逻辑”。
3. 不确定性不再是短期信息缺口，而是逐渐变成结构性问题。
4. 继续持有的理由，只剩“也许会回来”这类缺乏证据的叙事。

### 12.5.3 真实样本里的结束门槛可以怎么理解

继续沿用前面那类样本来看：

1. 如果后续财报继续无法修复关键盈利质量指标。
2. 如果毛利率或成长解释始终无法被权威披露清晰支持。
3. 如果原本作为支撑的中期结构也开始同步转弱。

那就意味着“待验证”已经不再是中性状态，而逐渐转成对原主线的否定。到这一步，结束当前计划比继续拖延更有纪律价值。

### 12.5.4 结束计划后，下一步应当进入复盘而不是立刻重开新故事

当前系统里，计划结束后最重要的衔接对象不是另一份新判断，而是交易复盘。真实复盘结构会关注：

1. **复盘结论**：这次计划整体怎么收尾。
2. **做得好的地方 / 暴露的问题 / 后续改进重点**：哪里做得好，哪里暴露了问题，后续改进重点是什么。
3. **时机分析 / 仓位分析 / 情绪分析 / 归因分析**：时机、仓位、情绪和归因层面分别出了什么问题。
4. **计划执行良好之处 / 偏离计划之处**：如果关联了交易计划，哪些地方遵守了，哪些地方偏离了。

这意味着第12课里的“结束”不是句号，而是第13课及后续复盘链路的入口。

## 12.6 把扩大、收缩、结束写成个人判断模板

### 12.6.1 一个最小可用模板

你可以用下面这套最小模板，把任意一份持仓研究转成自己的判断框架：

```text
当前状态：
- 当前结论是什么

支持继续保留的依据：
- 哪几条核心依据仍成立

限制继续强化的约束：
- 哪几条风险提示和不确定性仍在

下一步观察信号：
- 哪些 watch items 会改变判断

当前判断门槛：
- 什么情况下才评估扩大
- 什么情况下先收缩
- 什么情况下结束当前计划
```

### 12.6.2 模板的真正作用

这套模板不是为了让你写得漂亮，而是为了确保每次调整都能回答：

1. 为什么是现在。
2. 为什么不是更早或更晚。
3. 为什么是扩大、收缩或结束，而不是另一个动作。

只要这三件事能被清楚解释，动作就更可能来自纪律，而不是情绪。

## 12.7 第12课最常见的误区

### 12.7.1 把浮盈当成自动扩大理由

一笔持仓已经赚钱，只能说明价格高于成本，不能说明主逻辑已经得到更强验证。

### 12.7.2 等到完全证伪才愿意收缩

很多人愿意加不愿意减，理由是“逻辑还没完全坏”。但第12课要强调，收缩往往发生在完全证伪之前，是边界管理的一部分。

### 12.7.3 把结束计划当成承认失败

结束当前计划的目标，是保护纪律和资金表达，而不是证明自己从一开始就错了。

### 12.7.4 结束后不做复盘

如果一笔暴露结束后没有进入复盘，你就失去了把一次判断转成下一次能力提升的机会。

### 12.7.5 用旧式压缩字段代替真实阅读

如果你还在用“结论分数、目标位、风险等级表”直接替代报告正文，那么第11和第12课其实都还没真正落地。

## 12.8 本课小结与思考

### 本课要点回顾

1. 第12课讨论的不是动作快慢，而是扩大、收缩、结束三类判断分别需要跨过什么研究门槛。
2. 当前系统里最可靠的判断入口仍然来自持仓研究的当前结论、核心依据、风险提示、后续观察点和不确定性说明。
3. 扩大暴露的前提是证据变强，收缩暴露的前提是风险开始压过表达强度，结束计划的前提是原假设逐步被证伪。
4. 一旦结束计划，最重要的衔接对象是交易复盘，而不是立刻开启一套全新叙事。

### 思考题

1. 选一份你最近的持仓研究，只根据“核心依据、风险提示、后续观察点、不确定性说明”四块内容，判断它当前更接近“准备扩大、维持观察、准备收缩、结束计划”中的哪一种，并说明原因。
2. 按本课模板给一笔你最重视的持仓写一页判断卡，要求把“扩大门槛、收缩门槛、结束门槛”分别写成一句可验证的话。
3. 回顾一次你过去因为浮盈而继续加重、或因为不甘心而拖延结束的经历，重新判断当时到底是证据变了，还是情绪变了。
4. 如果一笔持仓今天真的结束，请用当前系统复盘结构中的“复盘结论、做得好的地方、暴露的问题、后续改进重点”先写一版最小复盘摘要，再考虑下一步要不要重新研究。

---

## 第五部分总结：持仓管理不是盯盘，而是持续判断“该保留、该收缩还是该结束”

学完第 11 课和第 12 课，这一部分真正要你带走的，不是几种持仓动作，而是三条管理底线：

1. 持仓管理的起点不是价格波动，而是当前结论、核心依据、风险提示、后续观察点和不确定性说明；
2. 扩大、收缩和结束不是情绪反应，而是不同研究门槛被触发后的判断结果；
3. 一笔持仓的每一次变化，最后都应该能接回后续跟踪和交易复盘，而不是停留在当下的感觉解释。

如果把第五部分压成一句话，就是：

**从这里开始，你管理的不是仓位本身，而是仓位背后的研究强度和边界变化。**

这也是进入风险管理篇前最重要的判断基础。
