## 🔑 阶段关键概念

- **AI 工作流架构师**（「分析流」→「流程管理」→「AI 智能创建」）:用自然语言描述需求,AI 生成工作流
- **Agent 工坊**（「分析流」→「Agent 工坊」）:自定义分析师角色
- **Skill 中心**（「分析流」→「Skill 中心」）:扩展平台能力的工具集
- **巴菲特工作流**:经典价值投资工作流案例

## ⚠️ 阶段限制

- ⚠️ **Agent 工坊**:高级功能,需要先有「分析流」→「流程管理」权限
- ⚠️ **Skill 中心**:部分 Skill 需要 API Key(数据源)
- ⚠️ **京东云版**:工作流生成和 Agent 创建受限,需平台开启
- ⚠️ **平台仅支持 A 股和 ETF**

- 创建 Skill 扩展平台
