## 📊 巴菲特工作流的"5 个核心"

### 核心 1:内在价值

- 巴菲特的核心: 找到**低于内在价值**的股票
- 内在价值 = 未来自由现金流折现
- 工具: DCF 模型

### 核心 2:护城河

- 巴菲特强调**持久竞争优势**
- 4 种护城河: 品牌 / 规模 / 网络效应 / 成本

### 核心 3:管理层

- 巴菲特看**管理层品质**
- 标准: 诚信 / 能力 / 股东导向

### 核心 4:安全边际

- **只在价格远低于价值**时买入
- 经验值: 价格 < 内在价值 × 80%

### 核心 5:长期持有

- 巴菲特: "我们最喜欢的持有期是**永远**"
- 关注**复利**而非短期波动

## 🖱️ 端到端操作

### 步骤 1:需求定义

写下"巴菲特工作流"的需求:

```markdown
## 巴菲特价值投资工作流

### 目标
找到符合巴菲特投资标准的 A 股,包括内在价值评估、护城河识别、管理层评估。

### 输入
- 股票代码(必填)
- 行业(可选,用于行业对比)

### 流程
1. **基础数据收集**: 财务数据(10 年)、行业数据、当前估值
2. **内在价值评估**: DCF 模型 + 简化估值
3. **护城河识别**: 4 种护城河评估
4. **管理层评估**: 从公开信息评估
5. **安全边际计算**: 当前价格 vs 内在价值
6. **最终建议**: 是否符合买入标准

### 输出
- 内在价值估算
- 护城河评分(0-5)
- 管理层评分(0-5)
- 安全边际(%)
- 是否建议买入(基于多维度)
```

### 步骤 2:用 AI 工作流架构师生成

1. 进入 `/workflow/architect`
2. 把上面的需求**完整粘贴**到输入框
3. AI 复述后,确认
4. AI 生成工作流(可能含 4-5 个节点)

### 步骤 3:检查生成的节点

AI 可能生成:

| 节点 | Agent | 作用 |
|------|-------|------|
| 1 | `fundamentals_analyst` | 财务数据收集 |
| 2 | `valuation_analyst` | 内在价值评估(可能用自定义) |
| 3 | `moat_analyst` | 护城河识别(自定义) |
| 4 | `management_analyst` | 管理层评估(自定义) |
| 5 | `decision_maker` | 最终建议 |

> 3 个节点(valuation / moat / management)是**自定义 Agent**,需要先创建。

### 步骤 4:创建 3 个自定义 Agent

#### Agent 1: 内在价值评估师

- **ID**: `intrinsic_value_analyst`
- **名称**: "内在价值评估师"
- **系统提示词**:

```
你是沃伦·巴菲特式的内在价值评估师。你的核心职责是用 DCF(折现现金流)模型估算股票内在价值。

你的分析方法:
1. 收集过去 5-10 年的自由现金流(FCF)
2. 估算未来 5-10 年的 FCF 增长率(基于行业平均 + 公司竞争优势)
3. 选择合理的折现率(无风险利率 3% + 风险溢价 5-8%)
4. 计算终值(永续增长率 2-3%)
5. 求和得到内在价值

你的输出格式:
- 内在价值估算(元/股)
- 假设的增长率(%)
- 假设的折现率(%)
- 计算过程(详细)

你的关注重点:
- 长期自由现金流稳定性
- 资本支出需求
- 资本回报率(ROIC)

禁止:
- 短期市场情绪判断
- 技术面分析
- 故事股(没有现金流支撑的)
```

#### Agent 2: 护城河分析师

- **ID**: `moat_analyst`
- **名称**: "护城河分析师"
- **系统提示词**:

```
你是巴菲特式的护城河分析师,评估公司的持久竞争优势。

4 种护城河类型:
1. 品牌护城河(品牌价值/定价权)
2. 规模护城河(规模经济/成本优势)
3. 网络效应护城河(用户越多价值越大)
4. 成本护城河(独特资源/地理优势)

你的评估方法:
- 看 ROE 是否持续 > 15%
- 看毛利率是否稳定/提升
- 看市场份额是否稳定/扩大
- 看用户粘性(留存率/复购率)
- 看竞争壁垒(技术/牌照/规模)

你的输出格式:
- 护城河评分(0-5,5 = 极强)
- 护城河类型(可多选)
- 关键证据
- 风险点

你的关注重点:
- 长期(不是短期)
- 实证(不是故事)
- 持续性(不是周期性)
```

#### Agent 3: 管理层评估师

- **ID**: `management_analyst`
- **名称**: "管理层评估师"
- **系统提示词**:

```
你是巴菲特式的管理层评估师,从公开信息评估公司管理层品质。

评估维度:
1. 诚信: 是否有财务造假、欺诈等历史
2. 能力: 长期 ROE / 业绩表现
3. 股东导向: 是否重视股东回报(分红/回购)
4. 资本配置: 是否把钱投到高回报业务
5. 透明度: 信息披露质量

你的评估方法:
- 读年报、季报的"管理层讨论"
- 看分红历史(连续性、增长性)
- 看高管变动是否频繁
- 看是否有重大失败/危机处理
- 看股东结构(是否有长期机构投资者)

你的输出格式:
- 管理层评分(0-5)
- 关键优点
- 关键担忧
- 综合判断

你的关注重点:
- 长期(不是短期业绩)
- 资本回报率(不是营收规模)
- 股东利益(不是高管薪酬)
```

### 步骤 5:在 Agent 工坊创建这 3 个 Agent

1. 进入 `/agents`
2. 依次创建上面 3 个 Agent
3. 每个都点"测试",看输出
4. 调整提示词直到满意

### 步骤 6:回到工作流架构师,接入 Agent

1. 进入 `/workflow/architect`
2. 找到刚生成的工作流
3. 在节点列表里**选择**你创建的 3 个 Agent
4. 保存

### 步骤 7:跑测试用例

1. 在工作流上点"测试"
2. 输入测试代码: 600519(贵州茅台)
3. 看报告,包括:
   - 内在价值估算
   - 护城河评分
   - 管理层评分
   - 安全边际
   - 是否建议买入

### 步骤 8:调优

- 不满意输出?
- 调整 Agent 的提示词
- 或调整工作流的连接

### 步骤 9:保存到工作流库

- 满意后,点"保存"
- 命名为"巴菲特价值投资工作流"
- 设置为 `stock_analysis` 类型
- 标记为 `is_default = false`(不覆盖默认工作流)

### 步骤 10:使用

- 进入 `/analysis/single`
- 在"分析流程"下拉里选"巴菲特价值投资工作流"
- 跑 600519 的分析
- 看报告

## 📊 巴菲特工作流的"5 个使用建议"

### 建议 1:不要只看"内在价值"

- 内在价值是**模型估算**,有误差
- 重点是**安全边际**(价格远低于价值)

### 建议 2:护城河要长期

- 短期看不准护城河
- 至少看 5-10 年数据

### 建议 3:管理层重要但不唯一

- 即使管理层好,价格贵也不买
- 即使管理层一般,价格极便宜也可考虑

### 建议 4:耐心

- 巴菲特工作流可能**等很久**才有符合标准的标的
- 找不到时,空仓等待

### 建议 5:结合大盘

- 大盘整体高估时,即使有符合标准的也谨慎
- 大盘整体低估时,可以更积极

## ❓ FAQ

**Q:内在价值估算不准确怎么办?**
A: 正常。DCF 是模型,不是事实。重点:
- **估值的范围**(± 30%)
- **安全边际**(价格 < 价值 × 80%)
- **不要精确到个位数**

**Q:护城河评分有主观性怎么办?**
A: 护城河是**定性**评估,本来就主观。关键是:
- 多人评估一致(机构投资者、卖方分析师)
- 长期数据支持
- **不要只看一年**

**Q:管理层评分找不到数据怎么办?**
A: 重点看**公开信息**:
- 年报"管理层讨论"
- 业绩说明会
- 股东结构(是否长期机构)
- 是否有重大负面新闻

**Q:工作流跑得慢,怎么办?**
A: 5 个节点串行,可能 5-10 分钟。可以:
- 减少节点数量
- 调整连接为并行
- 降低分析深度
