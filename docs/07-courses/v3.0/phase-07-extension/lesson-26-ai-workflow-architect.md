# 第 26 课:AI 工作流架构师——用自然语言生成工作流

> **课时**: 25 分钟 | **难度**: ⭐⭐⭐ 进阶 | **前置**: 阶段 1-4 全部

> ⚠️ **风险提示**:本课程内容仅为平台功能教学,AI 输出的研究报告不构成投资建议,最终决策由你自己负责。

## 🎯 学完后能做什么

- 进入 AI 工作流架构师（「分析流」→「流程管理」→ 点右上角「AI 智能创建」绿色按钮）
- 用**自然语言**描述需求,AI 生成工作流
- 调整 AI 生成的工作流
- 把工作流接入「通用研究」菜单使用

## 🎯 什么是工作流

**工作流**(Workflow)是一组**有序执行的 Agent 集合**,定义了"用什么分析师、按什么顺序分析"。

| 工作流类型 | 用途 |
|----------|------|
| **股票分析** | 单股 / 批量分析 |
| **通用分析** | 通用研究(行业/主题) |
| **自定义** | 你的特殊需求 |

## 📍 入口

- **侧边栏**: 「分析流」→「流程管理」→ 点右上角「AI 智能创建」绿色按钮

## 🖱️ 操作步骤

### 步骤 1:进入工作流架构师

1. 点侧边栏「分析流」→「流程管理」，再点右上角「AI 智能创建」绿色按钮
2. 看到**对话界面**:左侧是历史需求,右侧是对话输入框

### 步骤 2:用自然语言描述需求

在输入框里描述你的需求,比如:

| 你的需求 | AI 会怎么生成 |
|---------|------------|
| "我想做一个**巴菲特价值投资**工作流,先看基本面(ROE/PE/营收),再看管理层,最后给价值评估" | 生成包含 `fundamentals_analyst` + `management_analyst` + `valuation_analyst` 的工作流 |
| "做一个**短线强势股**工作流,先看技术面(MA/MACD/RSI),再看看板,最后给操作建议" | 生成包含 `market_analyst` + `momentum_analyst` + `trade_advisor` 的工作流 |
| "做一个**行业研究**工作流,先看行业景气,再看看龙头,最后给行业评级" | 生成行业研究专用工作流 |

### 步骤 3:AI 复述需求

AI 会先**复述**你的需求,确认理解:

> **AI**: "我理解你想做一个**巴菲特价值投资**工作流,包含:
> 1. 基本面分析(ROE / PE / 营收)
> 2. 管理层评估
> 3. 价值评估
> 是否继续?"

### 步骤 4:AI 生成工作流

确认后,AI 自动生成工作流配置,包括:
- **工作流名称** 和描述
- **节点列表**(每个 Agent 是什么角色)
- **执行顺序**(并行 / 串行)
- **输入参数**(需要哪些数据)
- **输出结构**(报告长什么样)

### 步骤 5:调整和编辑

AI 生成后,可以:
- **重新生成**:点"重新生成"按钮
- **手动调整**:进入工作流编辑页,改节点
- **测试运行**:点"测试"看效果

### 步骤 6:保存到工作流库

- 满意后点"保存"
- 工作流入库,可以在「通用研究」菜单或「单股研究」菜单选择使用

## 🧭 通用研究菜单:工作流的应用

建好"通用分析类工作流"后,就能在「通用研究」菜单用自然语言研究行业/主题(无需明确股票)。

### 入口

- 侧边栏「通用研究」菜单

### 操作要点

1. **选分析流程**: 在"分析流程"下拉里选一个通用分析类工作流(如"行业研究流程")
2. **填动态参数**: 系统根据工作流的输入参数配置,自动生成表单

#### 支持的 7 种字段类型

| 类型 | UI | 适用场景 |
|------|-----|---------|
| `string` | 单行文本 | 股票代码、行业名 |
| `textarea` | 多行文本 | 研究问题、主题描述 |
| `number` | 数字输入 | 估值范围、PE 阈值 |
| `boolean` | 开关 | 是否包含风险/情绪 |
| `date` | 日期选择 | 起止日期 |
| `select` | 下拉单选 | 行业、市场 |
| `multiselect` | 下拉多选 | 多选股票/行业 |

3. **提交分析**: 点"开始分析",完成后在"分析记录" Tab 看历史

### 典型用例

| 用例 | 流程 | 参数示例 |
|------|------|---------|
| 行业研究 | 行业研究流程 | 行业=`新能源`、时间=2025-2026、子行业多选 |
| 主题研究 | 主题研究流程 | 主题=`固态电池产业化`、公司范围 5-10 家 |

> 💡 **对比**:通用研究(工作流版)适合固化成固定模板反复用;想快速摸底一个行业,直接用 AI 助手问(第 7 课)更快。

## 🧩 工作流的"5 个核心组件"

### 组件 1:节点(Agents)

- 每个节点是**一个 Agent**
- Agent 类型: 通用分析师 / 自定义 Agent(第 27 课)

### 组件 2:连接(Edges)

- 节点之间的**执行关系**
- 类型: 串行(A → B) / 并行(A ∥ B) / 条件(A → B if X)

### 组件 3:输入参数

- 输入参数定义工作流接受哪些参数
- 7 种字段类型: string / textarea / number / boolean / date / select / multiselect

### 组件 4:输出结构

- 输出结构定义报告长什么样
- 字段: 摘要 / 要点 / 子报告 / 决策标签

### 组件 5:执行配置

- 引擎: v2(默认)
- 并发: 是 / 否
- 错误处理: 失败重试 / 跳过

## 🧠 自然语言描述的"4 个要素"

想生成**好工作流**,需求描述要包含:

### 1. 目标

"我想分析 X 类问题" — 明确用途

### 2. 步骤

"先做 A,再做 B,最后做 C" — 明确顺序

### 3. 角色

"用基本面分析师 / 技术面分析师" — 明确 Agent

### 4. 输出

"最终给一个价值评估 / 操作建议" — 明确产出

**示例**:
> "我想做一个**短线选股**工作流:**先**用技术面分析师(看 MA/MACD/RSI)过滤,**再**用题材分析师(看新闻/板块轮动)评估热度,**最后**用交易顾问给操作建议。**输出**包括:综合评分、风险评分、决策标签。"

## 🛠️ 实操作业

1. 进入 AI 工作流架构师（「分析流」→「流程管理」→ 点右上角「AI 智能创建」绿色按钮）
2. 描述需求: "做一个**巴菲特价值投资**工作流,先看基本面(ROE/PE/营收),再评估管理层(用自定义 Agent),最后给价值评估"
3. 看 AI 复述,确认理解
4. AI 生成后,看工作流配置(节点 / 连接 / 输入 / 输出)
5. 保存到工作流库
6. 进入「通用研究」菜单,看刚生成的工作流是否可选
7. 跑一次,看报告

**做完这次作业**,你就有了**第一个**自己造的工作流。

## ❓ FAQ

**Q:AI 生成的 Agent 不存在怎么办?**
A: 进入「分析流」→「Agent 工坊」,**先创建自定义 Agent**(第 27 课),然后回到工作流架构师重新生成。

**Q:工作流跑不起来,哪里错了?**
A: 检查:
- 节点是否都存在(在「分析流」→「Agent 工坊」里能看到)
- 连接是否合法(不能 A → B 同时 A → C 又 C → B,会成环)
- 输入参数是否完整
- 用"测试"按钮看具体错误

**Q:工作流和单股研究的区别?**
A:
- **单股研究**: 固定的 7 个 Agent(标准)
- **工作流**: 任意组合 + 自定义 Agent

**Q:可以复制别人的工作流吗?**
A: 默认**不共享**,每个用户独立。需要的话**手动复制配置**到自己的工作流。
