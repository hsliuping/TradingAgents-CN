# 第 26 课:AI 工作流架构师——用自然语言生成工作流

> **课时**: 25 分钟 | **难度**: ⭐⭐⭐ 进阶 | **前置**: 阶段 1-4 全部

## 🎯 学完后能做什么

- 进入 `/workflow/architect` AI 工作流架构师
- 用**自然语言**描述需求,AI 生成工作流
- 调整 AI 生成的工作流
- 把工作流接入 `/analysis/general` 使用

## 🎯 什么是工作流

**工作流**(Workflow)是一组**有序执行的 Agent 集合**,定义了"用什么分析师、按什么顺序分析"。

| 工作流类型 | workflow_type | 用途 |
|----------|---------------|------|
| **股票分析** | `stock_analysis` | 单股 / 批量分析 |
| **通用分析** | `general` | 通用研究(行业/主题) |
| **自定义** | `custom` | 你的特殊需求 |

## 📍 入口

- **侧边栏**: 工作流 → 架构师
- **直接访问**: `/workflow/architect`

## 🖱️ 操作步骤

### 步骤 1:进入工作流架构师

1. 侧边栏"工作流 → 架构师"
2. 看到**对话界面**:左侧是历史需求,右侧是对话输入框

### 步骤 2:用自然语言描述需求

在输入框里描述你的需求,比如:

| 你的需求 | AI 会怎么生成 |
|---------|------------|
| "我想做一个**巴菲特价值投资**工作流,先看基本面(ROE/PE/营收),再看管理层,最后给价值评估" | 生成包含 `fundamentals_analyst` + `management_analyst` + `valuation_analyst` 的工作流 |
| "做一个**短线强势股**工作流,先看技术面(MA/MACD/RSI),再看看板,最后给操作建议" | 生成包含 `market_analyst` + `momentum_analyst` + `trade_advisor` 的工作流 |
| "做一个**行业研究**工作流,先看行业景气,再看看龙头,最后给行业评级" | 生成行业研究专用工作流 |

### 步骤 3:AI 复述需求

AI 会先**复述**你的需求,确认理解:

> **AI**: "我理解你想做一个**巴菲特价值投资**工作流,包含:
> 1. 基本面分析(ROE / PE / 营收)
> 2. 管理层评估
> 3. 价值评估
> 是否继续?"

### 步骤 4:AI 生成工作流

确认后,AI 自动生成工作流配置,包括:
- **工作流名称** 和描述
- **节点列表**(每个 Agent 是什么角色)
- **执行顺序**(并行 / 串行)
- **输入参数**(`input_config.fields`)
- **输出结构**(`output_config`)

### 步骤 5:调整和编辑

AI 生成后,可以:
- **重新生成**:点"重新生成"按钮
- **手动调整**:进入工作流编辑页,改节点
- **测试运行**:点"测试"看效果

### 步骤 6:保存到工作流库

- 满意后点"保存"
- 工作流入库,可以在 `/analysis/general` 或 `/analysis/single` 选择使用

## 📊 工作流的"5 个核心组件"

### 组件 1:节点(Agents)

- 每个节点是**一个 Agent**
- Agent 类型: 通用分析师 / 自定义 Agent(第 27 课)

### 组件 2:连接(Edges)

- 节点之间的**执行关系**
- 类型: 串行(A → B) / 并行(A ∥ B) / 条件(A → B if X)

### 组件 3:输入参数

- `input_config.fields` 定义工作流接受哪些参数
- 7 种字段类型: string / textarea / number / boolean / date / select / multiselect

### 组件 4:输出结构

- `output_config` 定义报告长什么样
- 字段: summary / key_points / reports / decision

### 组件 5:执行配置

- 引擎: v2(默认)
- 并发: 是 / 否
- 错误处理: 失败重试 / 跳过

## 🧠 自然语言描述的"4 个要素"

想生成**好工作流**,需求描述要包含:

### 1. 目标

"我想分析 X 类问题" — 明确用途

### 2. 步骤

"先做 A,再做 B,最后做 C" — 明确顺序

### 3. 角色

"用基本面分析师 / 技术面分析师" — 明确 Agent

### 4. 输出

"最终给一个价值评估 / 操作建议" — 明确产出

**示例**:
> "我想做一个**短线选股**工作流:**先**用技术面分析师(看 MA/MACD/RSI)过滤,**再**用题材分析师(看新闻/板块轮动)评估热度,**最后**用交易顾问给操作建议。**输出**包括:评分、信心度、买入点、止损点。"

## 🛠️ 实操作业

1. 进入 `/workflow/architect`
2. 描述需求: "做一个**巴菲特价值投资**工作流,先看基本面(ROE/PE/营收),再评估管理层(用自定义 Agent),最后给价值评估"

## ❓ FAQ

**Q:AI 生成的 Agent 不存在怎么办?**
A: 进入 `/agents` Agent 工坊,**先创建自定义 Agent**(第 27 课),然后回到工作流架构师重新生成。

**Q:工作流跑不起来,哪里错了?**
A: 检查:
- 节点是否都存在(在 `/agents` 列表里能看到)
- 连接是否合法(不能 A → B 同时 A → C 又 C → B,会成环)
- 输入参数是否完整
- 用"测试"按钮看具体错误

**Q:工作流和单股研究的区别?**
A:
- **单股研究**: 固定的 7 个 Agent(标准)
- **工作流**: 任意组合 + 自定义 Agent

**Q:可以复制别人的工作流吗?**
A: 默认**不共享**,每个用户独立。需要的话**手动复制配置**到自己的工作流。
