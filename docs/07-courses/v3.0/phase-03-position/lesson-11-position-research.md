# 第 11 课:持仓研究——让 AI 监控你的持仓

> **课时**: 25 分钟 | **难度**: ⭐⭐ 进阶 | **前置**: 第 10 课(模拟交易) 或 已有真实持仓

## 🎯 学完后能做什么

- 理解 **4 个持仓专属 Agent**(持仓技术面 / 持仓基本面 / 持仓风险评估 / 持仓操作建议)
- 在 `/portfolio` 跑持仓研究
- 让 AI 帮你"盯盘"—— 持仓技术面、基本面、风险
- 形成**持仓监控体系**

## 🆚 单股研究 vs 持仓研究

| 维度 | 单股研究 | 持仓研究 |
|------|---------|---------|
| 入口 | `/analysis/single` | `/portfolio` (点持仓的"分析"按钮) |
| 标的 | 任意股票 | **你的持仓** |
| 分析师 | 通用分析师(7 个) | **持仓专属 Agent**(4 个) |
| 输出 | 12 个子报告(深度时) | 持仓监控报告(4 块) |
| 用途 | "这只股票怎么样" | "**我的这只**持仓怎么样" |

## 📍 入口

- **侧边栏**: 持仓 → 持仓
- **直接访问**: `/portfolio`
- **从持仓行**: 在持仓列表上点"**分析**"按钮,自动跳到持仓研究

## 🧠 4 个持仓专属 Agent

来源: [agent_configs 集合](file:///c:/TradingAgentsCN/app/services/agent_configs.py)

| 角色 | 作用 | 看什么 |
|------|------|--------|
| **持仓技术面分析师** | 技术面 | MA / MACD / RSI / BOLL(基于**持仓成本**计算盈亏位) |
| **持仓基本面分析师** | 基本面 | PE / PB / ROE / 营收 / 利润(基于**当前估值**) |
| **持仓风险评估师** | 风险 | 持仓集中度 / 行业风险 / 个股风险 |
| **持仓操作建议师** | 操作 | 加仓 / 减仓 / 持有 / 止损(给出**具体动作**) |

> 💡 **4 个 Agent 都是为"持仓"特别设计**——比通用单股研究**更聚焦"我的持仓"**,而不是"这只股票"。

## 🖱️ 操作步骤

### 步骤 1:进入持仓页

1. 侧边栏"持仓 → 持仓"
2. 默认在"**💰 用户持仓**" Tab(真实持仓)
3. 切换到"**📊 模拟持仓**" Tab 看模拟账户持仓

### 步骤 2:添加持仓(真实持仓)

如果还没有真实持仓:
- 点"**添加持仓**" 按钮
- 填写:股票代码 / 数量 / 成本价 / 买入日期
- 保存后出现在持仓列表

> **京东云版用户**:不能 QMT 同步,只能**手动添加**。

### 步骤 3:看持仓列表

持仓列表显示:

| 字段 | 含义 |
|------|------|
| 代码 / 名称 | 股票 |
| 数量 | 持仓股数 |
| 成本价 | 加权平均成本 |
| 现价 | 最新价 |
| **浮动盈亏** | (现价 - 成本) × 数量 |
| **盈亏比例** | 浮动盈亏 / 成本 |
| 持仓天数 | 持有时长 |
| 行业 | 所属行业 |

### 步骤 4:点击"分析"

在持仓列表右侧点"**分析**" 按钮:
- 跳到持仓研究页(类似单股研究,但用 4 个持仓 Agent)
- 自动开始 3 档标准分析
- 完成后显示 4 个持仓 Agent 的报告

### 步骤 5:读持仓研究报告

报告分 4 块:

#### 块 1:持仓技术面
- MA / MACD / RSI / BOLL **当前值**
- 关键位:**持仓成本** vs **现价** vs **目标价**(AI 给的)
- 关键位:**支撑位** / **阻力位**

#### 块 2:持仓基本面
- 当前 PE / PB / ROE
- **持仓以来**的估值变化(对比买入时)
- 行业对比(这只在行业里什么水平)

#### 块 3:持仓风险评估
- 个股风险: 单一持仓占比是否过大?
- 行业风险: 行业集中度
- **持仓成本** 风险: 现在距成本多少?
- **持仓时间** 风险: 持有多久了?

#### 块 4:持仓操作建议
- AI 给出**具体动作**:加仓 / 减仓 / 持有 / 止损
- 理由(基于前 3 块的分析)

### 步骤 6:跟进操作

- 如果 AI 建议"加仓" → 走第 12 课(加减仓决策)
- 如果 AI 建议"止损" → 走第 13 课(风险跟踪)
- 如果 AI 建议"持有" → 继续跟踪,等下个时间点再看

## 📊 持仓监控的"4 个数字"

跟踪持仓时,**每天看 4 个数字**,其他不用看:

| 数字 | 含义 | 看哪里 |
|------|------|--------|
| **现价** | 最新价 | `/portfolio` 持仓列表 |
| **浮动盈亏比例** | 赚/亏 % | 同上 |
| **持仓天数** | 持有时长 | 同上 |
| **距离止损位** | 离止损还差多少 % | 第 13 课配置止损后才有 |

> 💡 **少于 4 只持仓**:每周跑 1 次 4 个持仓 Agent 深度研究。
> **多于 10 只持仓**:每周跑 1 次持仓研究(核心 5 只深度,其他 1 档快速)。

## 🛠️ 实操作业

1. 进入 `/portfolio`
2. 选**一只你有持仓的 A 股**(真实或模拟)
3. 点"分析"按钮
4. 等 3-5 分钟,看 4 个 Agent 的报告
5. 重点看:
   - 持仓技术面: 你的成本价 vs 关键位
   - 持仓风险评估: 持仓集中度风险
   - 持仓操作建议: AI 给的具体动作
6. 复盘:**这个建议和你自己判断一致吗?**

**做完这次作业**,你就有了"AI 帮你盯盘"的能力。

## ❓ FAQ

**Q:持仓研究和单股研究能一起跑吗?**
A: 能。**持仓研究** 用 4 个持仓 Agent,**单股研究** 用通用 7 个 Agent(可选)。如果想要最全,两个都跑(但费 Token)。

**Q:持仓 Agent 报告存在哪?**
A: 和单股研究一样,在 `analysis_reports` 集合,只是 `analysts` 字段是持仓 Agent ID。

**Q:持仓页能"批量分析所有持仓"吗?**
A: 暂不支持。需要**逐个**点"分析"按钮。

**Q:持仓没有分析按钮?**
A: 检查:
- 是否在"用户持仓" Tab
- 持仓是否已添加(有代码、数量、成本价)
- 是否京东云版(可能按钮被隐藏)

**Q:AI 建议"加仓",我能直接加吗?**
A: 不能直接加。AI 建议是**研究参考**。见第 12 课"加减仓决策"。
