## 🎯 阶段目标

完成本阶段后,你能管理**真实持仓 + 模拟持仓**:
- 在 `模拟交易` 纸上谈兵练手
- 在 `持仓` 页面管理真仓
- 用 **持仓研究** 跑持仓监控(系统调用持仓专属 Agent)
- 在交易计划里配置**止盈止损规则**
- 沉淀"操作经验"

## 🔑 阶段关键概念

- **模拟交易**(侧边栏「模拟交易」菜单):纸上谈兵,无风险练手,**A 股账户**
- **真实持仓**(侧边栏「持仓研究」菜单):管理真仓,**用户持仓 Tab**
- **模拟持仓**(侧边栏「持仓研究」菜单里的"模拟持仓" Tab):从模拟交易同步过来
- **持仓研究**: 系统调用的持仓专属 Agent,输出"决策标签 + 风险评估"
- **止盈止损规则**(侧边栏「交易计划」菜单)里配置

## ⚠️ 阶段限制

- ⚠️ **京东云版单并发**,持仓管理可能受队列影响
- ⚠️ **平台仅支持 A 股和 ETF**
- ⚠️ **模拟交易和真实持仓是分开的**,需要在两个页面分别看

## 🎓 学完后能做什么

- 用模拟交易无风险练手
- 让 AI 帮你监控持仓
- 在交易计划里配置止盈止损规则
- 用 AI 助手汇总持仓异动
