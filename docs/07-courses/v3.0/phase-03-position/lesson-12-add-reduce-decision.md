# 第 12 课:加减仓决策——AI 建议加仓,该听吗?

> **课时**: 25 分钟 | **难度**: ⭐⭐⭐ 进阶 | **前置**: 第 11 课(持仓研究)

## 🎯 学完后能做什么

- 理解**"该不该加仓 / 减仓"** 的判断框架
- 综合 AI 建议 + 个人风险偏好做决策
- 制定**个人加仓/减仓规则**
- 避免**"听 AI 就动手"** 的错误

## ⚠️ 这课不教新功能,只教"决策框架"

第 11 课你已经会用持仓研究监控持仓了。系统会输出**决策标签 + 风险评估**:
- 决策标签: 乐观 / 审慎 / 中性 / 偏多 / 偏空 / 待验证
- 风险评估: 风险等级 + 风险评分 + 评估结论 + 核心风险

**问题是:听不听?**

这课讲**"怎么听"**。

## 📊 加减仓的 5 个判断维度

做加减仓决策时,**不要只看 AI 建议**。综合 5 个维度:

### 维度 1:AI 报告的可信度

> 💡 报告里**不直接显示"信心度"数字**,但你可以从以下 3 个地方判断 AI 把握度:

| 看哪里 | 含义 | 你的反应 |
|-------|------|---------|
| **风险评分** (0-1) | 数字越低,AI 越确信风险可控 | 0-0.3 较有把握;0.3-0.5 中等;0.5+ 谨慎 |
| **评估结论** 的论据 | 是否有"具体数据"支持,还是"空泛" | 列举了具体数字、对比 → 较有把握;只讲概念 → 较没把握 |
| **核心风险** 列表 | 风险点多少,是否致命 | 0-2 个 + 都是小风险 → 较有把握;多个或含致命风险 → 谨慎 |

**总结**:
- 多个维度都"较有把握" → 重要参考
- **任何一项**"风险高"或"论据空" → **不要基于这个加仓**

### 维度 2:决策标签的强度

> **注意**:持仓研究输出的是"决策标签"(乐观/审慎/中性/偏多/偏空/待验证),不是直接的"加仓/减仓"建议。这是 v3.0 的合规要求。

AI 输出"决策标签"是哪一个?

| 决策标签组合 | 含义 |
|-------|------|
| **乐观 + 偏多**(两个都乐观) | 强信号,可以考虑 |
| **乐观** 或 **偏多**(只有 1 个) | 中等信号,看其他维度 |
| **中性** 或 **待验证** | 弱信号,等等再说 |
| **审慎 / 偏空** | **不行动** |

> 💡 **重点关注"审慎/偏空"的声音**——为什么?是评估结论里说了什么?

### 维度 3:个人持仓规则

你的**个人交易系统**(`/trading-system`)里有没有相关规则?

比如:
- "单只持仓超过 20% 必须减仓"
- "跌破 60 日均线止损"
- "盈利超过 30% 减仓一半"

**如果有规则,优先按规则走**——AI 建议只是参考。

### 维度 4:市场环境

- **大盘环境**: 牛市 / 熊市 / 震荡
- **行业环境**: 行业整体向上 / 向下
- **资金面**: 你的现金够不够

例: AI 说加仓,但大盘已经在 5000 点高位,行业整体回调——**慎重**。

### 维度 5:你为什么想加仓?

- "AI 说了" → **慎**,被动决策
- "我对这只更了解了" → **可**,主动决策
- "我有更多现金了" → **可**,资金驱动
- "不想错过机会" → **危险**,FOMO 心态
- "已经跌了 30%,抄底" → **危险**,锚定效应

## 🧠 加仓决策树

```
决策标签是"乐观"或"偏多"
   │
   ├── 风险评分 > 0.5? ──── 是 ──> 暂缓
   │      │
   │      否
   │      ↓
   ├── 评估论据充实? ──── 否 ──> 暂缓
   │      │
   │      是
   │      ↓
   ├── 你的规则允许? ──── 否 ──> 暂缓
   │      │
   │      是
   │      ↓
   ├── 市场环境支持? ──── 否 ──> 暂缓
   │      │
   │      是
   │      ↓
   ├── 你的"为什么"是合理的?
   │      │
   │      ├── 主动 → 加仓
   │      └── 被动 → 暂缓
   │
   └─> 决策:加仓(分批!)
```

## 📊 减仓决策树

减仓的判断**比加仓简单**——赚钱/亏钱都要有纪律:

```
决策标签是"审慎"或"偏空"
   │
   ├── 已经盈利 > 30%? ──── 是 ──> 减仓 50%(锁定利润)
   │      │
   │      否
   │      ↓
   ├── 已经亏损 > 20%? ──── 是 ──> 止损(全部卖)
   │      │
   │      否
   │      ↓
   ├── 持仓 > 90 天无进展? ──> 是 ──> 减仓 50%(机会成本)
   │      │
   │      否
   │      ↓
   ├── 风险评分 > 0.5? ──── 是 ──> 减仓 30%
   │      │
   │      否
   │      ↓
   └─> 暂缓,继续观察
```

> 💡 **减仓一定要"提前定规则"**,不要等到了"亏 20%" 再决策——那时候已经晚了。

## 📋 个人加仓/减仓规则模板

把这份模板填好,保存到 `/trading-system` 或 `/memory`:

```markdown
# 我的加减仓规则

## 加仓规则
1. 单只持仓最大比例: __%
2. 加仓触发条件: 决策标签是"乐观/偏多" + 风险评分 < 0.5 + 评估论据充实
3. 加仓方式: 分 3 批,每批间隔 5 个交易日
4. 加仓上限: 单只最多加 2 次,总仓位不超过 __%

## 减仓规则
1. 盈利 > 30%: 减仓 50%
2. 亏损 > 15%: 减仓 30%(给一次机会)
3. 亏损 > 25%: 全部卖出
4. 持仓 > 90 天无进展: 减仓 50%
5. 决策标签是"审慎/偏空" + 风险评分 > 0.5: 减仓 30%

## 绝对不做的
- 不在亏损时"加仓摊薄成本"
- 不在盈利时"贪婪不止盈"
- 不在市场情绪最高时加仓
- 不在市场情绪最低时减仓
```

## ⚠️ 常见错误

### 错误 1:AI 建议加仓,马上满仓

- 一次性全仓加,错了满盘皆输
- **正确做法**: 分 3-5 批加,每批间隔几天

### 错误 2:亏了 30% 还在等"回本"

- "已经亏 30%,再等等" 是最常见的陷阱
- **正确做法**: 提前定好"亏损多少就止损"的规则

### 错误 3:赚了 50% 还在等"更多"

- "已经赚 50%,再涨到 100% 就卖" → 经常跌回去
- **正确做法**: 锁定部分利润(减仓 30%-50%)

### 错误 4:加仓只加"已经赚的"

- 好的加仓应该是加"基本面好但被低估的",**不是"已经涨了很多的"**
- **正确做法**: 加仓时,问自己"现在买入,如果不知道持仓成本,我会买吗?"

## ❓ FAQ

**Q:决策标签是"乐观" + 风险评分 0.2,是不是一定听?**
A: **不一定**。说明 AI 较有把握,但**不保证 100% 正确**。还是要看其他 4 个维度(评估论据、持仓规则、市场环境、你的动机)。

**Q:加仓一次加多少合适?**
A: 经验值:
- **试探仓**: 5% 总资金
- **标准加仓**: 10-15% 总资金
- **重仓**: 20%+ 总资金
建议**分 3 批**加,而不是一次加完。

**Q:亏损多少该止损?**
A: 经验值:
- **短线**: 5-8%
- **中线**: 10-15%
- **长线**: 20-25%
根据自己的风险承受能力定,**关键是"提前定好,严格执行"**。

**Q:AI 建议和我的判断相反,听谁的?**
A: 看谁更有依据。
- **AI 依据**: 数据 + 模型推理
- **你的依据**: 经验 + 直觉 + 资金情况
**两者结合**——AI 给"理性参考",你做"最终决策"。
