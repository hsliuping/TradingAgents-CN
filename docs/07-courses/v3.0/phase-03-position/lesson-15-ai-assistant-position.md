## 🖱️ 持仓阶段的 6 个常用 AI 提示词

### 提示词 1:汇总持仓情况

> "汇总一下我现在的持仓情况"

AI 会:
- 读取你的持仓列表
- 列出每只持仓的现价、浮动盈亏
- 标注盈亏较大的持仓

### 提示词 2:跑持仓研究

> "帮我跑 600519 的持仓研究,深度 3 级"

AI 会:
- 调持仓研究 API
- 启动持仓专属分析(决策标签 + 风险评估)
- 完成后**对话里**显示报告摘要

### 提示词 3:查看价格提醒

> "我设置了哪些收益关注和价格下限提醒?"

AI 会:
- 查看你设置的收益关注提醒(价格上限)
- 查看你设置的价格下限提醒
- 列出提醒清单

### 提示词 4:研究个股

> "帮我研究一下 300750 现在怎么样?"

AI 会:
- 调单股研究 API
- 跑 🎯 3级 - 标准分析
- 显示决策标签 + 风险评估(研究参考,非交易指令)

### 提示词 5:检查持仓风险

> "帮我看看 000858 持仓目前的风险?"

AI 会:
- 调持仓研究 API
- 跑 3 级持仓分析
- 显示决策标签 + 风险评估(研究参考,非交易指令)

### 提示词 6:行业分析

> "我的持仓集中在新能源,这个行业最近怎么样?"

AI 会:
- 调通用研究 API
- 跑行业分析工作流
- 显示**行业洞察** + 对持仓的影响

## 📊 实战工作流

### 每日盘后 5 分钟

不用打开任何页面,直接问 AI 助手:

> 1. "汇总一下我现在的持仓情况"
> 2. "查看我的收益关注和价格下限提醒"
> 3. "新能源板块今天怎么样?"
> 4. "帮我看看亏损较多的持仓"

5 分钟,搞定盘后跟踪。

### 每周复盘 30 分钟

> 1. "本周我做了什么操作?"
> 2. "本周持仓表现怎么样?"
> 3. "下周需要关注什么?"
> 4. "生成我的周报"

### 每月深度 2 小时

> 1. "本月所有交易汇总"
> 2. "本月哪些决策是对的,哪些是错的?"
> 3. "下月我的持仓策略"
> 4. "生成本月总结"

## ❓ FAQ

**Q:AI 助手汇总的数据准吗?**
A: AI 助手**直接读数据库**(「持仓研究」菜单、「模拟交易」菜单等),所以数据是**实时的**。

**Q:AI 助手能直接帮我交易吗?**
A: **不能**。v3.0 不开放 AI 自动交易(合规要求)。AI 只能**给研究参考**,交易需要你**手动**操作。

**Q:AI 助手回答慢怎么办?**
A: 复杂任务(跑分析)需要时间(几分钟)。如果只是想**查询状态**,使用右下方**使用问答助手**(更快)。

**Q:AI 助手的"持仓异动"和 Dashboard 的一样吗?**
A: Dashboard 显示**预设**指标(涨跌幅、成交量),AI 助手可以**自定义**汇总(比如"只看亏损超过 10% 的")。
