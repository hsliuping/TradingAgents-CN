## 🖱️ 持仓阶段的 6 个常用 AI 提示词

### 提示词 1:汇总今日持仓异动

> "汇总一下我今天的持仓异动"

AI 会:
- 读 `/portfolio` 数据
- 对比昨日收盘价
- 列出**每只持仓的涨跌幅**
- 标注**异常波动**(> ±3%)

### 提示词 2:跑持仓研究

> "帮我跑 600519 的持仓研究,深度 3 级"

AI 会:
- 调持仓研究 API
- 启动持仓专属分析(决策标签 + 风险评估)
- 完成后**对话里**显示报告摘要

### 提示词 3:检查止盈止损

> "我的持仓有没有触发止盈止损?"

AI 会:
- 读 `/portfolio` 持仓
- 对比配置的止盈止损位
- 列出**已触发的告警**

### 提示词 4:加仓建议

> "我想加仓 300750,AI 怎么建议?"

AI 会:
- 调单股研究 API
- 跑 🎯 3级 - 标准分析
- 显示决策标签 + 风险评估

### 提示词 5:减仓建议

> "我想减仓一半 000858,AI 怎么建议?"

AI 会:
- 调持仓研究 API
- 跑 3 档持仓分析
- 显示**操作建议** + 风险评估

### 提示词 6:行业分析

> "我的持仓集中在新能源,这个行业最近怎么样?"

AI 会:
- 调通用研究 API
- 跑行业分析工作流
- 显示**行业洞察** + 对持仓的影响

## 📊 实战工作流

### 每日盘后 5 分钟

不用打开任何页面,直接问 AI 助手:

> 1. "汇总今天我的持仓异动"
> 2. "我的持仓有没有触发止盈止损?"
> 3. "新能源板块今天怎么样?"
> 4. "我明天有什么需要操作的?"

5 分钟,搞定盘后跟踪。

### 每周复盘 30 分钟

> 1. "本周我做了什么操作?"
> 2. "本周持仓表现怎么样?"
> 3. "下周需要关注什么?"
> 4. "生成我的周报"

### 每月深度 2 小时

> 1. "本月所有交易汇总"
> 2. "本月哪些决策是对的,哪些是错的?"
> 3. "下月我的持仓策略"
> 4. "生成本月总结"

## 🛠️ 实操作业

1. 进入 `/assistant`
2. 新建会话"我的持仓助手"
3. 依次问:

## ❓ FAQ

**Q:AI 助手汇总的数据准吗?**
A: AI 助手**直接读数据库**(`/portfolio`、`/paper` 等),所以数据是**实时的**。

**Q:AI 助手能直接帮我交易吗?**
A: **不能**。v3.0 不开放 AI 自动交易(合规要求)。AI 只能**给建议**,交易需要你**手动**操作。

**Q:AI 助手回答慢怎么办?**
A: 复杂任务(跑分析)需要时间(几分钟)。如果只是想**查询状态**,使用右下方**使用问答助手**(更快)。

**Q:AI 助手的"持仓异动"和 Dashboard 的一样吗?**
A: Dashboard 显示**预设**指标(涨跌幅、成交量),AI 助手可以**自定义**汇总(比如"只看亏损超过 10% 的")。
