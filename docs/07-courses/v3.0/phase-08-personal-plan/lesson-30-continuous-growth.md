## 🧠 30 课的"3 个核心思想"

### 思想 1:AI 是工具,决策是你

- v3.0 系统所有功能**都是研究工具**
- AI 决策是**参考**,不是指令
- **最终决策** 是你自己
- 课程反复强调这一点

### 思想 2:纪律 > 聪明

- 大多数人亏钱不是"不够聪明"
- 是"没纪律"
- 提前定规则 + 严格执行
- 比"找好股票"更重要

### 思想 3:持续迭代

- 交易系统**不是一次定好的**
- 是**持续迭代**的
- 每月微调、季度中调、年度大调
- 复盘是核心

## 📊 v3.0 平台能力回顾

### 8 大核心能力

| 能力 | 功能说明 |
|------|---------|
| **股票筛选** | 用自然语言或条件组合，从 6000 只股票中筛出符合你标准的标的 |
| **批量分析** | 一次对最多 10 只股票分别执行 AI 研究，快速覆盖一批候选标的 |
| **单股研究** | 对单只股票按 1-5 级深度开展多情景研究，从快速概览到全面分析 |
| **通用研究** | 针对行业、主题等维度进行研究，理解一只股票所处的大环境 |
| **持仓管理** | 同时管理真实持仓与模拟持仓，集中查看盈亏与持仓动态 |
| **模拟交易** | 用模拟资金练手，验证自己的交易策略，不用承担真实风险 |
| **AI 助手** | 用自然语言对话完成查报告、查数据、管理分析任务 |
| **使用问答** | 页面右下角的浮窗，随时询问平台功能怎么用 |

### 8 大辅助能力

| 能力 | 功能说明 |
|------|---------|
| **关注分组** | 按主题或策略给关注的股票分组，分类跟踪更清晰 |
| **定时分析** | 设置好周期自动对股票执行研究，不用每次手动触发 |
| **渠道推送** | 把研究结果通过邮箱、飞书、钉钉自动送到你手上 |
| **AI 记忆** | 助手长期记住你们的对话与结论，跨会话延续上下文 |
| **复盘系统** | 记录每笔交易的操作与结果，结构化复盘沉淀经验 |
| **交易系统** | 把你的交易规则固化成系统，帮助纪律化执行 |
| **工作流架构** | 用自然语言描述生成自定义分析工作流，编排多个 AI 步骤 |
| **Agent 工坊** | 自定义 Agent 角色与 Skill 技能，打造专属分析师 |

## 📈 持续优化的"3 个周期"

### 周期 1:每日(15 分钟)

- 盘后:AI 助手汇总今日持仓异动
- 看触发告警
- 记录今天的操作

### 周期 2:每周(1 小时)

- 跑持仓研究(2-3 只核心持仓)
- 跑 1 次行业研究
- 用 AI 记忆沉淀本周要点,写周报
- 复盘本周操作

### 周期 3:每月(2-3 小时)

- 完整复盘(每笔交易)
- 标记案例(成功/失败)
- 更新规则
- 月度系统检查(第 19 课)

### 周期 4:每季(半天)

- 评估持仓基本面变化
- 大版本规则更新
- 季度总结
- 调整投资风格(如果需要)

## 🎓 推荐的"3 步成长路径"

### 第 1 步:用熟基础(1-3 个月)

- 学完阶段 1-4
- 重点用好 8 大核心能力
- 用模拟交易功能练手,形成初步的交易系统

### 第 2 步:找到风格(3-6 个月)

- 学完阶段 5/6
- 明确自己短线还是中长线
- 优化交易系统
- 在模拟账户跑出**正收益**

### 第 3 步:打造专属(6-12 个月)

- 学完阶段 7
- 创建自定义工作流
- 沉淀个人案例库
- 在真实账户用 v3.0 平台执行

## ⚠️ 最后 5 个提醒

### 提醒 1:v3.0 平台是工具

- 平台不会让你"自动赚钱"
- 平台让你"更系统地决策"
- 赚钱靠的是**纪律 + 持续优化**

### 提醒 2:不要"过度优化"

- 规则太多 = 难执行
- 5-10 条核心规则即可
- 简单 = 可执行

### 提醒 3:不要"用完就忘"

- 学完 30 课 ≠ 掌握
- 持续实践 + 复盘 = 真正掌握
- **1 年后**回看,你的理解会完全不同

### 提醒 4:不要"过度交易"

- 频繁交易 = 高手续费 + 容易情绪化
- 按规则,**不操作就是操作**
- 等待是投资的一部分

### 提醒 5:不要"梭哈"

- 永远不满仓单只股票
- 永远不满仓单行业
- 留有余地,**才能长期**

学完这 30 课,你有了**一套方法论**。但**真正属于你的交易系统**,需要你在**实战中沉淀**。
