> ⚠️ **风险提示**:本课程内容仅为平台功能教学,AI 输出的研究报告不构成投资建议,最终决策由你自己负责。

## 🎯 学完后能做什么

- 整合**学到的所有方法论**
- 写一份**完整的**个人交易计划
- 录入「交易计划」菜单（交易系统）
- 这是**你**的交易系统,不是"千人一面"

## 🧠 为什么要"自己的"交易计划?

课程教的是**通用方法论**,但每个人:

| 维度 | 差异 |
|------|------|
| 资金 | 1 万 / 10 万 / 100 万 |
| 风格 | 短线 / 中线 / 长线 |
| 性格 | 激进 / 平衡 / 保守 |
| 经验 | 新手 / 老手 |
| 时间 | 全职 / 兼职 |
| 风险偏好 | 大 / 中 / 小 |

**同一个规则,不同人执行效果不同**。需要**个性化**。

## ⚠️ 3 个常见错误

### 错误 1:复制别人的计划

- "看着别人的很厉害,我就用他的"
- **错**: 别人能执行不代表你能
- **正确**: 根据自己的资金/性格调整

### 错误 2:规则太复杂

- "我有 50 条规则"
- **错**: 复杂 = 难执行
- **正确**: 5-10 条核心规则即可

### 错误 3:不更新计划

- "我定好了就用一辈子"
- **错**: 市场在变,你也在变
- **正确**: 月度微调、季度中调、年度大调

## ❓ FAQ

**Q:计划填不完怎么办?**
A: 分批填,先填最重要的:
- 风格定位(必填)
- 选股标准(必填)
- 止盈止损(必填)
- 风险控制(必填)
其他可以慢慢加

**Q:计划里要不要写"长期目标"?**
A: **强烈建议写**。目标是**前进的方向**:
- 1 年目标: 收益 + 胜率
- 3 年目标: 系统成熟
- 5 年目标: 长期复利

**Q:计划多久改一次?**
A:
- **月度**: 微调
- **季度**: 中调
- **年度**: 大调
- **事件触发**: 重大损失/收益时
