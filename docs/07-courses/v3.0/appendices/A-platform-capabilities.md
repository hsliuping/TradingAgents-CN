## 📊 5 级分析深度

| 深度 | 名称 | 耗时 | 适用场景 |
|------|------|------|---------|
| 1 级 | ⚡ 快速分析 | 2-4 分钟/只 | 快速预筛、盘中快速判断 |
| 2 级 | 📈 基础分析 | 4-6 分钟/只 | 日常跟踪、定期更新 |
| 3 级 | 🎯 标准分析 | 6-10 分钟/只 | 常规研究(推荐) |
| 4 级 | 🔍 深度分析 | 10-15 分钟/只 | 重要决策前(含辩论) |
| 5 级 | 🏆 全面分析 | 15-25 分钟/只 | 最深度研究(全 Tab) |

> 💡 **辩论角色**(🐂 积极证据 / 🐻 谨慎证据 / 🔬 整合员)只在 **4 级和 5 级** 才会启动。

## ⚠️ 风险评估字段

| 字段名 | 含义 | 取值 |
|--------|------|------|
| **风险等级** | 风险程度 | 低 / 中 / 高 |
| **风险评分** | 风险量化 | 0-1 之间小数(越低越可控) |
| **评估结论** | 风险综合判断 | 长文本 |
| **核心风险** | 主要风险点 | 列表 |
| **风控建议** | 风险控制建议 | 长文本 |
| **投资调整建议** | 策略调整建议 | 长文本 |

## 🏷️ 决策标签(研究结论倾向)

| 标签 | 含义 | ⚠️ 注意 |
|------|------|---------|
| **乐观** | 系统看好,关注 | 不是"买入" |
| **审慎** | 系统谨慎,警惕 | 不是"卖出" |
| **中性** | 系统中性,无明确倾向 | 不是"持有" |
| **偏多** | 持仓方向偏多 | 持仓研究专属 |
| **偏空** | 持仓方向偏空 | 持仓研究专属 |
| **待验证** | 暂无明确方向 | 需进一步研究 |

> ⚠️ **重要**:决策标签是系统的研究结论倾向,**不是交易指令**。最终买卖决策由你自己判断。
