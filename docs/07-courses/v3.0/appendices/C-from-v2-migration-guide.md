# 附录 C:从 v2.x 课程迁移指引

> 给学过 v2.x(advanced/)课程的老学员,了解 v3.0 课程的不同。

## 🔄 核心变化

| 维度 | v2.x 课程(advanced/) | v3.0 课程(本目录) |
|------|------------------|----------------|
| **组织方式** | 按"功能模块"(选股/择时/执行/...) | 按"炒股生命周期"(发现/跟踪/持仓/复盘/扩展) |
| **课时** | 25 课 | 30 课(更细颗粒度) |
| **v3.0 平台能力** | ❌ 完全没提 | ✅ 完整覆盖(AI 助手/京东云/工作流/Agent) |
| **港美股内容** | ⚠️ 含已暂停功能 | ✅ 仅 A 股(已清理) |
| **平台扩展** | 1 课(巴菲特) | 3 课(AI 架构师 + Agent + Skill) |
| **合规术语** | ⚠️ 含"买卖/目标价"等 | ✅ 统一"乐观/审慎/中性" |
| **角色** | **保留作为历史** | **推荐学习** |

## ⚠️ v2.x → v3.0 术语变化

| v2.x 术语 | v3.0 术语 | 说明 |
|-----------|-----------|------|
| 买入/卖出/持有 | 乐观/审慎/中性 | 合规要求,不输出交易指令 |
| 目标价/止损价 | (不输出) | 合规要求,由用户自定 |
| 看涨/看跌 | 乐观/审慎 | 合规术语 |
| 多空辩论 | 多情景辩论 | 合规表述 |
| 信心度 0.X | 决策标签 + 风险评分 | 不再输出 confidence_score |
| 3 档深度 | 3 级 - 标准分析 | 统一术语 |
| 看涨研究员 | 积极证据研究员 | 合规术语 |

**Q:v2.x 课程会删除吗?**
A: 不会。v2.x 课程保留作为历史参考,不会删除。

**Q:学过 v2.x 还需要学 v3.0 吗?**
A: 建议学。v3.0 覆盖了平台新增能力(AI 助手、工作流、Agent 工坊),这些 v2.x 没有。

**Q:v3.0 课程比 v2.x 难吗?**
