# 附录 B:学习路径建议

> 不同背景的用户,怎么选课最省时间。

## 🆕 新学员(没学过 v2.x 课程)

**完整学完所有 30 课**,预计 10-12 小时。

### 推荐顺序

```
阶段 1(发现) → 阶段 2(跟踪) → 阶段 3(持仓) → 阶段 4(复盘)
                                                          ↓
                                              根据风格选阶段 5 或 6
                                                          ↓
                                              阶段 7(扩展) → 阶段 8(个人计划)
```

### 关键节点

- **学完阶段 1-4**:能完整使用平台 8 大核心能力
- **学完阶段 5 或 6**:明确自己短线还是中长线风格
- **学完阶段 7-8**:能自己造工作流,有个人交易计划

## ⏰ 时间不够?最小可行学习路径

如果只有 **2 小时**,学这 5 课:

1. **第 1 课**:股票筛选(15 分钟)— 怎么找股票
2. **第 3 课**:单股研究入门(30 分钟)— 怎么深度研究
3. **第 11 课**:持仓研究(20 分钟)— 怎么管持仓
4. **第 16 课**:操作复盘(20 分钟)— 怎么复盘
5. **第 29 课**:个人交易计划模板(30 分钟)— 怎么定规则

学完这 5 课,你能完成"找股→研究→持仓→复盘→定规则"的完整闭环。

---

## 🎓 学完 30 课后呢?

### 持续实践

- 每日用 AI 助手汇总持仓异动(15 分钟)
- 每周跑持仓研究 + 写周报(1 小时)
- 每月完整复盘 + 更新规则(2-3 小时)
- 每季评估 + 大版本规则更新(半天)

### 深入学习

- 读投资经典(巴菲特致股东信、《聪明的投资者》等)
- 在真实账户小资金实战
- 持续迭代交易计划

### 平台扩展

- 创建自定义工作流(第 26 课)
- 创建自定义 Agent(第 27 课)
- 端到端造一个巴菲特工作流(第 28 课)
