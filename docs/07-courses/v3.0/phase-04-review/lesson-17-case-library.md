# 第 17 课:案例库沉淀——把复盘标记成可复用资产

> **课时**: 20 分钟 | **难度**: ⭐⭐ 进阶 | **前置**: 第 16 课(操作复盘)

> ⚠️ **风险提示**:本课程内容仅为平台功能教学,AI 输出的研究报告不构成投资建议,最终决策由你自己负责。

## 🎯 学完后能做什么

- 把有价值的复盘「保存到案例库」
- 用**标签**给案例分类
- 在案例库里快速回看
- 遇到类似情况时,翻案例库找参考

## � 案例库 vs 复盘历史

| 维度 | 复盘历史 | 案例库 |
|------|---------|--------|
| 包含 | 所有复盘 | 你**手动保存**的精选复盘 |
| 数量 | 多(每笔都复盘) | 少(只留有价值的) |
| 用途 | 看自己历史 | **参考**类似情况 |
| 进入方式 | 复盘完自动入 | 手动「保存到案例库」 |

> 💡 **类比**:复盘历史是"日记",案例库是"教科书"。

## 📍 入口

- **侧边栏**: 「操作复盘」菜单 → 切到「案例库」Tab

## 🖱️ 操作步骤

### 步骤 1:进入案例库

1. 点侧边栏「操作复盘」菜单
2. 切到「**案例库**」Tab

### 步骤 2:把复盘保存为案例

在「复盘历史」或复盘详情里,点「**保存到案例库**」,弹出对话框:

- 上方显示股票代码(只读)
- **标签**:多选,也可以输入新标签后回车创建(可选)

打上合适的标签(如"成功案例""止损及时"),点「保存」。

> 保存为案例**不需要写长篇文字**——核心就是"这条复盘值得回看"。

### 步骤 3:管理案例库

案例库列表展示:股票代码、股票名称、实现盈亏、标签、创建时间。

每行可操作:

- **查看详情**:看完整复盘报告
- **移除**:从案例库移除(复盘记录本身还在「复盘历史」里,不会删)

## 🏷️ 用标签给案例分类

案例库靠「标签」区分类型。系统预置了常用标签,你也可以自己建:

| 预置标签 | 含义 |
|---------|------|
| 成功案例 / 失败案例 | 这笔交易结果好坏 |
| 止损及时 / 止盈过早 | 具体执行问题 |
| 追涨杀跌 / 逆势操作 | 常见错误行为 |
| 仓位管理 / 情绪化交易 | 暴露的问题类型 |
| 纪律性强 / 需要改进 | 综合评价 |

> 💡 **建议**:用"结果 + 问题"双标签,例如 `失败案例` + `追涨杀跌`,以后检索更精准。

## 🧠 案例库的应用:3 个时机

### 时机 1:面对新标的时

> "我之前买过类似的吗?" → 翻案例库

### 时机 2:面对熟悉情况时

> "我以前处理过这种情况吗?" → 翻案例库,按经验走

### 时机 3:定期总结时

> "最近哪些案例反复出现?" → 看标签分布,发现自己的老毛病

## 🛠️ 实操作业

1. 用第 16 课的方法,复盘 1 笔交易
2. 点「保存到案例库」
3. 打 2-3 个标签(结果 + 问题)
4. 切到「案例库」Tab,确认新案例已出现
5. 模拟:现在面对 1 只新股票,翻案例库,看有没有类似情况可参考

**做完这次作业**,你就有了一个**个人交易案例库**。

## ❓ FAQ

**Q:每笔复盘都存案例,会不会太多?**
A: 案例库要**精选**。只留有代表性的:
- 结果特别好或特别差的
- 暴露出新问题的
- 有明确学习价值的
总数控制在 20-30 条比较合适。

**Q:标签怎么设计?**
A: 建议用"结果 + 问题"双标签,例如:
- `成功案例` + `纪律性强`
- `失败案例` + `追涨杀跌`
这样以后能同时按"结果"和"问题"两个角度检索。

**Q:案例可以分享给其他用户吗?**
A: 默认不分享,每个用户独立。

**Q:从案例库移除了,复盘记录还在吗?**
A: 在。「移除」只是从案例库拿掉,复盘记录本身还在「复盘历史」里。
