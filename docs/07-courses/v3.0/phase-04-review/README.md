# 阶段 4:复盘——卖完了怎么回顾?

> **4 课** | **总课时**: 约 1.5 小时 | **难度**: ⭐⭐ 进阶

## 🎯 阶段目标

完成本阶段后,你能:
- **系统化**复盘每笔交易
- 把**经验**沉淀到案例库
- 把**复盘结果** 转化为下次的行动指南
- 持续优化**交易系统**

## 📍 阶段路线图

```
[阶段 3 输出: 持仓管理中]
   │
   │  第 16 课: 操作复盘(这笔交易做对了吗)
   ↓
每笔交易的复盘报告
   │
   │  第 17 课: 案例库沉淀(把经验变成可复用的资产)
   ↓
个人交易案例库
   │
   │  第 18 课: 复盘结果怎么指导下次交易
   ↓
"复盘 → 规则"转化
   │
   │  第 19 课: 持续优化(基于复盘迭代交易系统)
   ↓
[阶段 5/6:短线/中长线]
   或
[阶段 8:个人交易计划]
```

## 🔑 阶段关键概念

- **复盘** `/review`:操作复盘 + 模拟交易复盘(2 大数据源)
- **4 个 Tab**:可复盘持仓 / 历史持仓 / 复盘历史 / 案例库
- **案例库**:沉淀经验,变成可复用资产
- **交易系统迭代**:基于复盘优化 `/trading-system`

## ⚠️ 阶段限制

- ⚠️ 复盘需要**已平仓**的持仓(还没平仓的持仓在"可复盘持仓" Tab)
- ⚠️ 京东云版**模拟交易复盘和真实持仓复盘分开**
- ⚠️ 平台仅支持 A 股和 ETF

## 🎓 学完后能做什么

- 系统化复盘每笔交易
- 把经验沉淀为案例库
- 持续优化个人交易系统
