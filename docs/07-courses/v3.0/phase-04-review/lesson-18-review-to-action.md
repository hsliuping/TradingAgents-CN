# 第 18 课:复盘到行动——把经验变成交易计划规则

> **课时**: 20 分钟 | **难度**: ⭐⭐ 进阶 | **前置**: 第 16-17 课

> ⚠️ **风险提示**:本课程内容仅为平台功能教学,AI 输出的研究报告不构成投资建议,最终决策由你自己负责。

## 🎯 学完后能做什么

- 把复盘/案例中提炼出的经验,变成**具体规则**
- 把规则录入「交易计划」的**对应模块**
- 让规则"写下来、可执行",避免复盘完就忘

## 🆚 复盘 vs 行动

| 复盘 | 行动 |
|------|------|
| 回答"发生了什么" | 回答"下次怎么办" |
| 过去时 | 未来时 |
| 看报告 | **改规则** |

> 💡 **没行动的复盘 = 浪费时间**。复盘后**必须**有规则变化。

## 🧱 交易计划的 7 个规则模块

交易计划不是"一堆规则",而是按模块组织的。录入前先搞清该放哪个模块:

| 模块 | 放什么规则 |
|------|-----------|
| **选股规则** | 选什么、排除什么 |
| **择时规则** | 什么时候买/卖 |
| **仓位规则** | 单只、总仓位上限 |
| **持仓规则** | 加仓、减仓、换仓条件 |
| **风险管理规则** | 止盈、止损、时间止损、逻辑止损 |
| **复盘规则** | 复盘频率、检查清单 |
| **纪律规则** | 禁止事项、必做事项 |

## 🖱️ 操作步骤

### 步骤 1:从案例库提炼规则

回看第 17 课的案例,问自己:"这条经验,能不能变成一条**可执行的规则**?"

### 步骤 2:录入交易计划对应模块

1. 点侧边栏「交易计划」菜单,进入或新建交易计划
2. 按经验类型,填到对应模块:

| 经验 | 放进哪个模块 |
|------|-------------|
| "决策标签转'审慎'要减仓" | 持仓规则(减仓条件) |
| "亏损 15% 必须止损" | 风险管理规则(止损) |
| "单只不超 20% 仓位" | 仓位规则 |
| "政策风险期不加仓" | 纪律规则(禁止事项) |

### 步骤 3:规则落地执行

交易计划是把规则**写清楚**,然后**由你自己按规则执行**。

> ⚠️ 平台**不开通自动下单**。止盈止损的"价格自动监控 + 推送告警"目前也仍在规划中(第 13 课)。所以规则的落地方式是:写清楚 → 你自己执行 → 复盘验证。

## 📋 规则转化的 4 个步骤

### 步骤 1:把"经验"变成"原则"

❌ "亏钱时不能慌" (太抽象)
✅ "亏损 15% 必须止损,无论原因" (可执行)

### 步骤 2:把"原则"变成"条件"

❌ "AI 决策乐观时加仓" (模糊)
✅ "AI 决策'乐观' + 风险评分<0.5 + 持仓<20% 总资金 → 加仓 10%" (可执行)

### 步骤 3:把"条件"填进对应模块

把上面的条件录入「交易计划」:
- 加仓条件 → **持仓规则**
- 单只比例 → **仓位规则**
- 止盈止损 → **风险管理规则**

### 步骤 4:把"规则"变成"习惯"

- **每月**回看哪些规则被执行了
- **每季**根据实际效果调整规则
- **每年**大幅重构(配合第 19 课的版本管理)

## 📊 规则落地的 3 个层次

### 第 1 层:写下来(最低)

规则只**写进交易计划**,触发时**提醒自己**,手工执行。

例: "决策标签'审慎' + 风险评分 > 0.5,提醒自己减仓"

### 第 2 层:定期跟踪(中等)

用平台已有的能力配合规则:
- 定时分析 → 定期跑持仓研究
- 复盘 → 检查规则执行情况

> ⚠️ 注意:平台目前**不提供"价格/决策标签变化后自动推送告警"**。第 2 层是"用定时分析 + 复盘来跟踪",不是"自动告警"。

### 第 3 层:自动交易(最高,未开通)

- 触发时自动下单执行
- ⚠️ v3.0 **不开通自动交易**(合规要求),留待后续合规版本

## 📋 实际案例:把经验变成规则

### 案例 1:白酒股分批止盈

**经验**: "AI 决策从'乐观'变'审慎'时,该分批减仓"

**录入**:
- 进入「交易计划」→「持仓规则」→ 减仓条件
- 条件: 决策标签 = "审慎"
- 动作: 减仓 50%

### 案例 2:不补亏损仓

**经验**: "不在亏损时加仓摊薄成本"

**录入**:
- 进入「交易计划」→「持仓规则」→ 加仓条件
- 条件: 仅允许对浮动盈利的持仓加仓

### 案例 3:政策风险评估

**经验**: "政策风险出现立即评估"

**录入**:
- 进入「交易计划」→「纪律规则」→ 必做事项
- 规则: 重大政策出现后 24 小时内,跑 1 次行业研究 + 持仓研究

## ⚠️ v3.0 重要变化

- ✅ **交易计划 7 模块**:选股/择时/仓位/持仓/风险管理/复盘/纪律
- ✅ **复盘 → 案例 → 规则**闭环:复盘出经验 → 存案例 → 提炼成交易计划规则
- ⚠️ **不开通自动交易**(合规)
- ⚠️ **止盈止损自动推送告警仍在规划中**(第 13 课)

## 🛠️ 实操作业

1. 从案例库里挑 3 条最有价值的经验
2. 判断每条该放进交易计划的哪个模块
3. 点侧边栏「交易计划」,录入这 3 条规则
4. 确认每条都写成了"可执行的条件"(不是抽象原则)
5. 记下来:下个月复盘时,验证这些规则是否被执行

**做完这次作业**,你就有了**真正落地的交易计划规则**。

## ❓ FAQ

**Q:规则太多记不住怎么办?**
A: 不要靠"记",靠"写":
- 录入「交易计划」的对应模块
- 定期复盘时对照检查
- 让规则沉淀在系统里,而不是脑子里

**Q:规则互相矛盾怎么办?**
A: 按"优先级"排:
- 止损 > 止盈 > 加仓 > 减仓
- 风险管理 > 其他规则
- 纪律规则 > 灵活发挥

**Q:规则需要多久调整?**
A: 经验值:
- **月度**: 微调(数值微调)
- **季度**: 中调(增减规则)
- **年度**: 大调(重写系统,用第 19 课的版本管理)

**Q:规则没效果,继续用吗?**
A: 看复盘结果:
- 规则被正确执行、结果也 OK → 保留
- 规则被执行了但结果差 → 规则本身可能错了,调整
- 规则根本没被执行 → 是纪律问题,不是规则问题
