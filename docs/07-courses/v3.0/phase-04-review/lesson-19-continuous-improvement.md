## 🧠 交易计划的本质

交易计划不是"一组规则",而是**一整套闭环**:

```
选股(怎么找) → 跟踪(怎么跟) → 持仓(怎么管) → 复盘(怎么回顾)
   ↑                                                    ↓
   └────────────── 规则优化(基于复盘) ←─────────────────┘
```

**任何一环出问题,系统就出问题**。

## 🖱️ 交易计划的 8 个组件

### 组件 1:投资风格定位

- **短线**(1-7 天) / **中线**(1-3 月) / **长线**(半年+)
- **激进** / **平衡** / **保守**
- 持仓数量: 单只最大比例
- **这是所有其他规则的基础**

### 组件 2:选股标准

- 行业偏好(白名单 / 黑名单)
- 财务阈值(PE < 30 / ROE > 10%)
- 估值偏好(成长 / 价值 / 均衡)
- 流动性(成交额 > X 亿)

### 组件 3:加仓规则

- 何时加仓(技术 / 基本面 / 政策 / 资金)
- 加几次(分批?)
- 每次比例

### 组件 4:减仓规则

- 何时减仓(止盈 / 止损 / 调整持仓周期)
- 减多少(全部 / 一半 / 三分之一)

### 组件 5:止盈规则

- 目标位(价格 / 涨幅)
- 一次性 / 分批
- 是否锁定

### 组件 6:止损规则

- 止损位(价格 / 比例)
- 一次性 / 分批
- 例外情况

### 组件 7:风险控制

- 单只最大比例
- 行业最大比例
- 总仓位上下限
- 资金分散

### 组件 8:复盘流程

- 复盘频率(每日 / 每周 / 每月)
- 复盘模板
- 案例库更新规则

## 📊 系统的"3 个迭代周期"

### 每月:微调

- **看**: 这个月触发了哪些规则?有效果吗?
- **调**: 数值微调(止盈 25% → 28%)
- **不调**: 框架不变

**输出**: 「AI 记忆」菜单中的月度总结

### 每季:中调

- **看**: 这个季度胜率多少?盈亏比多少?
- **调**: 增减规则(加 1 条 / 删 1 条)
- **不调**: 投资风格不变

**输出**: 「交易计划」菜单中的季度更新

### 每年:大调

- **看**: 这一年整体的交易风格是否合适?
- **调**: 风格调整(短线 → 中线)、核心规则重写
- **可调**: 投资风格

**输出**: 「交易计划」菜单中的年度大版本

## ❓ FAQ

**Q:交易计划没效果,放弃还是坚持?**
A: 看是"系统问题"还是"执行问题":
- **系统问题**: 规则本身不合理(胜率 < 30%) → 调整
- **执行问题**: 规则好但没执行 → 强化执行

**Q:每年大调要全部重写吗?**
A: 不需要。**保留有效规则**,只调整**不合适的**。
经验: 每年调整 20-30% 即可,不要推翻重来。

**Q:系统迭代需要"灵感"吗?**
A: 不需要。**基于复盘数据**迭代,不要基于"突然想到"。

**Q:不同市场环境(牛/熊)需要不同系统吗?**
A: 可以有"市场判断"组件:
- **牛市**: 规则可以更激进(止盈 30% / 止损 8%)
- **熊市**: 规则保守(止盈 15% / 止损 5%)
- **震荡**: 规则平衡(止盈 20% / 止损 10%)
