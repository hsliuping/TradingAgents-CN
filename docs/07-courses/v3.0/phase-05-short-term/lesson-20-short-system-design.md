# 第 20 课:短线研究的平台工具链——短线关注什么,平台对应什么功能

> **课时**: 25 分钟 | **难度**: ⭐⭐ 进阶 | **前置**: 完成阶段 1-4

> ⚠️ **风险提示**:本课程内容仅为平台功能教学,AI 输出的研究报告不构成投资建议,最终决策由你自己负责。

## 🎯 学完后能做什么

- 知道短线研究者**每天在盯哪几件事**
- 把每一件「关注的事」对应到**平台的具体功能模块**
- 用 AI 助手一句话把这些功能串起来,形成自己的短线研究闭环

## 🧭 短线研究者每天在盯什么

短线和中长线最大的区别是**关注点不同**。短线研究者的注意力集中在 8 件事上:

| # | 关注点 | 想问的问题 |
|---|--------|-----------|
| 1 | 大盘环境 / 市场情绪 | 今天市场强不强?赚钱效应怎么样? |
| 2 | 板块轮动 / 板块强弱 | 钱在往哪个板块流?哪个板块强? |
| 3 | 主力资金动向 | 主力/大单资金在流入还是流出? |
| 4 | 北向资金(外资)动向 | 外资最近在买什么? |
| 5 | 龙头识别 / 竞争格局 | 这个板块谁是龙头? |
| 6 | 技术面 / 量价 | 走势、成交量、技术指标怎么样? |
| 7 | 题材催化 / 新闻事件 | 有什么政策、公告、事件在催化? |
| 8 | 同业估值 / 个股位置 | 这只股在它行业里排第几?贵不贵? |

> 这 8 件事,平台**每一件都有对应的功能模块**能帮你查。下面逐一对应。

## 🧰 核心干货:8 大关注点 ↔ 平台功能模块

| 关注点 | 平台功能模块 | 在 AI 助手怎么问 |
|--------|-------------|-----------------|
| 大盘环境 / 市场情绪 | 大盘概览 + 涨跌停统计 | "今天大盘怎么样?" |
| 板块轮动 / 板块强弱 | 板块行情 / 综合板块分析 | "XX 板块最近怎么样?" |
| 主力资金动向 | 板块资金流向 | "今天哪些板块资金净流入?" |
| 北向资金动向 | 北向资金分析 | "北向资金最近流向?" |
| 龙头识别 / 竞争格局 | 同行业 TOP 公司 / 板块成分股 | "XX 板块的龙头是谁?" |
| 技术面 / 量价 | 技术指标 + 行情数据 | "帮我看看 XX 的技术面" |
| 题材催化 / 新闻事件 | 联网搜索 + 个股新闻 | "搜一下 XX 最近的政策和新闻" |
| 同业估值 / 个股位置 | 同业对比 | "XX 在它行业里是什么位置?" |

下面把每一个关注点拆开讲:你为什么要盯它,平台用什么功能帮你盯。

## 🔍 关注点逐个拆解

### 1. 大盘环境 / 市场情绪

**为什么盯**:个股再强,大盘整体弱时也很难独善其身。先看环境,再谈个股。

**平台怎么帮你查**:
- 大盘概览:上证、深证、创业板、科创50 等主要指数行情
- 涨跌停统计:涨停家数、跌停家数、涨跌家数,判断市场赚钱效应

**一句话问 AI 助手**:
> "今天大盘怎么样?涨跌停家数多少?"

### 2. 板块轮动 / 板块强弱

**为什么盯**:短线热点几乎都在板块里轮动,板块强,里面的个股才容易有表现。

**平台怎么帮你查**:
- 板块行情:板块指数近期走势、涨跌幅、成交量、换手率
- 综合板块分析:板块表现 + 轮动信号 + 同业对比 + 资金流向打包看

**一句话问 AI 助手**:
> "新能源板块最近怎么样?"

### 3. 主力资金动向

**为什么盯**:主力/大单资金是短线最直接的「钱往哪去」信号。

**平台怎么帮你查**:
- 板块资金流向:各板块资金净流入/流出排名、主力资金动向

**一句话问 AI 助手**:
> "今天资金净流入最多的板块是哪些?"

### 4. 北向资金(外资)动向

**为什么盯**:外资(北向)的持续流入/流出,常被当作市场风向的参考。

**平台怎么帮你查**:
- 北向资金分析:沪深港通资金净流入/流出及趋势

**一句话问 AI 助手**:
> "北向资金最近在流入还是流出?"

### 5. 龙头识别 / 竞争格局

**为什么盯**:一个板块里,龙头通常最先动、弹性最大,先搞清楚「谁是龙头」。

**平台怎么帮你查**:
- 同行业 TOP 公司:按市值排序的行业龙头名单
- 板块成分股:板块内成分股列表 + 龙头股

**一句话问 AI 助手**:
> "固态电池板块的龙头股有哪些?"

### 6. 技术面 / 量价

**为什么盯**:短线决策高度依赖走势、成交量和技术指标(MACD/RSI/KDJ/BOLL)。

**平台怎么帮你查**:
- 技术指标:MACD、RSI、KDJ、BOLL 等
- 行情数据:K 线走势 + 成交量

**一句话问 AI 助手**:
> "帮我分析 300XXX 的技术面,看下 MACD 和成交量"

### 7. 题材催化 / 新闻事件

**为什么盯**:短线行情大多由政策、公告、事件驱动,催化在,热度才在。

**平台怎么帮你查**:
- 联网搜索:搜最新新闻、政策、公告
- 个股新闻:个股相关新闻和公告

**一句话问 AI 助手**:
> "固态电池最近有什么新政策或大事件?"

### 8. 同业估值 / 个股位置

**为什么盯**:知道这只股在行业里的市值排名、估值位置、换手率,才能判断「它是不是真的强」。

**平台怎么帮你查**:
- 同业对比:同业市值/PE/PB/ROE/涨跌幅排名,以及换手率

**一句话问 AI 助手**:
> "300XXX 在它这个行业里市值排第几?估值什么水平?"

## 🔗 把 8 件事串成一个闭环

单查一件事不叫研究,把 8 件事**串起来**才是一个短线研究闭环:

```
[第1步] 先看大盘环境        → 今天适合研究吗?
[第2步] 看板块轮动/资金流向 → 钱在哪个板块?
[第3步] 找龙头             → 这个板块里看谁?
[第4步] 看技术面 + 量价     → 走势和量能如何?
[第5步] 查题材催化          → 有没有政策/事件驱动?
[第6步] 看同业估值位置      → 它在行业里强不强?
[第7步] 输出决策倾向        → 单股研究给「乐观/审慎/中性」标签
[第8步] 设提醒持续跟踪      → 价格提醒 + 定时分析自动盯
```

前三步是「**看环境**」,中间三步是「**看个股**」,最后两步是「**下结论 + 持续跟踪**」。

## ⚠️ 一条铁律:平台给的是研究,不是买卖指令

查完这 8 件事,平台能给你的是:

- ✅ **研究报告 + 决策标签**(乐观 / 审慎 / 中性)
- ✅ **数据与事实**(板块涨跌、资金流向、技术指标、新闻)
- ❌ **不提供**目标价、止损止盈点位、买卖时机、收益预期

> 换句话说:平台帮你把「该看什么、怎么查、看完怎么跟踪」自动化,但**「买不买、卖不卖、买多少」永远是你自己的决定**。

## ⚠️ 常见错误

| 错误 | 为什么错 | 正确做法 |
|------|---------|---------|
| 只盯个股,不看大盘和板块 | 环境差时个股难独善其身 | 先看环境,再谈个股 |
| 把研究结论当买卖指令 | 决策标签只是研究倾向 | 结论 + 你自己的规则一起看 |
| 一次查完就不再跟踪 | 短线变化快,结论会过期 | 价格提醒 + 定时分析持续盯 |
| 每天都跑 5 级全面分析 | 浪费 Token、结果冗余 | 日常 1-2 级,重要时点再升深度 |

## 🛠️ 实操作业

选一个你最近关注的板块,按下面 8 件事,每件都用 AI 助手查一遍:

1. 问"今天大盘怎么样?"
2. 问"XX 板块最近怎么样?"
3. 问"今天资金净流入最多的板块有哪些?"
4. 问"XX 板块的龙头股有哪些?"
5. 挑 1 只龙头,问"帮我分析它的技术面"
6. 问"XX 板块最近有什么政策或大事件?"
7. 问"这只股在它行业里市值排第几?"
8. 跑 1 次单股研究(1 级),读一遍决策标签

**做完这次作业**,你就完整走过了一遍「8 件事」的短线研究,也摸清了平台对应的每一块功能。

## ❓ FAQ

**Q:这 8 件事都要查吗?**
A: 不必每次都全查。日常跟踪查 1-3 件(环境 + 板块 + 个股);重要决策前才把 8 件走一遍。

**Q:我不会记工具名,能直接用吗?**
A: 能。你只要用上面的**自然语言问 AI 助手**,它会自己判断调哪个工具,不需要你记工具名。

**Q:平台能告诉我"该买哪只"吗?**
A: 不能。平台给研究报告和决策标签,选股和买卖由你自己决定。

**Q:短线一定要天天盯盘吗?**
A: 不一定要手动盯。用定时分析 + 价格提醒 + 渠道推送,让系统帮你盯,你按提醒再看。
