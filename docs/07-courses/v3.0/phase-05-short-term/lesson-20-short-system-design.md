# 第 20 课:短线交易系统设计

> **课时**: 20 分钟 | **难度**: ⭐⭐ 进阶 | **前置**: 完成阶段 1-4

## 🎯 学完后能做什么

- 理解**短线 vs 中长线**的核心差异
- 设计**短线交易系统**
- 录入 `/trading-system`

## 🆚 短线 vs 中长线 关键差异

| 维度 | 短线 | 中长线 |
|------|------|--------|
| 持仓周期 | 1-7 天 | 1-6 个月 |
| 胜率要求 | > 60% | > 50% |
| 盈亏比 | 1.5-2:1 | 2-3:1 |
| 单笔风险 | < 2% 总资金 | < 5% 总资金 |
| 跟踪频率 | 每日多次 | 每周 1-2 次 |
| 核心依赖 | 技术面+情绪 | 基本面+估值 |
| 典型持有数 | 2-5 只 | 5-10 只 |

## 🖱️ 短线交易系统 8 组件

### 1. 投资风格

```
短线(1-7 天)
- 持仓数量: 2-5 只
- 单只最大: 20%
- 行业最大: 30%
```

### 2. 选股标准

```
技术面优先:
- 站上 5/10 日均线
- 成交量放大(> 5 日均量 1.5 倍)
- 题材热点 / 板块轮动
- 流通市值 50-500 亿(中小盘活跃)
- 排除 ST、停牌、刚上市(< 60 天)
```

### 3. 买入触发

```
触发条件(任一):
- 突破关键阻力位 + 放量
- 强势板块龙头首次回调
- 突发利好(政策、订单)
- 技术指标共振(MACD 金叉 + RSI 强势 + BOLL 上轨)
```

### 4. 仓位管理

```
单笔仓位:
- 试探仓: 30% 计划仓位
- 加仓: 浮盈 3% 加 30%
- 满仓: 浮盈 5% 满仓

分批: 1+2+2 = 试探 1 份 + 加 2 次
```

### 5. 止盈规则

```
目标位:
- 短线 1: +5%
- 短线 2: +8%
- 短线 3: +10% 以上看情况

分批止盈:
- +3% 减仓 30%
- +5% 减仓 30%
- +8% 清仓
```

### 6. 止损规则

```
严格止损:
- 跌破 5 日均线
- 亏损 3% 立即止损
- 突破失败(突破后 2 天内回跌破)
- 突发利空
```

### 7. 风险控制

```
- 单只最大 20%
- 行业最大 30%
- 连续 3 笔亏损 → 暂停 1 周
- 单日最大亏损 5% → 暂停当日
```

### 8. 复盘流程

```
每日盘后:
- 看每笔操作是否按规则
- 计算当日盈亏
- 更新关注列表

每周:
- 计算周胜率
- 提炼 1 条经验
- 更新案例库
```

## 📋 短线用户最常见的 4 个错误

### 错误 1:把短线做成中长线

- "买完一直拿着,亏了 30% 不止损" → **已经不是短线**
- 短线核心是**纪律**,不是"看好就拿"

### 错误 2:仓位过重

- 短线胜率 60%,盈亏比 2:1 → 数学上能赚钱
- 但如果仓位 50%,一次 5% 止损 = 总资金亏 2.5% → 还是亏

### 错误 3:看技术面但用中长线选股

- 短线选股要**活跃**(中小盘、热点、成交量)
- 用中长线"白马"做短线 = 不匹配

### 错误 4:没时间盯盘却做短线

- 短线**需要快速反应**(盘中机会、突发风险)
- 没时间 = 错过机会 + 错过止损

## ⚠️ v3.0 实战建议

### 京东云版短线用户

- **单只最大仓位**: 10-15%(单并发限制)
- **每天跑分析次数**: 控制在 5 次内
- **分析深度**: 1-2 档(快速/基础)
- **告警**: 必须用飞书/钉钉(实时)

### 短线常用工具组合

- **盘中**: 飞书/钉钉告警(实时)
- **盘后**: AI 助手汇总"今日持仓异动"
- **复盘**: `/review` 模拟交易复盘
- **案例库**: 标记"短线好操作" / "短线坏操作"

## 🛠️ 实操作业

1. 进入 `/trading-system`
2. 在"投资风格"组件选"短线"
3. 把 8 个组件(选股/加仓/减仓/止盈/止损/风险/复盘)**全部填好**

**做完这次作业**,你就有了一个**可执行的**短线系统。

## ❓ FAQ

**Q:短线胜率 60% 算高吗?**
A: 经验值:
- 50% 以下: 长期亏
- 50-60%: 不亏不赚
- 60-70%: 优秀(常见)
- 70%+: 极少(警惕"过拟合")

**Q:盈亏比 1.5:1 够吗?**
A: 数学上:
- 胜率 60% + 盈亏比 1.5:1 = 期望收益 +30%(非常优秀)
- 胜率 50% + 盈亏比 2:1 = 期望收益 +50%(理想)
- 胜率 60% + 盈亏比 2:1 = 期望收益 +80%

**Q:短线要看哪些技术指标?**
A: 核心 4 个:
- **MA**(均线): 5/10/20 日
- **MACD**: 金叉/死叉
- **RSI**: 超买(> 70)/超卖(< 30)
- **BOLL**: 上下轨
- **量能**: 成交量(> 5 日均量)
