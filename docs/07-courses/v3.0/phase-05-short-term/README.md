## 🔑 短线特点

- **持仓周期**: 1-7 天
- **跟踪频率**: 每日盘前+盘后
- **分析深度**: 1-2 档(快速/基础)
- **告警频率**: 实时(飞书/钉钉)
- **核心关注**: 技术面 + 资金面 + 短期催化
- **风险**: 单笔小(< 5% 总资金),胜率要高
- **典型收益**: 月度 5-10%(优秀 15%+)

## ⚠️ 阶段限制

- ⚠️ **京东云版单并发**,频繁跑分析会排队
- ⚠️ 短线要求**盯盘时间多**,不适合没空的人
- ⚠️ 平台仅支持 A 股和 ETF
