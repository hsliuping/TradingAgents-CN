## 🔑 短线研究的特点(平台视角)

- **持仓周期**: 1-7 天
- **跟踪频率**: 每日盘前 + 盘后
- **分析深度**: 1-2 级(快速/基础)
- **核心关注**: 板块轮动、资金流、短期催化
- **高频功能**: AI 助手板块数据、价格提醒、每日定时分析

## ⚠️ 阶段限制

- ⚠️ **京东云版单并发**: 建议深度 1-2 级、每天 ≤ 5 次分析
- ⚠️ 短线研究要**高频跟踪**,建议配置定时分析 + 渠道推送
- ⚠️ 平台仅支持 A 股和 ETF
- ⚠️ 平台**不提供**目标价、止损止盈点位、买卖时机、收益预期

## 🎓 学完后能做什么

- 用平台功能独立完成一次短线研究闭环
- 用定时分析 + 价格提醒持续跟踪短线标的
- 用操作复盘 AI 自动复盘短线操作
