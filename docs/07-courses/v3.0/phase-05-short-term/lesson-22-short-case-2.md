# 第 22 课:短线研究实战(下)--超跌反弹的跟踪与复盘

> **课时**: 25 分钟 | **难度**: ⭐⭐ 进阶 | **前置**: 第 21 课

> ⚠️ **风险提示**:本课程内容仅为平台功能教学,AI 输出的研究报告不构成投资建议,最终决策由你自己负责。

## 🎯 学完后能做什么

- 用**定时分析 + 价格提醒**持续跟踪超跌反弹标的
- 用**技术指标**判断反弹是否"成立"
- 用「操作复盘」做 **AI 自动复盘**(时机/仓位/情绪/归因)
- 把经验沉淀到**案例库**和**交易计划**

## � 接上节课

第 21 课你完成了:发现超跌板块 -> 验证超跌成立 -> 查清下跌原因 -> 验证反弹条件 -> 跑单股研究 -> 建立跟踪。

本课接着走:**跟踪反弹进度 -> 判断反弹是否成立 -> 复盘 -> 沉淀**。

## 🖱️ 第一步:跟踪--让系统自动盯

### 1. 定时分析每日自动跑

你在第 21 课建的「每日盘后」定时分析任务会自动跑超跌反弹关注分组,结果通过**渠道推送**(飞书/钉钉/邮件)发给你。

你每天只需**看结果**,不用手动重复提交。

### 2. 价格提醒触发

- **价格下限提醒**触发 -> 可能超跌判断有误,继续下跌中
- **收益关注提醒**触发 -> 反弹已到一定幅度,该看是否"成立"了

> 💡 提醒只是通知你"价格到了你关心的位置",怎么处理由你自己决定。

### 3. AI 助手查最新报告

随时追问:

> "300XXX 最新报告怎么说?决策标签有没有变化?"

AI 调**报告查询工具**,返回最新报告。重点关注**决策标签是否变化**:

- 持续「乐观」-> 研究判断未变
- 从「乐观」变「审慎」-> 可能出现新风险,仔细读报告

## 🖱️ 第二步:用技术指标判断反弹是否"成立"

反弹不是"涨了一天"就算成立。要用技术指标**持续验证**。

### 1. MACD 是否金叉

问 AI 助手:

> "300XXX 的 MACD 状态怎么样?有没有金叉?"

- MACD 柱状线从负转正(DIFF 上穿 DEA)-> **金叉**,多头动能出现
- MACD 柱状线持续为负 -> 反弹动能不足

### 2. 量能是否放大

追问:

> "最近成交量有没有放大?"

- 反弹时**成交量放大** -> 有资金参与,反弹可能有持续性
- 反弹时**成交量萎缩** -> 无人响应,可能是假反弹

### 3. 是否站稳关键位置

追问:

> "股价现在在什么位置?有没有站稳?"

- 股价站上**短期均线**(5 日 / 10 日)-> 短期趋势可能转好
- 股价仍在中长期均线下方 -> 只能算反弹,不是反转

### 4. RSI 是否回升

追问:

> "RSI 现在回到多少了?"

- RSI 从超卖区(< 30)回升到 40-50 -> 超卖状态在修复
- RSI 再次跌回 30 以下 -> 反弹可能已失败

### 反弹状态判断表

| 指标 | 反弹成立信号 | 反弹失败信号 |
|------|------------|------------|
| MACD | 金叉,柱状线转正 | 死叉,柱状线回负 |
| 量能 | 反弹放量 | 反弹缩量 |
| 均线 | 站稳 5 日/10 日均线 | 跌破均线 |
| RSI | 从超卖区回升 | 再次跌回超卖区 |
| 资金流向 | 净流入 | 再次大幅流出 |

> 💡 **至少 3 个指标指向"成立"**,反弹才比较有说服力。如果多数指向"失败",说明之前的超跌判断或反弹条件判断需要修正。

### 5. 判断反弹"成立"后

反弹成立不代表"该卖了"。它只说明你的**研究判断得到了验证**。接下来怎么处理,由你结合自己的规则决定。

### 6. 判断反弹"失败"后

反弹失败也不等于"该割了"。它说明你的**研究判断需要修正**:
- 重新查新闻,看是不是出现了新的利空
- 重新跑单股研究,看决策标签是否变化
- 在「操作复盘」里分析这次判断哪里出了问题(见第四步)

## 🖱️ 第三步:模拟交易练手(可选)

如果你还没用真金白银,可以先用「模拟交易」菜单练手:

- 用模拟资金记录你的操作
- 模拟持仓也能进「操作复盘」做 AI 复盘
- 把研究判断和实际结果对比,积累经验

## 🖱️ 第四步:操作复盘--AI 自动分析

不管反弹是"成立"还是"失败",这一步都要做。短线研究不复盘,等于白做。

### 1. 发起操作复盘

- 进「操作复盘」菜单
- 顶部选数据源:「持仓操作复盘」(真实) 或「模拟交易复盘」
- 找到这只股票,点「复盘」->「开始复盘」

### 2. 读 AI 复盘报告

AI 从 **4 个维度**自动分析(见第 16 课):

| 维度 | 这次复盘会分析什么 |
|------|------------------|
| **时机** | 超跌判断的时机对不对?是不是太早了?是不是太晚了? |
| **仓位** | 仓位管理是否合理?有没有一次性押太多? |
| **情绪** | 有没有因为"跌了很多"就情绪化?纪律执行如何? |
| **归因** | 如果判断对了,是能力还是运气?如果错了,错在哪一步? |

### 3. 重点看"归因"

对于超跌反弹研究,「归因」维度特别有价值:

- **判断对了**: 是技术指标分析到位?还是运气好碰上了催化?
- **判断错了**: 是超跌判断有误?还是下跌原因判断错了?还是反弹条件没看准?

> 复盘的目的是**找到可复制的经验**和**需要修正的错误**,不是给自己打分。

## 🖱️ 第五步:沉淀--把经验变成资产

### 1. 保存到案例库

把这次超跌反弹研究「保存到案例库」(第 17 课),记录:

- 研究判断(超跌确认 + 反弹条件)
- 实际结果(成立 / 失败)
- 关键经验(哪一步判断最准 / 最不准)

以后遇到类似超跌场景,可以**回看对比**。

### 2. 更新交易计划

根据复盘发现的问题,调整你自己的规则(第 13 课):

- 如果发现自己总是"太早判断超跌"-> 在交易计划里加一条「至少等 3 个指标确认」
- 如果发现自己忽略基本面 -> 加一条「必须先查清下跌原因」

> 交易计划里的规则是**你自己定的**,平台不替你推荐具体数字。

### 3. AI 记忆自动沉淀

你在 AI 助手里的对话和研究结论,会自动沉淀到「AI 记忆」(第 6 课)。下次研究同一只股票或同一板块时,AI 会自动引用之前的经验。

## 🔄 超跌反弹研究完整闭环

把第 21、22 课合起来,就是一个完整的短线研究闭环:

```
[第21课:发现与验证]
   │
   ├─ 1. 发现超跌板块(板块行情 + 板块 RSI)
   ├─ 2. 找超跌个股(板块成分股)
   ├─ 3. 验证超跌(RSI + KDJ + BOLL + 量能,≥3 确认)
   ├─ 4. 查超跌原因(联网搜索:错杀 vs 该跌)
   ├─ 5. 验证反弹条件(资金流 + 板块止跌 + 催化)
   ├─ 6. 跑单股研究(决策标签交叉验证)
   └─ 7. 建立跟踪(关注列表 + 价格提醒 + 定时分析)
         │
[第22课:跟踪与复盘]
   │
   ├─ 1. 定时分析自动跑 + 价格提醒触发
   ├─ 2. 判断反弹是否成立(MACD + 量能 + 均线 + RSI)
   ├─ 3. 模拟交易练手(可选)
   ├─ 4. 操作复盘(AI 4 维:时机/仓位/情绪/归因)
   └─ 5. 沉淀(案例库 + 交易计划 + AI 记忆)
```

## ⚠️ 本案例的合规边界

- 全程**没有**「买入 / 卖出 / 止损位 / 止盈位 / 收益预期」
- "反弹成立 / 失败"是**研究判断的验证**,不是买卖信号
- 技术指标变化是**客观市场状态**,不是操作指令
- 复盘结论用于**反思学习**,不构成投资建议
- 交易计划里的规则是**你自己定的**,不是平台推荐

## 🛠️ 实操作业

接第 21 课的作业,继续走完:

1. 确认「每日盘后」定时分析任务已启用,查收一次渠道推送结果
2. 等 1-2 个交易日,用 AI 助手问"300XXX 的 MACD / 量能 / 均线 / RSI 怎么样?",填反弹状态判断表
3. 判断反弹"成立"还是"失败"
4. 进「操作复盘」,对这只股票发起 AI 复盘,重点看「归因」维度
5. 把这次研究「保存到案例库」
6. 如果复盘发现问题,去「交易计划」更新你自己的规则

**做完这次作业**,你就走完了「跟踪 -> 判断 -> 复盘 -> 沉淀」的完整闭环。

## ❓ FAQ

**Q:反弹"成立"了,是不是该卖了?**
A: "成立"只说明你的研究判断得到了验证,不等于"该卖"。怎么处理,由你结合自己的规则决定。

**Q:反弹"失败"了,是不是该割了?**
A: "失败"说明研究判断需要修正。先重新查新闻、重跑单股研究,再决定怎么处理。复盘的目的是找原因,不是给你下一步的操作指令。

**Q:每次反弹都要走这么多步吗?**
A: 日常跟踪简化(看 MACD + 量能);判断"成立/失败"这个关键节点建议走完整 5 项。复盘一定要做,短线不复盘等于白做。

**Q:模拟交易复盘和真实持仓复盘有区别吗?**
A: AI 复盘的 4 个维度一样,但模拟交易没有真金白银的心理压力,「情绪」维度的参考价值有限。建议先模拟练手,再过渡到真实操作复盘。
