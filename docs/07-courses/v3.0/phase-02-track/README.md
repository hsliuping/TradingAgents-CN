# 阶段 2:跟踪——用 AI 助手持续跟进

> **4 课** | **总课时**: 约 2 小时 | **难度**: ⭐⭐ 进阶

## 🎯 阶段目标

完成本阶段后,你能**用 AI 助手**持续跟踪你选出的股票和行业:
- 用 **AI 助手**做行业/主题研究(联网搜索 + 板块数据)
- 用 **AI 助手**驱动"发现→研究→读报告→跟踪→沉淀"的完整闭环
- 用**定时分析 + 渠道推送**让系统自动跑、自动通知
- 掌握**跟踪节奏**,不浪费 Token、不漏关键信号

## 🔑 阶段关键概念(基于真实功能)

- **AI 智能助手**(侧边栏「智能助手」菜单):自然语言研究中枢,内置联网搜索、板块数据、触发分析、查报告、价格提醒等工具
- **主题树**:多会话并行研究,互不串台
- **AI 记忆**(侧边栏「AI 记忆」菜单):对象记忆 + 偏好纪律 + 事实记忆三层沉淀
- **定时分析**(「设置」→「个人设置」→「定时分析配置」):多时段、Cron、关注分组
- **渠道推送**(「设置」→「个人设置」→「渠道推送」):飞书/钉钉/邮件

## ⚠️ 阶段限制(基于实际代码)

- ⚠️ **通用研究菜单**(工作流驱动)属高级功能,在第 26 课讲;本阶段的行业研究用 AI 助手即可
- ⚠️ **京东云版定时分析可能受 API 限速影响**(并发=1)
- ⚠️ **渠道推送需先配置渠道**,否则只站内通知
- ⚠️ **平台仅支持 A 股和 ETF 基金**

## 🎓 学完后能做什么

完成本阶段后,你可以:
- 用自然语言**问 AI 各种研究问题**
- 用 AI 助手**做行业研究**(联网搜索 + 板块数据)
- 用 AI 助手**一句话触发分析、查报告、设提醒**
- 让系统**每天自动**分析关注列表,结果自动推送到飞书/钉钉/邮件
- 管理**多主题**研究 + 沉淀**对象记忆**
