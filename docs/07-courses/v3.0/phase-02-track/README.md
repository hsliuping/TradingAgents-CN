# 阶段 2:跟踪——选出来后怎么持续跟进?

> **4 课** | **总课时**: 约 1.5 小时 | **难度**: ⭐⭐ 进阶

## 🎯 阶段目标

完成本阶段后,你能**不手动**地持续跟踪你选出的 10-20 只股票:
- 用**通用研究**分析行业、主题
- 用**定时分析**让系统自动跑
- 用**渠道推送**让结果自动发到飞书/钉钉/邮件
- 用**AI 对话助手**做"非结构化问题"的研究

```

```

## 🔑 阶段关键概念(基于真实功能)

- **通用研究**(侧边栏「通用研究」菜单):基于"通用分析流程"工作流的灵活研究
- **定时分析**(侧边栏「设置」→「个人设置」→「定时分析配置」):支持多时段、Cron 表达式、关注分组
- **渠道推送**(侧边栏「设置」→「个人设置」→「渠道推送」):飞书/钉钉/邮件,3 种渠道,4 种事件
- **AI 对话助手**(侧边栏「智能助手」菜单):自然语言对话式研究
- **AI 记忆**(侧边栏「AI 记忆」菜单):多主题会话管理

## ⚠️ 阶段限制(基于实际代码)

- ⚠️ **京东云版定时分析可能受 API 限速影响**(并发=1)
- ⚠️ **渠道推送需要先配置 channel**(否则只会在站内通知)
- ⚠️ **AI 助手对话规划阶段会拒绝港美股关键词**(底层数据可用,但对话式提问暂不支持)
- ⚠️ **平台仅支持 A 股和 ETF 基金**

## 🎓 学完后能做什么

完成本阶段后,你可以:
- 让系统**每天自动**分析你的关注列表
- 分析结果**自动发到飞书/钉钉/邮件**
- 不用每天手动提单
- 用自然语言**问 AI 各种问题**
- 管理**多主题**研究(AI 记忆)
