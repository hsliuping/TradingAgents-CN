## 🎯 阶段目标

本阶段为**中长线风格**用户定制。学完后,你能:
- 用**平台功能**做中长线研究(发现 -> 验证 -> 跟踪 -> 复盘 -> 沉淀)
- 把中长线研究常用的**工具链**串起来
- 走一遍**价值股估值修复**和**成长股业绩跟踪**两种实战流程

> 注意:本阶段讲的是「怎么用平台做中长线研究」,不提供任何交易指令、收益预期或止盈止损点位。

## 🔑 中长线研究的特点(平台视角)

- **持仓周期**: 1-6 个月
- **跟踪频率**: 每周 1-2 次(财报季加频)
- **分析深度**: 3-4 级(标准/深度)
- **核心关注**: 基本面、估值、行业景气、财报业绩
- **高频功能**: 持仓研究、行业研究、每周定时分析

## ⚠️ 阶段限制

- ⚠️ **京东云版**: 中长线持仓周期长,单并发影响较小
- ⚠️ 中长线**要看基本面变化**,数据需要稳定同步
- ⚠️ 平台仅支持 A 股和 ETF
- ⚠️ 平台**不提供**目标价、止损止盈点位、买卖时机、收益预期

## 🎓 学完后能做什么

- 用平台功能独立完成一次中长线研究闭环
- 用持仓研究 + 每周定时分析持续跟踪中长线标的
- 用操作复盘 AI 自动复盘中长线操作
