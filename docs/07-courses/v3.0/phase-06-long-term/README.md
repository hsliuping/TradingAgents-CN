## 🔑 中长线特点

- **持仓周期**: 1-6 个月
- **跟踪频率**: 每周 1-2 次
- **分析深度**: 3-4 档(标准/深度)
- **告警频率**: 每日汇总(邮件)
- **核心关注**: 基本面+估值+行业
- **风险**: 单笔中等(< 10% 总资金)
- **典型收益**: 季度 5-15%(优秀 25%+)

## ⚠️ 阶段限制

- ⚠️ **京东云版**: 中长线持仓周期长,**单并发影响较小**
- ⚠️ 中长线**要看基本面变化**,数据需要稳定同步
- ⚠️ 平台仅支持 A 股和 ETF

## 🎓 学完后能做什么

- 设计自己的中长线系统
- 用 v3.0 平台做中长线实战
