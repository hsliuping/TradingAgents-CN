# 第 23 课:中长线投资系统设计

> **课时**: 20 分钟 | **难度**: ⭐⭐ 进阶 | **前置**: 完成阶段 1-4

> ⚠️ **风险提示**:本课程内容仅为平台功能教学,AI 输出的研究报告不构成投资建议,最终决策由你自己负责。

## 🎯 学完后能做什么

- 理解**中长线 vs 短线**的核心差异
- 设计**中长线交易系统**
- 录入 `/trading-system`

## 🆚 中长线 vs 短线的 5 个关键差异

| 维度 | 短线 | 中长线 |
|------|------|--------|
| 持仓周期 | 1-7 天 | 1-6 个月 |
| 决策基础 | 技术面+题材 | **基本面+估值** |
| 胜率要求 | > 60% | > 50% 即可 |
| 盈亏比要求 | 1.5-2:1 | **2-3:1** |
| 跟踪频率 | 每日多次 | 每周 1-2 次 |
| 核心痛苦 | 频繁决策 | **耐心** |

> 💡 **中长线核心**: 找到**好公司 + 合理价格 + 长期持有**。

## 🖱️ 中长线系统 8 组件

### 1. 投资风格

```
中长线(1-6 个月) / 长线(半年+)
- 持仓数量: 5-10 只
- 单只最大: 25%
- 行业最大: 40%
```

### 2. 选股标准

```
基本面优先:
- 行业: 景气行业(白名单)
- 市值: > 100 亿(中大盘)
- ROE: > 10%(过去 3 年平均)
- 营收增长: > 10%(年化)
- 利润增长: > 10%(年化)
- 负债率: < 60%
- 估值: PE < 行业平均 + 30%
```

### 3. 买入触发

```
基本面信号(任一):
- PE 处于历史 30% 分位以下
- 行业政策利好
- 业绩超预期
- 估值修复(从折价到合理)
- 技术面: 周线站上 20 周均线
```

### 4. 仓位管理

```
中长线不用频繁加减仓:
- 初始仓位: 50%
- 下跌 10% 加仓 30%
- 下跌 20% 加仓 20%
- 满仓后持有
```

### 5. 止盈规则

```
基本面变差 → 减仓:
- 业绩连续 2 季度下滑
- 行业景气度下行
- 估值偏高(> 行业平均 + 50%)

技术面变差 → 减仓:
- 周线跌破 60 周均线
- 月线 MACD 死叉

目标位:
- +30% 减仓 30%
- +50% 减仓 30%
- 剩余 40% 持有
```

### 6. 止损规则

```
深度止损:
- 亏损 20% 评估(基本面变了吗?)
- 基本面变 → 全部卖
- 基本面没变 → 持有(甚至加仓)

技术面止损:
- 月线跌破 60 月均线
- 长期趋势走坏
```

### 7. 风险控制

```
- 单只最大 25%
- 行业最大 40%
- 持仓时间最少 1 个月
- 季度最多换手 30%
```

### 8. 复盘流程

```
每周:
- 跑 1 次持仓研究(🎯 3级 - 标准分析)
- 跑 1 次行业研究(通用研究)
```
每月:
- 计算月胜率
- 提炼 1 条经验
- 更新案例库

每季:
- 评估持仓基本面变化
- 调整配置
```

## 🆚 中长线的"4 个核心痛苦"

### 痛苦 1:买了不涨

- 中长线经常"买了 3 个月不涨"
- 短线:换股
- 中长线:**持有,等基本面兑现**

### 痛苦 2:跌了不敢加

- "已经亏 20% 了,再加就 30% 了"
- 中长线:基本面没变,**应该加**

### 痛苦 3:赚了不跑

- "已经涨 30% 了,再等等到 50%"
- 中长线:**有纪律分批止盈**

### 痛苦 4:看到别人涨得猛

- 短线暴涨,自己的"慢股"不动
- 中长线:**坚持自己的节奏**

## ⚠️ v3.0 实战建议

### 京东云版中长线用户

- **单只最大仓位**: 25%(正常)
- **每周跑分析次数**: 2-3 次(持仓研究)
- **分析深度**: 3-4 级(标准/深度)
- **告警**: 邮件(每日汇总,不用实时)

### 中长线常用工具组合

- **每周**: 定时分析(周日晚上)批量跑持仓研究
- **每月**: AI 助手问"我这个月持仓表现怎么样?"
- **每季**: 通用研究(行业) + 持仓基本面重评
- **告警**: 月线跌破重要均线 → 飞书告警

## 📋 中长线 vs 短线 决策差异

| 场景 | 短线 | 中长线 |
|------|------|--------|
| 跌 5% | 立即止损 | 持有(基本面没变) |
| 涨 5% | 减仓 30% | 持有 |
| 行业利空 | 立即卖 | 评估(影响 1 个季度还是 1 年?) |
| 个股利空 | 立即卖 | 看具体(管理层问题 vs 一次性事件) |
| 大盘跌 | 减仓 | **可能加仓**(好公司更便宜了) |

## 🛠️ 实操作业

1. 进入 `/trading-system`
2. 在"投资风格"组件选"中长线"
3. 把 8 个组件全部填好
4. (实操)选 3-5 只**符合你选股标准**的 A 股
5. 加到关注列表
6. 每周跑 1 次 🎯 3级 - 标准分析(持仓研究)
7. 持有 1-3 个月,按规则加减仓
8. 完整复盘

**做完这次作业**,你就有了一个**可执行的**中长线系统。

## ❓ FAQ

**Q:中长线选股用 AI 决策靠谱吗?**
A: AI 决策是**研究参考**。中长线更重要的是**自己看财报、行业**:
- AI: 决策标签、风险评估
- 你: 基本面判断、行业理解

**Q:中长线持仓周期 1-6 个月,具体多长?**
A: 看"持有理由":
- **估值修复**: 3-6 个月
- **业绩增长**: 6-12 个月
- **行业景气**: 6-18 个月
- **价值回归**: 12-24 个月

**Q:中长线要不要止损?**
A: 看"基本面是否变":
- **没变**: 持有(甚至加仓)
- **变了**: 全部卖
中长线**不设硬止损**,设"基本面止损"。

**Q:中长线怎么看待大盘?**
A: 大盘是中长线的**背景**:
- 大盘跌: 好公司也跌 → 可能加仓
- 大盘涨: 持股不动
- 关键:**个股逻辑**比大盘重要
