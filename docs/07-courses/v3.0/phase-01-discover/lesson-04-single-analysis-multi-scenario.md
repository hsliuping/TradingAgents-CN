# 第 4 课:多角色辩论——怎么读懂 AI 的"积极证据 vs 谨慎证据"研究

> **课时**: 30 分钟 | **难度**: ⭐⭐⭐ 进阶 | **前置**: 第 3 课(单股研究入门)
>
> ⚠️ **风险提示**:本课程内容仅为平台功能教学,AI 输出的研究报告不构成投资建议,最终决策由你自己负责。

## 🎯 学完后能做什么

- 理解 v3.0 的 **2 角色辩论机制**(🐂 积极证据研究员 / 🐻 谨慎证据研究员)
- 读懂 4-5 级深度报告里的 **3 个辩论子报告 Tab** 是什么、怎么读
- 区分 3 种**风险视角**(⚡ 高弹性 / 🛡️ 防御 / ⚖️ 基准)
- 用"辩论"模式做**重要决策前的尽调**

## 📍 入口

- **第 3 课提交的分析任务** → 选 4 级或 5 级深度
- 完成后,报告会包含 3 个辩论子报告 Tab

## 🧠 辩论机制(用户实际看到的报告 Tab)

### 触发条件

只有 **4 级(深度)** 或 **5 级(全面)** 才会启动辩论,1-3 级没有。

### 角色分工(用户看到的 Tab 名)

报告里有 3 个辩论相关 Tab(来自 [ReportDetail.vue:286-312](file:///c:/TradingAgentsCN/frontend/src/views/Reports/ReportDetail.vue#L286-L312)):

| 用户看到的 Tab 名 | 后端 key | 立场 | 关注点 |
|------|----|------|--------|
| **🐂 积极证据研究员** | `bull_researcher` | 多头 | 寻找**支持上涨**的证据:增长、突破、利好、估值修复 |
| **🐻 谨慎证据研究员** | `bear_researcher` | 空头 | 寻找**支持下跌**的证据:风险、泡沫、坏消息、技术破位 |
| **🔬 研究整合员** | `research_manager` | 中性 | **综合两边**,出整合性结论 |

> 注意:报告**顶部**显示的 Agent 名是"乐观情景研究员/审慎情景研究员"(无图标),**Tab 上**显示的是"🐂 积极证据研究员/🐻 谨慎证据研究员"(有图标),**是同一个 Agent 的不同展示位置**。

### 辩论流程

1. **🐂 积极证据研究员**先出报告(找所有积极证据)
2. **🐻 谨慎证据研究员**看积极证据报告后,出反驳报告(找谨慎证据)
3. **🔬 研究整合员**看两份报告后,出"综合整合"结论
4. **风险辩论**(⚡ 高弹性 / 🛡️ 防御 / ⚖️ 基准)3 个情景分析
5. **👔 风险评估师**综合三方风险评估
6. **🧾 综合研究结论** 整合所有,出最终结论

> 💡 **这模拟了真实投资委员会**:多方观点碰撞,避免单点偏见。

## 🛡️ 3 风险视角(同样以 Tab 名显示)

辩论完之后,报告里出现 3 个**风险情景分析 Tab**:

| 用户看到的 Tab 名 | 后端 key | 风险偏好 | 关注点 |
|------|----|---------|--------|
| **⚡ 高弹性情景分析师** | `risky_analyst` | 进取 | **机会大于风险**,进取型视角 |
| **🛡️ 防御情景分析师** | `safe_analyst` | 保守 | **风险大于机会**,保守型视角 |
| **⚖️ 基准情景分析师** | `neutral_analyst` | 中性 | **风险机会平衡**,客观视角 |

最终 **👔 风险评估师**(`risk_management_decision`)综合三方风险评估,出 ⚠️ 风险审阅 Tab。

## 🖱️ 怎么读辩论报告

### 步骤 1:提交 4 级或 5 级分析

1. 进入 `/analysis/single`
2. 选 **4 级(深度)** 或 **5 级(全面)**
3. 分析师勾选时,根据场景选 2-4 个(剩下研究角色是工作流自动跑出来的)
4. 提交分析

### 步骤 2:看报告 Tab 顺序

报告完成后,在 `/reports/view/:id` 看完整 Tab 列表。**重点按这个顺序看**:

```
1. 📈 市场分析师 / 💰 基本面分析师        ← 客观数据
2. 🐂 积极证据研究员                      ← 多头观点
3. 🐻 谨慎证据研究员                      ← 空头观点
4. 🔬 研究整合员                          ← 综合
5. ⚡ 高弹性 / 🛡️ 防御 / ⚖️ 基准 风险三视角  ← 风险
6. 👔 风险评估师                          ← 风险综合
7. 🧾 综合研究结论                        ← 最终结论
```

### 步骤 3:识别"决策"的关键信号

读辩论报告时,关注**这些信号**:

| 信号 | 含义 |
|------|------|
| 🐂 报告**理由薄弱**(如只讲概念) | 多头信心不足 |
| 🐻 报告**理由薄弱** | 空头信心不足 |
| 两个研究员**结论分歧大** | 这只股票**有争议**,风险高 |
| 两个研究员**结论一致** | 共识强,可以参考 |
| 🔬 研究整合员**质疑多** | 系统在"避险",🧾 综合研究结论可能是"中性" |
| 3 个风险分析师**都偏保守** | 系统认为风险大于机会 |

## 📊 实战案例(基于真实报告样本)

**股票**: 宁德时代 300750
**分析日期**: 2026-01-24
**深度**: 5 级(全面)

### 🐂 积极证据研究员核心结论

> "新能源行业景气度持续,公司全球市占率提升,锂电池技术领先,2025 年 Q4 出货量超预期,营收与利润增速均高于行业平均。"

### 🐻 谨慎证据研究员核心结论

> "短期涨幅过快,RSI 进入超买区,行业竞争加剧(比亚迪刀片电池、固态电池冲击),估值已反映乐观预期,存在回调风险。"

### 🔬 研究整合员综合结论

> "两边都有道理,当前价位 347 元已部分反映乐观预期,短期可能震荡,中长期需看业绩兑现。建议关注 320-340 区间的支撑有效性。"

### 🧾 综合研究结论

- **决策标签**:**中性**(系统研究结论倾向,非交易指令)
- **🧾 综合研究结论** Tab 内容:综合期望收益+7.8%, 风险回撤-10.2%, RAROC 调整后+2.1%
- **⚠️ 风险审阅** Tab:
  - 风险等级:中等
  - 风险评分:0.42
  - 评估结论:核心矛盾是年报信息真空而非方向失衡

> **解读**:虽然积极谨慎两边都有依据,但**期望收益仅 +7.8%**,**风险回撤 -10.2%**——**风险大于收益**,所以决策标签为"中性"。
>
> ⚠️ **重要**:决策标签"乐观/审慎/中性"是系统的研究结论倾向,**不是交易指令**。"中性"不等于"持有"或"观望",最终买卖决策由你自己判断。

## ⚠️ v3.0 重要变化

- ✅ **2 角色辩论 + 1 整合员**(🐂 / 🐻 / 🔬)
- ✅ **3 风险视角**(⚡ / 🛡️ / ⚖️)
- ✅ 只有 **4-5 级深度** 才跑辩论
- ⚠️ 报告结构:详细研究报告里有 14 个 Tab(深度全跑时)
- ⚠️ 决策标签合规化(乐观 / 审慎 / 中性),不再有"目标价/止损价"等交易指令

## 🛠️ 实操作业

1. 选**一只你关注的股票**(还没深入研究过的)
2. 进入 `/analysis/single`,选**5 级 - 全面分析**
3. 分析师**全部勾选**(让所有分析师都跑)
4. 提交分析,等 15-25 分钟
5. 完成后按上面的"读辩论报告顺序",逐个看 14 个 Tab
6. 重点对比:
   - 🐂 积极证据研究员 和 🐻 谨慎证据研究员 的**核心结论差异**
   - 🔬 研究整合员 怎么"综合"
   - 3 个风险分析师(⚡ / 🛡️ / ⚖️)的**风险偏好倾向**
   - 🧾 综合研究结论 里的决策标签(乐观/审慎/中性)
7. 看完后,**用一句话总结**:系统对这只股票是"乐观/审慎/中性"?为什么?

**做完这次作业**,你就掌握了 v3.0 最深度的分析能力。

## ❓ FAQ

**Q:辩论机制会不会拖慢分析?**
A: 是的,4 级比 3 级慢 4-5 分钟,5 级比 4 级慢 5-10 分钟。但**重要决策前**值得多花这几分钟。

**Q:🐂 积极 和 🐻 谨慎 结论相反,我该信谁?**
A: **都信**。这正是辩论的价值——避免单点偏见。重点看 **🔬 研究整合员** 怎么综合,以及 **🧾 综合研究结论** 怎么拍板。

**Q:如果辩论最终决策标签是"乐观",是不是该买入?**
A: 不是。系统输出是**研究参考**,不是交易指令。决策标签"乐观/审慎/中性"只表达系统对这只股票的研究结论倾向,**不等于"买入/卖出/持有"**。要结合你自己的风险偏好、资金情况、市场环境 综合判断。

**Q:3 风险视角有什么用?**
A: 帮你理解"不同风险偏好的人会怎么看这只股票"。如果你是保守型,但所有风险分析师都进取,可能说明**这只股票风险确实较低**。

**Q:能不能只看辩论报告,不看技术面/基本面?**
A: 不建议。辩论是**基于基础数据的推演**,没有基础数据,辩论会"空对空"。

**Q:深度 4 级和 5 级辩论有什么区别?**
A: 4 级跑 3 角色辩论(🐂 / 🐻 / 🔬)+3 风险视角(⚡ / 🛡️ / ⚖️)。5 级会跑得更细,但**结论通常差异不大**。
