# 第 4 课:多角色辩论——怎么读懂 AI 的"看涨 vs 看跌"

> **课时**: 30 分钟 | **难度**: ⭐⭐⭐ 进阶 | **前置**: 第 3 课(单股研究入门)

## 🎯 学完后能做什么

- 理解 v3.0 的 **3 角色辩论机制**(看涨/看跌/中性)
- 读懂 4-5 档深度报告里的 **bull_researcher / bear_researcher / neutral_analyst** 3 个子报告
- 区分 3 种**风险视角**(激进/保守/中性)
- 用"辩论"模式做**重要决策前的尽调**

## ⚠️ 课程命名说明

v3.0 实际只有 **3 角色辩论**(看涨/看跌/中性),**不是 5 情景**。本文档基于真实代码撰写:

| 实际机制 | 旧课程错误描述 |
|---------|-------------|
| 3 角色辩论(看涨/看跌/中性) | 5 情景(乐观/基准/审慎/高弹性/防御) |
| 单点决策(`decision.action`) | 多情景价格区间 |

老课程中"乐观/基准/审慎/高弹性/防御"5 情景是**误传**,系统无此结构。

## 📍 入口

- **第 3 课提交的分析任务** → 选 4 档或 5 档深度
- 完成后,报告会包含 3 个辩论子报告

## 🧠 3 角色辩论机制

### 触发条件

只有**4 档(深度)**或**5 档(全面)** 才会启动辩论,1-3 档没有。

### 角色分工

| 角色 | ID | 立场 | 关注点 |
|------|----|------|--------|
| **看涨研究员** | `bull_researcher` | 多头 | 寻找**支持上涨**的证据:增长、突破、利好、估值修复 |
| **看跌研究员** | `bear_researcher` | 空头 | 寻找**支持下跌**的证据:风险、泡沫、坏消息、技术破位 |
| **中性风险分析师** | `neutral_analyst` | 中性 | **平衡视角**,质疑两边的极端论断 |

### 辩论流程

1. **看涨研究员**先出报告(找所有看涨证据)
2. **看跌研究员**看涨报告后,出反驳报告(找看跌证据)
3. **中性分析师**看两份报告后,出"拨乱反正"的中性视角
4. **研究经理**综合三方,出 `research_team_decision`
5. **风险经理**(激进/保守/中性)各自出风险评估
6. **最终决策** 综合所有,出 `final_trade_decision` 和 `decision.action`

> 💡 **这模拟了真实投资委员会**:多方观点碰撞,避免单点偏见。

## 🛡️ 3 风险视角

辩论完之后,**3 个风险分析师** 各自从不同风险偏好分析:

| 角色 | ID | 风险偏好 | 关注点 |
|------|----|---------|--------|
| **激进风险分析师** | `risky_analyst` | 激进 | **机会大于风险**,建议加大仓位 |
| **保守风险分析师** | `safe_analyst` | 保守 | **风险大于机会**,建议减仓或止损 |
| **中性风险分析师** | `neutral_analyst` | 中性 | **风险机会平衡**,建议持有 |

最终 **风险经理** (`risk_manager`) 综合三方风险评估,出 `risk_management_decision`。

## 🖱️ 怎么读辩论报告

### 步骤 1:提交 4 档或 5 档分析

1. 进入 `/analysis/single`
2. 选 **4 档(深度)** 或 **5 档(全面)**
3. 分析师勾选时**至少包含**:bull_researcher + bear_researcher + neutral_analyst + risky_analyst + safe_analyst + research_manager + risk_manager (7 个)
4. 提交分析

### 步骤 2:查看 12 个子报告

报告完成后,在 `/reports/view/:id` 看完整 12 个子报告。重点看以下顺序:

```
1. 看 market_report(市场分析师的技术面)        ← 客观数据
2. 看 fundamentals_report(基本面)              ← 客观数据
3. 看 bull_researcher(看涨)                    ← 一方观点
4. 看 bear_researcher(看跌)                    ← 另一方观点
5. 看 neutral_analyst(中性,看两边证据)         ← 综合
6. 看 research_team_decision(研究经理综合)     ← 决策
7. 看 risky/safe/neutral 风险三视角            ← 风险
8. 看 risk_management_decision(风险经理综合)   ← 风险决策
9. 看 final_trade_decision + decision 字段     ← 最终结论
```

### 步骤 3:识别"决策"的关键信号

读辩论报告时,关注**这些信号**:

| 信号 | 含义 |
|------|------|
| 看涨报告**理由薄弱**(如只讲概念) | 多头信心不足 |
| 看跌报告**理由薄弱** | 空头信心不足 |
| 两个研究员**结论分歧大** | 这只股票**有争议**,风险高 |
| 两个研究员**结论一致** | 共识强,可以参考 |
| 中性分析师**质疑多** | 系统在"避险",可能是 `decision.action = 中性` |
| 3 个风险分析师**都偏保守** | 系统认为风险大于机会 |

## 📊 实战案例(基于真实报告样本)

**股票**: 宁德时代 300750
**分析日期**: 2026-01-24
**深度**: 5 档(全面)

### 看涨报告(`bull_researcher`)核心结论

> "新能源行业景气度持续,公司全球市占率提升,锂电池技术领先,2025 年 Q4 出货量超预期,目标价可看至 ¥380。"

### 看跌报告(`bear_researcher`)核心结论

> "短期涨幅过快,RSI 进入超买区,行业竞争加剧(比亚迪刀片电池、固态电池冲击),估值已反映乐观预期,建议减仓。"

### 中性分析师(`neutral_analyst`)核心结论

> "两边都有道理,当前价位 347 元已部分反映乐观预期,建议在 320-340 区间分批建仓,而非追高。"

### 综合决策

- `decision.action`: **中性**(合规术语,意思是"持有/观望")
- `confidence_score`: **0.76**(信心度 76%)
- `target_price`: **375.0**
- `stop_loss`: **338.0**
- `risk_level`: **中等**
- `key_points` 第 1 条: "综合研究经理的中性评估(期望收益+7.8%, 风险回撤-10.2%, RAROC调整后+2.1%)"

> **解读**:虽然看涨看跌都有依据,但**期望收益仅 +7.8%**,**风险回撤 -10.2%**——**风险大于收益**,所以决策是"中性"(持有观望)。

## ⚠️ v3.0 重要变化

- ✅ **3 角色辩论机制**(不是 5 情景)
- ✅ **3 风险视角**(激进/保守/中性)
- ✅ 只有 **4-5 档深度** 才跑辩论
- ⚠️ 报告结构:`reports` 字典 12 个子报告(深度全)
- ⚠️ 决策术语合规化(`action` ∈ {乐观, 审慎, 中性})

## 🛠️ 实操作业

1. 选**一只你关注的股票**(还没深入研究过的)
2. 进入 `/analysis/single`,选**5 档(全面)**
3. 分析师**全部勾选**(让所有 Agent 都跑)
4. 提交分析,等 8-16 分钟
5. 完成后按上面的"读辩论报告顺序",逐个看 12 个子报告
6. 重点对比:
   - bull_researcher 和 bear_researcher 的**核心结论差异**
   - neutral_analyst 怎么"拨乱反正"
   - 3 个风险分析师的**风险偏好倾向**
7. 看完后,**用一句话总结**:系统对这只股票是"乐观/审慎/中性"?为什么?

**做完这次作业**,你就掌握了 v3.0 最深度的分析能力。

## ❓ FAQ

**Q:辩论机制会不会拖慢分析?**
A: 是的,4 档比 3 档慢 2-3 分钟,5 档比 4 档慢 4-5 分钟。但**重要决策前**值得多花这几分钟。

**Q:看涨看跌结论相反,我该信谁?**
A: **都信**。这正是辩论的价值——避免单点偏见。重点看**中性分析师**怎么综合,以及**研究经理**怎么拍板。

**Q:如果 3 角色辩论最终决策是"乐观",是不是该买入?**
A: 不是。系统输出是**研究参考**,不是交易指令。要结合你自己的风险偏好、资金情况、市场环境 综合判断。

**Q:3 风险视角有什么用?**
A: 帮你理解"不同风险偏好的人会怎么看这只股票"。如果你是保守型,但所有风险分析师都激进,可能说明**这只股票风险确实较低**。

**Q:能不能只看辩论报告,不看技术面/基本面?**
A: 不建议。辩论是**基于基础数据的推演**,没有基础数据,辩论会"空对空"。

**Q:深度 4 档和 5 档辩论有什么区别?**
A: 4 档跑 3 角色辩论+3 风险视角(共 6 个辩论 Agent)。5 档会跑得更细,但**结论通常差异不大**。
